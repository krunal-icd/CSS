1. Themed Buttons with currentColor

Buttons that automatically style borders based on their color. Change just the color property, everything else updates automatically.

CSS
.btn { border: 2px solid currentColor; background: transparent; color: #667eea; transition: all 0.3s ease; } .btn:hover { background: currentColor; color: white; } .btn-success { color: #28a745; } .btn-danger { color: #dc3545; }

Key Takeaways

  • DRY Principle: Specify color once, use it everywhere via currentColor
  • Flexible Components: Create theme variants without duplicating CSS
  • Icon Synchronization: Icons always match text color automatically
  • Interactive Elements: Borders, shadows, and effects all use one color source
  • Maintenance: Change color in one place, everything updates
  • Accessibility: Focus states can inherit the element's color scheme
  • Performance: Less CSS code = smaller file sizes
  • Consistency: Ensures design cohesion across all variations
