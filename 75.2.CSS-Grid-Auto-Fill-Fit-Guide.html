Decision Quick Reference

Use auto-fill when:

  • Items should maintain consistent size
  • Empty columns/space on the right is acceptable
  • E-commerce grids (consistent product sizing)
  • Icon or thumbnail galleries
  • You want predictable, structured layouts

Use auto-fit when:

  • Items should stretch to fill available space
  • Number of items is variable (2-20 items)
  • Content-driven layouts (blogs, articles)
  • Responsive grids that adapt to content
  • You want maximum use of available space

The Magic Formula:

  • Most responsive: repeat(auto-fit, minmax(250px, 1fr))
  • Most predictable: repeat(auto-fill, minmax(250px, 250px))
  • Balanced: repeat(auto-fill, minmax(250px, 1fr)) with large item count
