CSS User-Select Property

12 Practical Interactive Examples

1. User-Select: Auto

Default behavior

user-select: auto
Default browser behavior. Text is selectable normally. Most common for article content.
Try selecting this text - it works normally!
user-select: auto;
✓ Normal text selection enabled

2. User-Select: None

Not selectable

user-select: none
Text cannot be selected. Perfect for buttons and UI elements where selection is unwanted.
Try selecting this text - it WON'T work! (user-select: none)
user-select: none;
⚠️ Text selection prevented

3. User-Select: Text

Explicitly selectable

user-select: text
Explicitly enables selection, even if parent container prevents it. Override for important content.
This text IS selectable - explicitly set even in restricted containers!
user-select: text;
✓ Selection explicitly enabled

4. User-Select: All

Select all on click

user-select: all
Click anywhere and entire text is selected at once. Great for code snippets and contact info.
👉 Click me to select ALL text at once!
user-select: all;
⭐ One-click select all

5. User-Select: Contain

Selection contained

user-select: contain
Selection is restricted within this element. Cannot extend beyond boundaries. Good for tables.
Try selecting - it stays within this box!
user-select: contain;
✓ Selection restricted to element

6. Button (No Selection)

Interactive control

user-select: none
Buttons shouldn't have selectable text. Try clicking or dragging - no text highlighting.
button { user-select: none; }
✓ Professional button behavior

7. Navigation Menu

Menu links

user-select: none
Navigation menu items shouldn't be selectable. Prevents accidental selection when clicking.
Home About Services Contact
nav a { user-select: none; }
✓ Polished navigation

8. Code Block

Copyable code

user-select: all
Code is selectable with one click. Perfect for developers who want to copy code easily.
const hello = "world"; console.log(hello);
code, pre { user-select: all; }
⭐ Developer-friendly

9. Email/Phone

Copyable contact

user-select: all
Contact information with one-click selection. Users can easily copy email or phone number.
📧 hello@example.com
.email, .phone { user-select: all; }
✓ Easy one-click copy

10. Card (Mixed Selection)

Selective content

Combination: none + text
Card title not selectable, but content text is. Demonstrates selective override.

Card Title

This paragraph IS selectable. You can copy this content but not the title.

.card { user-select: none; } .card p { user-select: text; }
✓ Selective control

11. Icon with Label

Clickable item

user-select: none
Icon and label together without text selection. Great for list items and clickable elements.
⭐
Favorite Item
.icon-text { user-select: none; }
✓ Clean interactive element

12. Override Disabled

Selective enable

Override: user-select: text
Parent prevents selection, but specific child content IS selectable. Shows selective override.

This text is NOT selectable (parent restriction)

But THIS text IS selectable (overridden)

And this is NOT selectable again

.parent { user-select: none; } .parent .selectable { user-select: text; }
✓ Flexible control

Quick Reference Guide

user-select: auto - Default browser behavior
user-select: none - Prevent selection (buttons, menus)
user-select: text - Enable selection explicitly
user-select: all - Select all on click (code, contact)
user-select: contain - Selection confined to element

✓ Use none for UI elements and buttons
✓ Use all for copyable content (code, contact)
✓ Use text to override parent restrictions
✓ Use contain for tables and nested elements
✓ Include vendor prefixes for older browser support
