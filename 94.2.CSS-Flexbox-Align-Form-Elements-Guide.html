CSS Flexbox - Align Form Elements

Practical Real-World Form Examples

1. Basic Horizontal Form

Classic form layout with labels on the left and inputs on the right, all vertically centered.

CSS
.form { display: flex; flex-direction: column; gap: 20px; } .form-group { display: flex; align-items: center; gap: 15px; } .form-label { flex: 0 0 150px; font-weight: 600; } .form-input { flex: 1; padding: 12px; border: 2px solid #ddd; }

2. Mobile-Friendly Stacked Form

Labels above inputs (mobile-first design). Responsive: stays vertical on mobile, horizontal on desktop.

CSS
.mobile-form .form-group { flex-direction: column; align-items: flex-start; } .mobile-form .form-label { width: 100%; margin-bottom: 6px; } .mobile-form .form-input { width: 100%; }

3. Two-Column Form Layout

Related fields grouped in two columns for efficient space use on desktop.

CSS
.form-row { display: flex; gap: 20px; } .form-column { flex: 1; display: flex; flex-direction: column; gap: 20px; }

4. Form with Error Messages

Error messages aligned properly under inputs using nested flex layout.

⚠ Invalid email format
⚠ Password too short (minimum 8 characters)
CSS
.input-wrapper { flex: 1; display: flex; flex-direction: column; gap: 6px; } .error-message { color: #dc3545; font-size: 0.85rem; }

5. Search Bar with Button

Search input expands to fill space while button maintains fixed width.

CSS
.search-bar { display: flex; gap: 10px; align-items: center; } .search-bar input { flex: 1; } .search-bar button { flex: 0 0 auto; }

6. Address Form with Multi-Row Layout

Address form with full-width street, then two-column city/state/zip.

CSS
.address-row { display: flex; gap: 20px; } .address-row .form-group { flex: 1; }

7. Responsive Filter Bar

Multiple filters that wrap responsively with consistent alignment.

CSS
.filter-bar { display: flex; gap: 15px; align-items: center; flex-wrap: wrap; } .filter-item { display: flex; align-items: center; gap: 8px; }

8. Inline Newsletter Form

Email input and subscribe button in a single line with responsive stacking.

CSS
.inline-form { display: flex; gap: 10px; align-items: center; flex-wrap: wrap; }

9. Settings Form with Toggles

Settings rows with toggle switches aligned to the right.

Email Notifications

Receive email updates

Marketing Emails

Receive promotional content

Newsletter Subscription

Weekly newsletter digest

CSS
.form-group { justify-content: space-between; align-items: center; } .switch { flex: 0 0 auto; }

10. Checkbox and Radio Groups

Properly aligned checkboxes and radio buttons with labels.

CSS
.checkbox-group { display: flex; flex-direction: column; gap: 12px; } .checkbox-item { display: flex; align-items: center; gap: 10px; }

11. Complete Contact Form

Full-featured contact form with text, email, phone, dropdown, and textarea.

CSS
.form { display: flex; flex-direction: column; gap: 20px; } .form-actions { display: flex; gap: 10px; justify-content: flex-end; }
