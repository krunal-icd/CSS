CSS Block-Size & Inline-Size

Practical Examples & Real-World Implementations

Example 1: Card Sizing with Logical Properties

Cards that adapt their dimensions based on logical properties instead of physical width/height. These cards maintain consistent sizing regardless of writing mode.

/* Horizontal Card */
.card.horizontal {
  inline-size: 300px;
  block-size: 150px;
  display: flex;
  align-items: center;
}

/* Vertical Card */
.card.vertical {
  inline-size: 150px;
  block-size: 300px;
}

Vertical

Key Insight: inline-size determines width in horizontal text, but switches to height in vertical text. block-size does the opposite, making your CSS truly direction-aware.

Example 2: Responsive Container Sizing

Containers that use block-size to create flexible layouts that adapt to content flow direction.

.responsive-box {
  inline-size: 100%;
  block-size: auto;
  padding: 20px;
  display: flex;
}

/* Variations */
.responsive-box.small {
  block-size: 80px;
}

.responsive-box.large {
  block-size: 200px;
}

Benefit: Set inline-size: 100% once, it respects parent's flow direction automatically.

Example 3: Grid Items with min-block-size

.grid-item {

Example 4: Aspect Ratio with Logical Sizing

Combining aspect-ratio with logical sizing for flexible component dimensions.

.aspect-box {
  min-block-size: 200px;
  aspect-ratio: 1 / 1;
  display: flex;
}

.aspect-box.wide {
  aspect-ratio: 16 / 9;
}

.aspect-box.tall {
  aspect-ratio: 9 / 16;
}

Powerful Combo: min-block-size + aspect-ratio ensures responsive sizing that maintains proportions.

Example 5: Flexible Component Architecture

Building reusable components using logical properties for consistent sizing across different contexts.

.component {
  border-radius: 8px;
  overflow: hidden;
}

.component-header {
  min-block-size: 50px;
  display: flex;
  align-items: center;
}

.component-body {
  min-block-size: 150px;
  padding-inline: 20px;
  padding-block: 20px;
}
Feature

Logical sizing makes components reusable across all writing modes and directions.

Responsive

Example 6: Writing Mode Adaptation

The same CSS works perfectly with different writing modes. Logical properties automatically adapt.

/* Same CSS for all writing modes */
.writing-box {
  min-block-size: 150px;
  min-inline-size: 150px;
  padding-inline: 20px;
  padding-block: 20px;
}

/* Change writing mode */
.vertical-rl {
  writing-mode: vertical-rl;
}

Magic Moment: No CSS changes needed! The same .writing-box styles adapt automatically to each writing mode.

Key Takeaways

Physical vs Logical: width/height are fixed to screen axes. inline-size/block-size follow text flow.

Minimum Sizing: min-block-size and min-inline-size replace min-height and min-width with direction awareness.

Component Reusability: Write components once with logical properties, they work globally in any language/script.

Writing Mode Support: Horizontal, vertical-rl, vertical-lr — same CSS, different layouts automatically.

Future-Proof: 99%+ browser support means you can use logical properties today with zero fallback concerns.

Pro Tip: Pair logical sizing with logical margins (margin-inline, margin-block) and padding (padding-inline, padding-block) for a completely direction-aware design system.

Implementation Checklist

✓ Replace all width/height with inline-size/block-size

✓ Use min-block-size for minimum heights

✓ Use min-inline-size for minimum widths

min-inline-size: 200px; /* replaces min-width */

✓ Combine with writing-mode for vertical text

writing-mode: vertical-rl; /* dimensions auto-flip */

✓ Test with container queries for responsive behavior

@container (min-block-size: 500px) { /* styles */ }
