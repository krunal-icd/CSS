Best Practices for shape-outside

✓ Do

  • Always float: shape-outside only works on floated elements. Use float: left or float: right
  • Match shapes: Use identical shape-outside and clip-path values for consistent visuals
  • Add margins: Use shape-margin (10-20px) to improve text readability around shapes
  • Use percentages: Use percentage-based values for responsive, device-independent shapes
  • Test accessibility: Ensure text remains readable and flows logically for screen readers
  • Provide fallbacks: Browsers without support will wrap around bounding box—ensure content is still usable

✗ Don't

  • Forget float: shape-outside without float has zero effect
  • Create confusing flows: Avoid shapes that make text hard to follow
  • Use overly complex polygons: 20+ points can impact performance
  • Sacrifice readability: Never let design override content clarity
  • Ignore mobile: Test your shapes on all device sizes
  • Forget shape-margin: Text too close to shapes reduces readability

Responsive Design Patterns

Mobile-Friendly Shape Implementation

/* Desktop: shapes with text wrapping */ @media (min-width: 768px) { .profile-circle { float: left; shape-outside: circle(50%); width: 120px; height: 120px; } } /* Mobile: remove shape floating for full-width layout */ @media (max-width: 767px) { .profile-circle { float: none; shape-outside: none; width: 100%; max-width: 200px; margin-bottom: 20px; } }

Fluid Shape Sizing

/* Responsive shapes using CSS variables */ .responsive-shape { float: left; width: clamp(80px, 20vw, 150px); height: clamp(80px, 20vw, 150px); shape-outside: circle(50%); shape-margin: clamp(8px, 2vw, 20px); margin-right: clamp(10px, 3vw, 30px); }
Responsive Tip: Use clamp() with vw units for truly fluid shapes that scale smoothly across all device sizes while respecting min/max boundaries.
