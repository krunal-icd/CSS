CSS if() Function

Conditional CSS values based on expressions and comparisons

What is the CSS if() Function?

The CSS if() function (part of CSS Values and Units Level 4) allows you to write conditional logic directly in CSS values. It evaluates a condition and returns one of two values based on whether the condition is true or false. This brings programming-like logic to CSS without needing JavaScript.

⚠️ Status: EXPERIMENTAL — The if() function is still in early specification stages. Browser support is limited. For production use, consider CSS custom properties with JavaScript or JavaScript-based solutions.

Key Capabilities

Conditional Values: Return different CSS values based on conditions.

Expression Evaluation: Evaluate mathematical and logical expressions in CSS.

Responsive Design: Create truly responsive values without media queries.

No JavaScript Needed: Pure CSS conditional logic without runtime overhead.

Basic Syntax & Structure

The if() function follows a simple ternary-like syntax similar to JavaScript.

Syntax

if(condition, true-value, false-value)

Detailed Breakdown

condition: A boolean expression that evaluates to true or false. Examples: width > 800px, color-contrast > 4.5, color-gamut: p3
true-value: The CSS value to use if the condition evaluates to true. Example: 2rem, blue, flex, etc.
false-value: The CSS value to use if the condition evaluates to false. Example: 1rem, red, block, etc.

Simple Example

/* Set font size based on viewport width */
font-size: if(viewport-width > 768px, 1.5rem, 1rem);

/* Set display based on color gamut */
display: if(color-gamut: p3, grid, flex);
Important: The if() function returns a single value, not multiple declarations. It's designed to work with properties that accept multiple value types.

Types of Conditions

The CSS if() function supports various condition types for different scenarios.

1. Viewport-Based Conditions

/* Width comparisons */
font-size: if(viewport-width > 1024px,
  2rem, 1.5rem);

/* Height comparisons */
height: if(viewport-height > 600px,
  100vh, auto);

/* Aspect ratio */
display: if(viewport-aspect-ratio > 2,
  flex, block);
Viewport Conditions: Compare viewport dimensions and aspect ratio for responsive design.

2. Color Capability Conditions

/* Color gamut detection */
color: if(color-gamut: p3,
  color(display-p3 1 0 0),
  red);

/* Dynamic range support */
--highlight: if(dynamic-range: high,
  luminance(400),
  white);
Color Conditions: Optimize colors for different display capabilities (HDR, wide gamut).

3. User Preference Conditions

/* Contrast preference */
border: if(prefers-contrast > 1,
  2px solid black,
  1px solid gray);

/* Motion preferences */
animation-duration: if(prefers-reduced-motion,
  0s, 0.3s);
Accessibility Conditions: Respect user preferences for contrast, motion, and other accessibility settings.

4. Container Query Conditions

/* Component-level responsive logic */
font-size: if(container-query-width > 500px,
  1.5rem, 1rem);

/* Combining conditions */
display: if(container-query-width > 500px AND prefers-contrast > 1,
  grid, flex);

Practical Examples

Example 1: Responsive Typography Without Media Queries

Use if() to scale typography based on viewport width elegantly.

font-size: if(viewport-width > 768px,
  2rem, 1.5rem);

line-height: if(viewport-width > 1024px,
  1.8, 1.5);

max-width: if(viewport-width > 1200px,
  1200px,
  100%);

Responsive Typography

Font size adapts based on viewport width

Example 2: Color Gamut Detection

Deliver vibrant colors to capable displays, fallback to sRGB for older devices.

/* Use P3 colors on capable displays */
--accent: if(color-gamut: p3,
  color(display-p3 1 0.5 0),
  rgb(255, 128, 0));

.button {
  background: var(--accent);
  color: white;
}
Benefit: Display-wide color support detected automatically. Users with HDR displays get superior color accuracy.

Example 3: Accessibility-Aware Animations

Respect user motion preferences while maintaining visual polish.

animation-duration: if(prefers-reduced-motion,
  0s,
  0.3s);

animation-timing-function: if(prefers-reduced-motion,
  linear,
  ease-out);
Accessibility First: Users who prefer reduced motion see no animation delay. Animations are crisp and immediate.

Example 4: Dynamic Spacing Based on Screen Space

Optimize spacing for available screen real estate.

.container {
  padding: if(viewport-width > 768px,
    2rem, 1rem);
  
  gap: if(viewport-width > 1024px,
    2rem, 1rem);
}

Browser support improves; prototyping future-ready code; experimenting with new CSS features

Need complex conditions or real-time updates based on user interaction or data

Best Practices & Guidelines

Provide Fallbacks: Always include a fallback for browsers that don't support if().

Use with Progressive Enhancement: Treat if() as an enhancement, not a requirement.

Keep Conditions Simple: Use straightforward conditions that are easy to understand and maintain.

Test Thoroughly: Test across browsers and devices, especially when relying on feature detection.

Combine with Other Features: Use if() alongside media queries, container queries, and custom properties.

Common Pitfalls to Avoid

Assuming Universal Support: Don't use if() expecting all users to see correct styling.

Complex Nested Conditions: Avoid deeply nested if() functions — they reduce readability.

Replacing All Media Queries: Media queries have better browser support and clearer syntax for most cases.

Performance Assumptions: While performant, don't assume negligible overhead from complex conditions.
