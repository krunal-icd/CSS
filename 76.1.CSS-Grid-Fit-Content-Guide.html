CSS Grid: Fit-Content Property

Size columns/rows to fit content with maximum constraints

Understanding fit-content()
What is fit-content()?
fit-content(): A sizing function that sizes a track (column or row) based on its content, but respects a maximum limit. The track grows only as large as its content allows, up to the specified maximum.
The Formula
fit-content(max-size) = min(content-size, max-size) Meaning: Use the smaller of: • The natural size needed for content • The maximum size you specify Examples: fit-content(200px) → Grow to fit content, max 200px fit-content(50%) → Grow to fit content, max 50% of container fit-content(20em) → Grow to fit content, max 20em
Key Characteristics
  • Intrinsic Sizing: Sizes based on content first
  • Maximum Constraint: Won't exceed the max size you specify
  • Flexible: Can be smaller than max if content is smaller
  • Responsive: Adapts to content changes automatically
  • Works with units: px, %, em, rem, etc.
Visual Explanation
fit-content(200px) with different content: Short text ("Hi"): ┌────────┐ │ Hi │ ← Grows only to 35px (content size) └────────┘ Medium text ("Hello World"): ┌──────────────────┐ │ Hello World │ ← Grows to 115px (content size) └──────────────────┘ Long text ("This is very long text..."): ┌──────────────────────────┐ │ This is very long tex... │ ← Capped at 200px (max-size) │ t that won't fit │ Text wraps, height grows └──────────────────────────┘
fit-content() vs auto vs minmax()
The Three Sizing Methods
Property Sizing Behavior Min Size Max Size Best For
auto Fits content exactly Content size Content size Columns that should be exact size of content
fit-content(200px) Fits content up to max Content size 200px Content with a maximum limit
minmax(100px, 1fr) Grows to fill space 100px Available space Flexible columns that grow
1fr Fills all available space Share of space All space Equal-width flexible columns

Syntax & Usage Patterns
Basic Syntax
/* Single column with fit-content */ .grid { display: grid; grid-template-columns: fit-content(200px); } /* Multiple columns mixed */ .grid { grid-template-columns: fit-content(150px) 1fr fit-content(200px); } /* For rows */ .grid { grid-template-rows: fit-content(100px) 1fr; } /* With repeat() - NOT allowed */ /* fit-content doesn't work with repeat() */
Common Patterns
/* Sidebar + Content layout */ .layout { grid-template-columns: fit-content(300px) 1fr; /* Sidebar grows to content, max 300px */ /* Content gets remaining space */ } /* Header + Main + Footer */ .page { grid-template-rows: fit-content(80px) 1fr fit-content(60px); /* Header: content-based, max 80px */ /* Main: fills remaining height */ /* Footer: content-based, max 60px */ } /* Sidebar + Content + Sidebar */ .three-column { grid-template-columns: fit-content(250px) 1fr fit-content(300px); }
Key Differences from Similar Properties
fit-content() vs auto
auto: Grows to fit content exactly. No maximum limit. Content can be any size.
fit-content(max): Grows to fit content but respects maximum. Won't exceed the max-size you specify.
/* With "This is very long text..." */ .grid-auto { grid-template-columns: auto 1fr; } /* Column 1: 250px (full text width) */ .grid-fitcontent { grid-template-columns: fit-content(150px) 1fr; } /* Column 1: 150px (capped), text wraps */
fit-content() vs minmax()
minmax(min, max): Has both minimum and maximum. Grows to fill available space if larger than content.
fit-content(max): No minimum. Only grows as much as content needs, up to max.
/* With "Hi" and container 400px wide */ .grid-minmax { grid-template-columns: minmax(100px, 1fr); } /* Column: 400px (fills space, minimum 100px) */ .grid-fitcontent { grid-template-columns: fit-content(400px); } /* Column: ~35px (content size "Hi") */
Real-World Use Cases
Scenario 1: Responsive Sidebar Navigation
Sidebar should grow with navigation items but never exceed 300px. Content takes remaining space.
.layout { display: grid; grid-template-columns: fit-content(300px) 1fr; height: 100vh; } aside { /* Sidebar */ } main { /* Content area */ }
Why fit-content: Navigation width varies, but shouldn't take more than 300px. Perfect use case for fit-content(300px).
Scenario 2: Three-Column Dashboard
Left sidebar (actions), main content (grows), right sidebar (widgets). Both sidebars should fit content with max limits.
.dashboard { display: grid; grid-template-columns: fit-content(200px) 1fr fit-content(250px); }
Scenario 3: Blog Post with Sidebar
Post content fills main area. Sidebar with metadata/tags stays compact with max width.
.post-layout { grid-template-columns: 1fr fit-content(280px); gap: 20px; } /* Sidebar content never wider than 280px */
Scenario 4: Page Layout (Header/Footer/Main)
Header and footer fit their content with max heights. Main area fills remaining space.
.page { display: grid; grid-template-rows: fit-content(100px) 1fr fit-content(80px); height: 100vh; } header { /* Content-sized, max 100px */ } main { /* Fills remaining height */ } footer { /* Content-sized, max 80px */ }

Best Practices & Tips
✓ Do's
  • Use for sidebars: fit-content(300px) for sidebars that grow with content but have limits
  • Use for headers/footers: fit-content(100px) for rows that grow with content but cap at height
  • Set reasonable max-sizes: Choose max values that make sense for your design
  • Combine with 1fr: Pair fit-content with 1fr for main content areas
  • Use with gap: Gap doesn't affect fit-content sizing
  • Test responsive behavior: See how content changes affect sizing
✗ Don'ts
  • Don't use with repeat(): fit-content() doesn't work inside repeat()
  • Don't set max-size too small: If max is smaller than minimum content, content will overflow
  • Don't forget to specify units: fit-content(300) won't work, must be fit-content(300px)
  • Don't use for all columns: If all columns are fit-content, nothing fills remaining space
  • Don't expect it to wrap automatically: fit-content constrains width but doesn't add text wrapping
Pro Tips
💡 Tip 1: Use fit-content(200px) instead of auto for columns that need a reasonable maximum. Prevents layout breakage.
💡 Tip 2: fit-content works great with CSS Custom Properties: grid-template-columns: fit-content(var(--sidebar-width)) 1fr
💡 Tip 3: Combine fit-content with @media queries for responsive max-sizes at different breakpoints.
💡 Tip 4: Use fit-content(50%) for columns that should fit content but never exceed half the container width.
💡 Tip 5: fit-content is perfect for collapsible sidebars that expand/collapse based on content.
Quick Reference

fit-content(max-size)

  • Sizes based on content, respects maximum
  • Formula: min(content-size, max-size)
  • Perfect for sidebars, headers, footers
  • Doesn't fill remaining space (need 1fr for that)

Common Syntax:

  • grid-template-columns: fit-content(300px) 1fr;
  • grid-template-rows: fit-content(100px) 1fr fit-content(80px);
  • Supports: px, %, em, rem, ch, vw, etc.

When to Use:

  • Sidebars with variable width but max limit
  • Headers/footers with variable height but max cap
  • Navigation bars that grow with items
  • Three-column layouts (sidebar + content + sidebar)
