📏 CSS Line-Height - Practical Guide

🎯 What is Line-Height?

Line-Height controls the vertical space between lines of text. It affects readability, spacing, and overall typography appearance.

✓ Why It Matters:
• Controls text readability
• Affects layout and spacing
• Improves user experience
• Essential for typography
• Affects vertical centering
💡 Key Point: Line-height is inherited by child elements, so set it carefully on parent containers.

📋 Syntax & Value Types

Basic Syntax

/* Different value types */ line-height: normal; /* Default value */ line-height: 1.5; /* Unitless (multiplier) */ line-height: 1.5em; /* Relative to font-size */ line-height: 24px; /* Absolute pixels */ line-height: 150%; /* Percentage */ line-height: inherit; /* Inherit from parent */

The quick brown fox jumps over the lazy dog. Very spacious with maximum vertical breathing room.

The quick brown fox jumps over the lazy dog. Fixed pixel value regardless of font size.

🔗 Relationship with Font-Size

Example 1: font-size: 16px, line-height: 1.5 Calculation: 16px × 1.5 = 24px (total line height)
Example 2: font-size: 20px, line-height: 1.6 Calculation: 20px × 1.6 = 32px (total line height)
Example 3: font-size: 14px, line-height: 2 Calculation: 14px × 2 = 28px (total line height)
Example 4: font-size: 24px, line-height: 1.2 Calculation: 24px × 1.2 = 28.8px (total line height)
💡 Formula: Actual line-height = font-size × line-height value
Example: 16px × 1.5 = 24px

💡 Best Practices

1. Use Unitless Values
line-height: 1.5; is better than line-height: 1.5em; because it scales better with font-size changes.
2. Set at Body Level
Set line-height on body or main container to inherit throughout. Override only where needed.
3. Match Content Type
Use 1.5-1.7 for body text, 1.2-1.3 for headings, and adjust based on content.
4. Consider Font Family
Serif fonts may need slightly higher line-height. Sans-serif can be tighter.
5. Avoid Pixel Values
Fixed pixel values don't respond to zoom or font-size changes. Use relative units instead.
6. Test Readability
Different screen sizes and browsers may render differently. Test on multiple devices.

❌ Common Mistakes & Solutions

❌ Wrong

Using pixel values everywhere
line-height: 24px; /* Doesn't respond to zoom */
Inconsistent heading spacing
h1 { line-height: 1 } h2 { line-height: 1.5 } h3 { line-height: 2 } /* Confusing variation */
Too tight line-height
p { line-height: 1; } /* Hard to read */

✅ Correct

Using unitless values
line-height: 1.5; /* Responsive and flexible */
Consistent heading spacing
h1, h2, h3 { line-height: 1.2; } /* Clear and consistent */
Readable line-height
p { line-height: 1.6; } /* Easy to read */
