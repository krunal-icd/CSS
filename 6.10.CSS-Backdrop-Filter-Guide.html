CSS backdrop-filter Property

All 9 Properties - Practical Examples

🎨 1. Blur Property

What is Blur?

The blur property applies a Gaussian blur effect to the background behind the element. It creates a frosted glass effect by blurring everything visible through the element's transparency.

Syntax

blur(5px) | blur(10px) | blur(20px)

Higher values = more blur

Practical Examples - Blur Effect
blur(5px) - Light blur
blur(10px) - Medium blur
blur(20px) - Heavy blur

blur(10px)

blur(20px)

CSS Code
/* Light blur - for subtle effects */ .blur-light { background: rgba(255, 255, 255, 0.1); -webkit-backdrop-filter: blur(5px); backdrop-filter: blur(5px); } /* Medium blur - most common */ .blur-medium { background: rgba(255, 255, 255, 0.1); -webkit-backdrop-filter: blur(10px); backdrop-filter: blur(10px); } /* Heavy blur - strong frosted glass */ .blur-heavy { background: rgba(255, 255, 255, 0.1); -webkit-backdrop-filter: blur(20px); backdrop-filter: blur(20px); }
💡 Use Case: Frosted glass effect for modals, cards, navigation menus, and overlay text. Recommended for modern UI design.

☀️ 2. Brightness Property

What is Brightness?

Brightness adjusts the luminance (lightness/darkness) of the background. Values less than 1 darken, while values greater than 1 lighten the background.

Syntax

brightness(0.6) - Darker

brightness(1) - Normal

brightness(1.5) - Lighter

Practical Examples - Brightness Levels

CSS Code
/* Darken background */ .brightness-dark { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: brightness(0.6); backdrop-filter: brightness(0.6); } /* Normal brightness */ .brightness-normal { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: brightness(1); backdrop-filter: brightness(1); } /* Lighten background */ .brightness-light { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: brightness(1.5); backdrop-filter: brightness(1.5); }
💡 Use Case: Creating dark overlays for hero sections, highlighting content, or improving text readability over colorful backgrounds.

🎭 3. Contrast Property

What is Contrast?

Contrast controls the difference between light and dark areas. Values below 1 reduce contrast (flatten colors), while values above 1 increase contrast (intensify colors).

Syntax

contrast(0.8) - Lower

contrast(1.2) - Higher

contrast(2) - Very High

Practical Examples - Contrast Levels
contrast(0.8) - Flattened
contrast(1.2) - Enhanced

CSS Code
/* Low contrast - muted colors */ .contrast-low { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: contrast(0.8); backdrop-filter: contrast(0.8); } /* Medium contrast - enhanced */ .contrast-medium { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: contrast(1.2); backdrop-filter: contrast(1.2); } /* High contrast - intense */ .contrast-high { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: contrast(2); backdrop-filter: contrast(2); }
💡 Use Case: Making content stand out more or creating softer, more subtle backgrounds. Great for accessibility improvements.

⚫️ 4. Grayscale Property

What is Grayscale?

Grayscale removes or reduces color saturation from the background. A value of 100% completely removes all color (black and white only), while 0% keeps full color.

Syntax

grayscale(0%) - Full color

grayscale(50%) - Half color

grayscale(100%) - No color

Practical Examples - Grayscale Intensity

CSS Code
/* Full color - no grayscale */ .grayscale-none { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: grayscale(0%); backdrop-filter: grayscale(0%); } /* Partial grayscale */ .grayscale-partial { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: grayscale(50%); backdrop-filter: grayscale(50%); } /* Complete grayscale */ .grayscale-full { background: rgba(255, 255, 255, 0.2); -webkit-backdrop-filter: grayscale(100%); backdrop-filter: grayscale(100%); }
💡 Use Case: Creating vintage/nostalgic effects, disabling hover states, or creating professional monochrome overlays.

🌈 7. Hue-Rotate Property

What is Hue-Rotate?

Hue-rotate shifts colors along the color wheel. It rotates all colors by a specified angle (0-360 degrees). A 180-degree rotation inverts all colors.

Syntax

hue-rotate(180deg)

hue-rotate(270deg)

🔄 8. Invert Property

What is Invert?

Invert reverses all colors - light becomes dark and dark becomes light. It's like creating a negative of a photograph. 100% inverts completely.

👁️ 9. Opacity Property

What is Opacity?

Opacity controls the transparency of the backdrop filter effect itself. Lower values make the effect more transparent (less visible), while higher values make it more opaque.

Syntax

opacity(30%) - Transparent

opacity(60%) - Semi

opacity(100%) - Opaque

💡 Use Case: Fine-tuning the visibility of backdrop effects, creating layered overlays, or blending elements with background content.

✨ Bonus: Combining Multiple Properties

Power of Combinations

You can combine multiple backdrop-filter properties in a single declaration for more sophisticated effects. Separate each effect with a space.

Common Combinations
/* Professional glassmorphism */ .glass-1 { backdrop-filter: blur(10px) brightness(1.1); } /* Vintage photo effect */ .vintage { backdrop-filter: sepia(50%) grayscale(30%) blur(3px); } /* Dark overlay with enhanced colors */ .dark-overlay { backdrop-filter: brightness(0.7) contrast(1.2) saturate(1.1); } /* Artistic effect */ .artistic { backdrop-filter: blur(8px) hue-rotate(45deg) saturate(1.5) brightness(1.1); } /* Extreme effect */ .extreme { backdrop-filter: blur(15px) invert(50%) grayscale(50%) saturate(2) brightness(1.2); }
⚠️ Performance Warning: Combining many effects can impact performance. Start with 2-3 effects and test on various devices. Heavy blur + multiple effects on large areas can cause lag.
