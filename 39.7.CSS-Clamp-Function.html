🎯 CSS clamp() Function - Practical Examples

What is the CSS clamp() Function?

The clamp() function sets a minimum, preferred, and maximum value. It returns the middle value if it's within the range, or the min/max if it exceeds the bounds.

Basic Syntax:
property: clamp(minimum, preferred, maximum);
✅ Browser Support: All modern browsers (Chrome 79+, Firefox 75+, Safari 13.1+, Edge 79+)

How It Works:

clamp(200px, 50%, 800px)
200px (MIN)
→
50% (PREFERRED)
→
800px (MAX)
  • Minimum: Smallest allowed value
  • Preferred: Ideal value (usually responsive unit)
  • Maximum: Largest allowed value

Example 1: Responsive Container Width

Create a container with both minimum and maximum constraints.

CSS Code:

.container { width: clamp(200px, 50%, 800px); }

How it Works:

  • Minimum 200px on tiny screens
  • Scales to 50% of parent on medium screens
  • Caps at 800px on large screens

Example 2: Fluid Typography (Most Popular Use)

Perfect for creating text that scales smoothly between min and max sizes.

CSS Code:

h1 { font-size: clamp(16px, 5vw, 48px); } h2 { font-size: clamp(14px, 3.5vw, 36px); } p { font-size: clamp(12px, 2vw, 18px); }

How it Works:

  • Minimum 16px for mobile readability
  • Scales to 5% of viewport width
  • Caps at 48px on large screens
  • No media queries needed!

Demo:

Decision Tree:

Use Case Function Example
Only want a maximum width min() width: min(90%, 600px)
Only want a minimum width max() width: max(200px, 50%)
Want both minimum and maximum clamp() width: clamp(200px, 50%, 800px)

💡 Best Practices

1. Start with Minimum for Accessibility

Always set a reasonable minimum to ensure content is accessible on small devices (min 44px for touch targets)

2. Use Preferred Value Smartly

The middle value should be responsive - use vw, vh, or % for fluid scaling

3. Keep Ranges Reasonable

Don't set min and max values too far apart - the range should be visually consistent

4. Typography First

clamp() is most powerful for fonts - use it for headings, body text, and reading experience

5. Test Extensively

Test on real devices from very small phones to large desktop monitors

6. Combine with Grid

Use clamp() inside CSS Grid's minmax() for perfect responsive layouts

🚀 Real-World Example: Complete Website Setup

Recommended CSS for a Complete Site:

/* Typography */ html { font-size: clamp(14px, 1.5vw, 18px); } h1 { font-size: clamp(28px, 6vw, 56px); line-height: clamp(1.2, 1.5vw, 1.5); } h2 { font-size: clamp(24px, 5vw, 42px); } h3 { font-size: clamp(18px, 4vw, 28px); } /* Spacing */ body { padding: clamp(20px, 5%, 40px); } section { margin: clamp(40px, 8%, 80px) 0; } /* Layout */ .container { width: clamp(300px, 90%, 1200px); margin: 0 auto; } .grid { display: grid; grid-template-columns: repeat( auto-fit, minmax(clamp(200px, 25%, 300px), 1fr) ); gap: clamp(15px, 3%, 30px); }

Browser Fallback Example

With Fallback for Older Browsers:

.heading { /* Fallback for browsers without clamp() */ font-size: 24px; /* Modern browsers use this */ font-size: clamp(18px, 5vw, 48px); }
Older browsers ignore the clamp() value and use the fallback (24px), while modern browsers use the fluid clamp() value.
