CSS Font-Size Property

Complete Guide to Text Sizing and Responsive Typography

1. Introduction to Font-Size

The font-size property sets the size of a font. Changing the font size also updates the size of line boxes and heights of text, affecting the overall layout of the document.

Syntax

font-size: <size> | <percentage> | inherit; /* Examples */ font-size: 16px; font-size: 1.5em; font-size: 100%; font-size: larger;

Key Points

  • Fundamental for text hierarchy and readability
  • Supports multiple units (px, em, rem, pt, etc.)
  • Crucial for responsive design
  • Affects accessibility when sized inappropriately
  • Inherited from parent elements by default

2. Font-Size Units Explained

Absolute Units (Fixed Size)

Pixels (px)

1px = 1/96 inch

Fixed size, predictable. Most common for web.

font-size: 16px;

Points (pt)

1pt = 1/72 inch

Traditional print unit. Use for print stylesheets.

font-size: 12pt;

Centimeters (cm)

1cm = fixed metric

Rarely used for web typography.

font-size: 1cm;

Millimeters (mm)

1mm = 0.1cm

Print design only.

font-size: 10mm;

Relative Units (Responsive Size)

Em (em)

Relative to parent's font-size

Scalable. 2em = 2x parent font-size.

font-size: 1.5em;

Rem (rem)

Relative to root font-size

Consistent throughout document. Modern standard.

font-size: 1.5rem;

Percentage (%)

Relative to parent's font-size

150% = 1.5x parent font-size.

font-size: 150%;

Viewport (vw, vh)

Relative to viewport dimensions

Fluid typography. Use with caution.

font-size: 5vw;

Keyword Values

font-size: xx-small; /* Smallest */ font-size: x-small; font-size: small; font-size: medium; /* Default (usually 16px) */ font-size: large; font-size: x-large; font-size: xx-large; /* Largest */ font-size: smaller; /* Relative to parent */ font-size: larger; /* Relative to parent */

4. Em vs Rem: The Great Debate

Em Units

Em is relative to the parent element's font-size. This creates cascading calculations.
/* Em Example */ html { font-size: 16px; } body { font-size: 1em; } /* 16px */ .container { font-size: 1.5em; } /* 24px */ .container p { font-size: 0.875em; } /* 21px (0.875 × 24px) */

Rem Units

Rem is relative only to the root (<html>) element's font-size. Consistent throughout.
/* Rem Example */ html { font-size: 16px; } /* All rems based on this */ body { font-size: 1rem; } /* 16px */ .container { font-size: 1.5rem; } /* 24px */ .container p { font-size: 0.875rem; } /* 14px (always relative to root) */

Comparison

Feature Em Rem
Reference Point Parent element's font-size Root (<html>) font-size
Predictability Can compound and cascade Consistent and predictable
Nesting Depth Affects calculations deeply No impact from nesting
Use Case Component-specific sizing Global design system
Browser Support All modern browsers IE9+ and modern browsers
Recommended For padding/margins in components ✅ Preferred for font-size
Best Practice: Use rem for font-sizes and em for spacing within components for optimal consistency and maintainability.

5. Responsive Font Sizing

Mobile-First Approach

/* Base sizes for mobile */ html { font-size: 14px; } body { font-size: 1rem; } h1 { font-size: 1.75rem; } h2 { font-size: 1.5rem; } h3 { font-size: 1.25rem; } /* Larger screens */ @media (min-width: 768px) { html { font-size: 16px; } h1 { font-size: 2rem; } h2 { font-size: 1.75rem; } } @media (min-width: 1024px) { html { font-size: 18px; } h1 { font-size: 2.5rem; } h2 { font-size: 2rem; } }

Fluid Typography (Modern Approach)

/* Fluid font-size that scales with viewport */ html { font-size: clamp(14px, 2.5vw, 18px); } h1 { font-size: clamp(1.75rem, 5vw, 3rem); } h2 { font-size: clamp(1.25rem, 4vw, 2rem); } body { font-size: clamp(1rem, 1.2vw, 1.2rem); }
clamp() Syntax: clamp(MIN, PREFERRED, MAX)
  • MIN - Minimum size (never goes below)
  • PREFERRED - Ideal size (usually viewport-based)
  • MAX - Maximum size (never goes above)

7. Accessibility & Best Practices

Minimum Font Sizes

✅ Recommended

  • Body text: 16px or larger
  • Headings: 20px or larger
  • Captions: 12px minimum
  • Line height: 1.5x font-size minimum

❌ Avoid

  • Body text below 12px
  • Paragraph text less than 1.5 line-height
  • Forcing fixed sizes on user text
  • Ignoring user's browser settings

WCAG Guidelines

Web Content Accessibility Guidelines (WCAG):
  • Level A: Ensure text can be resized up to 200% without loss of functionality
  • Level AA: Contrast ratio of 4.5:1 for normal text
  • Level AAA: Contrast ratio of 7:1 for normal text
  • Use relative units (rem, em) to respect user zoom settings

Best Practices Checklist

  • ✅ Use rem for consistent sizing across the site
  • ✅ Base body text should be at least 16px (1rem)
  • ✅ Use relative units (not px) to support accessibility features
  • ✅ Maintain adequate line-height for readability (1.5-1.8)
  • ✅ Test font sizes on different devices and browsers
  • ✅ Provide user controls for font size preferences
  • ✅ Ensure color contrast meets WCAG standards
  • ✅ Use em units for component-specific padding/margins
  • ✅ Create a documented type scale system
  • ✅ Never prevent users from zooming text (avoid user-scalable=no)

9. Common Issues & Solutions

Issue 1: Text Too Small on Mobile

/* Problem */ body { font-size: 12px; } /* Solution */ body { font-size: 1rem; } @media (max-width: 768px) { body { font-size: 1.125rem; } }

Issue 2: Em Cascade Getting Out of Control

/* Problem - cascading ems */ .container { font-size: 1.2em; } .container .item { font-size: 1.2em; } .container .item .text { font-size: 1.2em; } /* Result: 1.2 × 1.2 × 1.2 = 1.728em! */ /* Solution - use rem */ .container { font-size: 1.2rem; } .container .item { font-size: 1.2rem; } .container .item .text { font-size: 1.2rem; } /* All sizes are consistent */

Issue 3: Font Size Not Changing

/* Check for specificity issues */ body { font-size: 16px; } p { font-size: 14px; } /* ✅ More specific */ /* Check for !important interference */ p { font-size: 14px; } p.special { font-size: 18px !important; } /* Use only when necessary */ /* Check inheritance */ .parent { font-size: 20px; } .child { font-size: inherit; } /* Explicitly inherit */
