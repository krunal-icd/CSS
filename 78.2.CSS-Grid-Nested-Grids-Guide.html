CSS Grid: Nested Grids

Practical Examples & Real-World Implementations

1. Product Cards (Traditional Nesting)
Each product card is a nested grid with 4 rows: image, info, price, button. Complete independence from parent grid.
.product-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); }
.product-card { display: grid; grid-template-rows: 120px auto 40px 50px; gap: 10px; }

.table-row { display: subgrid; grid-column: 1 / -1; }

2-column form. Each form field spans 2 parent columns (label + input). Subgrid ensures labels and inputs align vertically.

.form-field { display: subgrid; grid-column: span 2; }

5. Article Layout (Column Subgrid)
Article content with sidebar. Article content uses column subgrid to inherit parent columns. Sections stay aligned.
.article-layout { display: grid; grid-template-columns: 1fr 250px; }
.article-content { display: subgrid; grid-template-columns: subgrid; }

Introduction

Subgrid allows nested grids to inherit parent track definitions. This enables perfect alignment of content across multiple nested grid levels.

Key Benefits

Perfect alignment, cleaner CSS, responsive synchronization, and flexible nesting. Subgrid is powerful for complex multi-level layouts.

Use Cases

Data tables, forms, dashboards, articles with sidebars, and any layout where vertical alignment across rows matters.

Decision Guide & Best Practices

Traditional Nesting (display: grid):

  • Independent nested structures
  • Each nested grid has own columns/rows
  • Perfect for cards, components
  • Works in all modern browsers

Subgrid (display: subgrid):

  • Inherits parent grid tracks
  • Perfect column/row alignment
  • Ideal for data tables, forms
  • Newer feature (check browser support)

Common Combinations:

  • Subgrid at top level → Traditional nesting for components
  • Data table with subgrid rows → Perfect alignment
  • Form with subgrid fields → Professional layout
  • Cards with nested grids → Flexible components
