What is list-style-type?

The list-style-type CSS property specifies the appearance of list markers (bullets, numbers, letters) used in ordered and unordered lists. It allows you to customize how list items are displayed, choosing from predefined marker styles or creating custom ones.

Core Concept:

  • Controls the visual marker appearing before list items
  • Applies to both <ol> (ordered) and <ul> (unordered) lists
  • Supports 50+ predefined marker styles
  • Can be combined with list-style-position and list-style-image
  • Inherited property - applies to nested lists unless overridden
  • Can be customized with CSS counters for advanced effects
Browser Support: Universal support across all modern and legacy browsers. IE 6+ supported.

Symbol & Special Marker Types

Non-Alphabetic & Symbol Markers

Display symbols, discs, and special characters:

/* Basic symbols for unordered lists */ ul { list-style-type: disc; } /* • */ ul { list-style-type: circle; } /* ○ */ ul { list-style-type: square; } /* ■ */ /* No marker */ ul { list-style-type: none; } /* (no marker) */ /* Symbolic numbering */ ol { list-style-type: symbols(cyclic, "◉" "◎" "◍"); } /* Thai numerals */ ol { list-style-type: thai; } /* ๑, ๒, ๓... */ /* Lao numerals */ ol { list-style-type: lao; } /* ໑, ໒, ໓... */ /* Devanagari numerals (Hindi) */ ol { list-style-type: devanagari; } /* १, २, ३... */ /* Bengali numerals */ ol { list-style-type: bengali; } /* ১, ২, ৩... */ /* Khmer numerals (Cambodian) */ ol { list-style-type: khmer; } /* ១, ២, ៣... */ /* Vietnamese */ ol { list-style-type: vietnamese; } /* I, II, III... */

List Style Properties

Complete list-style Shorthand

Combine list-style properties in a single declaration:

/* Shorthand: type | position | image */ ul { list-style: square inside url('bullet.png'); } /* Equivalent to: */ ul { list-style-type: square; list-style-position: inside; list-style-image: url('bullet.png'); } /* Individual properties */ ol { list-style-type: upper-roman; /* Marker type */ list-style-position: outside; /* Marker position */ list-style-image: none; /* Custom image */ }

Position Values

/* outside (default) - marker outside text box */ ol { list-style-position: outside; } /* inside - marker inside text box */ ol { list-style-position: inside; }

Nested Lists

/* Different markers for nested levels */ ol { list-style-type: decimal; } ol ol { list-style-type: lower-alpha; } ol ol ol { list-style-type: lower-roman; } /* Result: 1, 2, 3 / a, b, c / i, ii, iii */

Best Practices

✓ DO:

  • Match list type to purpose: Use decimal for steps, lower-alpha for lettered options
  • Consider accessibility: Maintain readable contrast between marker and text
  • Use nested markers appropriately: Use different markers for multi-level lists
  • Test with different languages: Some marker types are language-specific
  • Keep it simple: Stick to common marker types for better compatibility
  • Use list-style shorthand: Cleaner than individual properties
  • Consider mobile rendering: Test marker appearance on small screens

✗ DON'T:

  • Use none without replacement: Provide visual hierarchy or alternative markers
  • Mix too many marker types: Consistency aids comprehension
  • Ignore semantics: Use <ol> for ordered lists, <ul> for unordered
  • Make markers invisible: Ensure sufficient contrast for accessibility
  • Combine conflicting properties: list-style-image overrides list-style-type
  • Use language-specific markers incorrectly: Match marker to content language

Key Takeaways

  • 50+ Marker Types: CSS provides extensive options for numeric, alphabetic, and symbol markers
  • Language Support: Markers exist for various languages and writing systems
  • Semantic HTML First: Use <ol> for ordered and <ul> for unordered lists
  • Nested Lists: Use different marker types at each nesting level for clarity
  • Position Property: Control whether markers appear inside or outside content flow
  • Accessibility Matters: Ensure markers are visible and provide meaningful structure
  • Universal Browser Support: Basic markers work everywhere; advanced ones need testing
  • Use list-style Shorthand: Combine type, position, and image in one property
