CSS text-orientation Property

12 Practical Examples • Vertical Text & Character Orientation

1. Mixed Orientation (Default)

Mixed

Default mixed orientation - most characters upright but certain characters rotate. Perfect for CJK text.

Vertical Text 2024
element { writing-mode: vertical-rl; text-orientation: mixed; } Result: Most chars upright, numbers/Latin rotate

2. Upright Orientation

Upright

All characters display upright in their normal orientation. Requires specific fonts.

Upright Text
element { writing-mode: vertical-rl; text-orientation: upright; } Result: All characters in normal orientation

3. Sideways Orientation

Sideways

Text rotates 90 degrees counterclockwise. Useful for labels and annotations.

Sideways Text
element { writing-mode: vertical-rl; text-orientation: sideways; } Result: Text rotates -90° (counterclockwise)

4. Vertical Left-to-Right

LR Mode

Vertical text flowing from left to right (alternative vertical writing mode).

Vertical LR Text
element { writing-mode: vertical-lr; text-orientation: mixed; } Result: Text flows left-to-right vertically

5. Vertical Table Headers

Table

Compact table headers with vertical text. Perfect for narrow columns with long header names.

Product Name Quantity Price Total
Item A 5 $10 $50
Item B 3 $15 $45
th { writing-mode: vertical-rl; text-orientation: mixed; width: 50px; }

6. Mixed CJK & Latin Characters

Mixed Script

Handles mixing Chinese/Japanese with English text. Latin text rotates, CJK stays upright.

漢字 ABC 文字 123 テキスト XYZ 日本語
element { writing-mode: vertical-rl; text-orientation: mixed; } Result: CJK upright, Latin/numbers rotate

7. Artistic Vertical Design

Artistic

Large, spaced vertical text for creative layouts and design purposes.

DESIGN
element { writing-mode: vertical-lr; text-orientation: mixed; font-size: 2em; letter-spacing: 0.3em; }

8. Rotated Annotation Labels

Labels

Sideways text with rotation for annotations and callouts that read right-to-left.

← Important Label
label { writing-mode: vertical-rl; text-orientation: sideways; transform: rotate(180deg); }
