🎯 CSS max() Function - Practical Examples

What is the CSS max() Function?

The max() function returns the largest value from a list of comma-separated values. It's perfect for setting minimum constraints and ensuring elements don't get too small.

Basic Syntax:
property: max(value1, value2, value3, ...);
✅ Browser Support: All modern browsers (Chrome 78+, Firefox 75+, Safari 11+, Edge 79+)

Key Difference from min():

  • min(): Returns smallest value (good for max constraints)
  • max(): Returns largest value (good for minimum constraints)

Example 1: Minimum Width for Content

Ensure an element doesn't shrink below a certain size, even on mobile.

CSS Code:

.container { width: max(300px, 50%); margin: 0 auto; }

How it Works:

  • On small screens: uses 300px (minimum width)
  • On large screens: uses 50% (if larger than 300px)
  • Always maintains readability

Example 3: Minimum Font Size

Scale text fluidly but never let it get too small to read.

CSS Code:

.text { font-size: max(16px, 2vw); }

How it Works:

  • On small screens: minimum 16px for readability
  • On large screens: scales to 2% of viewport width
  • Perfect for responsive typography

Example 6: Using Multiple Values

Compare multiple values and use the largest one.

CSS Code:

.element { width: max(100%, 400px, 50vw); }

Logic:

  • 100% = full parent width
  • 400px = fixed minimum
  • 50vw = 50% of viewport width
  • Browser picks the largest value

Demo:

Example 7: Optimal Reading Width

Maintain comfortable line length for reading while adapting to screen size.

CSS Code:

.article { max-width: max(60ch, 100%); margin: 0 auto; }

How it Works:

  • 60ch = 60 character width (optimal for reading)
  • 100% = full parent width if smaller
  • Never gets narrower than optimal reading length

Demo:

This text maintains an optimal reading width of 60 characters. The line length stays between 60 characters and 100% of the container, whichever is larger. Perfect for articles and blog posts!

Comparison: min(), max(), and clamp()

Function Purpose Example Use When
min() Returns smallest value min(90%, 600px) You want a maximum limit
max() Returns largest value max(300px, 50%) You want a minimum constraint
clamp() Sets min, preferred, max clamp(16px, 2vw, 32px) You want both min AND max

Visual Examples:

min(90%, 600px) → Caps at 600px
Small: 90% | Large: 600px (capped)
max(300px, 50%) → Minimum 300px
Small: 300px (minimum) | Large: 50%
clamp(300px, 50%, 800px) → Between 300px and 800px
Small: 300px (min) | Medium: 50% | Large: 800px (max)

💡 Best Practices

1. Use for Minimum Constraints

Use max() when you want something NOT to shrink below a certain size

2. Combine with Percentage Units

Mix fixed units (px) with relative units (%) for flexible minimum constraints

3. Accessibility First

Use max() to ensure touch targets are always clickable (min 44px)

4. Readability Constraints

Combine with line-length units (ch) for optimal reading experience

5. Performance Benefits

No JavaScript needed - calculations happen at CSS render time

Browser Fallback Example

With Fallback for Older Browsers:

.container { /* Fallback for older browsers */ width: 50%; /* Modern browsers will use this */ width: max(300px, 50%); }
Old browsers ignore the second declaration and use 50%, while modern browsers use the max() value to ensure minimum 300px width.

When to Use max() vs Other Methods

⚠️ Choose the Right Tool:
  • max(): For minimum constraints that scale
  • min-width: For absolute minimum that doesn't scale
  • Media queries: For complex layout changes
  • clamp(): When you need both min and max
