CSS Font-Weight Property

Master text emphasis and visual hierarchy with font weights

1. Introduction to Font-Weight

The font-weight property specifies the thickness or boldness of text. It controls how "heavy" or "light" the letterforms appear, affecting readability, emphasis, and visual hierarchy.

Syntax

font-weight: normal | bold | lighter | bolder | <number> | inherit; /* Examples */ font-weight: 400; font-weight: bold; font-weight: 700; font-weight: lighter;

Key Points

  • Numeric values: 100, 200, 300, 400, 500, 600, 700, 800, 900
  • Keyword values: normal (400), bold (700), lighter, bolder
  • Affects text emphasis and visual hierarchy
  • Required font files must support specified weights
  • Can impact readability and page loading time
  • Inherited from parent elements by default

4. Practical Usage Examples

Basic HTML Elements

/* Default styles for common elements */ strong, b { font-weight: bold; /* 700 */ } em, i { font-weight: inherit; /* No change to weight */ } p { font-weight: normal; /* 400 - default */ } small { font-weight: normal; /* 400 - don't make lighter */ }

Visual Hierarchy with Font-Weight

H1 Main Heading - Bold (700)
H2 Section Heading - Semibold (600)
H3 Subsection - Semibold (600)
Body text - Normal (400) - This is standard paragraph text that users read. It should be comfortable and not too heavy.
Caption text - Medium (500) - Metadata or supporting information

Using Font-Weight for Emphasis

/* Emphasis within text */ p { font-weight: 400; } p strong { font-weight: 600; /* Slightly bolder than normal for emphasis */ } /* Buttons */ button { font-weight: 600; /* Medium boldness for readability */ } /* Links */ a { font-weight: 500; /* Slightly heavier to distinguish from text */ } /* Form labels */ label { font-weight: 500; }

Headline Typography

/* Responsive headlines with varying weights */ h1 { font-size: 2.5em; font-weight: 700; /* Maximum impact */ line-height: 1.2; } h2 { font-size: 2em; font-weight: 600; /* Strong but not as heavy */ line-height: 1.3; } h3 { font-size: 1.5em; font-weight: 600; } h4 { font-size: 1.25em; font-weight: 500; /* Lighter approach */ } p { font-size: 1em; font-weight: 400; /* Standard */ }

5. Relative Weight Values: Lighter & Bolder

How Lighter and Bolder Work

lighter and bolder are relative values that adjust based on the parent element's font-weight.
Parent Weight lighter Result bolder Result
100 100 (no change) 400
200 100 400
300 100 400
400 (normal) 100 700
500 400 700
600 500 700
700 (bold) 400 900
800+ 700 900

Example: Relative Weight Usage

/* Parent with normal weight */ .container { font-weight: 400; } /* Child using lighter - becomes 100 */ .container .light { font-weight: lighter; } /* Child using bolder - becomes 700 */ .container .emphasis { font-weight: bolder; } /* Nested example */ .container { font-weight: 700; /* Bold parent */ } .container .light { font-weight: lighter; /* Becomes 400 */ } .container .light .lighter { font-weight: lighter; /* Becomes 100 */ }

6. Font Files & Weight Support

Understanding Font Variants

Not all fonts support all 9 weight levels. Each weight that should render requires a separate font file.

Common Font Weights by Family

Font Family Available Weights Notes
Georgia 400, 700 Only normal and bold. No intermediate weights.
Arial 400, 700 Limited to basic weights.
Open Sans 300, 400, 500, 600, 700, 800 Modern font with many options.
Roboto 100, 300, 400, 500, 700, 900 Comprehensive weight support.
Lora 400, 500, 600, 700 Good variety for body and headers.

Defining Multiple Weights with @font-face

/* Define each weight separately */ @font-face { font-family: 'CustomFont'; src: url('customfont-light.woff2') format('woff2'); font-weight: 300; } @font-face { font-family: 'CustomFont'; src: url('customfont-regular.woff2') format('woff2'); font-weight: 400; } @font-face { font-family: 'CustomFont'; src: url('customfont-bold.woff2') format('woff2'); font-weight: 700; } /* Now use in CSS */ body { font-family: 'CustomFont'; font-weight: 400; } strong { font-family: 'CustomFont'; font-weight: 700; }
Important: If a font weight is requested but not defined in @font-face, the browser will attempt to synthesize (fake) it, which looks poor. Always define the weights you plan to use.

7. Performance Considerations

Loading Impact

✅ Better Performance

  • System fonts (instant)
  • Limit to 2-3 weights max
  • Use common weights (400, 700)
  • Lazy load extra weights
  • Use WOFF2 format

❌ Slower Performance

  • Loading all 9 weights
  • Multiple font variants
  • Large file sizes
  • Unoptimized font formats
  • Blocking font loads

Optimization Tips

/* 1. Load only necessary weights */ @import url('https://fonts.googleapis.com/css2?family=Open+Sans:wght@400;600;700&display=swap'); /* 2. Preload critical weights */ <link rel="preload" as="font" href="opensans-700.woff2" crossorigin> /* 3. Use font-display: swap */ @font-face { font-family: 'CustomFont'; src: url('font.woff2') format('woff2'); font-display: swap; /* Show fallback immediately */ } /* 4. Avoid synthesized weights */ strong { font-weight: 700; } /* Use actual font file */ /* DON'T do this: */ strong { font-weight: 600; } /* If 600 not defined, browser fakes it */

8. Readability & Accessibility

Best Practices for Readable Typography

  • ✅ Body text: 400 (normal) - most readable default
  • ✅ Headings: 600-700 - clear visual hierarchy
  • ✅ Emphasis: 500-600 - not too heavy
  • ✅ Labels: 500-600 - good balance
  • ✅ Captions: 400-500 - appropriate for secondary content
  • ❌ Avoid very light weights (< 300) for body text
  • ❌ Avoid very heavy weights (> 800) for large amounts of text
  • ❌ Don't rely on weight alone for meaning

WCAG Accessibility Guidelines

Font-Weight for Accessibility:
  • Use adequate contrast (4.5:1 minimum for normal text)
  • Heavier weights naturally improve contrast
  • Don't use weight as only indicator of importance
  • Maintain readability with line-height and spacing
  • Test with accessibility tools

9. Common Issues & Solutions

Issue 1: Font Not Getting Bold

/* Problem: Font weight not supported */ body { font-family: Georgia; } strong { font-weight: 700; } /* Georgia only supports 400, 700 */ /* Solution: Check available weights */ /* Use only weights the font supports */ strong { font-weight: bold; } /* Or load extended weight family */ @import url('https://fonts.googleapis.com/css2?family=Roboto:wght@300;400;500;700&display=swap'); body { font-family: Roboto; } strong { font-weight: 700; }

Issue 2: Synthesized Weights Looking Bad

/* Problem: Requesting unsupported weight */ @font-face { font-family: 'MyFont'; src: url('myfont-regular.woff2'); } strong { font-weight: 600; } /* ❌ 600 not defined, browser fakes it */ /* Solution: Define separate font files for each weight */ @font-face { font-family: 'MyFont'; src: url('myfont-regular.woff2'); font-weight: 400; } @font-face { font-family: 'MyFont'; src: url('myfont-semibold.woff2'); font-weight: 600; } strong { font-weight: 600; } /* ✅ Now uses actual font file */

Issue 3: Lighter Keyword Not Working as Expected

/* Problem: Misunderstanding lighter/bolder */ .container { font-weight: 400; /* Parent is normal */ } .container span { font-weight: lighter; /* Becomes 100, too light */ } /* Solution: Use specific weight values */ .container span { font-weight: 300; /* Explicitly light, not too extreme */ }

Issue 4: Cascading Weight Issues

/* Problem: Unexpected weight inheritance */ .container { font-weight: 700; } .container .nested { font-weight: bolder; } /* Becomes 900, too heavy! */ /* Solution: Use explicit weights */ .container { font-weight: 700; } .container .nested { font-weight: 500; } /* Explicit, no surprises */

11. Font-Weight Best Practices

Typography Scale Guidelines

/* Recommended font-weight scale */ :root { --fw-light: 300; /* Light text, secondary info */ --fw-normal: 400; /* Default body text */ --fw-medium: 500; /* Emphasis, labels */ --fw-semibold: 600; /* Subheadings */ --fw-bold: 700; /* Headings, strong emphasis */ } body { font-weight: var(--fw-normal); } h1, h2, h3 { font-weight: var(--fw-bold); } h4, h5, h6 { font-weight: var(--fw-semibold); } strong { font-weight: var(--fw-semibold); } label { font-weight: var(--fw-medium); } small { font-weight: var(--fw-normal); }

Complete Best Practices Checklist

  • ✅ Use 400 for body text (default/normal)
  • ✅ Use 600-700 for headings
  • ✅ Use 500-600 for emphasis and labels
  • ✅ Load only weights you actually use
  • ✅ Define separate @font-face rules for each weight
  • ✅ Never rely on font weight as the only indicator
  • ✅ Test on multiple browsers and devices
  • ✅ Use variable fonts for flexibility
  • ✅ Optimize font loading with font-display
  • ✅ Maintain adequate line-height with heavier weights
  • ❌ Don't use font-weight for semantic meaning (use <strong>, <b> tags)
  • ❌ Don't load all 9 weights
  • ❌ Don't use very light (< 300) for body text
  • ❌ Don't rely on synthesized weights
  • ❌ Don't forget to test readability

12. Variable Fonts (Advanced)

What Are Variable Fonts?

Variable fonts support a continuous range of weights (and other properties) in a single file, reducing the number of HTTP requests and file sizes.

Using Variable Fonts

/* Import variable font */ @import url('https://fonts.googleapis.com/css2?family=Open+Sans:wght@300;400;500;600;700&display=swap'); /* Use any weight value */ .light { font-weight: 350; } /* Between 300 and 400 */ .medium { font-weight: 450; } /* Between 400 and 500 */ .semibold { font-weight: 650; } /* Between 600 and 700 */ /* CSS custom properties */ :root { --font-weight: 400; } body { font-weight: var(--font-weight); } @media (prefers-contrast: more) { :root { --font-weight: 600; /* Heavier for high contrast preference */ } }
Variable Font Benefits:
  • Single file supports all weights
  • Smaller total file size
  • Smooth weight transitions
  • Responsive typography options
  • Better performance
