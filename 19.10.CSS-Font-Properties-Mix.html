1. Professional Blog Typography

Combining font-family, font-size, font-weight, and font-style for blog content:

The Art of Web Design
A Journey Through Modern Typography

Web design has evolved dramatically over the past decade. Today's designers must understand typography deeply to create engaging and readable experiences. The interplay between font families, sizes, weights, and styles determines how users perceive and interact with content.

Each property serves a distinct purpose: font-family establishes the typeface personality, font-size controls readability, font-weight creates emphasis and hierarchy, and font-style adds nuance and meaning to words.

CSS Code:

/* Title */ .blog-title { font-family: 'Playfair Display', serif; font-size: 2.5em; font-weight: 700; font-style: normal; } /* Subtitle */ .blog-subtitle { font-family: 'Crimson Text', serif; font-size: 1.3em; font-weight: 600; font-style: italic; } /* Body Text */ .blog-body { font-family: 'Crimson Text', serif; font-size: 1.1em; font-weight: 400; font-style: normal; line-height: 1.8; } /* Emphasis */ .blog-body em { font-style: italic; font-weight: 600; } .blog-body strong { font-weight: 600; }

Create beautiful user experiences

4. Technical Documentation

Typography for technical content with code and emphasis:

Getting Started with CSS
Introduction

CSS (Cascading Style Sheets) is used to style and layout web pages. The font-family property specifies the typeface, while font-size controls the text size. Use font-weight for boldness and font-style for italics.

Properties

The six main font properties work together to create complete typography control: font-family, font-size, font-weight, font-style, font-variant, and font-stretch.

CSS Code:

/* Title */ .tech-title { font-family: 'Open Sans', sans-serif; font-size: 2.2em; font-weight: 700; font-style: normal; } /* Section Heading */ .tech-section { font-family: 'Open Sans', sans-serif; font-size: 1.3em; font-weight: 600; font-style: normal; } /* Inline Code */ .tech-code { font-family: 'Courier New', monospace; font-size: 0.95em; font-weight: 400; } /* Body Text */ .tech-text { font-family: 'Open Sans', sans-serif; font-size: 1em; font-weight: 400; font-style: normal; }

8. Font Shorthand Property

The font shorthand combines multiple font properties:

Syntax:

font: [ <font-style> || <font-variant> || <font-weight> ] <font-size> [ / <line-height> ] <font-family>;

Examples:

/* Simple */ font: bold 1.2em Arial, sans-serif; /* Complete */ font: italic bold 1.2em/1.5 'Crimson Text', serif; /* With variant */ font: small-caps 600 1.1em 'Open Sans', sans-serif; /* Professional Blog */ font: italic 600 1.3em/1.6 'Crimson Text', serif; /* Modern UI */ font: 500 0.95em/1.6 'Open Sans', sans-serif; /* Luxury Design */ font: normal 1.15em/1.9 'Playfair Display', serif;
Note: When using the font shorthand, font-size and font-family are required. Other properties can be included in any order before the size. Line-height is optional and comes after font-size.

9. Best Practices for Font Properties

✅ Do's:

  • Use font families that complement each other (serif for body, sans-serif for UI)
  • Maintain consistent font stacks across your project
  • Use font-weight (600-700) for emphasis instead of artificial bolding
  • Combine font-size and line-height for better readability
  • Use font-variant for professional typography (small-caps, ligatures)
  • Use responsive techniques (clamp, media queries) for font properties
  • Test typography across different devices and browsers
  • Use variable fonts for flexible, efficient typography
  • Maintain adequate contrast between font weights for hierarchy
  • Use semantic HTML with appropriate font styling

❌ Don'ts:

  • Don't mix too many font families (limit to 2-3 max)
  • Don't use very light weights (< 300) for body text
  • Don't skip fallback fonts in your font stack
  • Don't use italic for semantic emphasis alone (combine with weight)
  • Don't forget about readability when choosing sizes and weights
  • Don't ignore line-height when setting font-size
  • Don't use extreme font-stretch values excessively
  • Don't forget to test with actual content and users

10. Complete Implementation Template

Ready-to-use CSS template combining all font properties:

/* ========================================== COMPLETE FONT PROPERTY SETUP ========================================== */ /* Import web fonts */ @import url('https://fonts.googleapis.com/css2?family=Playfair+Display:ital,wght@0,400;0,700;1,400;1,700&family=Crimson+Text:ital,wght@0,400;0,600;1,400;1,600&family=Open+Sans:ital,wght@0,300;0,400;0,600;0,700;1,400&display=swap'); /* Base typography */ html { font-family: 'Open Sans', -apple-system, BlinkMacSystemFont, sans-serif; font-size: 16px; line-height: 1.6; } body { font-weight: 400; font-style: normal; color: #333; } /* Headings */ h1 { font: bold 2.5em/1.2 'Playfair Display', serif; } h2 { font: 600 1.8em/1.3 'Playfair Display', serif; } h3 { font: 600 1.3em/1.4 'Open Sans', sans-serif; } /* Body text */ p { font-family: 'Crimson Text', serif; font-size: 1.1em; font-weight: 400; font-style: normal; line-height: 1.8; } /* Emphasis */ strong { font-weight: 600; font-style: normal; } em { font-weight: 400; font-style: italic; } strong em { font-weight: 600; font-style: italic; } /* Advanced features */ blockquote { font-family: 'Crimson Text', serif; font-size: 1.2em; font-weight: 400; font-style: italic; font-variant: small-caps; } code, pre { font-family: 'Courier New', monospace; font-size: 0.9em; font-weight: 400; } /* Responsive */ @media (max-width: 768px) { h1 { font-size: 1.8em; } h2 { font-size: 1.4em; } p { font-size: 1em; } }
