CSS prefers-color-scheme

Complete Guide to Light and Dark Mode Detection

1. What is prefers-color-scheme?

The prefers-color-scheme CSS media query allows you to detect whether the user has requested light or dark mode in their operating system or browser settings, and apply appropriate styles accordingly.

Key Characteristics:

  • Detects user's OS/browser color scheme preference
  • Respects system-level accessibility settings
  • Two possible values: light and dark
  • Works with all modern browsers
  • Can be combined with other media queries
  • Improves user experience and accessibility

Syntax:

@media (prefers-color-scheme: light) {
    /* Styles for light mode */
}

@media (prefers-color-scheme: dark) {
    /* Styles for dark mode */
}
Try it yourself: Change your system or browser color scheme preference and watch this page automatically adapt!

2. color-scheme Meta Tag

Always include the color-scheme meta tag in your HTML to declare which color schemes your site supports:

HTML Setup:

<meta name="color-scheme" content="light dark">

Options:

  • color-scheme: light - Light mode only
  • color-scheme: dark - Dark mode only
  • color-scheme: light dark - Both modes supported (recommended)

CSS Equivalent:

:root {
    color-scheme: light dark;
}
Benefits:
  • Browsers style form controls appropriately
  • Improves default appearance
  • Respects user preferences
  • Reduces flash of wrong colors on page load

3. Basic Implementation

Simple Light/Dark Mode:

/* Light mode (default) */
:root {
    --bg-color: #ffffff;
    --text-color: #333333;
    --accent-color: #667eea;
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
    :root {
        --bg-color: #1e1e1e;
        --text-color: #e0e0e0;
        --accent-color: #bb86fc;
    }
}

body {
    background-color: var(--bg-color);
    color: var(--text-color);
}

Background Images:

    background-image: url('light-bg.jpg');

/* Dark mode background */
@media (prefers-color-scheme: dark) {
    .hero {
        background-image: url('dark-bg.jpg');
    }

SVG Colors:

<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="var(--accent-primary)" />
</svg>

Image Filters:

/* Brighten dark images in dark mode */
@media (prefers-color-scheme: dark) {
    img {
        filter: brightness(0.9) contrast(1.1);
    }
}
Consider: Some images may need version-specific adjustments rather than filters for best quality.

9. Shadows and Elevation

Adaptive Shadow Colors:

:root {
    --shadow: rgba(0, 0, 0, 0.1);
    --shadow-hover: rgba(0, 0, 0, 0.15);
    --shadow-active: rgba(0, 0, 0, 0.2);
}

@media (prefers-color-scheme: dark) {
    :root {
        --shadow: rgba(0, 0, 0, 0.3);
        --shadow-hover: rgba(0, 0, 0, 0.4);
        --shadow-active: rgba(0, 0, 0, 0.5);
    }
}

Using Shadows:

.card {
    box-shadow: 0 2px 8px var(--shadow);
}

.card:hover {
    box-shadow: 0 5px 20px var(--shadow-hover);
}
Benefits:
  • Shadows appear more/less prominent depending on background
  • Better depth perception in both modes
  • Consistent visual hierarchy

12. Manual Theme Toggle with JavaScript

JavaScript Implementation:

// Check current preference
const isDarkMode = window.matchMedia('(prefers-color-scheme: dark)').matches;

// Listen for changes
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', e => {
    const newColorScheme = e.matches ? 'dark' : 'light';
    document.documentElement.setAttribute('data-theme', newColorScheme);
});

// Set initial theme
const theme = isDarkMode ? 'dark' : 'light';
document.documentElement.setAttribute('data-theme', theme);

CSS with data-theme:

/* Light theme */
html[data-theme="light"] {
    --bg-primary: #ffffff;
    --text-primary: #333333;
}

/* Dark theme */
html[data-theme="dark"] {
    --bg-primary: #1e1e1e;
    --text-primary: #e0e0e0;
}
Important: Always respect system preference first; manual override should be secondary.

13. Combining Media Queries

Dark Mode + High Contrast:

@media (prefers-color-scheme: dark) and (prefers-contrast: more) {
    :root {
        --text-primary: #ffffff;  /* Pure white */
        --bg-primary: #000000;     /* Pure black */
    }
}

Light Mode + Reduced Motion:

@media (prefers-color-scheme: light) and (prefers-reduced-motion: reduce) {
    * {
        animation: none !important;
        transition: none !important;
    }
}

Dark Mode + Forced Colors:

@media (prefers-color-scheme: dark) and (forced-colors: active) {
    button {
        border: 1px solid CanvasText;
        background: Canvas;
        color: CanvasText;
    }
}
Related Media Queries:
  • prefers-reduced-motion - Respect animation preferences
  • prefers-contrast - High contrast mode
  • prefers-reduced-transparency - Reduce transparency
  • forced-colors - Limited color mode

14. Best Practices

✓ Do's:

  • Include color-scheme meta tag in HTML
  • Use CSS variables for color management
  • Test both light and dark modes thoroughly
  • Respect user's OS preference
  • Ensure sufficient contrast in both modes
  • Use smooth transitions between modes
  • Provide adequate fallbacks for old browsers
  • Test with accessibility tools

✗ Don'ts:

  • Don't force one mode on users
  • Don't use low contrast colors
  • Don't ignore the prefers-color-scheme media query
  • Don't forget to test dark mode thoroughly
  • Don't use pure black/white in dark mode (use near-black/near-white)
  • Don't forget about images and icons
  • Don't make transitions too slow

16. Testing Light and Dark Modes

Chrome DevTools:

  • Open DevTools (F12)
  • Press Ctrl+Shift+P (Cmd+Shift+P on Mac)
  • Type "Render" → "Emulate CSS media feature prefers-color-scheme"
  • Select light or dark mode

Firefox:

  • Visit about:config
  • Search for "ui.systemUsesDarkTheme"
  • Change value: 0 (light) or 1 (dark)

Safari:

  • System Preferences → General → Appearance
  • Switch between Light and Dark

Windows 10/11:

  • Settings → Personalization → Colors
  • Choose Light or Dark mode

macOS:

  • System Preferences → General → Appearance
  • Choose Light, Dark, or Auto

  • Use CSS variables for better performance

  • Inline critical CSS for color scheme
  • Use preload for color-scheme specific resources
  • Cache theme preference in localStorage if manually toggling

18. Accessibility with Dark Mode

Contrast Requirements (WCAG):

  • Normal text: 4.5:1 minimum contrast ratio
  • Large text (18pt+): 3:1 minimum contrast ratio
  • UI components: 3:1 minimum

Testing Color Contrast:

  • WebAIM Contrast Checker
  • Chrome DevTools (Accessibility panel)
  • Color Blindness Simulator tools

Design for Accessibility:

  • Don't rely on color alone
  • Use icons and text together
  • Test with colorblindness simulators
  • Ensure keyboard navigation works
  • Provide focus indicators in both modes
  • Test with screen readers

19. Common Issues & Solutions

Issue 1: Colors too similar in dark mode

Solution: Increase contrast when switching to dark mode

Issue 2: Images look bad in dark mode

Solution: Use different image versions or apply filters

Issue 3: Text hard to read after mode switch

Solution: Use better contrast ratios (aim for 7:1 or higher)

Issue 4: Transitions feel jarring

Solution: Add smooth CSS transitions with appropriate timing

Issue 5: Form controls look inconsistent

Solution: Use standard form styling with proper color-scheme support

Testing: Always test in both light and dark modes across browsers!
