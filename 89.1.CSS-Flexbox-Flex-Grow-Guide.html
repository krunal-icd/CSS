📈 CSS Flexbox Flex-Grow Tutorial

Master proportional space distribution among flex items

What is Flex-Grow?

The flex-grow property determines how much a flex item will grow relative to other flex items when there is extra space in the flex container. It controls how remaining space is distributed.

Default value is 0, meaning items don't grow. Any value above 0 enables growth. The ratio between flex-grow values determines the proportion of available space each item receives.

💡 Key Point: Flex-grow ONLY grows items. It doesn't shrink them. Use flex-shrink to control shrinking behavior.
/* Basic Syntax - Applied to individual flex items */ .flex-item { flex-grow: 1; /* Item will grow equally with others */ } /* Default value */ .flex-item-default { flex-grow: 0; /* Item doesn't grow */ }

How Flex-Grow Distribution Works

Distribution Formula: Available Space = Container Width - Sum of All Item Base Widths Item Growth = (Item's flex-grow / Total flex-grow) × Available Space Final Item Width = Base Width + Item Growth

Example Calculation:

Container width: 400px Item base widths: 50px + 50px + 50px = 150px Available space: 400px - 150px = 250px Item 1: flex-grow: 1 Item 2: flex-grow: 1 Item 3: flex-grow: 2 Total flex-grow: 1 + 1 + 2 = 4 Item 1 growth: (1/4) × 250px = 62.5px → Final width: 112.5px Item 2 growth: (1/4) × 250px = 62.5px → Final width: 112.5px Item 3 growth: (2/4) × 250px = 125px → Final width: 175px

Flex-Grow Property Values

Value Description Example
0 Default - item doesn't grow flex-grow: 0
1 Item grows equally with others having flex-grow: 1 flex-grow: 1
2, 3, 4... Item grows proportionally (2x faster than flex-grow: 1) flex-grow: 2
0.5 Item grows slower than flex-grow: 1 flex-grow: 0.5

Common Layout Patterns with Flex-Grow

🎨 Equal Width Columns

.column { flex-grow: 1; /* All columns grow equally */ } /* Result: 3 columns of equal width */

🎨 Sidebar + Main Content

.sidebar { flex-grow: 0; /* Fixed width */ flex-basis: 250px; } .main { flex-grow: 1; /* Takes remaining space */ }

🎨 Proportional Layout

.left { flex-grow: 1; /* 33% of space */ } .center { flex-grow: 1; /* 33% of space */ } .right { flex-grow: 2; /* 67% of space (2x) */ }

🎨 Navbar with Expanding Space

.nav-item { flex-grow: 0; /* Fixed size items */ } .spacer { flex-grow: 1; /* Expands to push items apart */ }

Important Tips & Best Practices

✓ Flex-Grow Ratios Matter: Values are ratios, not absolute pixels. 1 vs 2 creates a 1:2 proportion.
✓ Need Flex-Basis First: Set flex-basis (or width/min-width) to define item's starting size before growth.
⚠ Flex-Grow Only Expands: It cannot shrink items. Use flex-shrink for that behavior.
✓ Use Shorthand: flex: 1 is shorthand for flex: 1 1 0
⚠ Browser Rounding: Final widths may be off by 1-2px due to browser rounding. This is normal.
✓ Zero Flex-Basis: Use flex-basis: 0 when you want flex-grow to be the only size factor.
✓ Fractional Values: You can use decimal values like 0.5, 1.5, 2.5 for finer control.

Real-World Use Cases

📊 Dashboard Grid: Widgets grow to fill available space equally
📝 Form Layout: Input fields flex to fill width while labels stay fixed
🎯 Navigation Bar: Nav items fixed, spacer grows to push items apart
📄 Page Layout: Sidebar fixed, content area grows to fill remaining space
🏆 Result Cards: Featured card grows 2x while others grow equally

Browser Support

The flex-grow property is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.item { flex-grow: 1; /* No vendor prefixes needed for modern browsers */ }
