What is text-orientation?

The text-orientation CSS property specifies the orientation of text characters in vertical writing modes. It controls whether characters are rotated, upright, or mixed when text flows vertically. This property is essential for supporting non-Latin scripts and creating vertical layouts in East Asian typography.

Core Concepts:

  • Controls character orientation in vertical writing mode
  • Works with writing-mode property
  • Values: mixed, upright, sideways, sideways-right
  • Essential for CJK (Chinese, Japanese, Korean) text
  • Affects layout and readability of vertical text
  • Typically used with writing-mode: vertical-*
Browser Support: Modern browsers (Chrome 48+, Firefox 41+, Safari 13.1+, Edge 79+). Excellent support for international typography.

Property Values

mixed (Default)

Most characters upright (in their normal orientation) but rotates certain characters:

element { writing-mode: vertical-rl; text-orientation: mixed; /* Default value */ } /* Result: Most text is upright, numbers and Latin letters rotate 90° */

upright

All characters display upright (in their normal horizontal orientation):

element { writing-mode: vertical-rl; text-orientation: upright; } /* Result: All text appears upright, may require rotation when viewed */

sideways

All text rotates 90 degrees counterclockwise (sideways left):

element { writing-mode: vertical-rl; text-orientation: sideways; } /* Result: Text flows horizontally but reads from right to left */

sideways-right

Text rotates 90 degrees clockwise (non-standard, rarely used):

element { writing-mode: vertical-rl; text-orientation: sideways-right; } /* Result: Text rotates clockwise, less common */

Complete Example with writing-mode

/* Vertical text with mixed orientation */ .vertical-text { writing-mode: vertical-rl; /* Right-to-left vertical */ text-orientation: mixed; /* Mixed character orientation */ height: 200px; } /* Alternative vertical modes */ .vertical-lr { writing-mode: vertical-lr; /* Left-to-right vertical */ text-orientation: upright; } .horizontal-rtl { writing-mode: horizontal-tb; /* Horizontal (default) */ text-orientation: upright; /* No effect in horizontal mode */ }

Interaction with writing-mode

Understanding writing-mode First

The text-orientation property only works with vertical writing modes:

/* Vertical writing modes */ writing-mode: vertical-rl; /* Right to left, vertical */ writing-mode: vertical-lr; /* Left to right, vertical */ /* Horizontal writing modes (text-orientation has no effect) */ writing-mode: horizontal-tb; /* Default: left to right, horizontal */ writing-mode: horizontal-lr; /* Synonym for horizontal-tb */ /* Legacy (avoided) */ writing-mode: tb-rl; /* Top-to-bottom, right-to-left */

Combined Properties

/* Complete vertical text setup */ .cjk-vertical { writing-mode: vertical-rl; text-orientation: mixed; /* Default for mixed script */ direction: rtl; /* Right-to-left reading */ } /* East Asian typography */ .japanese-vertical { writing-mode: vertical-rl; text-orientation: mixed; /* Japanese standard */ font-family: 'Hiragino Kaku Gothic', 'Yu Gothic', sans-serif; } /* Upright characters (requires specific fonts) */ .upright-vertical { writing-mode: vertical-lr; text-orientation: upright; letter-spacing: 0.1em; }
Combinations

Real-World Use Cases

CJK Typography

Traditional vertical text for Chinese, Japanese, Korean:

.cjk-text { writing-mode: vertical-rl; text-orientation: mixed; height: 300px; padding: 20px; }
CJK

Table Headers

Vertical text for narrow table column headers:

th { writing-mode: vertical-rl; text-orientation: mixed; padding: 10px; width: 30px; }
Tables

Rotated Labels

Sideways text for rotated labels and annotations:

.rotated-label { writing-mode: vertical-rl; text-orientation: sideways; transform: rotate(180deg); }
Labels

Artistic Layouts

Creative vertical text for design purposes:

.artistic-text { writing-mode: vertical-lr; text-orientation: mixed; font-size: 2em; letter-spacing: 0.2em; }
Design

Mixed Scripts

Handling mixed Latin and CJK characters:

.mixed-script { writing-mode: vertical-rl; text-orientation: mixed; /* Latin rotates, CJK upright */ font-family: 'Noto Serif CJK', serif; }
Scripts

Responsive Text

Vertical text that adapts to layout:

@media (max-width: 768px) { .adaptive-text { writing-mode: horizontal-tb; text-orientation: upright; /* No effect but explicit */ } }
Responsive

text-orientation Values Reference

Value Description Character Rotation Use Case
mixed Default orientation mixing Upright + rotated CJK text, standard vertical
upright All characters upright 0° (normal) Special upright fonts
sideways Rotates counterclockwise -90° (left) Sideways text, labels
sideways-right Rotates clockwise +90° (right) Rare, non-standard

Best Practices

✓ DO:

  • Use appropriate writing-mode: vertical-rl or vertical-lr for CJK text
  • Use mixed for CJK: Most natural for East Asian typography
  • Test with appropriate fonts: Some orientations require specific fonts
  • Consider readability: Vertical text may be challenging for some users
  • Use for CJK content: Primary purpose of this property
  • Provide alternatives: Horizontal fallback for accessibility
  • Test across browsers: Support varies for mixed/upright values

✗ DON'T:

  • Use on horizontal text: Has no effect, ineffective
  • Overuse sideways: Difficult to read, use sparingly
  • Ignore writing-mode: Must be set to vertical first
  • Forget accessibility: Vertical text may cause issues
  • Mix too many orientations: Confusing and hard to read
  • Use for layout tricks: Use transform for rotation instead
  • Assume universal support: Some orientations have limited support

Key Takeaways

  • Vertical Text Only: text-orientation only works with vertical writing modes
  • Four Values: mixed (default), upright, sideways, sideways-right
  • CJK Primary Use: Essential for Chinese, Japanese, Korean typography
  • Works with writing-mode: Must combine with vertical-rl or vertical-lr
  • mixed is Standard: Default and most common for natural CJK text
  • Font Support Matters: Some orientations require specific fonts
  • Accessibility Important: Consider readability and alternatives
  • Modern Browser Support: Excellent across Chrome, Firefox, Edge
