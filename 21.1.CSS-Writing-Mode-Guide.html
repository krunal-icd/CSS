Introduction to Elementor

Elementor is a powerful WordPress page builder that allows you to create professional, responsive websites without writing code. It provides a drag-and-drop interface with extensive customization options, including CSS writing modes for advanced text orientation and layout control.

💡 What is Elementor?

Elementor enables users to design beautiful websites using a visual editor with real-time preview capabilities. It supports multiple languages and right-to-left (RTL) layouts through CSS Writing Mode properties.

Key Features

  • Drag-and-drop page builder
  • Real-time editing with live preview
  • Responsive design templates
  • Advanced CSS styling options
  • Writing mode support for RTL and vertical text
  • Mobile optimization tools
  • Template library
  • Custom code integration

Installation Steps

Understanding CSS Writing Modes

The CSS writing-mode property defines how text flows in your layout. This is particularly useful for:

  • Supporting right-to-left (RTL) languages like Arabic, Hebrew, and Persian
  • Creating vertical text for artistic designs
  • Building international websites with language-specific layouts
  • Implementing Asian typography (Chinese, Japanese, Korean)

Writing Mode Values

Value Description Use Case
horizontal-tb Default: left-to-right, top-to-bottom English, Spanish, and most Western languages
vertical-rl Vertical text, right-to-left flow Traditional Chinese, Japanese, Korean
vertical-lr Vertical text, left-to-right flow Mongolian, some Asian languages
sideways-rl Text rotated 90° clockwise from vertical-rl Artistic designs, modern layouts
sideways-lr Text rotated 90° clockwise from vertical-lr Creative typography effects

Related CSS Properties

/* Related properties that work with writing-mode */ .element { writing-mode: vertical-rl; direction: rtl; /* Left-to-right or right-to-left */ text-orientation: mixed; /* How letters are oriented */ }

Code Examples

/* Arabic or Hebrew text */ .rtl-text { writing-mode: horizontal-tb; direction: rtl; text-align: right; font-family: 'Arabic Typesetting', 'Microsoft Uighur'; }

Example 2: Vertical Text (Traditional Chinese/Japanese)

/* Traditional Chinese or Japanese vertical text */ .vertical-text { writing-mode: vertical-rl; text-orientation: mixed; height: 300px; width: 100px; }

Example 3: Artistic Sideways Text

/* Creative design element */ .sideways-text { writing-mode: sideways-rl; font-size: 2em; font-weight: bold; color: #667eea; transform: scaleX(-1); }

Example 4: Mixed Orientation (Asian Languages)

/* Numbers and Latin in vertical Asian text */ .mixed-orientation { writing-mode: vertical-rl; text-orientation: mixed; } /* Override for specific elements */ .mixed-orientation em { text-orientation: upright; }

Example 5: Responsive Writing Mode

/* Responsive design with writing mode */ .responsive-text { writing-mode: horizontal-tb; } /* Change to vertical on desktop */ @media (min-width: 768px) { .responsive-text { writing-mode: vertical-lr; } }

Elementor Implementation Guide

Step 1: Install and Activate Elementor

✓ Installation Complete

After activation, you'll see "Elementor" in your WordPress left menu. You can now create pages with Elementor.

Step 2: Create a New Page with Writing Mode

/* In Elementor, add custom CSS to your widget */ .my-section { writing-mode: vertical-rl; padding: 20px; } /* Ensure proper dimensions for vertical text */ .my-section { min-height: 200px; min-width: 80px; }

Step 3: Add Custom CSS to Widgets

  1. Select any widget in Elementor
  2. Go to the "Advanced" tab
  3. Scroll down to "Custom CSS"
  4. Add your writing-mode CSS rules
  5. Update and preview in real-time

Step 4: Test Responsiveness

Use Elementor's responsive editing tools to adjust writing modes for different screen sizes:

/* Mobile first approach */ .text-block { writing-mode: horizontal-tb; /* Mobile */ } /* Tablet and above */ @media (min-width: 1024px) { .text-block { writing-mode: vertical-rl; } }

Step 5: Optimize for Performance

⚠️ Performance Note:

Excessive use of complex CSS properties can impact page load time. Minimize custom CSS and use Elementor's built-in features when possible.

Best Practices

1. Accessibility First

ℹ️ Include Alternative Text:

When using vertical or rotated text, provide clear fallbacks and ensure screen readers can interpret the content correctly.

2. Test Across Browsers

Writing modes are well-supported in modern browsers, but test extensively:

  • Chrome/Edge (Full support)
  • Firefox (Full support)
  • Safari (Full support)
  • Internet Explorer (Limited support)

3. Mobile Optimization

/* Don't force vertical text on small screens */ @media (max-width: 767px) { .vertical-heading { writing-mode: horizontal-tb; } } /* Use vertical on larger screens */ @media (min-width: 768px) { .vertical-heading { writing-mode: vertical-rl; } }

4. Language-Specific Considerations

RTL Languages

Arabic Hebrew Persian

Use direction: rtl with writing-mode: horizontal-tb for proper text flow and alignment.

Vertical Languages

Chinese Japanese Korean

Use writing-mode: vertical-rl or vertical-lr with appropriate text-orientation.

5. Performance Tips

  • Minimize font sizes with extreme writing modes
  • Use system fonts when possible for faster loading
  • Cache your custom CSS
  • Use CSS preprocessors (SASS/LESS) for maintainability
  • Minify custom CSS code

6. Combination Example: RTL + Elementor

/* Complete RTL setup for Arabic content */ body.rtl-layout { direction: rtl; } .rtl-layout .elementor-container { flex-direction: row-reverse; text-align: right; } .rtl-layout .elementor-heading-title { direction: rtl; text-align: right; }

Troubleshooting Common Issues

Issue 1: Writing Mode Not Applied

Problem: Your writing-mode CSS isn't showing up.

Solution:

  • Check that CSS is in the correct widget's "Advanced" → "Custom CSS" section
  • Clear WordPress cache
  • Use browser DevTools to inspect the element
  • Ensure the selector targets the correct element

Issue 2: Text Overflowing Container

/* Fix overflow issues with vertical text */ .vertical-container { writing-mode: vertical-rl; overflow: hidden; text-overflow: ellipsis; word-break: break-word; }

Issue 3: Mobile Display Problems

Quick Fix:

Use Elementor's responsive editing tools to hide or modify writing-mode on mobile devices. Set different CSS rules for each breakpoint.

Issue 4: Font Compatibility

/* Use Google Fonts with language support */ @import url('https://fonts.googleapis.com/css2?family=Noto+Sans+Arabic:wght@400;700'); .arabic-text { font-family: 'Noto Sans Arabic', sans-serif; direction: rtl; }

Issue 5: Browser Compatibility

For older browser support, use fallback CSS:

/* Fallback for older browsers */ .text { writing-mode: horizontal-tb; /* Fallback */ writing-mode: vertical-rl; transform: rotate(180deg); }

Debugging Checklist

  • Open browser DevTools (F12)
  • Inspect the element and verify CSS is applied
  • Check for CSS conflicts from other stylesheets
  • Test with CSS specificity: use !important if necessary
  • Disable all plugins temporarily to identify conflicts
  • Try a different browser to rule out browser-specific issues
