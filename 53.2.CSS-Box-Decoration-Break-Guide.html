CSS Box-Decoration-Break Property

11 Practical Interactive Examples

1. Slice (Default)

Continuous appearance

box-decoration-break: slice
Decorations appear as one continuous box, even when text wraps. This is the default behavior.

This is a long piece of text with slice box-decoration-break that wraps across multiple lines and demonstrates how the background appears continuous.

box-decoration-break: slice;
✓ Natural continuous appearance

2. Clone

Individual line styling

box-decoration-break: clone
Each line of wrapped text gets its own complete set of decorations independently styled.

This is a long piece of text with clone box-decoration-break where each line gets complete styling with padding and background.

box-decoration-break: clone;
⭐ Each line fully decorated

Quick Reference Guide

box-decoration-break: slice - Continuous effect (default)
box-decoration-break: clone - Each fragment styled independently

✓ Use clone for: Highlights, badges, emphasis, inline code
✓ Use slice for: Continuous backgrounds
✓ Include -webkit- prefix for Safari/Chrome
✓ Works with inline elements only (span, a, em, strong, code, etc.)
✓ Applies to: background, border, padding, box-shadow, border-radius
