📱 Example 6: Responsive Cropping

Adjust crop values based on viewport size for optimal display on all devices:

Resize your browser to see different crop values

Responsive Image
Desktop (>768px): object-view-box: inset(10%)
Tablet (≤768px): object-view-box: inset(20%)
Mobile (≤480px): object-view-box: inset(30%)
/* Desktop */ img { object-view-box: inset(10%); } /* Tablet */ @media (max-width: 768px) { img { object-view-box: inset(20%); } } /* Mobile */ @media (max-width: 480px) { img { object-view-box: inset(30%); } }
✨ Advantage: Responsive cropping ensures images remain well-composed and focused on mobile devices while showing more context on larger screens.

When to Use Object-View-Box:

  • Gallery thumbnails: Crop various aspect ratio images to consistent squares
  • Profile avatars: Focus on faces in user profile images
  • Hero sections: Extract the most interesting part of background images
  • Product grids: Create uniform product display regardless of source images
  • Responsive designs: Adjust crops based on viewport size
  • Art direction: Show different versions of same image for different contexts

Best Practices:

  • Always combine with object-fit: Typically use object-fit: cover
  • Use percentages: More flexible than fixed pixel values
  • Test in target browsers: Check browser support before production
  • Start small: Begin with 10-15% crops before trying extreme values
  • Consider mobile: Adjust crops for different viewport sizes
  • Maintain aspect ratios: Avoid distortion by pairing with proper sizing
⚠️ Browser Support Note: While browser support is improving (Chrome 111+, Firefox 121+), always check current support and provide fallbacks for production websites.

💡 Quick Implementation Guide

Step 1: Set Container Dimensions

img { width: 300px; height: 300px; }

Step 2: Add Object-Fit

img { width: 300px; height: 300px; object-fit: cover; }

Step 3: Apply Object-View-Box

img { width: 300px; height: 300px; object-fit: cover; object-view-box: inset(15%); }

Step 4: Optional - Make Responsive

@media (max-width: 768px) { img { object-view-box: inset(25%); } }
✨ Done! Your images are now cropped with precise control using pure CSS.
