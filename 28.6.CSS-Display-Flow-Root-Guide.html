Key Takeaways

  • Use flow-root to establish a Block Formatting Context
  • Prevents margin collapse between parent and children
  • Contains floated elements without height collapse
  • Cleaner than overflow: hidden or clearfix hacks
  • No side effects like overflow might have
  • Perfect for card components and containers
  • Works with text next to floats
  • Enables proper grid-like layouts with floats
  • Modern alternative to legacy workarounds
  • Check browser support (IE11 not supported)
  • Can be combined with other properties
  • No performance impact
