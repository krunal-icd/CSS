CSS Attribute Selectors

Practical Examples & Real-World Use Cases

Input Type Styling

[type=value]

Style different input types with distinct colors and behaviors.

input[type="email"] {
  border-color: #667eea;
  background: #f0f4ff;
}

input[type="password"] {
  border-color: #ff9800;
}

input[type="submit"] {
  background: #4caf50;
  color: white;
}
Use Case: Visual differentiation of form input fields without adding classes.

Required Form Fields

[required]

Highlight form fields that must be filled out.

input[required] {
  border: 2px solid #667eea;
}

input:not([required]) {
  border: 1px solid #ccc;
}
Use Case: Visual indicator for mandatory form fields using HTML attributes.

Disabled State Styling

[disabled]

Style disabled buttons and inputs distinctly from active ones.

button:not([disabled]) {
  background: #667eea;
  color: white;
}

button[disabled] {
  background: #ccc;
  cursor: not-allowed;
  opacity: 0.6;
}
Use Case: Conditional button styling without JavaScript.

Link Protocol Detection

[href^=value]

Style external and internal links differently based on protocol.

HTTPS External Link HTTP External Link Local Page Contact Page
a[href^="https"] {
  background: #4caf50;
}

a[href^="/"] {
  background: #667eea;
}
Use Case: Visual distinction between internal and external navigation.

Download File Types

[href$=value]

Color-code download links based on file extension.

Download PDF Download Excel Download Word Download ZIP
a[href$=".pdf"] {
  background: #f44336;
}

a[href$=".xlsx"] {
  background: #4caf50;
}

a[href$=".zip"] {
  background: #9c27b0;
}
Use Case: Visual file type indicators for downloads without JavaScript.

Facebook Twitter LinkedIn GitHub

  content: "📘 ";
}

a[href*="twitter"]::before {

}

a[href*="github"]::before {

Use Case: Dynamic social media icons without hardcoding.

Form Validation States

:valid/:invalid

Visual feedback for valid and invalid form inputs.

input[required]:valid {
  border-color: #4caf50;
  background: #f1f8f6;
}

input[required]:invalid {
  border-color: #f44336;
  background: #ffebee;
}
Use Case: Real-time form validation feedback using native HTML validation.

Language-Based Styling

[lang|=value]

Style content based on language attributes.

Hello, this is American English.

Hello, this is British English.

Bonjour, c'est du français.

Hallo, das ist Deutsch.

p[lang|="en"] {
  border-left: 4px solid #667eea;
}

p[lang|="fr"] {
  border-left: 4px solid #ff9800;
}

p[lang|="de"] {
  border-left: 4px solid #4caf50;
}
Use Case: Multi-language website styling by language variants.

Tooltip Styling

[title]

Style elements with tooltips differently from those without.

button[title] {
  background: #667eea;
  color: white;
}

button[title]:hover::after {
  content: attr(title);
  position: absolute;
  background: #333;
}
Use Case: Styling elements with help text or accessibility hints.

Input Placeholder Styling

[placeholder]

Style inputs with placeholder text distinctly from those without.

input[placeholder] {
  background: #f9f9f9;
  border: 2px solid #667eea;
}

input[placeholder]::placeholder {
  color: #999;
  font-style: italic;
}
Use Case: Styling text inputs with guidance text.

Case Insensitive Matching

[attr=value i]

Match attributes regardless of capitalization using the i flag.

/* Without i flag - only matches "button" */
input[type="button"] { ... }

/* With i flag - matches all variations */
input[type="button" i] {
  background: #667eea;
  color: white;
}
Use Case: Handling inconsistent or user-generated attribute values.

Attribute Selector Reference

Selector Example What It Matches
[attr] [required] Any element with the attribute
[attr=value] [type="email"] Exact value match
[attr~=value] [class~="active"] Word-based match
[attr|=value] [lang|="en"] Prefix or exact match
[attr^=value] [href^="https"] Starts with
[attr$=value] [src$=".png"] Ends with
[attr*=value] [title*="error"] Contains
[attr operator i] [type="button" i] Case insensitive

Key Takeaways

  • Presence [attr]: Select any element that has the attribute, regardless of value.
  • Exact [attr=value]: Perfect for form input types and exact value matching.
  • Word [attr~=value]: Best for space-separated values like class attributes.
  • Prefix [attr|=value]: Ideal for language codes (en, en-US, en-GB).
  • Starts With [attr^=value]: Great for protocol detection (https, http) or file paths.
  • Ends With [attr$=value]: Perfect for file types (.pdf, .jpg, .zip).
  • Contains [attr*=value]: Powerful for partial matches anywhere in the attribute.
  • Case Insensitive (i): Use when matching user-generated or inconsistent values.
  • Combination: Chain multiple attribute selectors for precise targeting without classes.
  • Performance: Combine with element type (e.g., input[type="email"]) for better specificity.
