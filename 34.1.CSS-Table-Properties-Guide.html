CSS Table Properties Guide

border-collapse Property

Controls whether table borders are collapsed or separate.

Values: collapse | separate | inherit

collapse - Merged Borders

Name Score Grade
Alice 95 A
Bob 87 B
border-collapse: collapse;
border-spacing Property

Sets the distance between borders of adjacent cells (only works with border-collapse: separate).

Values: length | inherit

Separate with 10px Spacing

Product Price Stock
Laptop $999 15
Mouse $25 120
border-collapse: separate; border-spacing: 10px;
empty-cells Property

Controls visibility of borders and background on empty cells.

Values: show | hide | inherit

empty-cells: show

Item Price
Widget $10
$20

empty-cells: hide

Item Price
Widget $10
$20
caption-side Property

Positions the table caption above or below the table.

Values: top | bottom | inherit

Caption Position: Top

Q4 2025 Sales Report
Month Revenue Growth
October $50,000 +12%
November $65,000 +18%
caption { caption-side: top; }
table-layout Property

Controls how the browser calculates table and column widths.

Values: auto | fixed | inherit

table-layout: fixed

Column width is fixed. Long text wraps.

Title (40%) Description (60%)
Product A high-quality premium product with excellent features

table-layout: auto

Width based on content. Columns expand as needed.

Title Description
Product A high-quality premium product with excellent features
table-layout: fixed; /* Faster rendering, fixed column widths */ table-layout: auto; /* Slower rendering, flexible column widths */
vertical-align Property

Aligns content vertically within table cells.

Values: top | middle | bottom | baseline | inherit

Vertical Alignment Examples (80px height)

Top Align Middle Align Bottom Align
Content aligned to the top of the cell Content aligned to the middle of the cell Content aligned to the bottom of the cell
vertical-align: top; /* Aligns to top */ vertical-align: middle; /* Aligns to center */ vertical-align: bottom; /* Aligns to bottom */
