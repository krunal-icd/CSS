CSS Font-Stretch Property

Master condensed, normal, and expanded font widths

1. Introduction to Font-Stretch

The font-stretch property controls the width of text by selecting between condensed, normal, and expanded variants. It enables responsive typography that adapts to different layouts and screen sizes, particularly useful for variable fonts.

Syntax

/* Keyword values */ font-stretch: normal | ultra-condensed | extra-condensed | condensed | semi-condensed | semi-expanded | expanded | extra-expanded | ultra-expanded | inherit; /* Percentage values (0-200%) */ font-stretch: 75%; font-stretch: 100%; font-stretch: 125%; /* Examples */ font-stretch: condensed; font-stretch: 90%; font-stretch: expanded;

Key Points

  • Keyword values: 9 predefined stretches (ultra-condensed to ultra-expanded)
  • Percentage values: 0% to 200% for fine-grained control
  • Requires font support for specific stretch values
  • Essential for responsive typography
  • Works seamlessly with variable fonts
  • Improves space efficiency and readability
  • Can create dynamic layouts
  • Inherited from parent elements by default

Percentage Values

/* Using percentage values for precise control */ font-stretch: 50%; /* Ultra-condensed equivalent */ font-stretch: 75%; /* Condensed equivalent */ font-stretch: 100%; /* Normal (default) */ font-stretch: 125%; /* Expanded equivalent */ font-stretch: 200%; /* Ultra-expanded equivalent */ /* Fine-tuning specific widths */ .headline { font-stretch: 85%; /* Between semi-condensed and condensed */ } .display { font-stretch: 130%; /* Between expanded and extra-expanded */ }
Percentage Precision: Percentage values allow granular control, especially useful with variable fonts. Not all fixed fonts support percentage values—they may round to the nearest supported keyword.

3. Practical Usage Examples

Responsive Headlines

/* Headlines that adapt to viewport size */ h1 { font-family: 'Barlow', sans-serif; font-size: 3em; font-stretch: normal; /* Default on desktop */ } @media (max-width: 768px) { h1 { font-stretch: condensed; /* Narrower on tablet */ font-size: 2em; } } @media (max-width: 480px) { h1 { font-stretch: extra-condensed; /* Extra narrow on mobile */ font-size: 1.5em; } }

Variable Font Responsive Typography

/* Smooth stretch transitions with variable fonts */ h1 { font-family: 'Barlow', sans-serif; font-size: clamp(1.5em, 5vw, 3em); font-stretch: clamp(75%, 5vw - 50px, 100%); /* Scales with viewport */ } /* Dynamic width based on content */ .card { font-size: 1.2em; font-stretch: 100%; } .card:hover { font-stretch: expanded; /* Expand on interaction */ }

Space Optimization

/* Efficient space usage */ .sidebar { font-stretch: semi-condensed; /* Save horizontal space */ } .narrow-column { font-stretch: condensed; /* Very tight space */ } .wide-column { font-stretch: normal; /* Comfortable reading */ } /* Data table with constrained width */ table { font-stretch: semi-condensed; } table strong { font-stretch: normal; /* Restore for emphasis */ }

Visual Hierarchy

/* Create hierarchy with stretch values */ .primary-headline { font-stretch: expanded; /* Most important, widest */ font-size: 2.5em; } .secondary-headline { font-stretch: semi-expanded; /* Secondary emphasis */ font-size: 1.8em; } .tertiary-headline { font-stretch: normal; /* Tertiary level */ font-size: 1.3em; } .body-text { font-stretch: semi-condensed; /* Efficient reading */ font-size: 1em; }

4. Font-Stretch in Responsive Design

Mobile-First Approach

/* Start narrow on mobile */ html { font-family: 'Barlow', sans-serif; } h1 { font-stretch: condensed; /* Mobile: narrow */ font-size: 1.5em; } /* Expand gradually on larger screens */ @media (min-width: 768px) { h1 { font-stretch: semi-condensed; font-size: 2em; } } @media (min-width: 1024px) { h1 { font-stretch: normal; font-size: 2.5em; } } @media (min-width: 1440px) { h1 { font-stretch: expanded; font-size: 3em; } }

Fluid Font-Stretch with clamp()

/* Smooth scaling without media queries */ h1 { font-family: 'Barlow', sans-serif; font-size: clamp(1.5em, 5vw, 3em); /* Font-stretch from condensed (75%) to expanded (125%) */ font-stretch: clamp(75%, 10vw - 30px, 125%); } /* More aggressive condensing on mobile */ .caption { font-size: clamp(0.8em, 2vw, 1em); font-stretch: clamp(50%, 3vw, 100%); /* Ultra-condensed to normal */ } /* Expansion for emphasis */ .highlight { font-size: 1.1em; font-stretch: clamp(100%, 5vw, 150%); /* Normal to extra-expanded */ }

Container Queries (Modern Approach)

/* Stretch based on container width */ @container (max-width: 300px) { .headline { font-stretch: ultra-condensed; } } @container (max-width: 500px) { .headline { font-stretch: condensed; } } @container (max-width: 800px) { .headline { font-stretch: semi-condensed; } } @container (min-width: 800px) { .headline { font-stretch: normal; } }

5. Font-Stretch with Variable Fonts

Why Variable Fonts Matter

Variable fonts include a continuous range of stretch values, enabling smooth transitions and fine-tuned typography without loading multiple font files.

Variable Font Setup

/* Import variable font with width axis */ @import url('https://fonts.googleapis.com/css2?family=Barlow:wdth@75;100&display=swap'); /* Or use variable font from CDN */ @font-face { font-family: 'MyFont'; src: url('myfont-variable.woff2') format('woff2-variations'); } /* Use any stretch value with variable fonts */ h1 { font-family: 'Barlow', sans-serif; font-stretch: 85%; /* Precise value - works smoothly */ } .headline { font-family: 'Barlow', sans-serif; font-stretch: 110%; /* Any value between 75% and 100%+ */ }

Dynamic Stretch with Variable Fonts

/* Smooth animation with variable fonts */ .text { font-family: 'Barlow', sans-serif; font-stretch: 100%; transition: font-stretch 0.3s ease; } .text:hover { font-stretch: 130%; /* Smooth expansion on hover */ } /* Responsive stretch with viewport width */ h1 { font-family: 'Barlow', sans-serif; font-size: clamp(1.5em, 5vw, 3em); /* Scale stretch from 75% (mobile) to 120% (desktop) */ font-stretch: clamp(75%, 20vw, 120%); } /* Multi-axis variable font control */ .premium-text { font-family: 'Barlow', sans-serif; font-weight: 600; font-stretch: 110%; /* Combine with weight axis */ font-size: 1.2em; }
Variable Font Benefits:
  • Single file replaces multiple font weights and widths
  • Smooth transitions between stretch values
  • Precise pixel-perfect control
  • Reduced file size and HTTP requests
  • Responsive typography at scale

Fallback Behavior

8. Font-Stretch Best Practices

Implementation Guidelines

  • ✅ Use for responsive typography on variable fonts
  • ✅ Combine with font-size for visual hierarchy
  • ✅ Test font support before implementation
  • ✅ Use clamp() for smooth scaling
  • ✅ Provide fallbacks for unsupported fonts
  • ✅ Use @supports for feature detection
  • ✅ Limit stretch range for readability (75%-125%)
  • ✅ Document stretch values in design systems
  • ✅ Test across browsers and devices
  • ✅ Consider performance with animations
  • ❌ Don't overuse extreme values (ultra-condensed, ultra-expanded)
  • ❌ Don't use stretch on small text
  • ❌ Don't forget fallback fonts
  • ❌ Don't animate stretch excessively
  • ❌ Don't ignore readability for design

Recommended Font-Stretch Strategy

/* Complete implementation pattern */ :root { --font-family: 'Barlow', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif; } body { font-family: var(--font-family); font-stretch: normal; } /* Responsive hierarchy with stretch */ h1 { font-size: clamp(1.5em, 5vw, 3em); font-stretch: clamp(75%, 10vw - 50px, 100%); font-weight: 700; } h2 { font-size: clamp(1.25em, 4vw, 2em); font-stretch: clamp(87.5%, 8vw - 40px, 100%); font-weight: 600; } h3 { font-size: clamp(1.1em, 3vw, 1.5em); font-stretch: clamp(100%, 5vw - 30px, 112.5%); font-weight: 600; } /* Narrow sidebar */ .sidebar { font-stretch: semi-condensed; } /* Space-constrained table */ table { font-stretch: condensed; } /* Feature detection fallback */ @supports not (font-stretch: condensed) { h1 { font-size: 0.95em; } h2 { font-size: 0.92em; } .sidebar { letter-spacing: -0.02em; } }

9. Common Issues & Solutions

Issue 1: Font-Stretch Not Working

/* Problem: Font doesn't support stretch */ h1 { font-family: Arial, sans-serif; font-stretch: condensed; /* No effect - Arial doesn't support it */ } /* Solution: Use a font that supports stretch */ h1 { font-family: 'Barlow', Arial, sans-serif; font-stretch: condensed; /* Works with Barlow */ } /* Check support */ @supports (font-stretch: condensed) { h1 { font-stretch: condensed; } }

Issue 2: Percentage Values Not Supported

/* Problem: IE or older browsers don't support percentages */ h1 { font-stretch: 85%; /* Might not work in older browsers */ } /* Solution: Use keywords as fallback */ h1 { font-stretch: semi-condensed; /* Fallback */ font-stretch: 85%; /* Modern browsers use this */ } /* Or detect support */ @supports (font-stretch: 85%) { h1 { font-stretch: 85%; } }

Issue 3: Readability Compromised

/* Problem: Extreme stretch hurts readability */ body { font-stretch: ultra-condensed; /* Too narrow, hard to read */ } /* Solution: Stay within reasonable range */ body { font-stretch: semi-condensed; /* 87.5% - still readable */ } /* Use extreme values only for display */ .headline { font-stretch: ultra-condensed; /* Only for short headlines */ } .body-text { font-stretch: semi-condensed; /* Readable for extended text */ }

Issue 4: Animation Performance

/* Problem: Animating stretch causes reflow */ .text { animation: expand 1s ease-in-out infinite; } @keyframes expand { 0%, 100% { font-stretch: normal; } 50% { font-stretch: expanded; } } /* Causes layout recalculation each frame */ /* Solution: Limit animation usage */ .hover-effect:hover { font-stretch: 110%; transition: font-stretch 0.3s ease; } /* Only animate on interaction */ /* Or use transform instead */ .text { transition: transform 0.3s ease; } .text:hover { transform: scaleX(1.1); /* More performant */ }
