7. Transition Effect Task

transition-property, transition-duration, transition-timing-function, transition-delay alag likhe. Button par hover karo.

  transition-property: background-color, transform;
  transition-duration: 0.4s;
  transition-timing-function: ease-in-out;
  transition-delay: 0s;
}
.btn:hover {
  background-color: #1d4ed8;
  transform: scale(1.1);
}

9. Keyframe Animation Task

@keyframes bana ke animation-name, animation-duration, animation-iteration-count set kiye.

@keyframes bounce {
  0%   { transform: translateY(0px); }
  50%  { transform: translateY(-18px); }
  100% { transform: translateY(0px); }
}
.box {
  animation-name: bounce;
  animation-duration: 1.2s;
  animation-iteration-count: infinite;
  animation-timing-function: ease-in-out;
}

13. Box-sizing Task

}

15. CSS Combinators Task

Descendant, child (>), adjacent sibling (+), general sibling (~) selectors practice kiye.

Descendant + direct child paragraph (blue, bold)

A plain descendant span (not styled by these rules)
Anchor element
Adjacent sibling — right after anchor (yellow bg + green border)
General sibling — further away (only green border)
.parent p     { color: #2563eb; }        /* descendant */
.parent > p   { font-weight: 700; }      /* direct child */
.anchor + div { background-color: #fde68a; } /* adjacent sibling */
.anchor ~ div { border-left-width: 4px; border-left-style: solid; border-left-color: #10b981; } /* general sibling */
