Example 2: Perspective Origin (Vanishing Point)

Change the viewer's apparent position using perspective-origin. Each container has different vanishing point.

Center

Viewer at center

Top

Viewer above

Left

Viewer left

Corner

Viewer top-left

CSS Code

.center { perspective-origin: center; } .top { perspective-origin: top; } .left { perspective-origin: left; } .corner { perspective-origin: top left; } .element { transform: rotateX(45deg); }
Effect: Changing perspective-origin shifts where the viewer appears to be positioned, affecting how rotated elements distort.

CSS Code

Technique: translateZ values with perspective create depth layering. Lower values appear further away.

Best Practices Summary

Pattern Perspective Value Use Case
Dramatic 500px Stylized, extreme 3D effects
Standard 1000px Most 3D effects (recommended)
Subtle 1500px Gentle, natural effects
Minimal 2000px+ Barely noticeable 3D

Key Tips

  • ✓ Start with 1000px - adjust based on effect intensity
  • ✓ Apply to container - affects all 3D children consistently
  • ✓ Combine with transform-style: preserve-3d - maintains 3D space
  • ✓ Use perspective-origin - control viewer's apparent position
  • ✓ Test across devices - performance varies by platform
  • ✓ Profile performance - complex 3D scenes can cause jank
