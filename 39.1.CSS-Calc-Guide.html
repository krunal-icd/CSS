🔢 CSS calc() Function

Complete Guide with Practical Examples

What is CSS calc()?

Perform mathematical calculations in CSS values

The CSS calc() function allows you to perform mathematical operations (addition, subtraction, multiplication, and division) directly in CSS property values. It enables dynamic sizing, positioning, and other calculations without JavaScript.

💡 Key Benefits:
  • Dynamic sizing based on multiple units
  • Responsive layouts without JavaScript
  • Mix different units (px, rem, %, vw, etc.)
  • Cleaner, more maintainable code
  • Better browser performance
/* Basic calc() syntax */ width: calc(100% - 20px); padding: calc(1rem + 5px); font-size: calc(1vw + 10px); margin: calc(50% - 100px); /* With CSS variables */ width: calc(100% - var(--sidebar-width)); padding: calc(var(--space-base) * 2);
💡 Syntax Rules: Always include spaces around operators (+, -, *, /). For multiplication and division, spaces are optional but recommended.

Supported Operators

Mathematical operations available in calc()

Operator Description Example Result
+ Addition calc(100% + 20px) Full width plus 20px
- Subtraction calc(100% - 20px) Full width minus 20px
* Multiplication calc(10px * 3) 30px
/ Division calc(100% / 3) One-third width
/* Addition - combining units */ width: calc(50% + 10px); padding: calc(1rem + 5px); /* Subtraction - reducing space */ width: calc(100% - 20px); height: calc(100vh - 60px); /* Multiplication - scaling values */ margin: calc(10px * 2); font-size: calc(1rem * 1.5); /* Division - creating proportions */ width: calc(100% / 3); column-width: calc(100% / 4); /* Complex expressions */ width: calc((100% - 20px) / 3); padding: calc(1rem + 5px * 2);
⚠️ Important: For multiplication and division, at least one operand must be a number (unitless). You cannot multiply two percentages or divide percentages by percentages.

/* Common unit combinations */ /* Percentage minus pixels */ .sidebar { width: calc(100% - 300px); } /* Viewport minus fixed pixels */ .fullscreen { height: calc(100vh - 60px); } /* Relative unit scaled */ .large-text { font-size: calc(1.5rem + 5px); } /* CSS variables with units */ .box { width: calc(var(--base-size) * 2 - 10px); }
💡 Addition/Subtraction Rule: When adding or subtracting, operands must be compatible (same or convertible units). Multiplication/division are more flexible.

Operator Precedence & Nesting

Order of operations and complex calculations

Order of operations Parentheses Precedence

Correct Order

/* Multiply first, then add */ width: calc(100% + 10px * 2); /* Equals: 100% + 20px */ /* Use parentheses for clarity */ width: calc((100% + 10px) * 2); /* Equals: (100% + 10px) * 2 */

Operator Precedence

/* * and / have higher precedence */ calc(10px + 5px * 2) = 20px calc(10 + 5 * 2) = 20 (not 30) /* Use parentheses to override */ calc((10px + 5px) * 2) = 30px calc((10 + 5) * 2) = 30
/* Complex nested calculations */ /* Responsive padding: 5% + min fixed amount */ padding: calc(5% + 10px); /* Three-column layout */ width: calc((100% - 40px) / 3); /* (100% minus gaps) divided by 3 columns */ /* Fluid font size */ font-size: calc(1rem + 2vw); /* Base size plus viewport-relative scaling */ /* Dynamic margin based on multiple factors */ margin: calc(var(--base) * 2 - 20px + 1vh);
💡 Precedence Rules:
  • * and / are evaluated before + and -
  • Use parentheses to clarify intent
  • Spaces around + and - are required
  • Spaces around * and / are optional

🎯 Practical Use Cases

Real-world applications of calc()

1. Responsive Layout with Fixed Sidebar

/* Sidebar is 300px, content takes remaining space */ .container { display: flex; } .sidebar { width: 300px; flex-shrink: 0; } .content { width: calc(100% - 300px); overflow: hidden; } /* Responsive: sidebar collapses on mobile */ @media (max-width: 768px) { .sidebar { width: 80px; } .content { width: calc(100% - 80px); } }

2. Full-Height Layout with Fixed Header

header { height: 60px; } main { height: calc(100vh - 60px); overflow-y: auto; } footer { height: 40px; } /* Sticky footer with dynamic content area */ .app { display: flex; flex-direction: column; height: 100vh; } .content { flex: 1; overflow-y: auto; height: calc(100vh - 60px - 40px); /* header - footer */ }

3. Three-Column Grid with Gaps

.grid { display: grid; grid-template-columns: repeat(3, calc((100% - 40px) / 3)); gap: 20px; /* 3 gaps of 20px each = 40px */ padding: 20px; } /* Responsive: 2 columns on tablet, 1 on mobile */ @media (max-width: 900px) { .grid { grid-template-columns: repeat(2, calc((100% - 20px) / 2)); gap: 10px; } } @media (max-width: 600px) { .grid { grid-template-columns: 1fr; } }

4. Fluid Typography

/* Font size scales with viewport */ h1 { font-size: calc(1rem + 2vw); /* Minimum: 1rem, scales with viewport */ } .large-text { font-size: calc(1rem + 1.5vw); } .body-text { font-size: calc(0.95rem + 0.5vw); } /* With min/max for clamping */ h1 { font-size: clamp(1.5rem, calc(1rem + 2vw), 3rem); }

5. Dynamic Padding/Margin

/* Responsive padding that scales */ .section { padding: calc(2rem + 5vw); /* Base padding + responsive scaling */ } .container { padding: calc(var(--space-base) * 2); margin: calc(var(--space-base) - 10px); } /* Aspect ratio with calc */ .video-container { width: 100%; padding-bottom: calc(100% * 9 / 16); /* 16:9 ratio */ position: relative; } .video-container iframe { position: absolute; top: 0; left: 0; width: 100%; height: 100%; }

6. Centered Box with Max Width

.centered-box { width: calc(100% - 40px); max-width: 1200px; margin: 0 auto; padding: 20px; } /* Responsive margins */ .card { width: calc(100% - 4rem); margin: 0 auto; max-width: 600px; } @media (max-width: 600px) { .card { width: calc(100% - 2rem); } }

calc() with CSS Variables

Powerful combination of features

CSS Variables Dynamic Maintainable
:root { --space-base: 1rem; --space-lg: 2rem; --sidebar-width: 300px; --header-height: 60px; } /* Use with calc() */ .container { width: calc(100% - var(--sidebar-width)); } .main { height: calc(100vh - var(--header-height)); } .section { padding: calc(var(--space-base) * 2); margin: calc(var(--space-base) + 10px); } /* Dynamic calculations */ .grid { grid-template-columns: repeat(3, calc((100% - var(--space-lg) * 2) / 3)); gap: var(--space-lg); } /* Update all sizes by changing variables */ @media (max-width: 768px) { :root { --sidebar-width: 80px; --space-lg: 1rem; } }
💡 Best Practice: Combine calc() with CSS variables for maximum flexibility. Change a variable once and all calculations update automatically.

✨ Best Practices & Tips

Guidelines for using calc() effectively

1. Always Use Spaces

Include spaces around + and - operators. Spaces around * and / are optional but recommended for readability.

2. Mix Compatible Units

For addition/subtraction, units must be compatible (% and px, em and px, etc.). For multiplication/division, be flexible.

3. Use Parentheses

Use parentheses to clarify complex calculations and ensure correct order of operations.

4. Combine with CSS Variables

Use calc() with CSS variables for maintainable, dynamic sizing throughout your stylesheet.

5. Provide Fallbacks

For IE11 support, provide a fallback value before the calc() declaration.

6. Test Edge Cases

Test calculations on different screen sizes and browsers to ensure they work as expected.

7. Consider Performance

Simple calculations have minimal performance impact. Complex nested calc() may be slightly slower, but generally negligible.

8. Avoid Nesting Too Deep

Keep calculations readable. Very deep nesting makes code hard to understand and maintain.

/* ===== BEST PRACTICES EXAMPLE ===== */ :root { --space: 1rem; --gap: 20px; } /* Provide fallback for IE11 */ .responsive-box { width: 90%; /* Fallback */ width: calc(100% - 20px); } /* Use calc() with variables */ .section { padding: calc(var(--space) * 2); margin: calc(var(--space) + 10px); } /* Complex calculation with clarity */ .grid { grid-template-columns: repeat( 3, calc((100% - (var(--gap) * 2)) / 3) ); gap: var(--gap); } /* Responsive adjustments */ @media (max-width: 768px) { .grid { grid-template-columns: repeat(2, calc((100% - var(--gap)) / 2)); } }
