CSS Text-Align Complete Guide

Master all text alignment properties with practical examples

What is text-align?

The text-align CSS property sets the horizontal alignment of inline or inline-block content within a block container. It's one of the most fundamental properties for controlling text layout on web pages.

This guide covers all possible text-align values, real-world use cases, and best practices for implementing text alignment in your projects.

Quick Reference

  1. left - Align text to the left
  2. right - Align text to the right
  3. center - Center text horizontally
  4. justify - Stretch text to fill container
  5. start - Align to start of text direction
  6. end - Align to end of text direction
  7. match-parent - Match parent's alignment
  8. RTL Text Alignment - Right-to-left languages
  9. Responsive Alignment - Mobile-friendly text
  10. Vertical Alignment - Text positioning

1text-align: left

Standard left alignment

This text is aligned to the left. This is the default alignment for most web content and is the most common choice for body text and paragraphs.

CSS:
.container {
  text-align: left;
}

2text-align: right

Right alignment

This text is aligned to the right. Use this for quotes, captions, or when designing for right-to-left languages.

CSS:
.container {
  text-align: right;
}

3text-align: center

Center alignment

This text is centered. Perfect for headings, titles, and call-to-action buttons.

CSS:
.container {
  text-align: center;
}

4text-align: justify

Justified alignment

This text is justified, meaning it stretches to fill the entire width of the container. Justified text aligns both the left and right margins. This creates a clean, formal look commonly seen in print publications and magazines.

CSS:
.container {
  text-align: justify;
}

5text-align: start

Start direction alignment

This text aligns to the start of the text direction. For LTR (left-to-right) it's left, for RTL (right-to-left) it's right.

CSS:
.container {
  text-align: start;
}

6text-align: end

End direction alignment

This text aligns to the end of the text direction. For LTR it's right, for RTL it's left. Best for multilingual sites.

CSS:
.container {
  text-align: end;
}

8text-align: match-parent

Inherit parent alignment

This text matches its parent's alignment (center). Useful for nested elements.

CSS:
.child {
  text-align: match-parent;
}

Advanced Text Alignment Techniques

1. Text-Align with Flexbox

While text-align doesn't affect flex items, you can achieve similar effects with justify-content:

CSS:
.flex-container {
  display: flex;
  justify-content: center; /* Centers flex items */
}

2. Text-Align with CSS Grid

Grid offers justify-items and place-items for horizontal alignment:

CSS:
.grid-container {
  display: grid;
  place-items: center; /* Centers both horizontally and vertically */
}

3. Text-Align with Justify-Content

For inline elements, you can use text-align. For block elements, use margin: auto with width:

CSS:
.center-block {
  margin-left: auto;
  margin-right: auto;
  width: fit-content;
}

4. Vertical Text Alignment

The vertical-align property works only on inline or table-cell elements:

CSS:
.inline-text {
  display: inline-block;
  vertical-align: middle;
  height: 100px;
}

5. Justify with Text-Align-Last

Control alignment of the last line in justified text:

CSS:
p {
  text-align: justify;
  text-align-last: center; /* Last line is centered */
}

🌐 Browser Support

Basic Values (left, right, center, justify): All browsers

Modern Values (start, end, match-parent): Chrome 27+, Firefox 43+, Safari 16+

Text-Align-Last: Chrome 35+, Firefox 49+, Safari 16+

Vertical-Align: All browsers (inline/table-cell only)

💡 Best Practices & Tips

  • Readability First: Left-aligned text is easiest to read. Use other alignments sparingly for emphasis.
  • Justified Text Warning: Justified text can create large gaps between words. Use hyphens: auto and word-break: break-word to improve appearance.
  • Mobile Responsiveness: Consider changing text alignment on mobile devices. Center or left-align for better mobile UX.
  • RTL Languages: Use dir="rtl" in HTML and direction: rtl in CSS for Arabic, Hebrew, etc.
  • Use start/end: Prefer start and end for multilingual sites for automatic direction handling.
  • Consistency: Maintain consistent text alignment throughout your design for a professional look.
  • Context Matters: Headlines are often centered or right-aligned, body text is usually left-aligned.
  • Performance: Text alignment doesn't impact performance, but excessive justify can affect rendering on mobile devices.

Common Use Cases

🎯 Headings & Titles

Center-align for emphasis and visual hierarchy. Creates a focal point on the page.

📄 Body Text

Left-align for optimal readability. The natural reading direction for LTR languages.

💬 Testimonials & Quotes

Center or right-align for distinction. Makes quotes stand out from regular text.

📚 Magazine/Print Layout

Justify for professional appearance. Create balanced, uniform columns.

🔘 Buttons & CTAs

Center-align for prominence. Draws user attention and encourages action.

🌍 Multilingual Sites

Use start/end values for automatic RTL/LTR handling.
