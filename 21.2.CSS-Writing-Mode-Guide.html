7. Practice Exercises

Exercise 1: Create a Vertical Book Title

Challenge:

Create vertical text that looks like a book spine. Use writing-mode: vertical-rl and add a border to make it look like a book cover.

<div class="book-spine">My Book Title</div> .book-spine { writing-mode: vertical-rl; border-right: 3px solid #333; padding: 20px; height: 300px; background: linear-gradient(135deg, #667eea 0%, #764ba2 100%); color: white; font-weight: bold; }
✓ Try it! You can implement this in your Elementor page using a Text widget with custom CSS.

Exercise 2: RTL Form Layout

Challenge:

Create a contact form that works in both LTR and RTL modes. Make sure labels and inputs align correctly.

.form-rtl { direction: rtl; text-align: right; } .form-rtl label { display: block; text-align: right; margin-bottom: 8px; } .form-rtl input { width: 100%; text-align: right; padding: 10px; }
✓ Try it! Test with Arabic or Hebrew text to see the RTL layout in action.

Exercise 3: Mixed Language Layout

Challenge:

Create a layout that displays content in multiple languages with correct text direction for each.

.multilingual { display: grid; grid-template-columns: 1fr 1fr; gap: 20px; } .ltr-section { direction: ltr; text-align: left; } .rtl-section { direction: rtl; text-align: right; border-right: 2px solid #667eea; }
✓ Try it! Add English on the left and Arabic on the right with proper styling.

Exercise 4: Vertical Navigation Menu

Challenge:

Design a vertical navigation sidebar using writing-mode for menu items.

.nav-vertical { display: flex; flex-direction: column; background: #333; width: 80px; } .nav-item { writing-mode: vertical-rl; color: white; padding: 20px; text-align: center; cursor: pointer; transition: background 0.3s; } .nav-item:hover { background: #667eea; }
✓ Try it! This creates a modern sidebar navigation with vertical text.

Exercise 5: Magazine-Style Column Headers

Challenge:

Create magazine-style article layout with vertical column headers using text-orientation.

.magazine-header { writing-mode: vertical-rl; text-orientation: mixed; font-size: 1.8em; font-weight: bold; color: #667eea; height: 250px; display: flex; align-items: flex-end; } .magazine-content { column-count: 2; column-gap: 20px; }
✓ Try it! Perfect for professional magazine layouts in Elementor.

8. Best Practices & Tips

✓ Do's:

  • Use writing-mode for authentic multilingual content
  • Test vertical text on actual target devices
  • Combine writing-mode with direction property for RTL support
  • Use text-orientation to fine-tune character placement
  • Provide sufficient height/width for vertical text containers
  • Test accessibility with screen readers
  • Use CSS media queries for responsive vertical text

✗ Don'ts:

  • Don't use writing-mode for design gimmicks only
  • Don't forget to test browser compatibility
  • Don't mix LTR and RTL without clear separation
  • Don't use vertical text for long content passages
  • Don't ignore font support for specific languages
  • Don't make text too small in vertical orientation

💡 Pro Tips:

  • Combine writing-mode with CSS Grid for powerful layouts
  • Use writing-mode with animations for dynamic effects
  • Apply gradients and shadows to vertical text for visual interest
  • Use Elementor custom CSS for easy implementation
  • Test with actual user content in target languages
  • Document your CSS for team collaboration
