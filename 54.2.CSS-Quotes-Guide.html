CSS Quotes Property

Practical Examples & Real-World Use Cases

Basic English Quotes

Standard

Default English quotation marks for primary and nested quotes.

She said, I love CSS quotes for managing punctuation.

q {
quotes: '"' '"' "'" "'";
}

q::before { content: open-quote; }
q::after { content: close-quote; }
Use Case: Default English quotations in articles, blog posts, and web content.

No Quotes

Override

Remove automatic quotation marks entirely for custom styling.

She said, I prefer custom punctuation!

q {
quotes: none;
}

q::before { content: none; }
q::after { content: none; }
Use Case: When you want to style quotes manually or use custom markers.

Key Takeaways

  • Automatic Nesting: CSS quotes automatically alternate between primary and nested quote characters based on nesting depth.
  • Language Support: The quotes property supports proper typographic conventions for multiple languages.
  • Semantic HTML: Works with the <q> element using ::before and ::after pseudo-elements with open-quote and close-quote content.
  • Fallback Behavior: Set quotes: none to prevent automatic insertion and style manually if needed.
  • Browser Support: Excellent support across modern browsers (IE 8+, all current versions).
  • Accessibility: Screen readers respect CSS quotes, making content more accessible when properly marked up.
