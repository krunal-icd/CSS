Practical Examples & Real-World Implementations

1. Featured Item First (order: -1)
Product cards with one featured item. Using order: -1 moves featured card to front without changing HTML.

2. Responsive Layout Reordering
On mobile: Header → Main → Sidebar → Footer (stacked). On desktop: Header spans top, Main left, Sidebar right, Footer spans bottom. Order changes at breakpoint.
/* Mobile (order matters for stacking) */
.header { order: 1; }
.main { order: 2; }
.sidebar { order: 3; }
.footer { order: 4; }

/* Desktop (order still controls visual sequence) */

3. Priority-Based Item Ordering
Items ordered by priority level (high → medium → low) using data attributes. No HTML changes needed to reorder.
.item.priority-high { order: 1; }
.item.priority-medium { order: 2; }
.item.priority-low { order: 3; }

4. Role-Based Reordering (Admin vs User)
Admin-only items display first (order: 0), user items display after (order: 1). Perfect for dynamic UIs.
.item.admin { order: 0; } /* Admins first */
.item.user { order: 1; } /* Users after */

5. Custom Display Sequence

6. Pinned Items Always First
Pinned items always appear first (order: -1), normal items after (order: 1). Common in chat apps, favorites.
.item.pinned { order: -1; } /* Pinned first */
.item.normal { order: 1; } /* Normal after */

9. Active Navigation Item First
Navigation item that's currently active always appears first (order: -1), emphasizing current page.

Common Patterns & Quick Reference

Move One Item to Front:

  • .featured { order: -1; }
  • Perfect for featured items, pinned content, active states

Move One Item to Back:

  • .archived { order: 999; }
  • Good for archived content, less important items

Multiple Priority Levels:

  • .priority-1 { order: 1; }
  • .priority-2 { order: 2; }
  • .priority-3 { order: 3; }

Important Reminders:

  • Order affects VISUAL display only, not accessibility
  • Keep HTML structure semantic and logical
  • Screen readers still read HTML source order
  • Use order for design enhancements, not restructuring
