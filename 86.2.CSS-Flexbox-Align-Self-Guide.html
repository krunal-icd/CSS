Real-world components using align-self for individual item positioning

1️⃣ Navigation Bar - Mixed Alignment

Logo aligns to top, nav centered, button at bottom using individual align-self values.

CSS Code
.navbar { display: flex; align-items: center; height: 70px; } .navbar-logo { align-self: flex-start; /* Logo at top */ } .navbar-nav { align-self: center; /* Nav centered */ } .navbar-button { align-self: flex-end; /* Button at bottom */ }

💡 Key Takeaways

align-self: center - Use when most items should be centered vertically
align-self: flex-start - Use for top-aligned items like icons, images, labels
align-self: flex-end - Use for bottom-aligned items like action buttons, timestamps
align-self: stretch - Use to make individual items fill container height (featured cards)
align-self: baseline - Use for text alignment when items have different font sizes
🎯 Pro Tip: Combine align-self with flex-grow and flex-shrink for advanced layouts
🔧 Common Pattern: Use align-self: flex-start on icons/images, align-self: center on content, align-self: flex-end on actions
📱 Responsive: Override align-self on mobile with @media queries for better mobile layouts
