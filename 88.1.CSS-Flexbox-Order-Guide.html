🔄 CSS Flexbox Order Tutorial

Control the visual order of flex items independently from HTML structure

What is the Order Property?

The order property allows you to reorder flex items visually without changing the HTML structure. It's incredibly powerful for responsive designs where you want different visual layouts on different screen sizes.

By default, all flex items have order: 0. Items are displayed in source order, but you can change this with the order property on individual items.

💡 Key Point: The order property only affects visual display, not the semantic HTML structure. Screen readers and document outline remain based on HTML order.
/* Basic Syntax - Applied to individual flex items */ .flex-item { order: 2; /* Display this item in position 2 */ } /* Default value */ .flex-item-default { order: 0; /* Source order */ }

Order Property Values

Value Description Example
0 Default - items appear in source order order: 0
Positive numbers Move item forward (higher = more forward) order: 1, 2, 3
Negative numbers Move item backward (lower = more backward) order: -1, -2, -3
Integer only Accepts any integer value order: 100, -50

Understanding Order Behavior

📌 Default Behavior (order: 0)

All items default to order: 0, so they appear in their HTML source order.

/* HTML */ <div class="flex"> <div>Item A</div> <div>Item B</div> <div>Item C</div> </div> /* CSS - No explicit order */ .flex { display: flex; } /* Display: A, B, C (source order) */

📌 Ordering Items

Set different order values to change display sequence. Lower values appear first.

.item-1 { order: 3; } /* Display third */ .item-2 { order: 1; } /* Display first */ .item-3 { order: 2; } /* Display second */ /* Display: item-2 (1), item-3 (2), item-1 (3) */

📌 Negative Values

Negative values move items before items with positive or zero values.

.header { order: -1; } /* Display before everything */ .content { order: 0; } /* Default position */ .sidebar { order: 1; } /* Display after */ /* Display order: header (-1), content (0), sidebar (1) */

📌 Items with Same Order

Items with the same order value appear in source order.

.item-1 { order: 1; } /* First among order: 1 */ .item-2 { order: 1; } /* Second (in HTML) */ .item-3 { order: 1; } /* Third (in HTML) */ /* Display: item-1, item-2, item-3 (source order maintained) */

Common Layout Patterns with Order

🎨 Mobile-First Responsive Layout

/* Mobile (default order) */ .header { order: 1; } .sidebar { order: 2; } .content { order: 3; } .footer { order: 4; } @media (min-width: 768px) { /* Desktop - sidebar on left */ .sidebar { order: 1; } .content { order: 2; } }

🎨 Header Always First

.header { order: -1; } /* Always appears first */ .nav { order: 0; } .content { order: 1; } .sidebar { order: 2; } .footer { order: 3; }

🎨 Important Content First

.featured { order: 1; } /* Most important first */ .normal-item { order: 10; } .low-priority { order: 20; } .sidebar { order: 100; } /* Last */

🎨 Reverse Order on Mobile

/* Desktop */ .primary { order: 1; } .secondary { order: 2; } @media (max-width: 480px) { /* Mobile - reverse */ .primary { order: 2; } .secondary { order: 1; } }

Important Tips & Best Practices

✓ Semantic HTML Preserved: Order only affects visual layout. HTML structure and tab order remain the same, preserving accessibility.
✓ Perfect for Responsive: Use order with media queries to rearrange layouts without changing HTML between breakpoints.
⚠ Don't Abuse for Accessibility: Don't reorder content in a way that makes source order confusing for screen readers. Keep logical flow.
✓ Use Consistent Values: Use values with gaps (0, 10, 20, 30) to allow inserting items between later without changing everything.
✓ Integer Values Only: Order accepts only integer values, not decimals or percentages.
⚠ Tab Order Unaffected: Keyboard navigation follows HTML source order, not visual order. This is intentional for accessibility.
✓ Works with Auto Margins: Combine order with margin: auto for advanced positioning control.

Real-World Use Cases

📱 Mobile Navigation: Move navigation to bottom on mobile, top on desktop
🎯 Hero Section: Push hero to top on desktop, below nav on mobile
📋 Dashboard Layout: Prioritize important widgets, move less important to bottom
🛒 E-commerce: Show featured products first, standard items after
📄 Blog Layout: Feature selected post first, chronological order otherwise

Browser Support

The order property is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.item { display: flex; order: 2; /* No vendor prefixes needed */ }
