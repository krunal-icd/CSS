CSS Grid: Building with Rows & Columns

Master grid-template-columns and grid-template-rows for powerful layouts

Understanding Grid Structure

CSS Grid is built on a system of rows and columns. Every grid layout starts with defining how many rows and columns you want, and how large they should be. The two fundamental properties are:

  • grid-template-columns - Defines the number and size of columns
  • grid-template-rows - Defines the number and size of rows

These properties are the foundation of every grid layout. Understanding how to use them effectively is key to creating powerful, responsive designs.

grid-template-columns Basics

1. Fixed Width Columns

Define columns with specific pixel values:

.grid {
    display: grid;

4. repeat() Function

Create repetitive patterns efficiently:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);      /* Same as: 1fr 1fr 1fr */
    grid-template-columns: repeat(4, 200px);    /* 4 columns of 200px each */
    grid-template-columns: repeat(2, 1fr 2fr);  /* Pattern repeats: 1fr 2fr 1fr 2fr */
}

grid-column Property

Make an item span multiple columns:

.item {

Named Grid Areas (grid-template-areas)

Creating Semantic Layouts

Use named areas for readable, maintainable grid layouts:

.grid-container {
    display: grid;
    grid-template-columns: 1fr 2fr 2fr;
    grid-template-rows: auto 1fr auto;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

Responsive Named Areas

/* Desktop */
.grid {
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

/* Mobile */
@media (max-width: 768px) {
    .grid {
        grid-template-areas:
            "header"
            "sidebar"
            "main"
            "footer";
    }
}

Explicit vs Implicit Grid

Explicit Grid

You define the grid structure using grid-template-columns and grid-template-rows:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 3 columns defined */
    grid-template-rows: repeat(2, 100px);   /* 2 rows defined */
}

Implicit Grid

Additional items beyond your defined grid create implicit rows/columns:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);  /* 3 columns defined */
    /* 2 rows defined, but more items = implicit rows created */
    grid-auto-rows: 100px;  /* Size of implicitly created rows */
}

Real-World Examples

Example 1: Magazine Layout

.magazine {
    display: grid;
    grid-template-columns: 2fr 1fr;
    grid-template-rows: 250px 1fr;
    gap: 20px;
}

.featured { grid-column: 1 / 2; grid-row: 1; }
.articles { grid-column: 1 / 2; grid-row: 2; }
.sidebar { grid-column: 2; grid-row: 1 / 3; }

Example 2: Dashboard Layout

.dashboard {
    display: grid;
    grid-template-columns: repeat(4, 1fr);
    grid-template-rows: auto auto 1fr;
    gap: 20px;
    grid-template-areas:
        "header header header header"
        "stats stats stats stats"
        "chart1 chart1 chart2 chart2";
}

Example 3: Asymmetric Layout

.layout {
    display: grid;
    grid-template-columns: 100px 1fr 200px;
    grid-template-rows: 60px 1fr 40px;
}

.sidebar { grid-column: 1; grid-row: 2; }
.main { grid-column: 2; grid-row: 1 / 3; }
.rightbar { grid-column: 3; grid-row: 2; }

Complete Properties Reference

Container Properties

Property Values Purpose
grid-template-columns px, %, fr, auto, repeat(), minmax() Define column sizes and count
grid-template-rows px, %, fr, auto, repeat(), minmax() Define row sizes and count
gap / grid-gap Length value Space between rows and columns
row-gap Length value Space between rows only
column-gap Length value Space between columns only
grid-auto-rows px, %, fr, auto, minmax() Size of implicit rows
grid-auto-columns px, %, fr, auto, minmax() Size of implicit columns
grid-auto-flow row, column, dense How items fill the grid
grid-template-areas String literals Define named grid areas

Item Properties

Property Values Purpose
grid-column number / span number Specify column placement and span
grid-row number / span number Specify row placement and span
grid-area Named area / line numbers Assign item to named area

Best Practices & Tips

Do's ✓

  • Use fr units for responsive, proportional layouts
  • Use minmax() with auto-fit/auto-fill for responsive grids
  • Use grid-template-areas for semantic, readable code
  • Combine rows and columns thoughtfully—don't over-grid
  • Test your layouts at different screen sizes
  • Use gap instead of margin for cleaner spacing

Don'ts ✗

  • Don't hardcode pixel widths for responsive layouts
  • Don't nest grids unnecessarily—sometimes Flexbox is better
  • Don't forget about grid-auto-rows for implicit rows
  • Don't use complex spanning without clear purpose
  • Don't ignore browser DevTools—use the Grid Inspector

Column & Row Units Comparison

Pixel Values (px)

Fixed, absolute sizes that don't adapt to container

grid-template-columns: 200px 300px 150px;

Best for: Sidebars, fixed headers/footers

Fractional Units (fr)

Relative sizes that adapt to container width

grid-template-columns: 1fr 2fr 1fr;

Best for: Responsive layouts, proportional columns

Percentage (%)

Percentage of container width (less flexible than fr)

grid-template-columns: 25% 50% 25%;

Best for: When you need exact proportions

Auto

Size based on content, or remaining space

grid-template-columns: auto 1fr auto;

Best for: Content-driven sizing
