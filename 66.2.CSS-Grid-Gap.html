4. Form Layout - Balanced Gap

Two-column form with moderate gap between fields (gap: 25px)

.form-grid { display: grid; grid-template-columns: repeat(2, 1fr); gap: 25px; /* Balanced spacing between fields */ } .form-group.full { grid-column: 1 / -1; /* Full width for email */ }
Demo: Contact Form with 25px Gap
Use Case: Forms need enough gap to visually separate fields, improving readability and reducing errors. 25px provides clear field grouping.

.stats-grid { display: grid; grid-template-columns: repeat(4, 1fr); row-gap: 20px; /* More vertical space */ column-gap: 15px; /* Tighter horizontal space */ }

8. Responsive Gap with CSS Variables

Same grid adapts spacing based on screen size (8px mobile, 15px tablet, 25px desktop)

:root { --gap-mobile: 8px; --gap-tablet: 15px; --gap-desktop: 25px; } .responsive-grid { gap: var(--gap-desktop); } @media (max-width: 1024px) { .responsive-grid { gap: var(--gap-tablet); } } @media (max-width: 768px) { .responsive-grid { gap: var(--gap-mobile); } }

9. Nested Grids - Independent Gap

Parent grid (30px) contains items with their own child grids (8px)

.outer-grid { gap: 30px; /* Large spacing between outer items */ } .inner-grid { gap: 8px; /* Tight spacing for inner items */ }
