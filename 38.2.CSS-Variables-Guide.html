✨ Best Practices & Patterns

Guidelines for using CSS variables effectively

1. Define in :root

Put global design tokens in :root. Accessible to entire document. Perfect for colors, spacing, shadows.

2. Use Consistent Naming

Use kebab-case and semantic names: --primary-color, --space-lg, --shadow-md. Makes code self-documenting.

3. Component-Level Overrides

Define component-specific variables in component selector. Override global defaults when needed.

4. Leverage Calc()

Combine variables with calc() for responsive sizing: calc(var(--base) * 2) for calculated values.

5. Theme Switching

Use class-based themes to switch CSS variable values. Perfect for light/dark/custom themes.

6. Responsive Variables

Change variable values in media queries. Single media query can affect entire design system globally.

7. Provide Fallbacks

Always use fallback values: var(--color, #333). Helps with progressive enhancement and debugging.

8. Document Your System

Create a style guide showing all available variables. Helps team members understand and use them correctly.
