1️⃣ Mobile-First Responsive Layout

Desktop: Header, sidebar left, content right. Mobile: Vertical stack with reordering.

CSS Code
/* Mobile (default) */ .responsive-layout { display: flex; flex-direction: column; } .header { order: 1; } .sidebar { order: 2; } .content { order: 3; } .footer { order: 4; } /* Desktop */ @media (min-width: 768px) { .responsive-layout { flex-direction: row; flex-wrap: wrap; } .header { order: 1; flex-basis: 100%; } .sidebar { order: 2; flex: 0 0 200px; } .content { order: 3; flex: 1; } .footer { order: 4; flex-basis: 100%; } }

3️⃣ Featured Product First - order: -1

Featured product appears first with larger size, despite HTML order.

CSS Code
.product-card { flex: 0 1 calc(25% - 15px); } .product-card.featured { order: -1; /* Display first */ flex: 0 1 calc(50% - 10px); }

5️⃣ Article with Reorderable Sidebar

Desktop: 2-column. Mobile: Sidebar moves below content.

CSS Code
.article-layout { display: flex; } .article-main { order: 1; flex: 2; } .article-sidebar { order: 2; flex: 1; } @media (max-width: 768px) { .article-layout { flex-direction: column; } }

Understanding Flexbox Order

The order property is a powerful tool for creating responsive layouts without changing your HTML structure. It allows you to visually reorder flex items based on screen size and design requirements.

CSS Code

💡 Key Takeaways

Responsive Layouts: Use order with media queries to change layout at different breakpoints without HTML changes
Priority-Based Display: Use order: -1 for featured items to display them first
Mobile-First: Default HTML order for mobile, reorder for desktop breakpoints
Navigation Reordering: Move auth buttons or menus based on screen size
Dashboard Widgets: Prioritize important metrics with lower order values
Sidebar Movement: Move sidebars below content on mobile, beside on desktop
🎯 Pro Tip: Use order values with gaps (1, 10, 20, 100) to allow insertions without major changes
✅ Remember: Order only affects visual layout. HTML structure and tab order remain unchanged for accessibility
