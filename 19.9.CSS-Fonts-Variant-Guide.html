CSS Font-Variant Property

Master advanced typography with small caps, ligatures, and font features

1. Introduction to Font-Variant

The font-variant property controls advanced OpenType font features like small capitals, ligatures, numerical positioning, and contextual alternates. It provides fine-grained control over how text is displayed beyond basic weight and style.

Syntax

/* Shorthand */ font-variant: normal | small-caps | inherit; /* Extended syntax (CSS Fonts Level 3+) */ font-variant: [ <normal-variant-ligatures> || <normal-variant-discretionary-ligatures> || ... ]; /* Modern approach with individual properties */ font-variant-ligatures: normal | common-ligatures | discretionary-ligatures; font-variant-caps: normal | small-caps | all-small-caps; font-variant-numeric: normal | lining-nums | oldstyle-nums;

Key Properties

  • font-variant-caps - Controls capital letter styling (small caps, petite caps)
  • font-variant-ligatures - Controls ligature usage (fi, fl combinations)
  • font-variant-numeric - Controls number formatting (lining, oldstyle, tabular)
  • font-variant-alternates - Enables alternate character forms
  • font-variant-east-asian - Controls East Asian typography
  • Requires font support for specific features
  • Primarily used for professional typography
  • Greatly improves document quality and readability

2. Font-Variant-Caps: Capital Letter Styling

Understanding Small Caps

Small caps transform lowercase letters into smaller versions of uppercase letters. Commonly used in headlines, acronyms, and professional documents for visual sophistication.

Cap Styling Options

Value Description Use Case
normal Default - no special cap treatment Regular body text
small-caps Lowercase → small uppercase Headlines, acronyms, emphasis
all-small-caps All letters → small uppercase Acronyms, all-caps text
petite-caps Smaller version of small-caps Annotations, fine typography
all-petite-caps All letters → petite caps Detailed documents
unicase Mix of small and large caps Modern design
titling-caps Special capital forms for titles Headlines, titles

CSS Implementation

/* Small caps for headings */ h1, h2, h3 { font-variant-caps: small-caps; } /* All small caps for acronyms */ .acronym { font-variant-caps: all-small-caps; letter-spacing: 0.1em; } /* Petite caps for fine details */ .subtitle { font-variant-caps: petite-caps; font-size: 0.9em; } /* Titling caps for special occasions */ .title { font-variant-caps: titling-caps; font-size: 2em; font-weight: 700; }
Important: Font support varies. Not all fonts include small-caps variants. Test your chosen font to ensure it supports the desired cap style before implementation.

3. Font-Variant-Ligatures: Character Combinations

Understanding Ligatures

Ligatures are special character combinations where two or more letters are merged into a single glyph. Common ligatures include "fi" and "fl". They improve readability and add typographic sophistication.

Types of Ligatures

Type Description Example Recommendation
Common Ligatures Standard combinations: fi, fl, ffi, ffl fi, fl, ffi, ffl ✅ Use widely
Discretionary Ligatures Stylistic combinations: ct, st, f_t ct, st, f_t Use carefully
Historical Ligatures Old-style combinations: ſt, ſh ſt, ſh Use for historic texts
Contextual Ligatures Context-dependent forms Varies Use in display fonts

Ligature Control Values

/* Common ligatures */ font-variant-ligatures: common-ligatures; /* fi, fl, ffi, ffl */ font-variant-ligatures: no-common-ligatures; /* Disable common */ /* Discretionary ligatures */ font-variant-ligatures: discretionary-ligatures; /* Enable */ font-variant-ligatures: no-discretionary-ligatures; /* Disable (default) */ /* Historical ligatures */ font-variant-ligatures: historical-ligatures; /* Enable */ font-variant-ligatures: no-historical-ligatures; /* Disable (default) */ /* Contextual alternates */ font-variant-ligatures: contextual; /* Enable */ font-variant-ligatures: no-contextual; /* Disable */ /* Combined */ font-variant-ligatures: common-ligatures contextual;

4. Font-Variant-Numeric: Number Formatting

Understanding Number Variants

Different number styles serve different purposes. Lining figures work well in tables, while oldstyle figures integrate better with text. Tabular figures aid alignment in financial data.

Numeric Style Options

Value Description Best For
lining-nums All numbers align to baseline Headings, tables, modern design
oldstyle-nums Numbers have varying heights Body text, classic typography
tabular-nums Fixed width for alignment Financial data, columns
proportional-nums Variable width (default) Regular text
diagonal-fractions Diagonal fraction formatting Technical text, fractions
stacked-fractions Stacked fraction formatting Formal documents
ordinal Superscript ordinal forms Lists, rankings

CSS Implementation

/* Body text with oldstyle numbers */ body { font-variant-numeric: oldstyle-nums proportional-nums; } /* Financial tables with tabular lining numbers */ .financial-table { font-variant-numeric: tabular-nums lining-nums; } /* Headings with lining numbers */ h1, h2, h3 { font-variant-numeric: lining-nums; } /* Fractions in technical writing */ .fraction { font-variant-numeric: diagonal-fractions; } /* Ordinal numbers (1st, 2nd, 3rd) */ .ordinal { font-variant-numeric: ordinal; } /* Combined numeric features */ .refined-typography { font-variant-numeric: oldstyle-nums proportional-nums; }
Pro Tip: Use oldstyle-nums with proportional-nums for body text to maintain visual flow. Use lining-nums with tabular-nums for tables and financial data to ensure proper alignment and readability.

5. Font-Variant Shorthand

Using the Shorthand

The font-variant shorthand combines multiple font-variant properties into a single declaration, making code more concise.
/* Using individual properties */ h1 { font-variant-caps: small-caps; font-variant-ligatures: common-ligatures; font-variant-numeric: lining-nums; } /* Using shorthand */ h1 { font-variant: small-caps common-ligatures lining-nums; } /* Common combinations */ /* Enhanced typography */ .refined { font-variant: small-caps common-ligatures discretionary-ligatures oldstyle-nums; } /* Professional document */ .formal { font-variant: all-small-caps common-ligatures oldstyle-nums; } /* Modern minimalist */ .modern { font-variant: small-caps common-ligatures lining-nums; } /* Reset to normal */ .normal-text { font-variant: normal; }

7. Font Support & Requirements

OpenType Features

Font-variant properties rely on OpenType features embedded in the font file. Not all fonts support all features. Choose fonts that support the specific features you need.

Popular Fonts with Feature Support

Font Small Caps Ligatures Numeric Variants Best For
Crimson Text ✅ ✅ ✅ Typography, publishing
EB Garamond ✅ ✅ ✅ Classic elegance
Libre Baskerville ✅ ✅ ✅ Professional documents
Playfair Display ✅ ✅ Limited Headlines, display
Georgia ❌ Limited Limited Web-safe fallback

Checking Font Features

/* Check if font supports features before using */ @supports (font-variant-numeric: oldstyle-nums) { body { font-variant-numeric: oldstyle-nums; } } /* Fallback for unsupported features */ body { font-family: Georgia, serif; font-variant-numeric: oldstyle-nums; /* Will be ignored if unsupported */ } /* Only apply on capable devices */ @media (color-gamut: srgb) { h1 { font-variant: small-caps common-ligatures; } }
Tip: Google Fonts, Adobe Fonts, and Typekit offer fonts with excellent OpenType feature support. Check feature support before selecting a font for your project.

9. Font-Variant Best Practices

Implementation Guidelines

  • ✅ Test font support before implementation
  • ✅ Use small-caps for acronyms and headings
  • ✅ Enable common ligatures for body text
  • ✅ Use oldstyle-nums with proportional widths in body text
  • ✅ Use lining-nums with tabular widths in tables
  • ✅ Provide fallbacks for unsupported browsers
  • ✅ Use @supports queries for feature detection
  • ✅ Document font feature usage in style guides
  • ✅ Test across different screen sizes
  • ✅ Consider performance impact of extended features
  • ❌ Don't use all features simultaneously
  • ❌ Don't assume all fonts support all features
  • ❌ Don't disable ligatures unless necessary
  • ❌ Don't mix oldstyle and lining numbers inconsistently
  • ❌ Don't use discretionary ligatures in body text

Recommended Font-Variant Strategy

/* Base body text - professional and readable */ body { font-family: 'Crimson Text', Georgia, serif; font-variant-ligatures: common-ligatures; font-variant-numeric: oldstyle-nums proportional-nums; } /* Headings - clear and emphatic */ h1, h2, h3, h4, h5, h6 { font-variant-caps: small-caps; font-variant-numeric: lining-nums; } /* Financial data - aligned and precise */ .financial-data { font-variant-numeric: lining-nums tabular-nums; font-family: 'Courier New', monospace; } /* Citations and references - elegant */ cite, .citation { font-variant-ligatures: common-ligatures discretionary-ligatures; font-style: italic; } /* Acronyms - professional styling */ .acronym { font-variant-caps: all-small-caps; letter-spacing: 0.1em; font-size: 0.85em; } /* Code and technical text - no variants */ code, pre, kbd { font-variant: normal; } /* With feature detection fallback */ @supports (font-variant-numeric: oldstyle-nums) { body { font-variant-numeric: oldstyle-nums proportional-nums; } }

10. Common Issues & Solutions

Issue 1: Small Caps Not Displaying

/* Problem: Font doesn't support small-caps */ h1 { font-variant-caps: small-caps; /* No effect */ } /* Solution: Choose a font that supports small-caps */ h1 { font-family: 'Crimson Text', 'EB Garamond', Georgia, serif; font-variant-caps: small-caps; } /* Or provide fallback styling */ h1 { font-variant-caps: small-caps; text-transform: uppercase; /* Fallback */ font-size: 0.8em; }

Issue 2: Ligatures Making Text Unreadable

/* Problem: Discretionary ligatures too aggressive */ p { font-variant-ligatures: discretionary-ligatures; } /* Solution: Disable discretionary ligatures for body text */ p { font-variant-ligatures: common-ligatures; } /* Use discretionary only for display */ h1, .display { font-variant-ligatures: common-ligatures discretionary-ligatures; }

Issue 3: Numbers Misaligned in Tables

/* Problem: Proportional numbers cause misalignment */ table { font-variant-numeric: oldstyle-nums; } /* Solution: Use tabular numbers for tables */ table { font-variant-numeric: lining-nums tabular-nums; } /* Or use monospace font */ table { font-family: monospace; }

Issue 4: Features Not Working Across Browsers

/* Problem: Inconsistent browser support */ h1 { font-variant-caps: small-caps; } /* Solution: Use feature detection */ @supports (font-variant-caps: small-caps) { h1 { font-variant-caps: small-caps; } } /* Provide fallback */ h1 { text-transform: uppercase; /* Fallback for old browsers */ font-size: 0.75em; }

11. Performance & Optimization

Font-Variant Impact

✅ Minimal Performance Impact

  • CSS-only feature (no additional requests)
  • Processed by font rendering engine
  • No JavaScript required
  • Fast rendering
  • Improves perceived quality

⚠️ Considerations

  • Font files with features are slightly larger
  • Rendering complexity increases
  • Not all browsers support all features
  • Testing required across devices
  • May require fallback fonts

Optimization Tips

/* 1. Use variable fonts for efficient feature delivery */ @font-face { font-family: 'MyFont'; src: url('myfont-variable.woff2') format('woff2-variations'); } /* 2. Lazy load feature fonts */ @media (prefers-reduced-data: no-preference) { body { font-variant: small-caps common-ligatures oldstyle-nums; } } /* 3. Use feature detection to avoid unnecessary requests */ @supports (font-variant-numeric: oldstyle-nums) { body { font-variant-numeric: oldstyle-nums proportional-nums; } } /* 4. Limit feature usage to where it matters */ body { font-variant: normal; /* No features for body text */ } h1, .important { font-variant: small-caps common-ligatures; /* Features only here */ }
