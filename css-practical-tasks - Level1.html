Beginner CSS Practical Tasks

20 examples — only individual (longhand) properties used, no shorthand.

1. Heading Styling

h1 par color, font-size, font-weight, text-align set kiya.

This is a Styled Heading

.heading {
  color: #2c3e50;
  font-size: 28px;
  font-weight: 700;
  text-align: center;
}

2. Paragraph Text Formatting

font-family, font-size, line-height, letter-spacing alag-alag likhe.

This paragraph demonstrates individual font and spacing properties applied without using the font shorthand.

.para {
  font-family: Georgia, serif;
  font-size: 16px;
  line-height: 1.8;
  letter-spacing: 0.5px;
}

19. Overflow Property Task

Chhoti box mein bada text daal ke overflow-y: scroll test kiya.

Yeh ek lamba text hai jo box ki height se zyada hai, isliye scrollbar dikhega jab overflow-y scroll set hota hai.

  width: 160px;
  height: 60px;
  overflow-y: scroll;
}
