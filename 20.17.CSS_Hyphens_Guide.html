📚 Understanding CSS Hyphens

The hyphens property controls how hyphenation is handled when text wraps to multiple lines. It enables automatic language-aware word breaking with hyphens, manual hyphenation point control, or complete hyphenation suppression. Essential for justified text, narrow columns, narrow containers, and professional typography.

What is the Hyphens Property?

Hyphens specifies whether words should be hyphenated when they break across line boundaries. Three main values: none (no hyphenation), manual (only at soft hyphens), and auto (language-aware automatic hyphenation). Requires lang attribute for language-specific behavior.

Key Concept: Hyphens improves text flow in constrained spaces by breaking long words intelligently. Auto hyphenation is language-aware—English breaks differently than German or French.

/* Hyphens Syntax */ hyphens: none; /* No hyphenation (default) */ hyphens: manual; /* Only break at soft hyphens (­) */ hyphens: auto; /* Language-aware auto hyphenation */ /* Vendor Prefixes (for older browsers) */ -webkit-hyphens: auto; /* Safari, older Chrome */ -moz-hyphens: auto; /* Firefox */ -ms-hyphens: auto; /* IE 10+, Edge */ hyphens: auto; /* Standard */ /* Soft Hyphen (manual break point) */ <p>supercalifragilistic­expialidocious</p>
💡 Requirements for Hyphens:
  • lang attribute - MUST be set on element or parent (e.g., lang="en")
  • hyphens: auto - Requires language to be specified
  • Container width - Text must be constrained to trigger wrapping
  • Word-breaking properties - May need overflow-wrap: break-word

🚀 How to Implement Hyphens

Step 1: Set Language Attribute

  1. Add lang to HTML element: <html lang="en"> or specific element
  2. Required for auto hyphenation: Without lang, hyphens: auto won't work
  3. Override per element: Can set different lang on nested elements

Step 2: Set Hyphens Property

  1. For auto hyphenation: hyphens: auto;
  2. For manual control: hyphens: manual;
  3. To disable: hyphens: none;
  4. Include vendor prefixes: -webkit-, -moz-, -ms-
/* Complete Hyphens Implementation */ /* Basic body text with hyphens */ body { lang: en; hyphens: auto; -webkit-hyphens: auto; -moz-hyphens: auto; -ms-hyphens: auto; } /* Language-specific hyphens */ :lang(en) { hyphens: auto; } :lang(de) { hyphens: auto; /* German allows more aggressive breaking */ } :lang(fr) { hyphens: auto; } /* Justified text with hyphens */ .justified { text-align: justify; hyphens: auto; overflow-wrap: break-word; } /* Multi-column with hyphens */ .columns { column-count: 2; column-gap: 2em; hyphens: auto; } /* Accessibility with hyphens */ .accessible-text { hyphens: auto; line-height: 1.8; word-spacing: 0.15em; letter-spacing: 0.05em; } /* Mobile responsive hyphens */ @media (max-width: 600px) { body { hyphens: auto; /* More aggressive on mobile */ } .narrow-column { hyphens: auto; } } /* Manual hyphenation with soft hyphens */ .manual-hyphens { hyphens: manual; } /* No hyphenation for headings */ h1, h2, h3 { hyphens: none; } /* Technical terms - manual only */ .code-reference { hyphens: manual; font-family: monospace; }
💡 Implementation Pro Tips:
  • Always set lang attribute: Required for hyphens: auto to work properly
  • Include vendor prefixes: Use -webkit-, -moz-, -ms- for browser compatibility
  • Test with real content: Hyphenation behavior varies by language and browser
  • Combine with overflow-wrap: For maximum text flow control
  • Use with text-align: justify: Hyphens dramatically improves justified text
  • Apply to container, not inline: Works better on block-level elements
  • Disable for headings: Most headings shouldn't have hyphens
  • Consider performance: Hyphenation calculation can affect rendering
⚠️ Common Mistakes to Avoid:
  • ❌ Using hyphens: auto without lang attribute - won't work
  • ❌ Forgetting vendor prefixes - inconsistent browser support
  • ❌ Applying hyphens to inline elements - behavior may be unpredictable
  • ❌ Using hyphens on navigation/UI - breaks layout and UX
  • ❌ Not testing hyphenation - breaks look different in each browser
  • ❌ Disabling word-break completely - limits hyphenation effectiveness
  • ❌ Using manual hyphens everywhere - labor-intensive and hard to maintain
🔧 Advanced Techniques:
  • Combine hyphens: auto with overflow-wrap: break-word
  • Use :lang() selector for language-specific hyphenation rules
  • Apply different hyphens values to different breakpoints with media queries
  • Use soft hyphens (­) strategically for manual control when needed
  • Consider word-spacing and letter-spacing alongside hyphens
  • Test hyphenation across different fonts - breaking points vary

🔧 Soft Hyphen Reference

What is a Soft Hyphen (­)?

The soft hyphen (HTML: &shy;, Unicode: U+00AD) specifies an optional break point where a word can be hyphenated if needed. It only displays the hyphen if the text actually breaks at that point.

<p> Supercalifragilistic­expialidocious is a very long word. </p> <p> Internationalization­specialization­implementation requires careful placement. </p> <!-- Multiple break points --> <p> Antidis­establish­mentari­anism demonstrates strategic hyphenation. </p> <!-- In code snippets --> <code> very­LongClassNameThatExceedsLineWidth </code>
💡 When to Use Soft Hyphens:
  • Specialized technical terms where auto hyphenation is unreliable
  • Brand names or proper nouns that need controlled breaking
  • Very long compound words in specialized documents
  • URLs or email addresses where breaking must be precise
  • Code snippets with long identifiers
