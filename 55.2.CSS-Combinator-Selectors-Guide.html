Navigation Menu

Child >

Use child combinator to style only direct menu items, not nested submenus.

  • Products
  • Services

    • Development
  • Contact
/* Only direct nav items */
nav > ul > li > a {
  display: block;

}

/* Submenu only shows on hover */
nav > ul > li:hover > ul {

}
Use Case: Prevents submenu styling from affecting main menu items.

CSS-Only Toggle

General ~

Create an interactive toggle without JavaScript using the checkbox hack.

✓ Content is now visible! This is done with CSS using input:checked ~ selector.
/* Hide by default */
input ~ .hidden {
  display: none;
}

/* Show when checked */
input:checked ~ .hidden {
  display: block;
}
Use Case: CSS-only dropdowns, accordions, and toggles without JavaScript.

Combinator Reference Chart

Combinator Example What It Selects
Child (>) div > p Direct <p> children of <div>
Adjacent Sibling (+) h2 + p First <p> immediately after <h2>
General Sibling (~) h2 ~ p All <p> siblings following <h2>
Descendant (space) div p All <p> elements nested in <div>

Key Takeaways

  • Child (>): Best for preventing styles from cascading deeper than intended. More performant than descendant selectors.
  • Adjacent Sibling (+): Perfect for styling elements that immediately follow specific elements (e.g., first paragraph after heading).
  • General Sibling (~): Enables CSS-only interactive patterns like toggles and accordions using the checkbox hack.
  • Descendant (space): The most common combinator. Applies styles to all nested elements, useful for scoped typography.
  • Combination: Chain combinators for powerful, precise selection without adding extra classes.
  • Performance: Child combinators are faster than descendant selectors on large DOMs.
