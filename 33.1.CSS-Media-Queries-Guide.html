What are Media Queries?

Media queries are CSS techniques used to apply different styles for different devices or screen sizes. They allow you to create responsive web designs that work on mobile phones, tablets, laptops, and large desktop displays.

Media queries are a key component of responsive web design and help ensure your website looks great on any device.

Why Use Media Queries?

  • Create responsive layouts that adapt to different screen sizes
  • Improve user experience on mobile devices
  • Reduce bounce rate by ensuring content is readable on all devices
  • Optimize performance by hiding unnecessary content on smaller screens
  • Maintain single codebase instead of separate mobile/desktop sites
💡 Pro Tip: Mobile-first design is a best practice. Start with styles for mobile, then use media queries to enhance for larger screens.

Media Query Syntax

Basic Syntax

CSS
@media (condition) {
    /* CSS rules that apply when condition is true */
}

Media Types

Media Type Description Example
screen Computer screens, tablets, smartphones @media screen
print Printers and print preview @media print
all All media types (default) @media all
speech Screen readers @media speech

Media Features

Media features are specific conditions that define when styles apply:

Feature Description Example
width Viewport width (exact match) @media (width: 768px)
min-width Minimum viewport width @media (min-width: 768px)
max-width Maximum viewport width @media (max-width: 767px)
height Viewport height (exact match) @media (height: 600px)
min-height Minimum viewport height @media (min-height: 600px)
orientation Portrait or landscape @media (orientation: portrait)
aspect-ratio Viewport aspect ratio @media (aspect-ratio: 16/9)
prefers-color-scheme Dark or light mode preference @media (prefers-color-scheme: dark)

Logical Operators

CSS - AND (and)
/* Applies when BOTH conditions are true */
@media (min-width: 768px) and (max-width: 1024px) {
    body { font-size: 16px; }
}
CSS - OR (comma)
/* Applies when ANY condition is true */
@media (max-width: 600px), (orientation: portrait) {
    body { padding: 10px; }
}
CSS - NOT (not)
/* Applies when condition is NOT true */
@media not screen {
    /* Only applies to non-screen devices */
}

Common Breakpoints

Breakpoints are specific widths at which your layout changes to provide an optimized experience for that device size.

Common Media Features in Action

1. Width-Based Queries

CSS
/* Mobile first approach */
body {
    font-size: 14px;
    padding: 10px;
}

/* Tablet and up */
@media (min-width: 768px) {
    body {
        font-size: 16px;
        padding: 20px;
    }
}

/* Desktop and up */
@media (min-width: 1024px) {
    body {
        font-size: 18px;
        padding: 40px;
    }
}

2. Orientation Query

CSS
/* Portrait mode */
@media (orientation: portrait) {
    .content {
        flex-direction: column;
        width: 100%;
    }
}

/* Landscape mode */
@media (orientation: landscape) {
    .content {
        flex-direction: row;
        width: 100%;
    }
}

3. Dark Mode Support

CSS
/* Light mode (default) */
body {
    background: white;
    color: #333;
}

/* Dark mode */
@media (prefers-color-scheme: dark) {
    body {
        background: #1a1a1a;
        color: #e0e0e0;
    }
    
    .card {
        background: #2d2d2d;
        border-color: #444;
    }
}

4. High Contrast Detection

CSS
@media (prefers-contrast: more) {
    body {
        color: #000;
        background: #fff;
        border: 2px solid #000;
    }
}

@media (prefers-contrast: less) {
    body {
        color: #666;
        background: #f5f5f5;
    }
}

5. Reduced Motion

CSS
/* Default: animations enabled */
.element {
    animation: slide 1s ease-in-out;
}

/* For users who prefer reduced motion */
@media (prefers-reduced-motion: reduce) {
    .element {
        animation: none;
        transition: none;
    }
}

6. Device Pixel Ratio (Retina Displays)

CSS
/* Standard displays */
.logo {
    background-image: url('logo.png');
    width: 100px;
    height: 50px;
}

/* High-DPI displays (Retina, 2x+) */
@media (min-device-pixel-ratio: 2),
       (min-resolution: 192dpi) {
    .logo {
        background-image: url('logo@2x.png');
        background-size: 100px 50px;
    }
}

Practical Examples

Example 1: Responsive Navigation

HTML
<nav class="navbar">
    <div class="logo">Logo</div>
    <ul class="nav-menu">
        <li><a href="#">Home</a></li>
        <li><a href="#">About</a></li>
        <li><a href="#">Contact</a></li>
    </ul>
</nav>
CSS
/* Mobile */
.navbar {
    flex-direction: column;
    padding: 10px;
}

.nav-menu {
    flex-direction: column;
    gap: 0;
}

.nav-menu li {
    border-bottom: 1px solid #ddd;
}

/* Tablet and up */
@media (min-width: 768px) {
    .navbar {
        flex-direction: row;
        justify-content: space-between;
        padding: 20px;
    }

    .nav-menu {
        flex-direction: row;
        gap: 20px;
    }

    .nav-menu li {
        border-bottom: none;
    }
}

Example 2: Responsive Grid

CSS
/* Mobile: 1 column */
.grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
}

/* Tablet: 2 columns */
@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
        gap: 20px;
    }
}

/* Desktop: 3 columns */
@media (min-width: 1024px) {
    .grid {
        grid-template-columns: repeat(3, 1fr);
        gap: 25px;
    }
}

/* Large desktop: 4 columns */
@media (min-width: 1440px) {
    .grid {
        grid-template-columns: repeat(4, 1fr);
        gap: 30px;
    }
}

Example 3: Responsive Typography

CSS
/* Mobile */
h1 { font-size: 24px; }
h2 { font-size: 20px; }
p { font-size: 14px; line-height: 1.4; }

/* Tablet */
@media (min-width: 768px) {
    h1 { font-size: 32px; }
    h2 { font-size: 24px; }
    p { font-size: 16px; line-height: 1.6; }
}

/* Desktop */
@media (min-width: 1024px) {
    h1 { font-size: 42px; }
    h2 { font-size: 32px; }
    p { font-size: 18px; line-height: 1.8; }
}

Example 4: Responsive Flexbox

CSS
/* Mobile */
.container {
    display: flex;
    flex-direction: column;
    gap: 10px;
}

.sidebar {
    order: 2;
    width: 100%;
}

.main {
    order: 1;
    width: 100%;
}

/* Desktop */
@media (min-width: 1024px) {
    .container {
        flex-direction: row;
        gap: 20px;
    }

    .sidebar {
        order: 2;
        width: 25%;
    }

    .main {
        order: 1;
        width: 75%;
    }
}

Example 5: Hide/Show Elements

CSS
/* Mobile: Hide desktop menu, show hamburger */
.desktop-menu {
    display: none;
}

.hamburger {
    display: block;
}

/* Desktop: Show desktop menu, hide hamburger */
@media (min-width: 768px) {
    .desktop-menu {
        display: flex;
    }

    .hamburger {
        display: none;
    }
}

Responsive Design Patterns

Pattern 1: Mobile-First Approach

Start with styles for mobile, then enhance for larger screens using min-width queries.

CSS
/* Start with mobile (base styles) */
.container {
    width: 100%;
    padding: 10px;
    font-size: 14px;
}

/* Enhance for tablet */
@media (min-width: 768px) {
    .container {
        width: 750px;
        padding: 20px;
        font-size: 16px;
    }
}

/* Enhance for desktop */
@media (min-width: 1024px) {
    .container {
        width: 960px;
        padding: 30px;
        font-size: 18px;
    }
}
