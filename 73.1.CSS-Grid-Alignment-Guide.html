CSS Grid: Items Alignment Properties

Master justify-items, align-items, justify-self, align-self, and place-* properties

Understanding Grid Alignment Axes
The Two Axes
Inline Axis (Horizontal)

Left to right alignment of items within grid cells.

Properties:

justify-items
justify-self
justify-content
Block Axis (Vertical)

Top to bottom alignment of items within grid cells.

Properties:

align-items
align-self
align-content
Core Concept
Grid Alignment: Controls how items are positioned INSIDE their grid cells. The grid container and items are separate concepts. Grid tracks define the layout structure; alignment properties position items within those tracks.
Key Values (Used in Most Alignment Properties)
/* Most alignment properties accept these values */ start /* Align to start of cell/container */ end /* Align to end of cell/container */ center /* Center within cell/container */ stretch /* Expand to fill cell/container (default) */ baseline /* Align to text baseline */ space-between /* Distribute space between items */ space-around /* Distribute space around items */ space-evenly /* Equal space around all items */
Item-Level Alignment Properties
justify-items (Grid Container)
justify-items: Sets default horizontal alignment for ALL items in the grid. Applied to the grid container. Individual items can override with justify-self.
.grid { display: grid; grid-template-columns: repeat(3, 150px); justify-items: center; /* All items centered horizontally */ }
Values: start, end, center, stretch (default), baseline
align-items (Grid Container)
align-items: Sets default vertical alignment for ALL items in the grid. Applied to the grid container. Individual items can override with align-self.
.grid { display: grid; grid-template-rows: repeat(3, 150px); align-items: center; /* All items centered vertically */ }
Values: start, end, center, stretch (default), baseline
justify-self (Grid Item)
justify-self: Overrides justify-items for a single item. Allows you to align individual items differently from the grid default.
.grid { justify-items: start; /* Default: items at start */ } .grid-item { justify-self: center; /* Override: this item centered */ }
Values: start, end, center, stretch, baseline, auto (inherit from justify-items)
align-self (Grid Item)
align-self: Overrides align-items for a single item. Allows you to align individual items vertically differently from the grid default.
.grid { align-items: start; /* Default: items at start */ } .grid-item { align-self: end; /* Override: this item at end */ }
Values: start, end, center, stretch, baseline, auto (inherit from align-items)
Shorthand Alignment Properties
place-items (Grid Container)
place-items: Shorthand for align-items and justify-items. Format: place-items: align-items justify-items.
.grid { place-items: center; /* Shorthand for align-items: center; justify-items: center; */ } /* Equivalent to: */ .grid { align-items: center; justify-items: center; } /* Different values: */ .grid { place-items: start end; /* align-items: start; justify-items: end; */ }
place-self (Grid Item)
place-self: Shorthand for align-self and justify-self. Format: place-self: align-self justify-self.
.grid-item { place-self: center; /* Shorthand for align-self: center; justify-self: center; */ } /* Different values: */ .grid-item { place-self: end start; /* align-self: end; justify-self: start; */ }
Container-Level Alignment (justify-content & align-content)
justify-content (Grid Container)
justify-content: Aligns the entire grid horizontally within its container. Used when the grid doesn't fill all available space. Different from justify-items which aligns items within cells.
.grid-container { display: grid; grid-template-columns: repeat(3, 100px); /* 300px total */ width: 600px; /* Extra space available */ justify-content: center; /* Grid centered in container */ }
Values: start, end, center, stretch, space-between, space-around, space-evenly
align-content (Grid Container)
align-content: Aligns the entire grid vertically within its container. Used when the grid doesn't fill all available space. Different from align-items which aligns items within cells.
.grid-container { display: grid; grid-template-rows: repeat(2, 100px); /* 200px total */ height: 400px; /* Extra space available */ align-content: center; /* Grid centered in container */ }
Values: start, end, center, stretch, space-between, space-around, space-evenly
Key Difference: Items vs Content
justify-items vs justify-content: ┌─────────────────────────────┐ │ Grid Container (600px) │ │ │ │ [Grid: 300px wide] │ │ ┌─────────┬────────┐ │ │ │ Item 1 │ Item 2 │ │ │ └─────────┴────────┘ │ │ │ └─────────────────────────────┘ justify-items: How items are aligned INSIDE their cells justify-content: How the entire GRID is positioned in the container
Alignment Properties Comparison
Property Level Axis Purpose Common Values
justify-items Container Horizontal Default align items horizontally start, center, end, stretch
align-items Container Vertical Default align items vertically start, center, end, stretch
justify-self Item Horizontal Override horizontal alignment start, center, end, stretch, auto
align-self Item Vertical Override vertical alignment start, center, end, stretch, auto
justify-content Container Horizontal Position entire grid in container start, center, end, space-between, space-around
align-content Container Vertical Position entire grid in container start, center, end, space-between, space-around
place-items Container Both Shorthand for align-items + justify-items center, start, end, stretch
place-self Item Both Shorthand for align-self + justify-self center, start, end, stretch, auto
Real-World Scenarios
Scenario 1: Centered Content Cards
Center all content cards within their cells. Cards should be centered both horizontally and vertically.
.card-grid { display: grid; grid-template-columns: repeat(3, 200px); grid-template-rows: repeat(2, 200px); place-items: center; /* Center all cards */ }
Scenario 2: Stretch Cells (Hero Layout)
Make items stretch to fill all available space in their cells.
.hero-grid { display: grid; grid-template-columns: 1fr; grid-template-rows: 300px; place-items: stretch; /* Items fill entire cell */ }
Scenario 3: Mixed Alignment in Grid
Different items need different alignment. Header and footer centered, sidebar left-aligned, content stretches.
.layout { place-items: center; /* Default center */ } .header { place-self: center; } .sidebar { justify-self: start; align-self: start; } .content { place-self: stretch; } .footer { place-self: center; }
Scenario 4: Centered Grid in Container
Grid is smaller than container. Center the entire grid within the available space.
.wrapper { display: grid; width: 100%; height: 100vh; place-content: center; /* Center grid in wrapper */ } .grid { grid-template-columns: repeat(3, 100px); grid-template-rows: repeat(3, 100px); }
Best Practices & Tips
✓ Do's
  • Use place-items for shorthand: place-items: center is cleaner than justify-items: center; align-items: center;
  • Understand the two axes: Justify = horizontal (inline), Align = vertical (block)
  • Use justify-content for grid positioning: When your grid is smaller than the container
  • Use justify-items for item alignment: When items are smaller than their cells
  • Override with -self properties: Use justify-self/align-self for exceptions
  • Test with different viewport sizes: Alignment behavior changes responsively
  • Combine with grid-template-columns/rows: Make cells explicit sizes for meaningful alignment
✗ Don'ts
  • Don't confuse grid sizing with alignment: Grid-template-* defines track sizes; alignment properties position items within them.
  • Don't use both -content and -items: They work on different scopes; use appropriately
  • Don't rely on stretch with gap: Gap adds space; items may not stretch as expected with large gaps
  • Don't forget auto value: justify-self: auto inherits from justify-items (useful for exceptions)
  • Don't mix alignment with transform: Transform can conflict with alignment; use carefully
Pro Tips
💡 Tip 1: place-content shorthand combines justify-content + align-content for positioning the entire grid in its container.
💡 Tip 2: Use align-items: stretch (default) for full-height items without specifying heights. Perfect for equal-height cards.
💡 Tip 3: Baseline alignment is useful for text-heavy items to align by text baseline across cells.
💡 Tip 4: space-evenly in justify-content/align-content distributes space more evenly than space-around.
💡 Tip 5: Debug alignment issues: Use browser DevTools to see grid lines and cell boundaries clearly.
Quick Reference Chart

Container Properties (Applied to .grid):

  • justify-items: Align ALL items horizontally (default for cells)
  • align-items: Align ALL items vertically (default for cells)
  • justify-content: Position entire grid horizontally
  • align-content: Position entire grid vertically
  • place-items: Shorthand for align-items + justify-items
  • place-content: Shorthand for align-content + justify-content

Item Properties (Applied to .grid > item):

  • justify-self: Override horizontal alignment for one item
  • align-self: Override vertical alignment for one item
  • place-self: Shorthand for align-self + justify-self

Remember:

  • Justify = Horizontal (inline axis)
  • Align = Vertical (block axis)
  • -items = Default for cells / -self = Override for individual item
  • -content = Position entire grid / -items = Position items in cells
