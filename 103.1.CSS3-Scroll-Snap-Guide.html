What are scroll-snap Properties?

CSS scroll-snap properties enable scrollable containers to snap to specific elements or positions after scrolling. They create smooth carousel-like experiences and improve usability by helping users navigate content predictably. Three main properties control snap behavior: scroll-snap-type, scroll-snap-align, and scroll-snap-stop.

Core Concepts:

  • scroll-snap-type - Applied to container, defines snap behavior (direction and strictness)
  • scroll-snap-align - Applied to children, specifies alignment within container
  • scroll-snap-stop - Applied to children, forces scrolling to stop at element
  • Creates touch-friendly carousel experiences without JavaScript
  • Works with scroll-behavior for smooth snapping animations
  • Improves mobile scrolling predictability and accessibility
Browser Support: Modern browsers (Chrome 69+, Firefox 68+, Safari 15+, Edge 79+). Mobile support excellent for native scrolling.

scroll-snap-type Property

Syntax & Values

Applied to the scrollable container to enable snap behavior:

/* Disable snap scrolling (default) */ .container { scroll-snap-type: none; } /* X-axis snapping (horizontal) */ .carousel { scroll-snap-type: x mandatory; /* Must snap */ scroll-snap-type: x proximity; /* Snaps nearby */ } /* Y-axis snapping (vertical) */ .list { scroll-snap-type: y mandatory; /* Vertical mandatory */ scroll-snap-type: y proximity; /* Vertical proximity */ } /* Both axes */ .twodimensional { scroll-snap-type: both mandatory; /* Snap both directions */ scroll-snap-type: both proximity; /* Proximity on both */ } /* With scroll-padding adjustment */ .container { scroll-snap-type: y mandatory; scroll-padding-top: 50px; /* Offset for fixed headers */ }

Mandatory vs Proximity

/* mandatory - Browser MUST snap to nearest snap point */ .carousel { scroll-snap-type: x mandatory; } /* Result: Always snaps, every scroll stops at element */ /* proximity - Browser MAY snap if close to snap point */ .list { scroll-snap-type: y proximity; } /* Result: Snaps only if user scrolls near snap point */
Container

scroll-snap-align Property

Alignment Values

Applied to children, specifies where element aligns in container:

/* snap-align: start | center | end | none */ /* Align to start of container */ .snap-item { scroll-snap-align: start; } /* Align to center of container */ .snap-item { scroll-snap-align: center; } /* Align to end of container */ .snap-item { scroll-snap-align: end; } /* No snap alignment */ .snap-item { scroll-snap-align: none; } /* Two-dimensional alignment */ .snap-item { scroll-snap-align: start center; /* X: start, Y: center */ scroll-snap-align: center end; /* X: center, Y: end */ }

With scroll-snap-type: x mandatory

.carousel { scroll-snap-type: x mandatory; } /* Children snap to different positions */ .item.start { scroll-snap-align: start; /* Left edge of container */ } .item.center { scroll-snap-align: center; /* Center of container */ } .item.end { scroll-snap-align: end; /* Right edge of container */ }
Child Elements

scroll-snap-stop Property

Strictness Control

Determines if scrolling must stop at snap point:

/* normal - May skip snap points during fast scrolling */ .item { scroll-snap-stop: normal; } /* always - Cannot skip, must stop at this snap point */ .item { scroll-snap-stop: always; }

Use Cases

/* Gallery - always stop at each image */ .gallery-item { scroll-snap-type: x mandatory; scroll-snap-stop: always; /* Stops at every image */ scroll-snap-align: center; } /* List - may skip some items */ .list-item { scroll-snap-type: y proximity; scroll-snap-stop: normal; /* Can skip items */ scroll-snap-align: start; }
Child Elements

Complete Example Combinations

Horizontal Carousel

Mandatory snapping to center-aligned items:

.carousel { scroll-snap-type: x mandatory; overflow-x: auto; display: flex; } .carousel-item { scroll-snap-align: center; scroll-snap-stop: always; flex-shrink: 0; width: 100%; }

Full-height image gallery with strict snapping:

.gallery { scroll-snap-type: y mandatory; height: 100vh; overflow-y: auto; } .gallery-image { scroll-snap-align: start; scroll-snap-stop: always; height: 100vh; width: 100%; }

Two-Dimensional Grid

Snap both horizontally and vertically:

Related Properties

scroll-padding

Adjust snap position offset (useful for fixed headers/footers):

/* Add space at top for fixed header */ html { scroll-padding-top: 100px; } .container { scroll-snap-type: y mandatory; scroll-padding: 50px; /* All sides */ } /* Individual sides */ .container { scroll-padding-top: 100px; scroll-padding-bottom: 50px; }

Combining with scroll-behavior

.carousel { scroll-snap-type: x mandatory; scroll-behavior: smooth; /* Smooth animation */ } .item { scroll-snap-align: center; scroll-snap-stop: always; } /* Result: Smooth animation to snap points */

Best Practices

✓ DO:

  • Use mandatory for carousels: Users expect items to snap
  • Use proximity for lists: More flexible scrolling experience
  • Set scroll-snap-stop: always on important items: Ensure key content is visible
  • Combine with scroll-behavior: smooth: Create polished animations
  • Use scroll-padding for fixed headers: Prevent content overlap
  • Test on multiple devices: Mobile experience is different
  • Provide fallback styles: Older browsers won't have snapping

✗ DON'T:

  • Overuse mandatory snapping: Can feel restrictive
  • Set snap-stop: always on every item: Only on critical content
  • Use with heavy JavaScript scrolling: Can conflict and cause jank
  • Forget about touch users: Test on actual mobile devices
  • Create inconsistent snap points: Varying sizes confuse users
  • Snap items that don't fit container: Ensures visibility

Performance Considerations

Performance Tips:

  • Native browser feature: No JavaScript required, better performance than JS carousels
  • Hardware accelerated: Native scrolling uses GPU for smooth animations
  • Minimal CPU usage: Much lighter than JavaScript animation libraries
  • Predictable snapping: Browser handles snapping logic efficiently
  • Touch-optimized: Works seamlessly with native mobile scrolling
  • Battery friendly: Minimal power consumption compared to JS scrolling

Key Takeaways

  • Three Main Properties: scroll-snap-type (container), scroll-snap-align (child), scroll-snap-stop (child)
  • Mandatory vs Proximity: Mandatory always snaps, proximity snaps only when nearby
  • Direction Control: x (horizontal), y (vertical), both (2D)
  • Alignment Options: start, center, end for positioning within container
  • Pure CSS Solution: No JavaScript required for smooth carousel experiences
  • Mobile-Friendly: Excellent native browser support on all modern devices
  • Accessibility: Improves touch navigation and predictable content browsing
  • Performance: Native implementation is faster than JavaScript carousels
