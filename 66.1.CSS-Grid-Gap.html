CSS Grid: Gap Spacing Between Items

Master gap, row-gap, and column-gap properties for perfect spacing

Understanding Gap Properties

The gap property (formerly called grid-gap) is a powerful CSS Grid feature that controls the spacing between grid items. Instead of using margins on individual items, gap provides clean, consistent spacing throughout your entire grid layout.

Why Use Gap Instead of Margin?

  • Consistency: Applies uniform spacing to all items automatically
  • Simplicity: No need to add margin rules to every grid item
  • Flexibility: Separate control over row and column spacing
  • Responsive: Easy to adjust spacing at different breakpoints
  • Container-based: Spacing is defined on the grid container, not items
Note: gap only works on grid and flexbox containers. The older grid-gap property still works but is deprecated in favor of the universal gap property.

Basic gap Property

Single Value - Uniform Spacing

Set the same gap for both rows and columns:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px;  /* 20px gap on all sides */
}

row-gap and column-gap Properties

Different Spacing for Rows and Columns

Use separate properties to control spacing independently:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    row-gap: 30px;
    column-gap: 10px;
}

Gap Units and Values

Supported Units

Gap can use various CSS units:

Unit Example Use Case
Pixels (px) gap: 20px; Fixed, predictable spacing
Relative (rem, em) gap: 1.5rem; Scales with font size
Percentage (%) gap: 5%; Responsive to container
CSS Variables gap: var(--spacing); Dynamic, reusable spacing
Calc gap: calc(1rem + 5px); Calculated values

CSS Variables for Responsive Gap

:root {
    --spacing-small: 10px;
    --spacing-medium: 20px;
    --spacing-large: 40px;
}

.grid {
    display: grid;
    gap: var(--spacing-medium);
}

@media (max-width: 768px) {
    .grid {
        gap: var(--spacing-small);
    }
}

Gap vs Margin: Key Differences

🎯 Using Gap

Pros:

  • Applied to container
  • Uniform spacing
  • No external gaps
  • Cleaner code
  • Easy to adjust

📏 Using Margin

Cons:

  • Applied to items
  • Inconsistent edges
  • Extra margin outside
  • More code
  • Harder to maintain
/* ❌ Using Margin (Extra spacing at edges) */
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
}

.grid-item {
    margin: 10px;  /* Creates extra space on edges */
}

/* ✅ Using Gap (Clean edges) */
.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 10px;  /* Only between items, not on edges */
}

Gap Interaction with Alignment

Gap and justify-items

Gap works independently from alignment properties:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 150px);
    gap: 20px;
    justify-items: center;  /* Gap still applied */
}

Gap and justify-content

Gap is applied first, then content alignment:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 150px);
    gap: 20px;
    justify-content: space-around;  /* Space around all items including gaps */
}
Key Point: Gap creates space between grid tracks, while alignment properties position items within those tracks. They work together, not against each other.

Responsive Gap with Media Queries

Adjust Gap at Different Breakpoints

/* Mobile: Compact spacing */
.grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 10px;
}

/* Tablet: Moderate spacing */
@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(3, 1fr);
        gap: 20px;
    }
}

/* Desktop: Comfortable spacing */
@media (min-width: 1200px) {
    .grid {
        grid-template-columns: repeat(4, 1fr);
        gap: 30px;
    }
}

Gap in Nested Grids

Each grid has its own gap that doesn't affect parent or child grids:

.parent-grid {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 30px;  /* Gap between parent items */
}

.child-grid {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 10px;  /* Gap between child items (independent) */
}

Best Practices for Gap

Do's ✓

  • Use gap instead of margins on grid items
  • Define gap on the grid container, not items
  • Use CSS variables for reusable spacing values
  • Adjust gap at different breakpoints for responsive design
  • Use separate row-gap and column-gap when needed
  • Consider the visual hierarchy when choosing gap size

Don'ts ✗

  • Don't use both gap and margins (creates double spacing)
  • Don't apply gap to non-grid/non-flex elements
  • Don't forget gap doesn't apply to grid edges (only between items)
  • Don't use inconsistent gap values without reason
  • Don't ignore responsive adjustments
