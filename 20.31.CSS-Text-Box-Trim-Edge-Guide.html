CSS text-box-trim & text-box-edge

Complete Guide to Precise Text Box Control

1. What are text-box-trim & text-box-edge?

The text-box-trim and text-box-edge CSS properties allow precise control over the whitespace around text. They define which part of the text line's content area is used for metric calculations and rendering.

Key Characteristics:

  • Control text box boundaries and metrics
  • Remove unwanted whitespace above/below text
  • Improve typographic precision and alignment
  • Enable exact spacing between text elements
  • Part of the CSS Text Module Level 4
  • Still experimental in most browsers

What Problem Do They Solve?

Fonts include built-in whitespace (ascenders, descenders, line-height adjustments). These properties let you trim that whitespace to achieve perfect alignment and spacing.

Basic Syntax:

/* Trim text box */
text-box-trim: none | trim-start | trim-end | trim-both;

/* Define edge metrics */
text-box-edge: leading | text | cap | ex;

/* Combined usage */
h1 {
    text-box-trim: trim-both;
    text-box-edge: cap alphabetic;
}
⚠️ Experimental: These properties are still experimental and not widely supported. Use with caution in production.

2. text-box-trim Values

Available Values:

Value Description Use Case
none No trimming (default) Standard text rendering
trim-start Trim whitespace at start of text Remove top spacing
trim-end Trim whitespace at end of text Remove bottom spacing
trim-both Trim whitespace at both start and end Precise alignment, remove all extra space

3. text-box-edge Values

Understanding text-box-edge:

The text-box-edge property defines which line metrics are used as the reference for the text box edges. It works with text-box-trim to determine what gets trimmed.

Available Keywords:

Keyword Refers To Description
leading Line start First baseline of line
text Text content height Actual glyphs bounding box
cap Cap height Height of capital letters
ex X-height Height of lowercase 'x'

Combining Values:

/* Multiple values for start and end */
text-box-edge: leading text;
text-box-edge: cap alphabetic;
text-box-edge: leading cap;
text-box-edge: ex text;

Example 1: Perfect Heading Alignment

    font-size: 2.5em;
    line-height: 1.2;

Example 5: Label Alignment

    text-box-trim: trim-both;

6. How It Works (Technical Details)

Text Box Metrics:

Each font has built-in metrics that define:

  • Ascender height: How high letters like 'h' go
  • Cap height: Height of capital letters
  • X-height: Height of lowercase 'x'
  • Descender depth: How low letters like 'g' go
  • Line-height: Space allocated per line

Default Behavior:

/* By default, text includes all this space */
element {
    /* Line-height adds: ascender + cap + descender + extra */
    line-height: 1.5;
}

With text-box-trim:

/* Removes the extra whitespace */
element {
    text-box-trim: trim-both;
    text-box-edge: cap alphabetic;
    /* Now only includes capital and lowercase glyphs */
}

9. Best Practices & Tips

✓ Do's:

  • Use @supports for feature detection
  • Provide fallback styles
  • Test with different fonts
  • Combine with line-height adjustments
  • Use cap edge for headings
  • Use text edge for body content
  • Document your choices

✗ Don'ts:

  • Don't rely solely on text-box-trim yet
  • Don't use without fallbacks
  • Don't assume all browsers support it
  • Don't use trim-both carelessly
  • Don't ignore font metric differences
  • Don't use in production without testing
