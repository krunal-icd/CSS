Complete Example: Basic Flip Card

HTML Structure

<div class="flip-card"> <div class="flip-card-inner"> <div class="flip-card-front">Front</div> <div class="flip-card-back">Back</div> </div> </div>

CSS Implementation

.flip-card { width: 200px; height: 200px; cursor: pointer; perspective: 1000px; } .flip-card-inner { position: relative; width: 100%; height: 100%; transition: transform 0.6s; transform-style: preserve-3d; } .flip-card:hover .flip-card-inner { transform: rotateY(180deg); } .flip-card-front, .flip-card-back { position: absolute; width: 100%; height: 100%; backface-visibility: hidden; display: flex; align-items: center; justify-content: center; } .flip-card-front { background: linear-gradient(135deg, #667eea, #764ba2); color: white; } .flip-card-back { background: linear-gradient(135deg, #f093fb, #f5576c); color: white; transform: rotateY(180deg); }

JavaScript (Optional)

// Click to toggle flip document.querySelector('.flip-card').addEventListener('click', function() { this.querySelector('.flip-card-inner') .classList.toggle('flipped'); }); // Add this CSS for click-based flip: // .flipped { transform: rotateY(180deg); }
Key Points:
✓ backface-visibility: hidden hides the back of each element
✓ transform-style: preserve-3d enables 3D transformation space
✓ The back side is pre-rotated 180deg so it shows when parent rotates
✓ Transition smooths the flip animation
✓ perspective creates depth effect

💡 Tips & Tricks

🚀 Performance

Add transform: translateZ(0) for GPU acceleration on mobile devices.

🎯 Smooth Animation

Use transition: transform 0.6s ease-in-out for natural-feeling flips.

🎨 Visual Feedback

Change cursor to pointer and add hover effects to indicate interactivity.

📱 Mobile Support

Use touch events for mobile: replace :hover with click handlers.

🔄 Browser Prefixes

Add -webkit- and -moz- prefixes for older browser compatibility.

⚡ Animation Delay

Use animation-delay to stagger multiple flipping elements.
