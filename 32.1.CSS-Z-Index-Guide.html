Z-index Basics

What is Z-index?

The z-index CSS property controls the vertical stacking order of positioned elements. Elements with higher z-index values appear on top of elements with lower values along the z-axis.

💡 Key Point: Z-index only works on positioned elements (position: relative, absolute, fixed, sticky, or flex/grid containers).

Basic Z-index Example

CSS
.element {
    position: relative;
    z-index: 10;
}

Hover over the boxes to see them scale. Notice how the box with z-index: 3 appears on top, even though it was defined last in the HTML.

Z-index Values

Value Range Use Case Example
Negative (-1 to -9999) Push elements behind default layer Background decorations
auto (default) Stack in document order Normal HTML flow
0 Same level as non-positioned elements Base layer
1-99 Regular content layers Cards, panels
100-999 Overlays and modals Pop-ups, dropdowns
1000+ Critical overlays Top-level modals
⚠️ Warning: Don't use arbitrarily high values (e.g., 9999) unless absolutely necessary. This makes code harder to maintain and can cause conflicts.

Understanding Stacking Context

A stacking context is a 3D conceptualization of HTML elements along an imaginary z-axis. It's created by specific CSS properties and determines how elements layer relative to each other.

What Creates a Stacking Context?

  • position: absolute/relative/fixed/sticky with z-index other than auto
  • opacity less than 1
  • transform with any value other than none
  • filter with any value other than none
  • mix-blend-mode with any value other than normal
  • backdrop-filter with any value other than none
  • perspective with any value other than none
  • Root element (html)
  • Flex/grid containers with z-index not auto
💡 Critical Concept: Z-index values only compare within the same stacking context. A z-index: 1000 inside a parent with opacity: 0.5 cannot appear above a sibling with z-index: 1.

✓ Best Practice: Be aware that certain CSS properties create stacking contexts. If z-index isn't working as expected, check if the parent has a property that creates a new context.

Elementor-Specific Implementation

Elementor provides a visual layering panel in its advanced settings. This interface allows you to:

  • Quickly adjust z-index values

Common Elementor Issues & Solutions

Issue 1: Z-index Not Working

Problem: Z-index value isn't changing the layer order.

Solution:
  • Ensure element has a position value (not static)
  • Check if parent has opacity < 1
  • Verify no conflicting Elementor settings
  • Use browser DevTools to inspect actual CSS

Issue 2: Dropdown Menu Hidden Behind Content

Problem: Navigation dropdown appears behind other elements.

Solution:
  • Add z-index to navigation: z-index: 999
  • Ensure navigation doesn't have overflow: hidden
  • Check hamburger menu z-index on mobile

Issue 3: Modal Behind Other Elements

Problem: Pop-up or modal is hidden behind content.

Solution:
  • Use z-index: 1000+ for modal
  • Add z-index to backdrop overlay
  • Verify modal position is fixed, not absolute

Practical Examples

Example 1: Hero Section with Floating Elements

HTML Structure
<div class="hero-section">
    <div class="hero-background"></div>
    <div class="hero-content">
        <h1>Welcome</h1>
        <p>Your content here</p>
    </div>
    <div class="floating-shape"></div>
</div>
CSS
.hero-section {
    position: relative;
    height: 500px;
}

.hero-background {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
    background: linear-gradient(135deg, #667eea, #764ba2);
    z-index: 1;
}

.hero-content {
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
    z-index: 10;
    color: white;
    text-align: center;
}

.floating-shape {
    position: absolute;
    bottom: 20px;
    right: 20px;
    width: 100px;
    height: 100px;
    background: rgba(255, 255, 255, 0.2);
    border-radius: 50%;
    z-index: 5;
    animation: float 3s ease-in-out infinite;
}

Example 2: Sticky Navigation with Dropdowns

CSS
/* Sticky header container */
.site-header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    z-index: 100;
    background: white;
    box-shadow: 0 2px 5px rgba(0, 0, 0, 0.1);
}

/* Navigation menu */
.nav-menu {
    display: flex;
    list-style: none;
}

/* Dropdown menu */
.nav-menu li {
    position: relative;
}

.nav-menu .dropdown {
    position: absolute;
    top: 100%;
    left: 0;
    background: white;
    min-width: 200px;
    box-shadow: 0 4px 10px rgba(0, 0, 0, 0.15);
    z-index: 101; /* Higher than parent */
    opacity: 0;
    visibility: hidden;
    transform: translateY(-10px);
    transition: all 0.3s ease;
}

.nav-menu li:hover .dropdown {
    opacity: 1;
    visibility: visible;
    transform: translateY(0);
}

Best Practices & Tips

1. Create a Z-index Scale

Establish a consistent z-index scale for your project:

CSS Variables Approach
:root {
    --z-below: -1;
    --z-base: 0;
    --z-content: 10;
    --z-sticky: 50;
    --z-floating: 100;
    --z-dropdown: 200;
    --z-modal: 1000;
    --z-tooltip: 1001;
}

.nav-dropdown {
    z-index: var(--z-dropdown);
}

.modal {
    z-index: var(--z-modal);
}

2. Use BEM Naming for Clarity

BEM Pattern
/* Block */
.card { }

/* Element */
.card__image { z-index: 10; }
.card__content { z-index: 20; }

/* Modifier */
.card--featured .card__content { z-index: 30; }

3. Document Your Z-index Values

Comment Guidelines
/* Z-index: 100 | Sticky Navigation */
/* Purpose: Keep navigation above all page content */
/* Context: Global, applied to .site-header */
.site-header {
    z-index: 100;
}

4. Avoid Z-index Wars

❌ Bad Practice: 
.element-1 { z-index: 9999; }
.element-2 { z-index: 99999; }
.element-3 { z-index: 999999; }
✓ Good Practice: 
.element-1 { z-index: 10; }
.element-2 { z-index: 20; }
.element-3 { z-index: 30; }

5. Use Position: Relative Correctly

Z-index only works on positioned elements. Use position: relative with z-index instead of changing layout:

Correct Pattern
.overlay-element {
    position: relative;
    z-index: 10;
    /* Don't use top/left/right/bottom unless needed */
}

6. Mobile Responsive Z-index

Adjust z-index values for mobile to handle hamburger menus and touch interactions:

Responsive Z-index
/* Desktop */
.hamburger { display: none; }
.nav-menu { z-index: 50; }

/* Mobile */
@media (max-width: 768px) {
    .hamburger { 
        z-index: 101;
        display: block;
    }
    
    .nav-menu {
        position: fixed;
        top: 0;
        left: 0;
        z-index: 100; /* Below hamburger when open */
    }
}

7. Debug Z-index Issues with DevTools

  • Open browser DevTools (F12 or Right-click → Inspect)
  • Select the element in the Elements panel
  • Check the Computed styles for z-index value
  • Verify position property is not static
  • Check for stacking context creators (opacity, transform, etc.)
  • Use the 3D view in Chrome DevTools to visualize layers

8. Combining with CSS Grid/Flexbox

Z-index works with flex and grid containers when they have z-index explicitly set:

Flexbox with Z-index
.flex-container {
    display: flex;
    position: relative; /* Enables z-index */
}

.flex-item {
    z-index: 2;
}

.flex-item:hover {
    z-index: 3;
}

9. Performance Considerations

💡 Performance Tips:
  • Creating stacking contexts can affect performance; use sparingly
  • Properties like opacity, filter, and transform create new stacking contexts
  • Minimize repaints by grouping z-index changes
  • Use transform for animations instead of position changes

10. Elementor Custom CSS Module

Use Elementor's Custom CSS feature to maintain organized z-index values:

Custom CSS in Elementor
/* Header Navigation */

    z-index: 100;
}

/* Modal Overlay */
.elementor-element-def456 {
    z-index: 1000;
}

/* Floating Button */

    z-index: 50;

Common Mistakes to Avoid

❌ Mistake 1: Using Z-index Without Position 
/* This WON'T work */
.element {
    z-index: 10;
}
✓ Solution: 
/* This WILL work */
.element {
    position: relative;
    z-index: 10;
}
❌ Mistake 2: Infinite Z-index Escalation

Avoid constantly increasing z-index values. This leads to maintenance nightmares.

❌ Mistake 3: Not Understanding Stacking Context

High z-index values don't matter if the element is inside a different stacking context.

❌ Mistake 4: Overusing Z-index

Sometimes the solution isn't z-index—it could be restructuring HTML or using overflow: hidden.

Conclusion

Mastering z-index in Elementor requires understanding both the basics of the z-index property and the more complex concept of stacking contexts. By following the best practices outlined in this guide, you'll be able to create well-organized, maintainable designs with proper layering.

Remember:

  • Z-index only works on positioned elements
  • Create a consistent z-index scale
  • Be aware of stacking contexts
  • Document your z-index usage
  • Use DevTools to debug issues
  • Avoid z-index wars and excessive values
🎯 Final Tip: Start with a small z-index scale (1-100 range) and increase as needed. This approach prevents conflicts and makes your code more maintainable.
