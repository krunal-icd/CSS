Introduction to CSS Color Modes

CSS color modes allow you to define colors in multiple formats and implement light/dark mode support. This comprehensive guide covers all color formats, accessibility considerations, and modern color mode techniques.

✓ What You'll Learn:

Hex colors, RGB/RGBA, HSL/HSLA, Named colors, CSS Variables, Gradients, and Dark Mode with prefers-color-scheme.

• #000 (black)

RGB Color Format

Syntax: rgb(red, green, blue)

• Values: 0-255
• Or: 0%-100%
• rgb(255, 0, 0) = red
• rgb(0, 255, 0) = green
• rgb(0, 0, 255) = blue

/* RGBA format - with transparency */ .rgba-color { background: rgba(255, 107, 107, 0.5); box-shadow: 0 0 10px rgba(0, 0, 0, 0.2); } /* Alpha values: 0 = transparent, 1 = opaque */ .transparent { background: rgba(255, 255, 255, 0); } .semi-transparent { background: rgba(255, 255, 255, 0.5); } .opaque { background: rgba(255, 255, 255, 1); }

RGBA Color Format

Syntax: rgba(red, green, blue, alpha)

• Red, Green, Blue: 0-255
• Alpha: 0-1 (or 0%-100%)
• 0 = fully transparent
• 1 = fully opaque

9. Dark Mode with prefers-color-scheme

Implement dark/light mode support using the prefers-color-scheme media query:

/* Light mode (default) */ :root { --bg-color: white; --text-color: #333; --border-color: #ddd; } body { background: var(--bg-color); color: var(--text-color); } /* Dark mode */ @media (prefers-color-scheme: dark) { :root { --bg-color: #1a1a2e; --text-color: #e0e0e0; --border-color: #333; } }

13. Best Practices & Tips

✓ Do's:

  • Use CSS Variables for consistent theming
  • Implement dark mode support
  • Test color contrast for accessibility
  • Use HSL for easy color variations
  • Choose appropriate color formats for your needs
  • Use RGBA for transparency instead of opacity
  • Define colors at the root level for easy access

✗ Don'ts:

  • Don't use poor color contrast
  • Don't hardcode colors throughout your CSS
  • Don't ignore dark mode preferences
  • Don't use color alone to convey information
  • Don't mix multiple color format systems
  • Don't forget to test accessibility

💡 Pro Tips:

  • Use HSL for creating color palettes (adjust lightness/saturation)
  • Combine RGBA with background colors for overlay effects
  • Use CSS Variables with media queries for theme switching
  • Test with browser DevTools to verify color accessibility
  • Use color tools like Adobe Color or Coolors for palettes
  • Keep color definitions DRY (Don't Repeat Yourself)
