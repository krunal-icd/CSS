CSS Grid MinMax() Function

Practical Examples & Real-World Implementations

1. Responsive Card Grid (Most Common)
Create a responsive grid that adapts from 1 column on mobile to multiple columns on desktop. Cards never shrink below 280px but can grow to fill available space.
grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));

Feature One

Minimum width ensures readability. Maximum 1fr allows equal distribution across available space.

Feature Two

Cards automatically wrap to new row when space is constrained. No breakpoints needed!

Feature Three

Perfect for portfolio projects, service offerings, and product listings. Completely responsive.

Feature Four

Works great because minmax() does the heavy lifting. Add/remove cards without layout breaks.

💡 Resize your browser window: Cards automatically reflow without any media queries!
Use Case: Testimonials, team members, pricing cards, feature highlights, portfolio pieces
2. Fluid Typography with Flexible Grid
Combine minmax() for grid columns with clamp() for typography. Text sizes scale responsively with grid columns.
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
font-size: clamp(0.8em, 3vw, 1em);

Heading

Text scales with viewport and grid size

Dynamic

No breakpoints needed at all

Responsive

Everything adapts smoothly

Use Case: Stats displays, testimonial cards, feature highlights with variable text lengths

Quick Reference: When to Use MinMax()

✓ Use minmax() when:

  • You want responsive grids without media queries
  • Items should never be smaller than a readable size
  • Items should grow to fill available space
  • You want auto-fit or auto-fill behavior
  • Creating product grids, galleries, card layouts

💡 Pro Tips:

  • Combine minmax() with auto-fit for best responsive behavior
  • Use minmax() with repeat() for DRY, maintainable CSS
  • Pair with clamp() for fluid typography scaling
  • Perfect minimum values based on content readability
  • Test across different viewport sizes to validate breakpoints
