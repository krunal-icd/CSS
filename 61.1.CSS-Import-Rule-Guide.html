CSS @import Rule

Complete Guide to Importing External Stylesheets and Managing CSS Dependencies

What is @import?

The @import rule allows you to import one or more external CSS files into another CSS file or into a stylesheet within an HTML document. It enables modular CSS organization, code reuse, and dependency management, though modern approaches like CSS modules and build tools are often preferred for large projects.

Key Characteristics:

  • Imports external CSS files from URLs or file paths
  • Must be placed at the beginning of a stylesheet (before other rules)
  • Supports conditional imports with media queries
  • Can import multiple stylesheets in sequence
  • Supports both absolute and relative URLs
  • Can include layer rules for cascade management (modern browsers)
  • Performance impact: Creates additional HTTP requests
  • Excellent browser support across all modern and legacy browsers
  • Cannot be used inside CSS rules (only at top level)
  • Follows the CSS cascade and specificity rules

Syntax and Variants

Basic Syntax

@import url("path/to/stylesheet.css") media-queries;

Common Syntax Variants

/* URL notation */ @import url("styles.css"); @import url('styles.css'); @import url(styles.css); /* No quotes */ /* String notation */ @import "styles.css"; @import 'styles.css'; /* With media queries */ @import url("print.css") print; @import url("mobile.css") (max-width: 768px); /* With CSS Layers (modern) */ @import url("base.css") layer(base); @import url("utilities.css") layer(utilities);
Syntax Type Description Example
url() notation Standard URL function with quotes or without @import url("styles.css");
String notation Direct string without url() function @import "styles.css";
Media queries Conditional import based on media type @import "print.css" print;
CSS Layers Organize cascade with @layer (modern) @import url("base.css") layer(base);
External URLs Import from CDN or external servers @import url("https://cdn.example.com/styles.css");

Placement Rules

Correct: @import at Top Level

/* ✓ Correct: @import at the very beginning */ @import url("reset.css"); @import url("typography.css"); @import url("layout.css"); body { margin: 0; }

Incorrect: @import After Other Rules

/* ✗ Incorrect: @import after other rules will be ignored */ body { margin: 0; } @import url("reset.css"); /* This is ignored! */
⚠️ Important: The @import rule must appear before any other CSS rules (except other @import and @charset rules). Any @import rules after other declarations will be ignored by the browser.

Practical Examples

Example 1: Basic Multi-File Organization

/* main.css */ @import url("variables.css"); @import url("reset.css"); @import url("typography.css"); @import url("colors.css"); @import url("layout.css"); @import url("components.css"); /* Rest of styles... */

Example 2: Media Query Imports

/* Import different styles for different devices */ @import url("desktop.css") (min-width: 1024px); @import url("tablet.css") (min-width: 768px) and (max-width: 1023px); @import url("mobile.css") (max-width: 767px); @import url("print.css") print;

Example 3: Relative Paths

/* Assuming this is styles/main.css */ @import url("./base/reset.css"); /* Same folder */ @import url("./components/buttons.css"); /* Subfolder */ @import url("../shared/variables.css"); /* Parent folder */

Example 4: External CDN

/* Import from CDN or external server */ @import url("https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap"); @import url("https://cdn.jsdelivr.net/npm/bootstrap@5.1.3/dist/css/bootstrap.min.css");

Example 5: CSS Layers Organization (Modern)

/* Define layer order and import with layers */ @layer reset, base, layout, components, utilities; @import url("reset.css") layer(reset); @import url("base.css") layer(base); @import url("layout.css") layer(layout); @import url("components.css") layer(components); @import url("utilities.css") layer(utilities);

@import vs Link Tag vs CSS Modules

Method Syntax Performance Use Case Scope
@import @import "file.css"; Sequential loading Modular CSS, dependencies Global
<link> tag <link rel="stylesheet" href="file.css"> Parallel loading Primary stylesheets Global
CSS Modules import styles from 'file.module.css'; Best (bundled) Component-scoped styles Scoped
<style> tag <style> /* rules */ </style> Inline (fast) Critical CSS Global
💡 Note: While @import is still valid, modern best practices often favor <link> tags for better performance (parallel loading) or CSS-in-JS/CSS Modules for large-scale applications.

Performance Considerations

Impact of @import

❌ Performance Issues

  • Sequential loading (each @import waits for previous)
  • Additional HTTP requests per import
  • Can delay page rendering
  • Poor for critical path optimization
  • Not suitable for large stylesheet bundles

✓ Optimization Strategies

  • Use <link> tags instead for parallel loading
  • Bundle/concatenate CSS files with build tools
  • Use CSS modules or import @import in build process
  • Minimize @import depth (avoid nested imports)
  • Consider CSS-in-JS for component-based approaches

Link Tags vs @import

/* HTML with link tags (RECOMMENDED) - Parallel loading */ <link rel="stylesheet" href="reset.css"> <link rel="stylesheet" href="typography.css"> <link rel="stylesheet" href="main.css"> /* CSS with @import - Sequential loading */ @import url("reset.css"); @import url("typography.css"); @import url("main.css");
⚡ Pro Tip: For modern web development, link tags provide better performance. Reserve @import for organizing CSS within files or when build tools handle concatenation.

Media Queries with @import

/* Basic media type imports */ @import url("screen.css") screen; @import url("print.css") print; @import url("handheld.css") handheld; /* Media feature queries */ @import url("mobile.css") (max-width: 768px); @import url("tablet.css") (min-width: 769px) and (max-width: 1024px); @import url("desktop.css") (min-width: 1025px); /* Feature detection */ @import url("dark-mode.css") (prefers-color-scheme: dark); @import url("high-contrast.css") (prefers-contrast: more);

CSS Layers with @import

Layer Cascade Management

/* Define cascade order explicitly */ @layer reset, base, layout, components, utilities, overrides; /* Import into specific layers */ @import url("normalize.css") layer(reset); @import url("typography.css") layer(base); @import url("grid.css") layer(layout); @import url("buttons.css") layer(components); @import url("utilities.css") layer(utilities); /* Final overrides */ @layer overrides { button { color: white; } }
💡 Modern Feature: CSS Layers provide explicit cascade control, reducing reliance on specificity wars. Only works in modern browsers (Chrome 99+, Firefox 97+).

Best Practices

✓ DO

  • Place @import at the start of stylesheet
  • Use relative paths for flexibility
  • Organize files by functionality
  • Use layers for cascade control
  • Consider using build tools to bundle
  • Document file dependencies
  • Keep imports in logical order
  • Use descriptive filenames

✗ DON'T

  • Mix @import with other CSS rules
  • Use @import deeply nested
  • Create circular dependencies
  • Ignore performance implications
  • Use absolute URLs unnecessarily
  • Import unused stylesheets
  • Rely solely on @import for production
  • Forget to test import paths

Common Issues and Solutions

Issue: @import Not Working

/* Problem: @import after CSS rules */ body { margin: 0; } @import url("styles.css"); /* Won't work! */ /* Solution: Move @import to top */ @import url("styles.css"); body { margin: 0; }

Issue: File Not Found

/* Problem: Wrong relative path */ @import url("styles.css"); /* May not be found */ /* Solution: Use correct relative path */ @import url("./css/styles.css"); @import url("../shared/styles.css");

Issue: Circular Dependencies

/* Problem: A imports B, B imports A */ /* main.css */ @import url("utilities.css"); /* utilities.css */ @import url("main.css"); /* Circular! */ /* Solution: Plan hierarchy - no circular imports */ /* main.css depends on utilities */ /* utilities.css is standalone */
