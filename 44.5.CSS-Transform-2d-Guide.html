CSS 2D Transforms

Interactive Examples & Demonstrations

🔄 Rotate Transform

Rotates an element around a point (default: center). Value in degrees (deg).

45°
rotate(45deg)
90°
rotate(90deg)
-30°
rotate(-30deg)
.element { transform: rotate(45deg); }
Note: Positive values rotate clockwise, negative values counter-clockwise. Default origin is center (50%, 50%).

📏 Scale Transform

Scales an element. Value 1 = original size, >1 = larger, <1 = smaller.

1.5x
scale(1.5)
0.7x
scale(0.7)
scaleX(1.5) scaleY(0.8)
Separate X & Y
.element { transform: scale(1.5); /* Both X & Y */ transform: scaleX(1.5); /* Only X axis */ transform: scaleY(0.8); /* Only Y axis */ }
Note: Scale doesn't affect document flow. Use scaleX() and scaleY() for independent axis scaling.

➡️ Translate Transform

Moves an element along the X and Y axes. Values in px, em, %, etc.

XY
translate(20px, 30px)
X
translateX(30px)
Y
translateY(-25px)
.element { transform: translate(20px, 30px); /* Move X & Y */ transform: translateX(30px); /* Move X only */ transform: translateY(-25px); /* Move Y only */ }
Note: Translate is GPU-accelerated. Perfect for animations. Doesn't affect other elements' layout.

🔀 Skew Transform

Skews an element along the X and/or Y axes. Values in degrees (deg).

Skew X
skewX(20deg)
Skew Y
skewY(15deg)
Skew XY
skew(20deg, 15deg)
.element { transform: skew(20deg, 15deg); /* X & Y */ transform: skewX(20deg); /* X only */ transform: skewY(15deg); /* Y only */ }
Note: Skew distorts the shape. Useful for creating parallelograms and 3D-like effects.

🎛️ Matrix Transform

Advanced function combining all 2D transforms in one: matrix(a, b, c, d, e, f)

Matrix
matrix(1, 0.5, -0.5, 1, 20, 20)
.element { transform: matrix(1, 0.5, -0.5, 1, 20, 20); } /* Parameters: (scaleX, skewY, skewX, scaleY, translateX, translateY) */
Note: Matrix is the underlying mathematical representation. Rarely used directly; other functions are more readable.

🎯 Transform Origin

Sets the point around which transforms are applied. Default: center (50%, 50%).

Top Left
transform-origin: top left
Center
transform-origin: center
Bottom Right
transform-origin: bottom right
.element { transform-origin: center; /* Default */ transform-origin: top left; transform-origin: 50% 50%; /* Pixel or percentage */ transform-origin: 0px 0px; transform: rotate(45deg); }
Note: Keywords: top, bottom, left, right, center. Values: pixels, percentages, or a mix (e.g., "20px center").

🎨 Combining Multiple Transforms

Apply multiple transforms in one property. Order matters!

Combo 1
rotate → scale → translate
Combo 2
skewX → scale → translateY
Combo 3
rotate → scaleX → scaleY
.element { transform: rotate(15deg) scale(1.2) translate(10px, 10px); transform: skewX(10deg) scale(1.1) translateY(5px); transform: rotate(-10deg) scaleX(1.3) scaleY(0.9); }
Note: Read left-to-right as the execution order. Changing order produces different results (e.g., translate then rotate vs. rotate then translate).

✨ Creating Shapes with Transforms

Use transforms to create geometric shapes from rectangles.

Diamond
rotate(45deg)
Parallelogram
skewX(-20deg)
3D Feel
Multiple transforms
/* Diamond from square */ .diamond { width: 100px; height: 100px; transform: rotate(45deg); } /* Parallelogram from rectangle */ .parallelogram { width: 100px; height: 60px; transform: skewX(-20deg); }
Note: Combine transforms creatively to build custom shapes. These techniques are foundations for complex designs.

🎬 Animated 2D Transforms

CSS animations with transform properties for smooth, GPU-accelerated motion.

Spin
Rotating (3s)
Pulse
Scaling (2s)
Bounce
Translating (2s)
Wiggle
Skewing (1s)
Complex
All combined (3s)
@keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } .animate-rotate { animation: spin 3s linear infinite; } @keyframes pulse { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.3); } }
Note: Transforms are GPU-accelerated for smooth 60fps animations. Use on transform properties, not left/top/width/height for best performance.

Smooth state changes using CSS transitions. Hover over the boxes below to see effects!

.transition-box { transition: transform 0.6s cubic-bezier(0.68, -0.55, 0.265, 1.55); } .transition-box:hover { transform: rotate(10deg) scale(1.15) translateY(-10px); } .transition-box-2 { transition: all 0.8s ease; } .transition-box-2:hover { transform: skew(-15deg) scale(1.1); }
