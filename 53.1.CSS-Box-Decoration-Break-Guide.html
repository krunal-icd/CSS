CSS Box-Decoration-Break Property

Complete Guide to Multi-Line Element Styling

What is Box-Decoration-Break?

The box-decoration-break property specifies how the box decorations (borders, padding, background, margins) should be rendered when elements are broken across multiple lines, columns, or pages. It controls whether decorations are applied to each fragment or treated as a single continuous element.

Key Purpose: Box-decoration-break gives you control over how inline elements spanning multiple lines display their styling. Choose between cloning decorations on each fragment or applying them continuously.

This property is particularly useful when working with inline elements that wrap to multiple lines, multi-column layouts, or content spanning pages in print.

Syntax & Property Values

Basic Syntax

box-decoration-break: slice | clone;

All Box-Decoration-Break Values

Value Description When to Use
slice Decorations applied as if the element is not broken (default) Most common, continuous appearance
clone Decorations are cloned on each fragment Highlighted text, special effects

Understanding Box-Decoration-Break

Box-decoration-break only affects inline elements that break across multiple lines. For block-level elements, this property has no effect.

Visual Comparison

📦 Box-Decoration-Break: slice vs clone

box-decoration-break: slice

Default behavior. The background, border, and padding are treated as if the element is not broken. Decorations may be cut off at line breaks.

Example: Text spanning two lines with a background. The background appears continuous, as if the text is one box.

box-decoration-break: clone

Cloning mode. Each fragment (each line) receives a complete copy of the decorations independently. Borders, padding, and background are applied to each line.

Example: Each line of text gets its own background, padding, and borders.

Understanding Each Value

1. box-decoration-break: slice (Default)

What it does: Decorations are applied as if the element is a single continuous box, even if it breaks across lines. The decorations are "sliced" at the break points.

Characteristics:

  • Background and borders may appear cut off at line breaks
  • Decorations span continuously across fragments
  • Natural text-wrapping appearance
  • Padding removed at break points

Example:

span { background: #667eea; padding: 10px; border: 2px solid white; box-decoration-break: slice; /* Default */ }

2. box-decoration-break: clone

What it does: Each fragment of the broken element receives a complete copy of the box decorations. Every line gets full padding, borders, and background.

Characteristics:

  • Each fragment is independently styled
  • Complete padding on all sides of each fragment
  • Borders fully rendered on each fragment
  • Creates a "highlighted" or "boxed" appearance on each line
  • More visually distinct when breaking across lines

Example:

span { background: #f093fb; padding: 10px; border: 2px solid white; box-decoration-break: clone; }

Real-World Use Cases

✨ Highlighted Text

Use clone for search result highlights so each line gets its own background box.

📰 Multi-Column Text

Use clone when emphasized text spans column breaks for consistent styling.

🏷️ Inline Labels

Use clone for styled inline labels that wrap to ensure complete styling on each line.

📄 Print Design

Use clone for styled text in print layouts to handle page breaks elegantly.

🎨 Design Effects

Use clone for creative text effects with borders and backgrounds on wrapped text.

📝 Text Decoration

Use clone for consistently styled inline code or keywords across line breaks.

Practical Code Examples

Example 1: Highlighted Search Results

mark { background: yellow; padding: 5px 8px; border-radius: 3px; box-decoration-break: clone; /* Each line gets complete highlight box */ }

Example 2: Inline Code Styling

code { background: #f5f5f5; padding: 4px 8px; border-radius: 3px; border: 1px solid #ddd; box-decoration-break: clone; /* Code blocks styled consistently per line */ }

Example 3: Emphasized Text in Articles

em { background: rgba(255, 235, 59, 0.3); padding: 3px 6px; font-style: italic; box-decoration-break: clone; }

Example 4: Linked Text

a { color: #667eea; text-decoration: underline; background: rgba(102, 126, 234, 0.1); padding: 2px 4px; box-decoration-break: clone; /* Styling applied consistently across wrapped lines */ }

Example 5: Multi-Column Print

article { columns: 2; column-gap: 40px; } article span.highlight { background: #ffffcc; padding: 5px; box-decoration-break: clone; /* Highlights work correctly across columns */ }

Browser Support

CSS Box-Decoration-Break Compatibility

Chrome: 12+
Firefox: 32+
Safari: 6.1+
Edge: 12+ (partial)
Opera: 15+
IE: Not Supported
iOS Safari: 7+
Android: 4.4+
Note: Most modern browsers support both slice and clone. Internet Explorer does not support this property.

Vendor Prefixes

For maximum compatibility with older browsers, include the -webkit- prefix:

span { -webkit-box-decoration-break: clone; box-decoration-break: clone; }
Important: Safari and Chrome require the -webkit- prefix for this property to work properly.

Best Practices & Tips

✓ Best Practices:
  • Use clone for highlighted or emphasized inline text
  • Use slice for continuous background effects
  • Include -webkit- prefix for broader support
  • Test with multi-column layouts and print styles
  • Consider text wrapping behavior in your design
  • Use with inline elements (span, em, strong, code, etc.)
  • Combine with column-count for sophisticated layouts
⚠ Common Mistakes:
  • Using box-decoration-break on block elements (has no effect)
  • Forgetting the -webkit- prefix for Safari/Chrome
  • Not testing across different line-break scenarios
  • Using with non-inline elements
  • Expecting it to work in Internet Explorer

When Elements Break

Elements break across:

  • Text Wrapping: Long inline text that wraps to multiple lines
  • Multi-Column Layouts: Content spanning across CSS columns
  • Page Breaks (Print): Content spanning page boundaries
  • Flex/Grid Wrapping: Elements wrapping in flexible containers

Box-decoration-break applies to:

  • Background images and colors
  • Border properties
  • Padding and margins
  • Box-shadow effects
  • Border-radius

Related Properties

break-inside

Prevents element from breaking across columns, pages. Complementary to box-decoration-break.

column-count

Creates multi-column layout where box-decoration-break becomes relevant for styled inline content.

word-break

Controls where text breaks. Works together with box-decoration-break for text styling.

text-decoration

Applies underlines and overlines. Box-decoration-break doesn't affect text-decoration.

Conclusion

Box-decoration-break is a powerful property for controlling how inline elements are styled when they span multiple lines or fragments. While its use cases are specific, it's essential for creating polished, professional-looking wrapped text and multi-column layouts.

Quick Decision Guide:

  • Highlighted search results: Use clone
  • Inline code styling: Use clone
  • Emphasized text: Use clone
  • Continuous background: Use slice (default)
  • Multi-column layouts: Usually clone
