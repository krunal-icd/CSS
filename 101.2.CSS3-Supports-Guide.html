3. Aspect Ratio Sizing

Responsive

Use aspect-ratio property for consistent image dimensions, fallback to padding-bottom trick for older browsers.

3:2 Aspect Ratio
@supports (aspect-ratio: 1) { .image-container { aspect-ratio: 3 / 2; height: auto; } } @supports not (aspect-ratio: 1) { .image-container { padding-bottom: 66.66%; position: relative; } }

5. CSS Variables Theming

Interactive

Use CSS custom properties for dynamic theming when available, hardcoded values as fallback.

:root { --primary-color: #667eea; --secondary-color: #764ba2; } @supports (--css: variables) { .var-button { background: var(--primary-color); } .var-button:hover { background: var(--secondary-color); } }

8. Fluid Sizing with Clamp

Responsive

Use clamp() for fluid responsive sizing between min and max values, fixed width fallback.

Responsive Width
(Resize viewport to see fluid scaling)
@supports (width: clamp(200px, 50vw, 800px)) { .flexible-container { width: clamp(280px, 90vw, 1000px); } } @supports not (width: clamp(200px, 50vw, 800px)) { .flexible-container { width: 90%; max-width: 600px; } }

9. 3D Transforms

Effects

Apply 3D perspective transforms on hover when supported, 2D scale fallback for older browsers.

Hover to see 3D effect
@supports (transform: perspective(1000px)) { .card-3d:hover { transform: perspective(1000px) rotateY(15deg) rotateX(-10deg); } } @supports not (transform: perspective(1000px)) { .card-3d:hover { transform: scale(1.05); } }

11. Vendor Prefix Detection

Effects

Check for vendor-prefixed versions of newer properties like -webkit-backdrop-filter.

This element has backdrop blur applied (if supported)
@supports (backdrop-filter: blur(10px)) { .blur-element { backdrop-filter: blur(10px); } } @supports (-webkit-backdrop-filter: blur(10px)) { .blur-element { -webkit-backdrop-filter: blur(10px); } }
