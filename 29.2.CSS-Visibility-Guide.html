Practice Examples

Work through these interactive examples to understand visibility.

1️⃣ Visibility: Visible vs Hidden

See how visibility: hidden reserves space while display: none does not.

Item 1 - Visible
Item 2 - Hidden (space reserved)
Item 3 - Visible
.visible {
    visibility: visible;  /* Default */
}

.hidden {
    visibility: hidden;   /* Hidden but space reserved! */
}

Key Insight: Notice Item 2 is hidden but the space is still there. Compare with display: none which removes space entirely.

2️⃣ Toggle Visibility with JavaScript

Click items to toggle their visibility on and off.

Click to hide - Item 1
Click to hide - Item 2
Click to hide - Item 3
function toggleVisibility(element) {
    const visibility = window.getComputedStyle(element).visibility;
    element.style.visibility = visibility === 'hidden' ? 'visible' : 'hidden';
}

Interactive: Try clicking the items above!

3️⃣ Hover Tooltip with Visibility

Tooltip appears on hover using visibility: hidden/visible.

Hover me
Helpful tooltip! 
.tooltip {
    visibility: hidden;
    transition: visibility 0.3s ease;
}

.element:hover .tooltip {
    visibility: visible;
}

Key Point: Visibility works great for tooltips and dropdowns.

4️⃣ Form Error Messages

Hide error message but reserve space for it.

⚠️ Invalid email format 
.error-message {
    visibility: hidden;
    color: red;
    font-size: 0.85rem;
}

.form-group.error .error-message {
    visibility: visible;
}

Benefit: Form doesn't shift when error appears/disappears.

5️⃣ Hide Table Columns

Hide table columns while preserving layout.

/* Hide phone column but keep space */
table th:nth-child(3),

6️⃣ Animated Visibility with Opacity

Combine visibility with opacity for smooth transitions.

Success! This appeared smoothly. 
.message {
    visibility: hidden;
    opacity: 0;
    transition: opacity 0.3s ease, visibility 0.3s ease;
}

.message.show {
    visibility: visible;
    opacity: 1;
}

7️⃣ Child Overrides Parent Visibility

Child elements can show even if parent is hidden.

Parent is hidden...

But this child is visible! 
.parent {
    visibility: hidden;
}

.parent .important-child {
    visibility: visible;  /* Shows despite parent */
}

Feature: Visibility can be overridden in child elements.

8️⃣ Accessible Skip Link

Hide skip link but keep accessible to keyboard navigation.

Skip to main content

Try tabbing (may not be visible in this demo, but skip links use similar techniques)

.skip-link {
    position: absolute;
    left: -9999px;
    visibility: hidden;
}

.skip-link:focus {
    visibility: visible;
    left: 0;
}

Accessibility: Keyboard users can still access skip links.

Quick Reference & Tips

Visibility Property Selection

  • visibility: visible: Show element, take space
  • visibility: hidden: Hide element, reserve space
  • visibility: collapse: Hide table row/column

Common Patterns

.element {
    visibility: hidden;
}

.element.show {
    visibility: visible;
}
.tooltip {
    visibility: hidden;
}

.element:hover .tooltip {
    visibility: visible;
}
.element {
    visibility: hidden;
    opacity: 0;
    transition: all 0.3s ease;
}

.element.show {
    visibility: visible;
    opacity: 1;
}
.placeholder {
    visibility: hidden;
    height: 20px;
}
.parent {
    visibility: hidden;
}

.parent .important {
    visibility: visible;
}

Best Practices

  • ✅ Use visibility: hidden to preserve layout
  • ✅ Use display: none to remove from layout
  • ✅ Combine with opacity for animations
  • ✅ Use transitions for smooth effects
  • ✅ Test keyboard navigation
  • ❌ Don't hide critical navigation with visibility
  • ❌ Don't forget accessibility implications

Troubleshooting

  • Layout shifts: Use visibility: hidden to avoid this
  • Animation not smooth: Combine with opacity
  • Child not showing: Override parent with visibility: visible
  • Keyboard not accessing: Check visibility on parent
