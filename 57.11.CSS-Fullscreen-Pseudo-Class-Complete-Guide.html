CSS :fullscreen Pseudo-class

Complete Guide to Fullscreen Element Styling

1. What is :fullscreen?

The :fullscreen CSS pseudo-class selector matches elements that are currently displayed in fullscreen mode. It allows you to apply specific styles to elements when they enter or exit fullscreen.

Key Characteristics:

  • Matches elements in fullscreen display mode
  • Works with the Fullscreen API (JavaScript)
  • Applies styles only when element is fullscreen
  • Requires user interaction to trigger fullscreen
  • Essential for video players and interactive media
  • Browser security: requires element activation

Syntax:

/* Match element in fullscreen */
element:fullscreen {
    /* Styles applied when fullscreen */
}

/* Combined with other selectors */
video:fullscreen {
    width: 100vw;
    height: 100vh;
}

/* Prevent nesting */
:not(:fullscreen) {
    display: none;
}
Important: The :fullscreen pseudo-class only matches when the Fullscreen API is actively used. It's not related to maximizing the browser window.

2. Basic Usage & Examples

Simple Fullscreen Styling:

/* Normal state */
video {
    width: 100%;
    max-width: 800px;
    height: auto;
}

/* Fullscreen state */
video:fullscreen {
    width: 100vw;
    height: 100vh;
    object-fit: contain;
    margin: 0;
}

3. Fullscreen Selector Variations

Direct Fullscreen:

/* Element itself in fullscreen */
element:fullscreen {
    width: 100vw;
    height: 100vh;
}

Child of Fullscreen:

/* Any element inside a fullscreen element */
:fullscreen > div {
    width: 100%;
    height: 100%;
}

/* Direct child */
:fullscreen > video {
    width: 100%;
    height: 100%;
}

Not Fullscreen:

/* Elements NOT in fullscreen */
element:not(:fullscreen) {
    width: 100%;
    max-width: 800px;
}

Pseudo-element Considerations:

/* Using with pseudo-elements */
video:fullscreen::after {
    content: "Press ESC to exit fullscreen";
    position: absolute;
    bottom: 20px;
    right: 20px;
}

5. JavaScript Integration

Request Fullscreen:

// Simple fullscreen request
function enterFullscreen(element) {
    if (element.requestFullscreen) {
        element.requestFullscreen();
    } else if (element.webkitRequestFullscreen) {
        element.webkitRequestFullscreen();
    } else if (element.mozRequestFullScreen) {
        element.mozRequestFullScreen();
    }
}

// With options
function enterFullscreenWithOptions(element) {
    element.requestFullscreen({
        navigationUI: "show" // or "hide"
    });
}

Exit Fullscreen:

// Exit fullscreen
function exitFullscreen() {
    if (document.exitFullscreen) {
        document.exitFullscreen();
    } else if (document.webkitExitFullscreen) {
        document.webkitExitFullscreen();
    }
}

Detect Fullscreen Changes:

// Listen for fullscreen changes
document.addEventListener('fullscreenchange', (e) => {
    if (document.fullscreenElement) {
        console.log('Entered fullscreen:', document.fullscreenElement);
    } else {
        console.log('Exited fullscreen');
    }
});

// Check if element is fullscreen
function isFullscreen(element) {
    return document.fullscreenElement === element;
}

Complete Video Player Example:

class VideoPlayer {
    constructor(videoElement, containerElement) {
        this.video = videoElement;
        this.container = containerElement;
        this.setupControls();
    }

    setupControls() {
        const fullscreenBtn = document.querySelector('.fullscreen-btn');
        fullscreenBtn.addEventListener('click', () => this.toggleFullscreen());

        document.addEventListener('fullscreenchange', () => {
            this.updateUI();
        });
    }

    toggleFullscreen() {
        if (!document.fullscreenElement) {
            this.container.requestFullscreen();
        } else {
            document.exitFullscreen();
        }
    }

    updateUI() {
        if (document.fullscreenElement === this.container) {
            console.log('In fullscreen - styles applied');
        }
    }
}

@supports for Feature Detection:

/* Check if fullscreen is supported */
@supports (display: -webkit-fullscreen) {
    video:fullscreen {
        width: 100vw;
        height: 100vh;
    }

@supports not selector(:fullscreen) {
    video.fullscreen-fallback {
        width: 100vw;
        height: 100vh;
    }
}

8. Best Practices & Tips

✓ Do's:

  • Use 100vw and 100vh for fullscreen elements
  • Set margin and padding to 0 in fullscreen
  • Use object-fit for proper image/video scaling
  • Account for safe areas on notched devices
  • Provide clear exit instructions (ESC key hint)
  • Test fullscreen on actual devices
  • Use :fullscreen in CSS media queries
  • Hide non-essential UI when fullscreen

✗ Don'ts:

  • Don't force fullscreen without user interaction
  • Don't forget vendor prefixes for older browsers
  • Don't hide exit instructions completely
  • Don't assume fullscreen is always available
  • Don't use fullscreen for ads or unwanted content
  • Don't ignore security/permission requirements
  • Don't forget keyboard escape handling

11. Troubleshooting Common Issues

Issue 1: Fullscreen not working

Solution: Ensure element is triggered by user interaction, not automatically.

Issue 2: Styles not applying

Solution: Check specificity and use vendor prefixes for older browsers.

Issue 3: Scroll visible in fullscreen

/* Fix scrollbar visibility */
:fullscreen {
    width: 100vw;
    height: 100vh;
    overflow: hidden;
}

Issue 4: Notch/safe area problems

/* Use safe-area-inset */
:fullscreen {
    padding-top: env(safe-area-inset-top);
}

Issue 5: Browser inconsistencies

/* Use feature detection */
if (document.fullscreenEnabled) {
    // Fullscreen is supported
}
