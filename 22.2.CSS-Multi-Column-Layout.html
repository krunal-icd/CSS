6. column-fill Property

Controls how content is distributed across columns:

column-fill: balance

Columns are balanced (default) - content spreads evenly:

/* Balance columns (default) */ .column-balanced { column-count: 3; column-fill: balance; height: 300px; } /* Sequential fill */ .column-sequential { column-count: 3; column-fill: auto; height: 300px; }

Values: balance | auto

• balance (default)
• auto (sequential filling)

8. break-inside Property

Prevents breaking of elements between columns:

break-inside: avoid
Card 1

This card won't break across columns. Lorem ipsum dolor sit amet.

Card 2

This card stays together. Consectetur adipiscing elit. Sed do eiusmod.

Card 3

Another complete card. Tempor incididunt ut labore et dolore magna.

Card 4

Final card in layout. Aliqua ut enim ad minim veniam quis nostrud.

.cards { column-count: 3; column-gap: 30px; } .card { break-inside: avoid; page-break-inside: avoid; /* Fallback */ background: white; border: 2px solid #ddd; padding: 15px; margin-bottom: 15px; } /* Values: */ /* auto (default), avoid, avoid-page, avoid-column */

break-inside

Values: auto | avoid | avoid-page | avoid-column

• auto (default)
• avoid (prevent breaks)
• avoid-page (printing)
• avoid-column (column breaks)

12. Best Practices

✓ Do's:

  • Use columns for long-form text content
  • Combine with break-inside: avoid for cards
  • Test responsiveness on different screen sizes
  • Use column-rule for visual separation
  • Provide fallback layouts for older browsers
  • Use text-align: justify for better appearance
  • Combine with media queries for responsive design

✗ Don'ts:

  • Don't use columns for navigation or complex layouts
  • Don't force too many columns on small screens
  • Don't use columns with very narrow width
  • Don't forget to test in different browsers
  • Don't make columns too wide for readability
  • Don't combine with floats without caution

💡 Pro Tips:

  • Use columns: auto 200px for responsive layouts
  • Combine columns with Grid for hybrid layouts
  • Use column-rule for visual interest without extra markup
  • Always test readability at different zoom levels
  • Consider using max-width for optimal column width
  • Use Elementor custom CSS for easy implementation
