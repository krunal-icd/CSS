CSS Pseudo-Elements

Complete Guide to Virtual Elements and Content Insertion

CSS Pseudo-Elements represent virtual elements that don't exist in the HTML markup. They allow you to style specific parts of an element (like the first line or first letter) or insert generated content using ::before and ::after. Unlike pseudo-classes which describe element states, pseudo-elements target actual parts of content or create new virtual content.

::before and ::after

What It Does

::before creates a pseudo-element before the element's content. ::after creates one after the content. Both use the content property to insert generated content.

Syntax

element::before {
  content: "text";
  property: value;
}

Content Property Values

/* Text content */
content: "Hello World";

/* Empty (placeholder) */
content: "";

/* Image */
content: url('image.png');

/* Attribute value */
content: attr(data-label);

/* Counter */
content: counter(counter-name);

/* Multiple values */
content: " (" attr(href) ")";

Example Use Cases

Common Applications

  • Decorative icons and symbols before/after text
  • Adding quotation marks around quoted text
  • Displaying URLs after links (printing)
  • Creating clearfix for floats
  • Building tooltips and popovers
  • Creating decorative elements without extra HTML
  • Numbering items with counters
  • Loading animations and spinners

Important Notes

• ::before and ::after create inline boxes by default

• The content property is required; without it, nothing displays

• These elements can be styled with any CSS properties (colors, sizes, positioning)

• They don't appear in the DOM, so they won't be selected by JavaScript queries

• Useful for reducing HTML markup and keeping content semantic

::first-line

What It Does

Applies styles to the first line of text in a block-level element. The line length depends on viewport width and font size.

Syntax

element::first-line {
  property: value;
}

Allowed Properties

Only certain CSS properties work with ::first-line:

/* These work */
color, background, font-size,
font-weight, font-style, text-transform,
letter-spacing, word-spacing, line-height

Common Use Cases

  • Drop cap effect (larger first letter)
  • Highlighting first line of paragraphs
  • Different text styling for first line
  • Editorial typography effects
::first-letter

What It Does

Applies styles to the first letter of text. Commonly used for drop caps effects in typography.

Syntax

element::first-letter {
  font-size: 3em;
  float: left;
}

Example

/* Drop cap effect */
p::first-letter {
  font-size: 2em;
  font-weight: bold;
  color: #667eea;
  float: left;
  margin-right: 5px;
}

Common Use Cases

  • Drop cap typography
  • Highlighting first character
  • Magazine-style article formatting
  • Editorial design effects
::selection

What It Does

Applies styles to text that the user has selected/highlighted with the mouse or keyboard.

Syntax

::selection {
  background: #667eea;
  color: white;
}

/* Vendor prefix still needed for Firefox */
::moz-selection {
  background: #667eea;
  color: white;
}

Allowed Properties

Only these properties can be used with ::selection:

color, background, background-color,
text-shadow, cursor (limited)

Common Use Cases

  • Brand color for text selection
  • Accessible selection styling
  • Custom highlight colors
  • Improving visual feedback for users
::placeholder

What It Does

Styles the placeholder text in form inputs (the hint text that appears before user input).

Syntax

input::placeholder {
  color: #999;
  font-style: italic;
  opacity: 0.7;
}

Important Notes

• The opacity property must be set explicitly (default is 0.54)

• Use with caution as placeholder text is not a substitute for labels

• Always provide proper <label> elements for accessibility

• Vendor prefixes needed for some browsers (-webkit-, -moz-)

Common Use Cases

  • Custom placeholder text styling
  • Better form input accessibility
  • Brand-consistent form inputs
  • Improving placeholder visibility
::marker

What It Does

Styles the marker of list items (bullets, numbers, etc.).

Syntax

li::marker {
  color: #667eea;
  font-weight: bold;
}

Common Use Cases

  • Custom bullet colors
  • List number styling
  • Brand-consistent lists
::cue

What It Does

Styles video captions and subtitles in media players.

Syntax

video::cue {
  background: rgba(0, 0, 0, 0.8);
  color: white;
  font-family: sans-serif;
}

Common Use Cases

  • Custom caption styling
  • Brand-consistent subtitles
  • Accessibility improvements

Key Differences: Pseudo-Classes vs Pseudo-Elements

Feature Pseudo-Classes (:) Pseudo-Elements (::)
Syntax Single colon (:) Double colon (::)
What they do Select element states Select virtual parts
Example :hover, :focus, :nth-child() ::before, ::after, ::first-line
Purpose Interactive and structural Content and typography
In DOM Select existing elements Create virtual elements
Content property Not used Used with ::before/::after

Best Practices

✓ Do's

  • Use ::before/::after for decorative content - Keeps content semantic
  • Remember ::after is for clearing floats - Classic clearfix technique
  • Use double colon syntax (::) - Single colon (:) is deprecated
  • Always provide fallbacks for content - Use attr() for dynamic values
  • Test with ::first-line/::first-letter carefully - They have limited property support
  • Combine pseudo-elements with pseudo-classes - a::after:hover

✗ Don'ts

  • Don't use ::before/::after for critical content - Not in DOM, not selectable
  • Don't forget the content property - It's required for display
  • Don't overuse pseudo-elements - HTML elements are clearer for important content
  • Don't ignore browser support - Older pseudo-elements have better support
  • Don't expect pseudo-elements to be selectable by JS - Use data attributes instead
