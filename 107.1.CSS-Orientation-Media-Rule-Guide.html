CSS Orientation Media Rule

Master Device Orientation Detection

Responsive design for portrait and landscape screens

🎯 What is Orientation?

The CSS orientation media feature detects whether a device is in portrait or landscape mode. It's essential for responsive design on mobile devices and tablets.

Syntax

@media (orientation: portrait) {
  /* Styles for portrait mode */
}

@media (orientation: landscape) {
  /* Styles for landscape mode */
}

Valid Values

  • portrait: Height ≥ width (vertical orientation)
  • landscape: Width > height (horizontal orientation)
ℹ️ Note: Orientation is determined by the aspect ratio, not device rotation. A device is portrait if height ≥ width.

📱 Portrait Orientation

Detected when device height is greater than or equal to width. Common on mobile phones in standard position.

Portrait Example

Portrait
Mode

CSS Implementation

@media (orientation: portrait) {
  body {
    display: flex;
    flex-direction: column;
    width: 100%;
  }
  
  .sidebar {
    width: 100%;
    margin-top: 20px;
  }
}

Portrait Use Cases

  • Single column layouts
  • Full-width navigation
  • Stacked content blocks
  • Bottom navigation bars
  • Larger touch targets

🖥️ Landscape Orientation

Detected when device width is greater than height. Common on tablets, desktops, and rotated mobile phones.

Landscape Example

Landscape Mode

CSS Implementation

@media (orientation: landscape) {
  body {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-gap: 20px;
  }
  
  .sidebar {
    width: auto;
    margin-top: 0;
  }
}

Landscape Use Cases

  • Multi-column layouts
  • Side-by-side navigation
  • Video content optimization
  • Horizontal galleries
  • More screen real estate

🔗 Combining with Other Media Queries

Orientation works perfectly with other media features for more precise control.

With Width Breakpoints

/* Tablet in portrait */
@media (min-width: 768px) and (orientation: portrait) {
  .container {
    width: 90%;
    max-width: 600px;
  }
}

/* Tablet in landscape */
@media (min-width: 768px) and (orientation: landscape) {
  .container {
    width: 95%;
    max-width: 1000px;
  }
}

With Aspect Ratio

/* Ultra-wide landscape */
@media (orientation: landscape) and (aspect-ratio: 21 / 9) {
  .hero {
    height: 50vh;
  }
}
ℹ️ Tip: Use and keyword to combine multiple media features for precise targeting.

💼 Real-World Implementation Examples

Example 1: Responsive Navigation

/* Portrait: Bottom navigation */
@media (orientation: portrait) {
  nav {
    position: fixed;
    bottom: 0;
    width: 100%;
    display: flex;
    justify-content: space-around;
  }
}

/* Landscape: Top navigation */
@media (orientation: landscape) {
  nav {
    position: fixed;
    top: 0;
    width: 100%;
    display: flex;
    justify-content: flex-start;
  }
}

Example 2: Video Container

/* Portrait: Full width with reduced height */
@media (orientation: portrait) {
  .video-container {
    width: 100%;
    aspect-ratio: 16 / 9;
    margin-bottom: 20px;
  }
}

/* Landscape: Larger player */
@media (orientation: landscape) {
  .video-container {
    width: 90vw;
    height: 90vh;
    position: fixed;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
  }
}

Example 3: Grid Layout

/* Portrait: Single column */
@media (orientation: portrait) {
  .gallery {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
  }
}

/* Landscape: Two columns */
@media (orientation: landscape) {
  .gallery {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 20px;
  }
}

Example 4: Form Layout

/* Portrait: Full-width inputs */
@media (orientation: portrait) {
  form input, form textarea {
    width: 100%;
    margin-bottom: 15px;
  }
}

/* Landscape: Side-by-side inputs */
@media (orientation: landscape) {
  .form-row {
    display: grid;
    grid-template-columns: 1fr 1fr;
    gap: 15px;
  }
}

🏆 Best Practices & Tips

✅ Do:

  • Test on real devices: Emulators may not accurately reflect orientation behavior
  • Combine with width queries: Use both orientation and min-width/max-width
  • Optimize touch targets: Ensure buttons are 44px+ in portrait mode
  • Consider landscape keyboards: Virtual keyboards affect available height
  • Use appropriate layouts: Flex or CSS Grid adapt well to orientation changes
  • Test rotation transitions: Ensure smooth transitions when device rotates

❌ Don't:

  • Ignore landscape mode: Many users rotate their devices
  • Force portrait only: Some devices/users prefer landscape
  • Use only orientation: Combine with width queries for precision
  • Forget about safe areas: Consider notches and camera cutouts
  • Make text too small: Maintain readability in both orientations
  • Block rotation: Let users choose their preferred orientation
⚠️ Important: Always test orientation changes on real mobile devices. Browser emulators may not accurately represent the user experience.

⚙️ JavaScript Integration

Listen to Orientation Changes

window.addEventListener('orientationchange', function() {
  const orientation = window.innerHeight > window.innerWidth
    ? 'portrait'
    : 'landscape';
  
  console.log('Device orientation: ' + orientation);
  
  // Update layout or UI based on orientation
  document.body.classList.add(orientation);
});

Access Orientation API

// Get current orientation
const orientation = window.orientation;
// Returns: 0 or 180 (portrait), 90 or -90 (landscape)

// Check screen dimensions
const isPortrait = window.innerHeight > window.innerWidth;
const isLandscape = window.innerWidth > window.innerHeight;
ℹ️ CSS First: Use CSS media queries for most orientation changes. Reserve JavaScript for complex interactions.

⚡ Common Pitfalls & Solutions

Pitfall 1: Ignoring Landscape Mode

Problem: App looks broken when rotated to landscape.

Solution:

/* Test BOTH orientations */
@media (orientation: portrait) { /* ... */ }
@media (orientation: landscape) { /* ... */ }

Pitfall 2: Virtual Keyboard Space

Problem: Form inputs get hidden by keyboard in portrait mode.

Solution:

@media (orientation: portrait) {
  input:focus {
    scroll-behavior: smooth;
    padding-bottom: 50vh;
  }
}

Pitfall 3: Text Size Issues

Problem: Text becomes too small in landscape mode due to reduced height.

Solution:

@media (orientation: landscape) {
  h1 {
    font-size: clamp(1.5rem, 5vw, 2.5rem);
  }
  p {
    font-size: clamp(0.875rem, 2vw, 1rem);
  }
}

Pitfall 4: Notch/Safe Area

Problem: Content gets hidden behind notch or rounded corners.

Solution:

@media (orientation: landscape) {
  body {
    padding-top: max(20px, env(safe-area-inset-top));
    padding-left: max(20px, env(safe-area-inset-left));
  }
}
