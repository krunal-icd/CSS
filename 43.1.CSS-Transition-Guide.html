CSS Transition Properties: Complete Guide

Master CSS transitions for smooth animations. Learn all transition properties, timing functions, durations, and best practices for creating professional UI animations.

Overview

CSS transitions allow you to smoothly animate changes to CSS properties over a specified duration. Instead of instant property changes, transitions create smooth visual effects that enhance user experience.

Key Point: Transitions are simpler than animations—they animate between two states (start and end). Use transitions for hover effects, focus states, and state changes. Use animations for more complex, looping effects.

Applies To All elements Works on any HTML element

Transition Properties

The transition shorthand consists of four sub-properties:

Property Description Default Value Example
transition-property Which CSS property to animate all transition-property: background-color;
transition-duration How long the transition takes 0s transition-duration: 0.3s;
transition-timing-function Speed curve of the animation ease transition-timing-function: ease-in-out;
transition-delay Wait time before animation starts 0s transition-delay: 0.1s;

Syntax Variations

/* Individual properties */ transition-property: background-color; transition-duration: 0.3s; transition-timing-function: ease; transition-delay: 0s; /* Shorthand */ transition: background-color 0.3s ease 0s; /* Multiple properties */ transition: background-color 0.3s ease, transform 0.4s ease-in-out; /* All properties (default) */ transition: all 0.3s ease; /* With cubic-bezier */ transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);

transition-property

Specifies which CSS properties should be animated during the transition. You can animate most CSS properties, but not all.

/* Single property */ transition-property: background-color; /* Multiple properties */ transition-property: background-color, transform, opacity; /* All properties (default in shorthand) */ transition-property: all; /* None - no transition */ transition-property: none;

Commonly Animated Properties

Category Properties
Colors color, background-color, border-color, box-shadow
Dimensions width, height, padding, margin
Transforms transform, translate, rotate, scale
Opacity opacity, filter
Position top, left, right, bottom
Shadows box-shadow, text-shadow
Performance Tip: Avoid animating properties like width, height, and left/right/top/bottom as they trigger layout recalculation. Use transform instead for better performance.

transition-duration

Specifies how long the transition takes, in seconds (s) or milliseconds (ms). Default is 0s (instant).

/* In milliseconds */ transition-duration: 100ms; transition-duration: 300ms; transition-duration: 1000ms; /* In seconds */ transition-duration: 0.1s; transition-duration: 0.3s; transition-duration: 1s; transition-duration: 2s; /* Multiple durations for multiple properties */ transition-duration: 0.3s, 0.5s, 1s;

transition-timing-function

Specifies the speed curve of the transition. Common values include linear, ease, ease-in, ease-out, ease-in-out, and cubic-bezier().

/* Keyword values */ transition-timing-function: linear; transition-timing-function: ease; transition-timing-function: ease-in; transition-timing-function: ease-out; transition-timing-function: ease-in-out; /* Cubic-bezier for custom curves */ transition-timing-function: cubic-bezier(0.4, 0, 0.2, 1); /* Step functions */ transition-timing-function: steps(4); transition-timing-function: steps(4, start); transition-timing-function: steps(4, end);

Timing Function Comparison

linear

Constant speed throughout

ease (default)

Fast start, slow end

ease-in

Slow start, fast end

ease-out

Fast start, slow end

ease-in-out

Slow start and end

cubic-bezier()

Custom curve with overshoot

Timing Function Details

Function Cubic-Bezier Value Description
linear cubic-bezier(0, 0, 1, 1) Constant speed throughout the animation
ease cubic-bezier(0.25, 0.1, 0.25, 1) Slow start and end, faster in middle (default)
ease-in cubic-bezier(0.42, 0, 1, 1) Slow start, accelerating to end
ease-out cubic-bezier(0, 0, 0.58, 1) Fast start, decelerating to end
ease-in-out cubic-bezier(0.42, 0, 0.58, 1) Slow start and end, faster middle
Custom Cubic-Bezier: Use cubic-bezier.com to visualize and create custom timing functions. Perfect for bounce effects, elastic animations, and custom easing.

transition-delay

Specifies a delay before the transition starts, in seconds (s) or milliseconds (ms).

/* No delay */ transition-delay: 0s; /* Milliseconds */ transition-delay: 50ms; transition-delay: 100ms; /* Seconds */ transition-delay: 0.1s; transition-delay: 0.5s; transition-delay: 1s; /* Multiple delays for multiple properties */ transition-delay: 0s, 0.1s, 0.2s; /* Negative delay - starts animation partway through */ transition-delay: -0.2s;

Use Cases for Delay

  • Staggered animations: Delay each element differently for wave-like effect
  • Choreography: Control animation sequence for multiple elements
  • User feedback: Add slight delay for perceived responsiveness
  • Negative delay: Start animation partway through for repeating effects
Tip: Combine transition-delay with CSS selectors to create staggered effects without JavaScript: li:nth-child(1) { transition-delay: 0s; } li:nth-child(2) { transition-delay: 0.1s; }

Transition Shorthand Syntax

The transition shorthand combines all four properties into one declaration. Order matters!

/* Syntax: property duration timing-function delay */ transition: background-color 0.3s ease 0s; /* All shorthand forms are valid */ transition: all 0.3s; transition: all 0.3s ease-in-out; transition: background-color 0.3s, transform 0.4s; transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1) 0.1s; /* Multiple transitions (comma-separated) */ transition: background-color 0.3s ease, transform 0.4s ease-in-out, opacity 0.2s linear;

Property Order in Shorthand

Position Property Required Example
1st transition-property ✓ Yes background-color
2nd transition-duration ✓ Yes 0.3s
3rd transition-timing-function Optional (default: ease) ease-in-out
4th transition-delay Optional (default: 0s) 0.1s

Best Practices

✓ Use Transform

Animate transform instead of position/size properties for better performance

✓ Keep It Short

Use 0.2s-0.6s for most UI interactions. Longer transitions feel sluggish.

✓ Choose Right Easing

ease-out for enter, ease-in for exit, ease-in-out for both

✓ Prefer ease-in-out

Feels most natural for most animations. cubic-bezier(0.4, 0, 0.2, 1) is a great default

✓ Use Delays Sparingly

Delays should be subtle (0.05s-0.2s) to avoid feeling unresponsive

✓ Respect Preferences

Use prefers-reduced-motion to disable animations for users who request it

Accessibility: Respect Motion Preferences

/* Default: animations enabled */ button { transition: all 0.3s ease; } /* Respect user preference for reduced motion */ @media (prefers-reduced-motion: reduce) { button { transition: none; } } /* Or reduce animation duration/intensity */ @media (prefers-reduced-motion: reduce) { button { transition-duration: 0.01ms; } }
Performance Warning: Avoid transitioning properties that trigger layout recalculation (width, height, top, left). Use transform and opacity instead for GPU-accelerated animations.

Advanced Transition Techniques

Technique 1: Staggered Animations

/* Delay each list item's animation */ li { transition: all 0.3s ease; } li:nth-child(1) { transition-delay: 0s; } li:nth-child(2) { transition-delay: 0.1s; } li:nth-child(3) { transition-delay: 0.2s; } li:nth-child(4) { transition-delay: 0.3s; } li:hover { transform: translateX(10px); background: #f0f0f0; }

Technique 2: Multiple Property Transitions

button { transition: background-color 0.3s ease, color 0.3s ease, transform 0.2s ease, box-shadow 0.3s ease; } button:hover { background-color: #667eea; color: white; transform: translateY(-2px); box-shadow: 0 8px 16px rgba(0, 0, 0, 0.2); }

Technique 3: Smooth Reveal Animation

.reveal { opacity: 0; transform: translateY(20px); transition: all 0.6s ease-out; } .reveal.active { opacity: 1; transform: translateY(0); }

Technique 4: Bounce Effect with Cubic-Bezier

.bounce { transition: transform 0.6s cubic-bezier(0.68, -0.55, 0.265, 1.55); } .bounce:hover { transform: scale(1.1); }

Technique 5: Two-Stage Transition

.tooltip { opacity: 0; pointer-events: none; transition: opacity 0.2s ease 0s, visibility 0s ease 0.2s; visibility: hidden; } .tooltip.show { opacity: 1; pointer-events: auto; transition: opacity 0.2s ease 0s, visibility 0s ease 0s; visibility: visible; }

Summary

CSS transitions are essential for creating smooth, professional animations. Key takeaways:

  • ✓ Use transition shorthand for clean, concise code
  • ✓ Keep durations short (0.2s-0.6s) for UI responsiveness
  • ✓ Choose timing functions wisely—ease-in-out usually works best
  • ✓ Prioritize performance—animate transform and opacity
  • ✓ Use delays for staggered, choreographed effects
  • ✓ Always respect prefers-reduced-motion for accessibility
  • ✓ Test on real devices and browsers for smoothness
