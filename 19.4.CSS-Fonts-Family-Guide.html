CSS Font-Family Property

Complete Guide to Web Typography and Font Selection

1. Introduction to Font-Family

The font-family property specifies the font or list of fonts to use for displaying text. It supports multiple fallback options to ensure text displays properly even if the preferred font isn't available.

Syntax

font-family: [ family-name | generic-family ] #; /* Examples */ font-family: Georgia, serif; font-family: "Arial Black", sans-serif; font-family: 'Times New Roman', Times, serif; font-family: monospace; font-family: inherit;

Key Points

  • Always provide fallback fonts separated by commas
  • Quote font names with spaces or special characters
  • Generic families (serif, sans-serif, monospace) as last fallback
  • Font stacks should be ordered from most to least preferred
  • Impacts page load time and overall design appearance

2. Font Categories

Serif Fonts

Fonts with small lines at the end of characters. Traditional, formal appearance. Good for body text in print, less common on web.

Examples: Georgia, Times New Roman, Garamond, Palatino, Droid Serif

Sans-Serif Fonts

Fonts without decorative lines. Modern, clean appearance. Preferred for web body text and digital interfaces.

Examples: Arial, Helvetica, Verdana, Trebuchet MS, Open Sans, Roboto

Monospace Fonts

Fixed-width fonts where each character takes equal space. Used for code, technical text, and terminal-style content.

Examples: Courier New, Monaco, Consolas, 'Courier Prime', Menlo

Display Fonts

Decorative and stylized fonts for headings and special purposes. Use sparingly for impact.

Handwriting/Script Fonts

Mimics handwritten or calligraphic style. Use for special occasions or branding only.

Use these sparingly as they can reduce readability. Best for headers or decorative elements.

6. Font Stacking Best Practices

A font stack is a list of fonts in priority order. The browser uses the first available font and falls back to the next if unavailable.

How Font Stacks Work

font-family: 'Custom Font', 'Fallback 1', 'Fallback 2', generic-family; /* Browser logic */ 1. Try to load "Custom Font" 2. If not available, use "Fallback 1" 3. If not available, use "Fallback 2" 4. If all fail, use generic-family system default

Effective Font Stack Structure

/* Good Font Stack */ font-family: 'Georgia Pro', /* Specific licensed font */ Georgia, /* Web-safe serif font */ 'Times New Roman', /* Additional serif fallback */ 'Times', /* Older systems */ serif; /* Generic fallback /* Reasoning */ 1. Start with specific/premium fonts 2. Add trusted web-safe alternatives 3. Include older fallbacks for legacy browsers 4. End with generic family

Common Font Stacks by Use Case

Use Case Font Stack
Modern Web Design -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif
Professional Content 'Georgia Pro', Georgia, 'Times New Roman', serif
Technology/Code 'Monaco', 'Menlo', 'Ubuntu Mono', monospace
Clean Minimal 'Helvetica Neue', Helvetica, Arial, sans-serif
Accessibility First 'Arial', 'Helvetica', sans-serif

Font Stack Guidelines

  • ✅ Always quote font names with spaces or special characters
  • ✅ Order fonts from most to least specific
  • ✅ Include at least 2-3 fallbacks
  • ✅ Always end with a generic family
  • ✅ Test on multiple browsers and devices
  • ❌ Don't overuse exotic fonts
  • ❌ Don't mix too many fonts (2-3 maximum)
  • ❌ Don't forget to quote font names properly

7. Custom Fonts with @font-face

The @font-face rule allows you to use custom fonts hosted on your server or CDN, not installed on user's system.

Basic @font-face Syntax

@font-face { font-family: 'MyCustomFont'; src: url('/fonts/mycustomfont.woff2') format('woff2'), url('/fonts/mycustomfont.woff') format('woff'), url('/fonts/mycustomfont.ttf') format('truetype'); font-weight: normal; font-style: normal; } body { font-family: 'MyCustomFont', Arial, sans-serif; }

Font Formats

Format Extension Browser Support File Size
WOFF 2 .woff2 Modern browsers Smallest ✅
WOFF .woff All modern + IE9+ Small
TrueType .ttf Most browsers Large
OpenType .otf Most browsers Large

@font-face Best Practices

@font-face { font-family: 'MyFont'; src: url('/fonts/myfont.woff2') format('woff2'), url('/fonts/myfont.woff') format('woff'); font-weight: 400; font-style: normal; font-display: swap; /* Important for performance */ } /* Define separate rules for each weight */ @font-face { font-family: 'MyFont'; src: url('/fonts/myfont-bold.woff2') format('woff2'); font-weight: 700; } @font-face { font-family: 'MyFont'; src: url('/fonts/myfont-italic.woff2') format('woff2'); font-style: italic; }
font-display Property: Controls how font is displayed during loading.
  • auto - Default behavior
  • swap - Show fallback immediately, switch when custom font loads ✅ Recommended
  • block - Hide text while font loads (bad UX)
  • fallback - Brief hiding, then show fallback
  • optional - Use font if already cached

8. Font Performance & Optimization

Performance Impact

✅ Faster Loading

  • System fonts (instant)
  • Web-safe fonts (cached)
  • Minimal font variants
  • WOFF2 format

❌ Slower Loading

  • Custom @font-face fonts
  • Multiple font weights
  • Large file sizes
  • TTF/OTF formats

Optimization Techniques

/* 1. Limit Font Variants */ @import url('https://fonts.googleapis.com/css2?family=Open+Sans:wght@400;700&display=swap'); /* 2. Use font-display: swap */ @font-face { font-family: 'CustomFont'; src: url('font.woff2') format('woff2'); font-display: swap; } /* 3. Preload Critical Fonts */ <link rel="preload" as="font" href="font.woff2" type="font/woff2" crossorigin> /* 4. Use System Fonts (Fastest) */ font-family: system-ui, -apple-system, sans-serif; /* 5. Subset Fonts */ @import url('https://fonts.googleapis.com/css2?family=Roboto&text=Hello'); /* 6. Use font-weight and font-style strategically */ /* Load only weights you actually use */ @import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;700');
Performance Tip: Each font weight/variant requires a separate HTTP request. Load only what you need. A single poorly optimized font can delay page rendering.

9. Font Selection for Accessibility

Accessible Font Characteristics

  • ✅ Sans-serif fonts generally more readable on screen
  • ✅ High contrast between characters
  • ✅ Adequate spacing (line-height: 1.5+)
  • ✅ Minimum 16px for body text
  • ✅ Clear distinction between similar letters (0 vs O, l vs I)
  • ✅ Dyslexia-friendly fonts available when needed
  • ❌ Avoid very decorative or hard-to-read fonts
  • ❌ Don't rely on font alone to convey meaning

Dyslexia-Friendly Fonts

/* Popular dyslexia-friendly options */ font-family: 'Dyslexie', 'OpenDyslexic', sans-serif; font-family: 'Arial', sans-serif; /* Also suitable */ font-family: 'Verdana', sans-serif; /* Good choice */
WCAG Guidelines:
  • Use font-size of at least 14px (preferably 16px)
  • Maintain line-height of at least 1.5
  • Ensure sufficient color contrast (4.5:1 for normal text)
  • Avoid all caps text (use text-transform if needed)

10. Common Issues & Solutions

Issue 1: Font Not Loading

/* Problem: Font name mismatch */ /* CSS */ font-family: 'MyFont Bold'; /* Should be */ @font-face { font-family: 'MyFont'; src: url('myfont-bold.woff2'); font-weight: 700; } font-family: 'MyFont'; font-weight: 700;

Issue 2: Font Stack Ignored

/* Problem: Quotes missing */ font-family: Arial Black, sans-serif; /* ❌ Can break */ /* Solution: Always quote names with spaces */ font-family: 'Arial Black', sans-serif; /* ✅ Correct */

Issue 3: FOUT/FOIT (Flash of Unstyled/Invisible Text)

/* Use font-display to control behavior */ @font-face { font-family: 'CustomFont'; src: url('font.woff2'); font-display: swap; /* Show fallback while loading */ } /* Or use fallback-first approach */ body { font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif; }

Issue 4: Wrong Font Weight Not Rendering

/* Problem: Not defining font weights */ @font-face { font-family: 'MyFont'; src: url('myfont-regular.woff2'); } strong { font-weight: bold; } /* ❌ Browser creates fake bold */ /* Solution: Define each weight separately */ @font-face { font-family: 'MyFont'; src: url('myfont-regular.woff2'); font-weight: 400; } @font-face { font-family: 'MyFont'; src: url('myfont-bold.woff2'); font-weight: 700; } strong { font-weight: 700; } /* ✅ Uses actual font file */
