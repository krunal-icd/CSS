CSS shape-outside Property: Complete Guide

Master text wrapping around non-rectangular shapes with shape-outside. Learn all value types, practical applications, and best practices for creating sophisticated layouts.

Overview

The shape-outside property defines how text wraps around an element's content box. Instead of wrapping around the rectangular bounding box, content flows around the actual shape of the element.

Key Point: shape-outside only affects how surrounding content wraps around the element. The element itself remains unchanged visually—you may need to use clip-path or border-radius to actually see the shape.
Property Value Description
Property Name shape-outside Controls text wrapping around element shapes
Initial Value none No special shape; wraps around bounding box
Applies To Floated elements Only works on floated elements (float: left or right)
Inherited No Not inherited from parent elements
Browser Support Modern browsers Chrome 37+, Firefox 62+, Safari 10.1+, Edge 79+

Syntax

/* Keyword values */ shape-outside: none; /* Function values */ shape-outside: circle(50%); shape-outside: ellipse(50% 40%); shape-outside: polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%); shape-outside: inset(10px 20px 30px 40px); shape-outside: inset(10px 20px 30px 40px round 5px); /* Image values */ shape-outside: url('shape.png'); /* Box values */ shape-outside: margin-box; shape-outside: border-box; shape-outside: padding-box; shape-outside: content-box; /* Combinations */ shape-outside: url('shape.png') 10px 20px;

Value Types

circle()

Creates circular wrapping. Syntax: circle(radius at x y)

ellipse()

Creates elliptical wrapping. Syntax: ellipse(rx ry at x y)

polygon()

Creates custom polygonal wrapping from coordinate points.

inset()

Insets the wrapping shape. Syntax: inset(top right bottom left round radius)

url()

Uses image alpha channel to define wrapping shape.

margin-box

Wraps around the margin box of the element.

Related Properties

shape-margin

Adds space between the shape boundary and wrapping text.

shape-margin: 10px; shape-margin: 1em; shape-margin: 5%; /* Pushes text further from the shape edge */

shape-image-threshold

When using shape-outside: url(), defines the alpha threshold for determining shape boundaries.

shape-image-threshold: 0.5; /* Default: considers alpha >= 50% */ shape-image-threshold: 0.25; /* More transparent pixels included */ shape-image-threshold: 0.75; /* Only more opaque pixels included */

float

Required for shape-outside to work. The element must be floated (left or right).

float: left; /* shape-outside wraps content to the right */ float: right; /* shape-outside wraps content to the left */

clip-path (Visual Enhancement)

While shape-outside controls wrapping, use clip-path to actually see the shape visually.

/* shape-outside controls wrapping */ shape-outside: circle(50%); /* clip-path shows the actual shape */ clip-path: circle(50%);

Best Practices

✓ Coordinate Shapes

Use matching shape-outside and clip-path values so the wrapping matches the visible shape.

✓ Test Responsively

Use percentage-based values for shapes to maintain proportions on different screen sizes.

✓ Use shape-margin

Add breathing room between the shape and text with shape-margin for better readability.

✓ Performance Consideration

Complex polygons can impact performance. Test with many elements and consider simpler shapes if needed.

✓ Fallback Content

Browsers without shape-outside support will wrap around the bounding box—ensure content is still readable.

✓ Combine with Float

Always use float: left or float: right. shape-outside has no effect without floated elements.

Important: shape-outside only works on floated elements. For other positioning methods (flexbox, grid, absolute positioning), the property has no effect. The element MUST be floated for shape-outside to function.
Accessibility Note: While shape-outside enhances visual design, ensure text remains readable and flows logically. Test with screen readers to ensure content order makes sense.

Common Pitfalls & Solutions

❌ Forgetting float: left/right

Problem: shape-outside has no effect without float.

Solution: Always add float: left or float: right to the element.

❌ Mismatched Shapes

Problem: shape-outside and clip-path don't match visually.

Solution: Use identical values for both properties for consistent appearance.

❌ No Visual Indicator

Problem: Shape wrapping is invisible without clip-path.

Solution: Add clip-path with matching shape value to see the effect.

❌ Text Readability Issues

Problem: Text flows too close to shape edges.

Solution: Use shape-margin: 10px to create breathing room.

❌ Complex Polygons Performance

Problem: Many complex polygons cause rendering lag.

Solution: Simplify polygon coordinates or use circle/ellipse for better performance.

❌ Image Shape Transparency

Problem: Image-based shapes don't work as expected.

Solution: Adjust shape-image-threshold value to match your image's alpha channel.

Performance Optimization

Optimization Strategies

  • Use circles/ellipses over polygons: Simple shapes calculate faster than complex polygons
  • Limit polygon complexity: Keep polygons to under 20 points when possible
  • Cache shape calculations: Browser caches shape calculations; reuse shape values
  • Avoid animating shape-outside: Frequent shape changes trigger expensive reflows
  • Use CSS containment: Apply contain: layout style paint to isolated shape elements
  • Defer image-based shapes: Load images asynchronously to avoid blocking
  • Test on lower-end devices: Complex shapes can struggle on mobile hardware

CSS Containment for Shapes

.shape-element { float: left; shape-outside: circle(50%); /* Limit reflow impact to this element only */ contain: layout style paint; }
Performance Tip: Use CSS containment on shape elements to prevent the browser from recalculating layout for the entire page when shapes change. This significantly improves performance with multiple shaped elements.

Accessibility Considerations

Ensure Readability

  • Use sufficient shape-margin to prevent text crowding
  • Maintain adequate contrast between text and background
  • Ensure text flows in a logical reading order
  • Test with screen readers—logical content order is critical
  • Avoid shapes that create confusing text flows
  • Provide alt text for image-based shapes

Testing Accessibility

/* Test with screen readers */ /* Ensure content order remains logical despite shape wrapping */ .shape-element { float: left; shape-outside: circle(50%); shape-margin: 20px; /* Extra margin for readability */ margin-bottom: 20px; } /* Consider providing a text alternative in print media */ @media print { .shape-element { float: none; shape-outside: none; } }
Key Point: Visual shape wrapping shouldn't compromise content accessibility. Always test with assistive technologies and ensure text remains readable.
