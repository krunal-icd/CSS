CSS Filter Properties: Complete Guide

Master CSS filters for stunning visual effects. Learn all filter functions, syntax, combinations, and best practices for creating professional, polished web designs.

Overview

CSS filters allow you to apply graphical effects like blur, brightness, contrast, grayscale, hue rotation, inversion, opacity, saturation, sepia, and drop-shadow to elements. The filter property is powerful for visual enhancements without modifying the original element.

Key Point: CSS filters are GPU-accelerated and apply visual effects after the element is rendered, providing smooth performance and non-destructive styling.
Property Value Description
Property Name filter Applies visual effects to elements
Initial Value none No filters applied
Applies To All elements Works on any HTML element
Inherited No Not inherited from parent elements
Animatable Yes Can be animated with CSS transitions
Browser Support Modern browsers Chrome 18+, Firefox 35+, Safari 6+, Edge 12+

Syntax & Filter Functions

/* Basic syntax */ filter: none; filter: blur(5px); filter: brightness(120%); /* Multiple filters */ filter: blur(5px) brightness(120%) contrast(130%); /* With var() */ filter: blur(var(--blur-amount));

All Filter Functions

Filter Function Value Range Default Description
blur() 0px to any value 0px Blurs the element. Values in pixels.
brightness() 0% to 200%+ (0 to 2+) 100% (1) Adjusts brightness. <100% = darker, >100% = brighter
contrast() 0% to 200%+ (0 to 2+) 100% (1) Adjusts contrast. <100% = lower, >100% = higher
grayscale() 0% to 100% (0 to 1) 0% Converts to grayscale. 100% = fully grayscale
hue-rotate() 0deg to 360deg 0deg Rotates colors on the color wheel
invert() 0% to 100% (0 to 1) 0% Inverts colors. 100% = fully inverted
opacity() 0% to 100% (0 to 1) 100% (1) Adjusts element opacity (similar to CSS opacity)
saturate() 0% to 200%+ (0 to 2+) 100% (1) Adjusts color saturation. <100% = desaturated, >100% = oversaturated
sepia() 0% to 100% (0 to 1) 0% Applies sepia tone. 100% = full sepia
drop-shadow() offset-x offset-y blur-radius color N/A Applies drop shadow. Similar to box-shadow but applies to shape.

Combining Multiple Filters

You can chain multiple filters together to create complex visual effects. Filters are applied left to right.

/* Two filters */ filter: blur(3px) brightness(120%); /* Three filters */ filter: grayscale(100%) brightness(80%) contrast(150%); /* Complex combination */ filter: blur(2px) brightness(110%) contrast(120%) saturate(150%) drop-shadow(0 0 10px rgba(0,0,0,0.3)); /* With variables */ filter: blur(var(--blur)) brightness(var(--brightness));

Practical Usage Patterns

Pattern 1: Hover Effects on Images

img { transition: filter 0.3s ease; } img:hover { filter: brightness(120%) contrast(110%); }

Pattern 2: Dark Mode Toggle

/* Light mode */ body { filter: none; } /* Dark mode */ body.dark-mode { filter: invert(1) hue-rotate(180deg); }

Pattern 3: Vintage Photo Effect

.vintage-photo { filter: sepia(50%) saturate(60%) grayscale(30%) brightness(90%); }

Pattern 4: Focus/Blur Other Elements

.focused { filter: brightness(100%); } .unfocused { filter: brightness(60%) blur(2px); }

Pattern 5: Loading Animation

@keyframes loading { 0% { filter: brightness(100%); } 50% { filter: brightness(150%); } 100% { filter: brightness(100%); } } .loading-element { animation: loading 1.5s ease-in-out infinite; }

Pattern 6: Color Shift on Hover

.color-shift { transition: filter 0.3s ease; } .color-shift:hover { filter: hue-rotate(45deg) saturate(150%); }

Best Practices

✓ Use Sparingly

Filters enhance design but overuse creates visual noise. Use purposefully for effects that improve UX.

✓ Animate Smoothly

Use transition: filter 0.3s ease for smooth, professional animations on hover/focus states.

✓ Test Performance

Complex filters or multiple animations can impact performance. Test on mobile devices and lower-end hardware.

✓ Maintain Accessibility

Ensure filters don't compromise readability or accessibility. Low contrast filters can be problematic for users with vision impairments.

✓ Provide Fallbacks

Some older browsers don't support filters. Design experiences that work without filters as well.

✓ CSS Variables for Control

Use CSS custom properties for filter values to easily adjust effects globally or with JavaScript.

Performance Warning: Combining multiple filters with animations on many elements can cause jank. Use DevTools to profile and optimize.
Accessibility Important: Avoid filters that reduce contrast or make text harder to read. Always test with accessibility tools and real users.

Performance Considerations

What Impacts Performance

  • Blur: More expensive at higher pixel values. Use blur(5px) not blur(20px)
  • Multiple filters: Each additional filter adds computation cost
  • Large element sizes: Filters on full-screen elements cost more than small elements
  • Animations: Animating filter values causes repaints. Use GPU-accelerated filters when possible
  • Will-change: Can improve performance but use sparingly

Optimization Tips

/* Use GPU acceleration */ .optimized-filter { filter: brightness(120%); will-change: filter; transform: translateZ(0); /* GPU acceleration hint */ } /* Limit blur radius */ .light-blur { filter: blur(3px); /* Not blur(15px) */ } /* Use shorthand when possible */ .efficient { filter: sepia(1); /* Instead of sepia(100%) */ }
