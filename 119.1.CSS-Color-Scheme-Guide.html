CSS color-scheme Property

Master light/dark theme declaration and browser-native theme support

What is the color-scheme Property?

The CSS color-scheme property tells the browser which color schemes (light and/or dark) your website supports. This enables automatic browser UI theming, form styling, scrollbar colors, and media query matching for prefers-color-scheme. It's the foundation of modern dark mode support in CSS.

Core Function: Declare theme support to the browser, enabling automatic application of system-appropriate colors to form elements, scrollbars, and native components.

Key Capabilities

Browser Theme Matching: Browser UI (scrollbars, inputs, buttons) automatically adapts to declared schemes.

System Preference Detection: Works with prefers-color-scheme media queries for responsive theming.

Form Styling Automation: Form inputs and elements receive native styling matching your color scheme.

Meta Tag Support: Can be declared in HTML meta tags for immediate browser awareness.

Zero JavaScript: Pure CSS declaration — no runtime overhead or JavaScript dependency.

Basic Syntax & Values

The color-scheme property accepts keyword values specifying supported color modes.

Syntax

color-scheme: light | dark | light dark | only light;

Value Breakdown

light: Website supports light mode only. color-scheme: light;
dark: Website supports dark mode only. color-scheme: dark;
light dark: Website supports both light and dark modes (preferred order matters). color-scheme: light dark;
only light: Forces light mode, ignoring system preference. color-scheme: only light;
only dark: Forces dark mode, ignoring system preference. color-scheme: only dark;

Common Usage Patterns

/* 1. Support both themes (light preferred) */
:root {
  color-scheme: light dark;
}

/* 2. Support both themes (dark preferred) */
:root {
  color-scheme: dark light;
}

/* 3. Light mode only */
:root {
  color-scheme: light;
}

/* 4. Force light mode (ignore system preference) */
:root {
  color-scheme: only light;
}
Order Matters: When specifying multiple schemes like light dark, the first value is the default preference if the user has no system preference set.

HTML Meta Tag Declaration

Beyond CSS, you can declare color-scheme in HTML's meta tag for immediate browser awareness before CSS loads.

Meta Tag Syntax

<!-- In HTML head -->
<meta name="color-scheme"
      content="light dark">

Best Practice: Use Both

<!-- In HTML head (for immediate browser awareness) -->
<meta name="color-scheme"
      content="light dark">

/* In CSS (for consistency and override capability) */
:root {
  color-scheme: light dark;
}
Pro Tip: Use HTML meta tag for universal browser support and immediate effect, then declare in CSS for override capability and better organization.

Integration with prefers-color-scheme Media Query

color-scheme works hand-in-hand with the prefers-color-scheme media query to create adaptive, theme-aware websites.

How They Work Together

color-scheme (Declaration)

/* Tells browser what we support */
:root {
  color-scheme: light dark;
}

prefers-color-scheme (Detection)

/* Detects user preference */
@media (prefers-color-scheme: dark) {
  :root {
    --bg: #1a1a1a;
  }
}

Complete Example

/* 1. Declare supported schemes */
:root {
  color-scheme: light dark;
  --bg-primary: white;
  --text-primary: black;
  --border: #e5e7eb;
}

/* 2. Define dark mode colors */
@media (prefers-color-scheme: dark) {
  :root {
    --bg-primary: #1f2937;
    --text-primary: #f3f4f6;
    --border: #374151;
  }
}

/* 3. Use variables throughout */
body {
  background: var(--bg-primary);
  color: var(--text-primary);
}
Automatic Behavior: When you declare color-scheme: light dark, browsers automatically know to style form elements, scrollbars, and native components appropriately for each theme.

Best Practices & Tips

Use Both Meta Tag and CSS: Meta tag for immediate effect, CSS for organization and override capability.

Declare Early: Place color-scheme declaration near the top of your HTML/CSS for fastest application.

Define CSS Variables First: Establish all color variables in light mode, then override in dark mode media query.

Support Both Themes: Use light dark to support both, respecting user preference.

Test Form Elements: Verify that inputs, buttons, and selects render correctly in both themes.

Consider Contrast Ratios: Ensure colors meet WCAG AA standards (4.5:1 for text) in both themes.

Common Pitfalls to Avoid

Forgetting the Meta Tag: Without HTML meta tag, users see light mode until CSS loads.

Using Only CSS: CSS takes time to load. Meta tag provides instant browser awareness.

Forcing One Theme: Avoid only light or only dark unless necessary. Respect user preference.

Ignoring System Preference: Not declaring color-scheme means users see browser defaults, not your intended theme.

Inconsistent Variable Names: Use semantic names like --bg-primary, not --dark-bg (which implies hardcoding).

Complete Working Example

Here's a production-ready implementation combining HTML and CSS.

Full Implementation

<!-- HTML head -->
<meta name="color-scheme"
      content="light dark">

/* CSS */
:root {
  color-scheme: light dark;
  
  /* Light mode (default) */
  --color-bg-primary: white;
  --color-bg-secondary: #f8f9fa;
  --color-text-primary: #1a1a1a;
  --color-text-secondary: #666666;
  --color-border: #e5e7eb;
  --color-accent: #667eea;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #1a1a1a;
    --color-bg-secondary: #2d2d2d;
    --color-text-primary: #ffffff;
    --color-text-secondary: #b0b0b0;
    --color-border: #374151;
    --color-accent: #a78bfa;
  }
}

body {
  background: var(--color-bg-primary);
  color: var(--color-text-primary);
}
