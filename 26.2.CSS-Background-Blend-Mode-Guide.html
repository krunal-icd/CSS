Practice Examples

Work through these interactive examples to understand how different blend modes create various visual effects.

1️⃣ Multiply Mode - Darkening Effect

Multiply mode darkens the image. The darker the overlay color, the more dramatic the effect. Great for overlays with text.

.multiply-overlay {
    background-image: url('image.jpg');
    background-color: rgba(0, 0, 0, 0.5);  /* Adjust opacity */
    background-blend-mode: multiply;
}

Key Insight: White becomes transparent, black stays black. Use with semi-transparent black for natural darkening.

2️⃣ Screen Mode - Lightening Effect

Screen mode lightens the image. Perfect for creating glowing or light overlay effects. Opposite of multiply.

Real-World Projects

Project 1: Product Card with Hover Effect

Create a product card that changes blend mode on hover for an interactive effect.

.product-card {
    background-image: url('product.jpg');
    background-color: var(--primary);
    background-blend-mode: multiply;
    transition: background-blend-mode 0.3s ease;
}

.product-card:hover {
    background-blend-mode: normal;
    /* Changes from darkened to full image on hover */
}

Quick Reference & Tips

Blend Mode Selection Guide

Want to darken? Use multiply

Want to lighten? Use screen

Want high contrast? Use overlay

Want subtle effect? Use soft-light

Want color tint? Use color

Want brightness control? Use luminosity

Common Patterns

background-image: url('image.jpg');
background-color: rgba(0, 0, 0, 0.5);
background-blend-mode: multiply;
background-image: url('image.jpg');
background-color: rgba(255, 255, 255, 0.3);
background-blend-mode: screen;
background-image: url('image.jpg');
background-color: #fbbf24;  /* Any color */
background-blend-mode: color;
.element {
    background-image: url('image.jpg');
    background-color: var(--primary);
    background-blend-mode: multiply;
    transition: background-blend-mode 0.3s ease;

}

Best Practices

  • Always test with real images
  • Maintain text readability with proper contrast
  • Use subtle effects for professional designs
  • Combine blend modes for complex effects
  • Use transitions when changing blend modes
  • Test on actual devices and browsers
  • Consider performance with many blend modes
  • Provide fallback styles for older browsers
