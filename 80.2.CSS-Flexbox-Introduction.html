Hero section that switches from row to column layout on mobile devices using media queries.
CSS

💡 Key Takeaways
1. Use flex: 1 for flexible sizing – Items grow to fill available space equally.

2. Use flex: 0 0 value for fixed sizes – Sidebar, avatars, and specific widths stay constant.

3. Combine with gap for spacing – Cleaner than margin and easier to maintain.

4. Use flex-wrap: wrap for grids – Cards automatically wrap to new lines.

5. Always include media queries – Make layouts responsive by changing flex-direction on mobile.

6. Center content easily – Use justify-content: center; align-items: center; for perfect centering.

7. Combine with min-width – Prevents flex items from becoming too small in responsive design.
