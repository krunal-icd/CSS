📐 CSS Viewport Units Explained

What are Viewport Units?

Viewport units are measurements based on your browser window size. When you resize your browser, elements using viewport units automatically resize too! They're perfect for creating responsive designs that work on all devices.

VW - Viewport Width
1vw = 1% of viewport width

VMIN - Viewport Minimum
1vmin = 1% of smallest dimension

VMAX - Viewport Maximum
1vmax = 1% of largest dimension

EM - Relative to Font Size
1em = current element's font size
Unlike viewport units, EM is relative to font size. Below, parent has 20px font, child has 1.5em (so 30px):

REM - Relative to Root
1rem = root element's font size
REM is like EM but always refers to the document's root font size (usually 16px). More predictable than EM!

Unit Meaning Use Case Example
VW % of viewport width Full-width sections, responsive widths width: 80vw
VH % of viewport height Hero sections, full-height layouts height: 100vh
VMIN % of smallest (width or height) Mobile-friendly squares, icons width: 50vmin
VMAX % of largest (width or height) Large screens, responsive text font-size: 8vmax
EM Current font size (inherited) Padding, margins, relative sizes padding: 2em
REM Root font size (usually 16px) Consistent sizing, responsive text font-size: 1.5rem
💡 Pro Tip: Try resizing your browser window to see the viewport units change in real-time! Use mobile device preview mode to see how they behave on different screen sizes.
