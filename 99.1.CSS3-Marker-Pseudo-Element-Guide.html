CSS3 ::marker Pseudo-Element

Master List Marker Styling

Complete tutorial with practical applications

What is the ::marker Pseudo-Element?

The ::marker pseudo-element in CSS3 allows you to style the marker (bullet point, number, or custom symbol) of list items without affecting the list item content itself. Before ::marker, changing list marker appearance required removing the default list style and recreating it with pseudo-elements or extra markup.

::marker works with:

  • <li> elements in <ul> and <ol>
  • ::before and ::after on summary elements
  • List markers in CSS Lists specification
Key Insight: ::marker gives you direct access to style the marker portion of list items independently from the content, enabling beautiful custom list designs without complex markup or JavaScript.

Common use cases:

  • Changing marker color to match your design
  • Making markers bold, italic, or using specific fonts
  • Replacing bullets with emoji or custom symbols
  • Creating interactive numbered lists with highlights
  • Building custom checklists and progress indicators

Properties You Can Style with ::marker

The ::marker pseudo-element supports a limited but useful set of CSS properties:

Property Description Example
color Change marker color li::marker { color: red; }
font-size Adjust marker size li::marker { font-size: 1.5em; }
font-weight Make marker bold li::marker { font-weight: bold; }
font-family Change marker font li::marker { font-family: monospace; }
font-style Make marker italic li::marker { font-style: italic; }
content Replace marker with custom content li::marker { content: "→ "; }
white-space Control whitespace in marker li::marker { white-space: pre; }

Properties NOT Supported

Some properties don't work with ::marker: background, width/height, positioning properties (margin, padding), transforms, and box-shadow. This is intentional—markers are meant to be simple, inline elements.

Browser Support

::marker has good support in modern browsers:

  • ✓ Chrome 86+
  • ✓ Firefox 68+
  • ✓ Safari 12+
  • ✓ Edge 86+
  • ✗ IE 11 (not supported)

Recommendation: Use ::marker freely in modern projects. For IE11 support, provide fallback styling on the list items themselves.

Basic Syntax and Usage

Basic Example
/* Style unordered list markers */ ul > li::marker { color: #667eea; font-weight: bold; } /* Style ordered list markers */ ol > li::marker { color: #28a745; font-size: 1.1em; } /* Custom marker content */ li::marker { content: "✓ "; }

Selector Specificity

You can target ::marker on specific list types: ul > li::marker, ol > li::marker, or even specific classes: li.important::marker. This allows different styling for different lists.

Advanced Patterns

Pattern 1: Color-Coded Priority Lists

Use ::marker color to indicate priority levels without changing the list structure:

Priority List Pattern
li.high::marker { color: #dc3545; font-weight: bold; } li.medium::marker { color: #ffc107; font-weight: bold; } li.low::marker { color: #28a745; font-weight: bold; }

Pattern 2: Custom Emoji Markers

Replace standard bullets with emoji or custom symbols:

Emoji Markers
/* Checklist with checkmark emoji */ li.done::marker { content: "✅ "; } li.pending::marker { content: "⏳ "; } /* Feature list with star markers */ li.feature::marker { content: "⭐ "; font-size: 1.2em; }

Pattern 3: Numbered Lists with Custom Styling

Enhance ordered lists with custom styling and colors:

Enhanced Numbered Lists
ol li::marker { color: #667eea; font-weight: bold; font-size: 1.1em; } /* Alternative: Replace numbers with letters */ ol li::marker { content: var(--item-letter) ". "; }

Pattern 4: Interactive Lists

Change marker on hover or focus for interactive effects:

Interactive Markers
li::marker { color: #667eea; transition: color 0.3s ease; } li:hover::marker { color: #764ba2; font-weight: bold; }

Limitations and Considerations

⚠ Limited CSS Properties

::marker only accepts specific properties: color, font-*, white-space, and content. Layout properties like margin, padding, width are not supported.

⚠ Content Property Behavior

When you use content to replace the marker, it completely overrides the default marker. This is useful for custom symbols but requires manual numbering if needed.

⚠ Browser Support

IE11 doesn't support ::marker. For those users, the browser's default marker styling will show. Consider progressive enhancement.

⚠ Accessibility

When replacing markers with emoji or custom content, ensure the meaning is still clear to screen readers. Test with accessibility tools.

Best Practices

✓ Use for Simple Styling

Use ::marker for color, size, and font changes. It's perfect for these simple customizations.

✓ Maintain Clarity

Ensure custom markers are clear and meaningful. Don't sacrifice usability for design.

✓ Test Readability

Custom markers should have good contrast and be easy to distinguish from content.

✓ Consider Accessibility

Test with screen readers when using emoji or unconventional markers to ensure meaning is preserved.

✗ Don't Over-Complicate

Don't try to do complex layout with ::marker. It's meant for simple styling only.

✗ Don't Rely on Custom Content

If you replace markers with custom content, ensure it's appropriate for all contexts (lists can be copied, printed, etc.).

Key Takeaways

  • ::marker pseudo-element allows styling list markers independently
  • Works with color, font-size, font-weight, font-family, font-style, content, white-space
  • Perfect for custom bullet colors and sizes without changing HTML structure
  • Can replace markers with emoji or custom symbols using content property
  • Excellent for creating visual hierarchies (priority levels, status indicators)
  • Each list item's marker can be styled independently with classes
  • Good browser support in Chrome, Firefox, Safari, Edge (86+)
  • Should not be used for complex layout—use pseudo-elements for that
  • Consider accessibility when using custom markers
  • Perfect for interactive lists with hover effects on markers
