🎯 CSS min() Function - Practical Examples

What is the CSS min() Function?

The min() function returns the smallest value from a list of comma-separated values. It's perfect for creating flexible, responsive designs.

Basic Syntax:
property: min(value1, value2, value3, ...);
✅ Browser Support: All modern browsers (Chrome 78+, Firefox 75+, Safari 11+, Edge 79+)

Example 1: Responsive Container Width

Create a container that scales down on smaller screens but never exceeds a maximum width.

CSS Code:

.container { width: min(90%, 600px); margin: 0 auto; }

How it Works:

  • On large screens: uses 600px (max width)
  • On smaller screens: uses 90% of viewport
  • Automatically switches at breakpoint (~667px)

Example 2: Responsive Font Size

Create text that scales with viewport but never gets too large.

CSS Code:

.heading { font-size: min(5vw, 48px); }

How it Works:

  • On small screens: scales with 5% of viewport width
  • On large screens: capped at 48px
  • Always readable at any screen size

CSS Code:

Control spacing between grid items responsively.

CSS Code:

Example 6: Using Multiple Values

Compare multiple values and use the smallest one.

CSS Code:

.element { width: min(100%, 500px, 90vw); }

Logic:

  • 100% = full parent width
  • 500px = fixed maximum
  • 90vw = 90% of viewport width
  • Browser picks the smallest value

Related Functions: max() and clamp()

max() Function

max(value1, value2, ...) returns the largest value
width: max(50%, 300px) → Uses at least 300px

clamp() Function

clamp(min, preferred, max) sets a minimum, preferred, and maximum value
font-size: clamp(16px, 2vw, 32px) → Between 16px and 32px

Comparison:

Function Purpose Example
min() Use smallest value min(90%, 600px)
max() Use largest value max(50%, 300px)
clamp() Stay within range clamp(16px, 2vw, 32px)

💡 Best Practices

1. Combine with auto-fit/auto-fill

Use min() inside minmax() for perfect grid layouts

2. Compare Units

Mix fixed units (px), relative units (%, vw), and typography units (ch) for flexibility

3. Mobile-First Thinking

min() naturally prefers mobile constraints first

4. Performance

No JavaScript needed - calculations happen at render time

5. Fallbacks

Older browsers ignore min() - provide fallback values

Browser Fallback Example

With Fallback for Older Browsers:

.container { /* Fallback for older browsers */ width: 90%; /* Modern browsers will use this */ width: min(90%, 600px); }
Old browsers ignore the second declaration and use 90%, while modern browsers use the min() value.
