CSS Pseudo-Elements

Practical Examples & Real-World Use Cases

Status Icons

::before

Add status icons before text using ::before.

Operation completed successfully
Warning: Please review
Error: Action failed
.item::before {
  content: "✓ ";
  color: #4caf50;
  margin-right: 8px;
}

.warning::before {
  content: "⚠ ";
  color: #ff9800;
}
Use Case: Status indicators and alerts without extra HTML.

Create elegant drop cap effect for first letter.

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat.

First Line Styling

::first-line

Style the first line of text differently.

This is the first line of text that will be styled differently. It will appear in purple and bold. The rest of the paragraph continues with normal styling.

p::first-line {
  color: #764ba2;
  font-weight: 600;
  text-transform: uppercase;
  letter-spacing: 1px;
}
Use Case: Emphasis for article titles or introduction lines.

Style highlighted text with custom colors. Try selecting text!

Select this text to see the custom selection color in action. The background will turn blue and the text white when highlighted.

p::selection {
  background: #667eea;
  color: white;
}

p::-moz-selection {
  background: #667eea;
  color: white;
}
Use Case: Brand color implementation for text selection.

Form Placeholders

::placeholder

Custom styling for input placeholder text.

input::placeholder {
  color: #999;
  font-style: italic;
  opacity: 0.7;
}

input:focus::placeholder {
  color: #ccc;
}
Use Case: Improved form input visibility and accessibility.

Pseudo-Elements Reference

Pseudo-Element Purpose Use Case
::before Insert content before element Icons, labels, decorations
::after Insert content after element Tooltips, clearfix, closing marks
::first-line Style first line of text Typography, emphasis
::first-letter Style first character Drop caps, editorial design
::selection Style selected text Brand colors, UX
::placeholder Style input placeholder Form inputs
::marker Style list bullets/numbers Custom lists
::cue Style video captions Media captions

Key Takeaways

  • ::before and ::after: Use the content property to insert text, icons, or images.
  • content property: Required for ::before/::after to display. Can use text, url(), attr(), counter().
  • ::first-letter: Perfect for drop cap effects. Only works on block-level elements.
  • ::first-line: Style first line differently. Property support is limited.
  • ::selection: Customize text highlighting. Use both ::selection and ::-moz-selection.
  • ::placeholder: Style form input hints. Always provide proper labels.
  • ::marker: Style list bullets and numbers. Modern browsers only.
  • Double colon syntax (::): Correct for pseudo-elements. Single colon is deprecated.
  • Not in DOM: Pseudo-elements aren't selectable by JavaScript. Use data attributes instead.
  • Powerful for decoration: Use for visual enhancements without adding extra HTML elements.
