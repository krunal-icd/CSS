Basic Stacking Order

Example 1
Demonstrates how z-index controls the vertical stacking order. Higher values appear on top. All boxes are positioned absolutely with different z-index values.
z:1
z:2
z:3
CSS
.box-1 { position: absolute; z-index: 1; top: 20px; left: 20px; } .box-2 { position: absolute; z-index: 2; top: 80px; left: 80px; } .box-3 { position: absolute; z-index: 3; top: 40px; left: 140px; }
💡 Key Point: Notice how box-3 appears on top despite being smaller and defined last.

Modal Dialog with Overlay

A modal dialog system using overlays. The overlay has z-index: 998 and the modal content has z-index: 999 to ensure they sit above all other page content.

Example Modal

This modal uses z-index to appear above all other content on the page.

Z-index values:

  • Overlay: z-index 998
  • Modal: z-index 999

Parallax Effect with Layers

Example 6
A parallax scene with multiple layers at different z-indices. Lower z-index elements move more slowly, creating a depth effect.
CSS
.parallax-bg { z-index: 1; } .parallax-clouds { z-index: 2; } .parallax-foreground { z-index: 3; }
💡 Effect: Different layers stack to create depth and visual interest.

Stacking Context Comparison

Example 8
Left: Normal stacking where z-index works intuitively. Right: Inside a stacking context (opacity: 0.9), z-index values are relative to that context, not the page.
Normal Stacking
z:100
z:50
z:1
With Stacking Context (opacity)
z:100*
z:50
z:1
CSS - Right Example
.stacking-context-container { position: relative; opacity: 0.9; /* Creates new stacking context */ } /* z-index: 100 now only compares within this context */ .item-1 { z-index: 100; }
🎯 Key Insight: In the right example, even with z-index: 100, the item can't appear above z-index: 1 because it's in a different stacking context.

Common Issues & Solutions

Troubleshooting

❌ Problem 1: Z-index Not Working

Cause: Element doesn't have position property set
/* ❌ Won't work */ .element { z-index: 10; } /* ✓ Will work */ .element { position: relative; z-index: 10; }

❌ Problem 2: High Z-index Doesn't Help

Cause: Element is inside a stacking context (parent has opacity, transform, etc.)
/* Parent creates stacking context */ .parent { opacity: 0.9; } /* Child z-index: 1000 won't help vs sibling z-index: 1 */ .parent .child { z-index: 1000; }

❌ Problem 3: Dropdown Behind Content

Cause: Parent has overflow: hidden or z-index is too low
/* ❌ Parent overflow hides dropdown */ .nav { overflow: hidden; } /* ✓ Solution: Use overflow: visible */ .nav { overflow: visible; } /* ✓ Ensure dropdown has high z-index */ .dropdown { z-index: 1000; }

✓ Debugging Tips

  • Use DevTools to inspect computed z-index value
  • Check for stacking context creators in parent elements
  • Look for conflicting CSS that might set position: static
  • Verify parent doesn't have overflow: hidden
  • Use Chrome's 3D view to visualize stacking

💡 Pro Tip: Open your browser's Developer Tools (F12) and inspect the elements to see the actual CSS values in action.
