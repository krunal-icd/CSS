CSS Text-Decoration Complete Guide

Master all text decoration properties with practical examples

What is text-decoration?

The text-decoration CSS property is a shorthand that decorates text with a line. It includes underlines, overlines, line-through, and more advanced styling options introduced in CSS 3.

Modern CSS provides individual properties to control decoration style, color, thickness, and offset, giving you fine-grained control over text appearance. This guide covers all properties and real-world use cases.

Text-Decoration Properties Overview

  1. text-decoration-line - Type of decoration
  2. text-decoration-style - Line style
  3. text-decoration-color - Decoration color
  4. text-decoration-thickness - Line thickness
  5. text-underline-offset - Distance from text
  6. text-decoration-skip - Skip characters
  7. Shorthand: text-decoration - Combined property
  8. Multiple decorations - Multiple lines
  9. Interactive effects - Hover animations
  10. Advanced techniques - Custom styling

Advanced Text-Decoration Techniques

1. Custom Link Styling

Create unique link styles without removing the underline:

CSS:
a {
  color: #667eea;
  text-decoration: underline wavy;
  text-decoration-color: rgba(102, 126, 234, 0.5);
  text-underline-offset: 4px;
  transition: all 0.3s ease;
}

a:hover {
  text-decoration-color: #667eea;
  text-decoration-thickness: 2px;
}

2. Text-Decoration-Skip for Better Control

Control where decorations skip (spaces, punctuation, etc.):

CSS:
p {
  text-decoration: underline;
  text-decoration-skip: spaces; /* Skip spaces */
}

3. Emphasis with Multiple Decorations

Create strong emphasis with layered decorations:

CSS:
.emphasis {
  text-decoration: underline overline;
  text-decoration-color: #f39c12;
  text-decoration-thickness: 3px;
  font-weight: bold;
}

4. Deleted Text (E-commerce)

Show original prices with strikethrough:

HTML & CSS:
<del>$99.99</del> $49.99

del {
  text-decoration: line-through;
  text-decoration-color: #e74c3c;
  opacity: 0.7;
  margin-right: 10px;
}

5. Wavy Underline for Spelling Errors

Mimic browser spell-check styling:

CSS:
.spelling-error {
  text-decoration: underline wavy #e74c3c;
  text-underline-offset: 2px;
}

6. Animated Underline on Scroll

Advanced: Animated underline effect (requires JavaScript for scroll detection):

CSS:
@keyframes underline-grow {
  from {
    text-decoration-thickness: 1px;
  }
  to {
    text-decoration-thickness: 4px;
  }
}

.animated-link {
  text-decoration: underline;
  animation: underline-grow 0.5s ease-out forwards;
}

💡 Best Practices & Tips

  • Use for emphasis: Underlines draw attention and highlight important text sections.
  • Reserve strikethrough: Use line-through for deleted or outdated content, not just for styling.
  • Color contrast: Ensure decoration color has sufficient contrast against the background for readability.
  • Style consistency: Apply consistent text-decoration styles across your site for a professional appearance.
  • Avoid overuse: Multiple decorations can look cluttered. Use sparingly for maximum impact.
  • Offset for clarity: Use text-underline-offset to create space between text and underline for better readability.
  • Wavy for errors: Reserve wavy underlines for spell-check and validation errors.
  • Interactive feedback: Change decoration on hover/focus to provide visual feedback to users.
  • Links accessibility: Don't remove underlines from links entirely; users expect them to be underlined.
  • Test visibility: Ensure decorations remain visible on all screen sizes and backgrounds.

♿ Accessibility Considerations

Color alone: Don't rely solely on text-decoration color to convey information. Users with color blindness may not distinguish different colors. Combine with other visual indicators or text labels.

Contrast requirements: Text-decoration color should have a contrast ratio of at least 4.5:1 against the background per WCAG guidelines. Use tools like WebAIM Contrast Checker to verify.

Underlines on links: Keep underlines on links (or at least make them visible on focus) to help users identify interactive elements, especially for people with cognitive disabilities.

Semantic HTML: Use semantic tags like <del>, <ins>, <s>, and <u> along with CSS for meaning and styling.

Focus indicators: Always provide visible focus indicators for keyboard navigation. Text-decoration changes can serve as focus indicators.
