CSS Object-Fit Property

12 Practical Interactive Examples

1. Object-Fit: Contain

Fits completely, maintains aspect ratio

object-fit: contain
Image scales to fit completely inside container while maintaining aspect ratio. Empty space may appear (letter-boxing).
img { width: 100%; height: 200px; object-fit: contain; }
✓ Best for: Products, logos, UI elements

2. Object-Fit: Cover

Covers container, maintains aspect ratio

object-fit: cover
Image scales to cover entire container while maintaining aspect ratio. Parts may be cropped (no empty space).
img { width: 100%; height: 200px; object-fit: cover; }
✓ Best for: Hero images, thumbnails, galleries

3. Object-Fit: Fill

Stretches to fill container

object-fit: fill
Image stretches to completely fill container. Aspect ratio is ignored, which may cause distortion. Rarely recommended.
img { width: 100%; height: 200px; object-fit: fill; }
⚠️ Use with caution: May distort images

4. Object-Fit: Scale-Down

Smaller of contain or original size

object-fit: scale-down
Uses the smaller of contain or original size. Small images won't be enlarged; large images scale down. Never distorts.
img { width: 100%; height: 200px; object-fit: scale-down; }
✓ Best for: Responsive images of varying sizes

5. Object-Fit: None

No scaling, original size maintained

object-fit: none
Image keeps original size, not scaled. May overflow container. Used with object-position for precise cropping.
img { width: 100%; height: 200px; object-fit: none; object-position: 50% 50%; }
✓ Best for: Precise image positioning

6. Product Gallery

E-commerce grid layout

object-fit: contain in grid
Products displayed in grid with consistent sizing. Object-fit: contain shows full product with white space.
.product-item { object-fit: contain; padding: 10px; }
✓ Consistent product display with padding

7. Hero Banner Image

Full-width hero section

object-fit: cover + object-position
Hero image covers full width and height. Uses object-position: center to focus on middle of image.
.hero-image { width: 100%; height: 400px; object-fit: cover; object-position: center; }
✓ Professional hero sections

8. Circular Profile Pictures

Avatar images

object-fit: cover + border-radius
Circular profile pictures with object-fit: cover to automatically crop to best fit within circle.
.profile-pic { width: 120px; height: 120px; border-radius: 50%; object-fit: cover; }
✓ Always perfectly cropped avatars

9. Video Thumbnails Grid

YouTube-style thumbnail layout

object-fit: cover in grid
Uniform thumbnail display with object-fit: cover. All thumbnails fill their space without distortion.
.video-thumbnail { object-fit: cover; border-radius: 4px; }
✓ Consistent video grid layouts

10. Aspect Ratio Container

16:9 responsive box

aspect-ratio + object-fit
Responsive container with fixed aspect ratio (16:9). Object-fit: cover ensures image fills without distortion.
.container { aspect-ratio: 16 / 9; overflow: hidden; } img { width: 100%; height: 100%; object-fit: cover; }
✓ Responsive video embeds & iframes

11. Crop Focus: Top

object-position: top

object-fit: cover + top position
Focus crop at top of image. Perfect for photos with faces or important content at the top.
img { object-fit: cover; object-position: top; }
✓ Face-focused image cropping

12. Crop Focus: Bottom

object-position: bottom

object-fit: cover + bottom position
Focus crop at bottom of image. Useful for product photos or landscape with horizon at bottom.
img { object-fit: cover; object-position: bottom; }
✓ Landscape & horizon focus

Quick Reference Guide

object-fit: contain → Show entire image (letter-boxing OK)
object-fit: cover → Fill container (cropping OK)
object-fit: scale-down → Never enlarge small images
object-fit: fill → Stretch to fit (⚠️ may distort)
object-fit: none → Original size (may overflow)

object-position: center | top | bottom | left | right | custom %
✓ Always set explicit width/height on images
✓ Combine with overflow: hidden to prevent overflow
✓ Use aspect-ratio CSS for responsive boxes
