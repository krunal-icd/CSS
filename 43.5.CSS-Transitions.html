🎬 prefers-reduced-motion

Accessible CSS Media Query for Motion-Sensitive Users

✨ Full Motion Enabled: You're seeing animations and transitions. If animations cause discomfort, adjust your system preferences.
⏸️ Reduced Motion Enabled: Animations and transitions have been disabled for your comfort.

What is prefers-reduced-motion?

The prefers-reduced-motion CSS media query detects whether a user has requested reduced motion through their operating system settings. This is important for accessibility—many users experience motion sensitivity, vestibular disorders, or vertigo that make animations uncomfortable or even harmful.

Why It Matters: An estimated 15-30% of people experience motion sensitivity. Respecting this preference isn't optional—it's an accessibility requirement under WCAG 2.1 guidelines (Success Criterion 2.3.3).

How to Enable Reduced Motion

Windows 10/11: Settings → Ease of Access → Display → Turn on "Show animations"

macOS: System Preferences → Accessibility → Display → Enable "Reduce motion"

iOS: Settings → Accessibility → Motion → Enable "Reduce motion"

Android: Settings → Accessibility → Display → Enable "Remove animations"

Code Examples

Example 1: Disabling Animations

@media (prefers-reduced-motion: reduce) { .animated-element { animation: none; transition: none; } }

Example 2: Simplified Transitions

/* Default: smooth transition */ .button { transition: all 0.3s cubic-bezier(0.34, 1.56, 0.64, 1); } /* Reduced motion: instant change */ @media (prefers-reduced-motion: reduce) { .button { transition: none; } }

Example 3: Replace Animation with Static State

@media (prefers-reduced-motion: reduce) { .spinner { animation: none; opacity: 0.7; border-right-color: transparent; } }

Best Practices

✅ Always respect prefers-reduced-motion: Don't force animations on users who've disabled them.

✅ Provide alternatives: Use color changes, opacity, or static states instead of motion.

✅ Test both modes: Enable reduced motion in your OS and verify the experience.

✅ Keep transitions quick: If you use transitions for reduced motion users, keep them under 0.1s.

✅ Use meaningful animations: Avoid animations that don't add value or clarity.

❌ Don't ignore this setting: It's not a preference—it's an accessibility requirement.
