📖 Understanding CSS White-Space

White-space controls how whitespace characters (spaces, tabs, line breaks) are handled in text. It's essential for code display, preserving formatting, handling text wrapping, and controlling how text flows in containers. From preserving exact spacing to flexible text wrapping, white-space is fundamental to typography control.

What is White-Space?

White-space is a CSS property that determines how whitespace (spaces, tabs, newlines) is treated in text. It controls whether lines wrap, whether multiple spaces collapse, and whether line breaks are preserved. Critical for code blocks, poetry, preformatted text, and maintaining exact text formatting.

Key Concept: White-space has six main values: normal (default wrapping), nowrap (no wrapping), pre (preserve all), pre-wrap (preserve + wrap), pre-line (preserve lines, wrap text), and break-spaces (newest).

/* White-Space Syntax */ white-space: normal; /* Default: collapse spaces, wrap text */ white-space: nowrap; /* No wrapping, collapse spaces */ white-space: pre; /* Preserve all spaces and line breaks */ white-space: pre-wrap; /* Preserve spaces, wrap text */ white-space: pre-line; /* Collapse spaces, preserve line breaks */ white-space: break-spaces; /* Preserve spaces, wrap, trailing spaces */
💡 When Each Value is Used:
  • normal - Standard text wrapping (default)
  • nowrap - Single line, no wrapping
  • pre - Code display, exact formatting
  • pre-wrap - Code + wrapping support
  • pre-line - Preserve line breaks, wrap text
  • break-spaces - Edge case: trailing spaces matter

🎨 10 Professional White-Space Examples

1

Normal (Default) ⭐

Default behavior: collapses spaces, wraps text at container edge.

This is a text with multiple spaces and will wrap to the next line when it reaches the container width limit.
CSS Code:
white-space: normal;
When to use: Standard body text, paragraphs - DEFAULT
2

Nowrap

Forces text to single line, prevents wrapping. Collapses spaces.

This is a text that will not wrap to the next line no matter how wide the text becomes.
CSS Code:
white-space: nowrap;
When to use: Menu items, navigation, table headers
3

Pre (Preformatted)

Preserves all spaces, tabs, and line breaks exactly. No wrapping.

function hello() { console.log( "Hello World" ); return true; }
CSS Code:
white-space: pre;
When to use: Code blocks, ASCII art, exact formatting
4

Pre-Wrap

Preserves spaces and line breaks, but wraps text when needed.

function longFunctionName() { const veryLongVariableName = "This is a very long string that might need to wrap to next line"; console.log( veryLongVariableName ); }
CSS Code:
white-space: pre-wrap;
When to use: Code blocks with wrapping, formatted text
5

Pre-Line

Preserves line breaks, collapses spaces, wraps text as needed.

Line 1 with multiple spaces Line 2 with more spacing Line 3 that will wrap if it exceeds the container width limit
CSS Code:
white-space: pre-line;
When to use: Poem/poetry, addresses, line-separated content
6

Break-Spaces (Modern)

Like pre-wrap but treats trailing spaces as significant.

Text with spaces preserved and wrapped when needed.
CSS Code:
white-space: break-spaces;
When to use: Edge case: when trailing spaces matter
7

Code Display with Pre

Perfect for displaying code with exact indentation preserved.

// JavaScript function const users = [ { name: 'Alice', age: 25 }, { name: 'Bob', age: 30 } ];
CSS Code:
white-space: pre;
font-family: monospace;
When to use: Code snippets, technical documentation
8

Menu Item with Nowrap

Prevents menu items from breaking to multiple lines.

Home About Services Contact Blog
CSS Code:
white-space: nowrap;
display: inline-block;
When to use: Navigation, breadcrumbs, labels
9

Address/Poetry with Pre-Line

Preserves line structure while allowing text to wrap.

123 Main Street New York, NY 10001 United States Phone: +1 (555) 123-4567
CSS Code:
white-space: pre-line;
When to use: Addresses, poetry, structured line content
10

Flexible Content Mix

Switch based on content type using classes and media queries.

This content adapts based on screen size and content type. It wraps naturally when needed and maintains readability across all devices.
CSS Code:
/* Default - responsive */ white-space: normal; @media (max-width: 480px) { /* Adjust if needed */ word-break: break-word; }
When to use: Adaptive layouts, responsive design

🎯 Real-World Use Cases & Best Practices

📝 Body Text & Paragraphs Use normal. Default behavior. Collapses extra spaces, allows natural wrapping for readability.
💻 Code Blocks & Snippets Use pre or pre-wrap. Preserves indentation and formatting essential for code display.
🔗 Navigation & Menus Use nowrap. Prevents menu items from breaking into multiple lines. Essential for navigation bars.
📍 Addresses & Contact Info Use pre-line. Preserves line structure while allowing text to wrap on narrow screens.
✍️ Poetry & Literary Text Use pre-line. Maintains line breaks while allowing flexible wrapping for responsive design.
📋 Preformatted Text Use pre. Preserves exact spacing, tabs, indentation. Perfect for ASCII art or technical display.
🏷️ Labels & Badges Use nowrap. Keeps labels compact. Prevents awkward line breaks in UI elements.
📱 Responsive Design Use normal with overflow-wrap. Allows text to wrap naturally while handling long words gracefully.
🖥️ Terminal/Console Output Use pre or pre-wrap. Preserves exact formatting like actual terminal output. Font: monospace.
📄 User Comments/Input Use pre-wrap. Preserves line breaks from user input while allowing safe wrapping.

🚀 How to Implement in Elementor & CSS

Method 1: Elementor UI

  1. Select Text Element - Click heading, paragraph, or text widget
  2. Open Advanced Tab - Scroll down in left panel
  3. Custom CSS - Find "Custom CSS" section at bottom
  4. Add Code - Type white-space: pre;
  5. Preview & Adjust - See changes in real-time
  6. Save & Update - Publish to live page
/* Complete CSS Implementation Examples */ /* Example 1: Standard Body Text */ p, body, .text-content { white-space: normal; overflow-wrap: break-word; } /* Example 2: Code Block Display */ code, pre, .code-snippet { white-space: pre; font-family: 'Courier New', monospace; background: #f5f5f5; padding: 15px; border-radius: 5px; overflow-x: auto; } /* Example 3: Code with Wrapping */ .code-wrap { white-space: pre-wrap; font-family: monospace; } /* Example 4: Navigation Menu */ nav, .nav-menu { white-space: nowrap; overflow-x: auto; } /* Example 5: Menu Item */ .nav-item, .breadcrumb { white-space: nowrap; display: inline-block; } /* Example 6: Address Display */ .address, .contact-info { white-space: pre-line; } /* Example 7: Poetry/Verse */ .poetry, .verse, .lyrics { white-space: pre-line; line-height: 1.8; } /* Example 8: Preformatted Text */ .preformatted { white-space: pre; font-family: monospace; } /* Example 9: User Input Display */ .user-comment, textarea { white-space: pre-wrap; word-wrap: break-word; } /* Example 10: Terminal Output */ .terminal, .console { white-space: pre; background: #1a1a1a; color: #0f0; font-family: 'Courier New', monospace; padding: 15px; border-radius: 5px; } /* Example 11: Responsive Code Block */ @media (max-width: 768px) { code, pre, .code-snippet { white-space: pre-wrap; /* Allow wrapping on mobile */ font-size: 0.85em; } } /* Example 12: Flexible Text */ .flexible-text { white-space: normal; word-break: break-word; overflow-wrap: break-word; }
💡 Implementation Pro Tips:
  • Use pre for code: Preserves indentation critical for code readability
  • Use nowrap for single-line content: Navigation, labels, badges
  • Combine with font-family: monospace: For code, preformatted text, terminal
  • Add overflow-wrap: break-word: Handle long unbreakable words
  • Test on mobile: Narrow screens may require different white-space handling
  • Pre-wrap for user content: Preserves line breaks while allowing safe wrapping
  • Use media queries: Adjust white-space behavior for responsive design
  • Combine with overflow properties: Control scrolling behavior for constrained content
⚠️ Common Mistakes to Avoid:
  • ❌ Using white-space: pre for body text - creates unexpected line breaks
  • ❌ Forgetting overflow properties - content can overflow container
  • ❌ Nowrap without overflow handling - text can overflow container edge
  • ❌ Pre-wrap on everything - wastes space, defeats responsive design
  • ❌ Not testing different content types - behavior varies significantly
  • ❌ Ignoring mobile - very different behavior needed on small screens
  • ❌ Combining conflicting properties - white-space + text-overflow interactions
🔧 Advanced Techniques:
  • Combine white-space: pre-wrap with overflow-x: auto for scrollable code
  • Use white-space: nowrap with text-overflow: ellipsis for truncation
  • Apply word-break: break-all after white-space for more control
  • Use CSS custom properties to switch white-space values by theme
  • Combine with highlight.js or Prism for syntax highlighting on code
  • Use media queries to adjust white-space for responsive design
