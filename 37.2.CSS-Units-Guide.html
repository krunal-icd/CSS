1. Consistent Spacing System with rem

Build a scalable spacing scale using rem units

rem units Scalable Maintainable

Create a consistent spacing scale by defining rem-based variables. When you change the root font-size, all spacing scales proportionally.

Extra Small (0.5rem = 8px)
Small (1rem = 16px)
Medium (1.5rem = 24px)
Large (2rem = 32px)
Extra Large (3rem = 48px)
/* Define spacing scale in CSS variables */ html { font-size: 16px; --spacing-xs: 0.5rem; /* 8px */ --spacing-sm: 1rem; /* 16px */ --spacing-md: 1.5rem; /* 24px */ --spacing-lg: 2rem; /* 32px */ --spacing-xl: 3rem; /* 48px */ } /* Use throughout your project */ .section { padding: var(--spacing-lg); margin-bottom: var(--spacing-md); } .component { padding: var(--spacing-md); margin: var(--spacing-sm); } /* Scale everything on mobile */ @media (max-width: 768px) { html { font-size: 14px; /* All rem-based spacing scales down */ } }
💡 Benefit: Change one value (root font-size) and your entire spacing system scales. Perfect for responsive design!

3. Scalable Components with em

Buttons that scale proportionally with font-size

em units Component-based Proportional scaling

Build components using em so padding, margins, and borders scale proportionally with font-size.

/* Scalable button component using em */ .btn { border: none; border-radius: 0.375em; /* Proportional to font-size */ padding: 0.75em 1.5em; font-weight: 600; cursor: pointer; transition: all 0.3s ease; } .btn-small { font-size: 0.875rem; /* 14px */ /* Padding: 10.5px 21px */ } .btn-medium { font-size: 1rem; /* 16px */ /* Padding: 12px 24px */ } .btn-large { font-size: 1.25rem; /* 20px */ /* Padding: 15px 30px */ } /* All sizes maintain perfect proportions! */
💡 Magic of em: The padding adjusts automatically based on font-size, keeping the button perfectly proportioned at any size.

Font sizes that adapt to viewport

/* Responsive typography system */ html { font-size: 16px; /* Desktop base */ } h1 { font-size: 2.5rem; line-height: 1.2; } h2 { font-size: 2rem; line-height: 1.3; } h3 { font-size: 1.5rem; line-height: 1.4; } p { font-size: 1rem; line-height: 1.6rem; } .text-large { font-size: 1.125rem; } .text-small { font-size: 0.875rem; } /* Tablet - slightly smaller */ @media (max-width: 900px) { html { font-size: 15px; } } /* Mobile - even smaller */ @media (max-width: 600px) { html { font-size: 14px; } h1 { font-size: 2rem; } h2 { font-size: 1.5rem; } h3 { font-size: 1.25rem; } }
💡 Advantage: Change root font-size in breakpoints, and your entire typography scale adjusts automatically!

/* Auto-responsive grid with rem */ .grid-demo { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 1.5rem; /* Using rem for consistent spacing */ margin: 2rem 0; } .grid-item { background: white; border-radius: 0.5rem; padding: 1.5rem; } /* No media queries needed! ✨ Best Practices & Quick Reference

Guidelines for choosing and using CSS units

📐 Use rem for Global

Set base font-size on html element. Use rem for all spacing, fonts, and sizing. Scales globally with one change.

🎨 Use em for Components

Build self-contained components with em. Button padding, border-radius scale with font-size automatically.

📊 Use % for Layouts

Use percentages for width and flexible layouts. Creates truly responsive columns and containers.

🎬 Use vw/vh Sparingly

Perfect for full-screen heroes and dramatic sections. Avoid on mobile for vh (includes browser chrome).

⚡ Minimize px Usage

Reserve pixels for small fixed sizes like borders and shadows. Avoid for fonts and layouts - breaks responsiveness.

🔧 Mix Units Strategically

Combine units for different purposes. rem for spacing, % for layout, em for components, vw for typography scaling.

📱 Test All Breakpoints

Test your designs at multiple screen sizes. Ensure rem-based scaling works as expected across devices.

📖 Document Your System

Create a style guide with your unit conventions. Helps team members understand when to use each unit.
