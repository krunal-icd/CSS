Understanding CSS Units

Choose the right unit for your CSS properties

CSS provides various units to measure distances, sizes, and other properties. Understanding when to use each unit is crucial for creating responsive, scalable, and maintainable stylesheets. Units fall into two main categories: absolute (fixed) and relative (contextual).

💡 Key Concept: Absolute units are fixed sizes, while relative units scale based on parent elements, viewport, or root font size. Modern web design favors relative units for responsiveness.

📍 Absolute Units

Fixed, unchanging measurements regardless of context. Use sparingly in web design.

px, in, cm, mm, pt, pc

↔️ Relative Units

Scale based on parent, viewport, or root size. Better for responsive design.

em, rem, %, vw, vh, vmin, vmax, ch, ex

Font-Relative Units (em, rem)

Scale based on font size (root or parent)

Responsive Font-based Scalable
Unit Relative To Calculation Use Case
em Parent element's font-size 1em = parent font-size Relative sizing, padding, margins
rem Root element's font-size (html) 1rem = root font-size Global spacing, font sizes
ex Height of lowercase 'x' ~0.5em typically Rare, typography-specific
ch Width of character '0' ~0.5em typically Monospace text width
em vs rem Demonstration

em - Parent Relative

parent: 16px
child: 1.5em = 24px
grandchild: 1.5em = 36px

Compound: Each level multiplies by parent size

rem - Root Relative

root: 16px
1rem = 16px (always)
1.5rem = 24px (always)
2rem = 32px (always)

Consistent: Always relative to root only

/* Font-relative units */ html { font-size: 16px; /* 1rem = 16px */ } body { font-size: 1rem; /* 16px */ margin: 1rem; /* 16px */ } .heading { font-size: 2rem; /* 32px */ margin-bottom: 1.5rem; /* 24px */ } .container { padding: 1rem; /* Always 16px */ } /* em example - compounds */ .parent { font-size: 16px; } .parent .child { font-size: 1.5em; /* 24px */ } .parent .child .grandchild { font-size: 1.5em; /* 36px - compounded! */ }
💡 Recommendation: Use rem for most sizing (font-size, padding, margins). Use em when you need relative sizing within components.
💡 Pro Tip: Set root font-size to 10px (or 62.5%) for easier math: 1rem = 10px, 1.5rem = 15px, etc.

Viewport Units (vw, vh, vmin, vmax)

Scale based on viewport dimensions

Viewport-based Responsive Screen-relative
Unit Description Calculation Use Case
vw Viewport Width 1vw = 1% of viewport width Full-width layouts, responsive fonts
vh Viewport Height 1vh = 1% of viewport height Full-height sections, hero images
vmin Minimum of vw/vh 1vmin = 1% of smallest dimension Responsive scaling that won't overflow
vmax Maximum of vw/vh 1vmax = 1% of largest dimension Responsive scaling for visibility
Viewport Unit Demonstrations

Desktop (1000px width):

50vw = 500px
100vw = 1000px

Mobile (375px width):

50vw = 187.5px
80vw = 300px
/* Viewport units */ /* Full-height section */ .hero { height: 100vh; width: 100vw; } /* Responsive font size */ h1 { font-size: 5vw; /* 5% of viewport width */ } /* Square that scales */ .box { width: 30vmin; height: 30vmin; } /* Responsive padding */ .section { padding: 10vh 5vw; }
⚠️ Note: On mobile, vh includes browser chrome (address bar, controls) which can cause unexpected behavior. Use dvh (dynamic viewport height) in modern browsers.
💡 Best for: Hero sections, full-screen layouts, responsive typography, and scaling decorative elements.

Percentage Units (%)

Relative to parent container

Parent-relative Context-dependent Most Common

Percentages are relative to the parent element. The reference value depends on the property: width/height use parent dimensions, font-size uses parent font-size, margins/padding use parent width, etc.

Property Percentage Relative To Example
width / max-width Parent's width 50% width = half parent width
height / max-height Parent's height 100% height = full parent height
margin / padding Parent's width (always!) 10% margin = 10% of parent width
font-size Parent's font-size 150% font-size = 1.5x parent
line-height Element's own font-size 150% line-height = 1.5x font size
Percentage Examples
/* Common percentage patterns */ /* Responsive columns */ .container { width: 100%; max-width: 1200px; } .column { width: 33.333%; float: left; } /* Centered with percentage */ .centered { width: 80%; margin: 0 auto; /* centers automatically */ } /* Full-width sections */ .section { width: 100%; } /* Percentage padding (creates squares) */ .square { width: 100px; padding-bottom: 100%; /* 1:1 aspect ratio */ } /* Font scaling */ .large-text { font-size: 150%; /* 1.5x parent */ }
💡 Key Insight: Margins and padding always calculate percentage relative to parent width, even for top/bottom margins! This can be useful for maintaining aspect ratios.
💡 Pro Tip: Use 100% for full-width layouts and percentage-based columns for flexible grids.

🎯 Practical Examples & Patterns

Real-world CSS unit usage

1. Responsive Typography Scale
/* Scale fonts responsively */ html { font-size: 16px; } h1 { font-size: 2.5rem; /* 40px at base */ line-height: 1.2; } h2 { font-size: 2rem; /* 32px at base */ } body { font-size: 1rem; /* 16px */ line-height: 1.6rem; /* Readable line height */ } @media (max-width: 768px) { html { font-size: 14px; /* Smaller on mobile */ } /* All rem-based sizes scale down automatically */ }
2. Flexible Layout Grid
/* Percentage-based responsive grid */ .container { width: 90%; /* Leaves 5% margin each side */ max-width: 1200px; margin: 0 auto; } .column { width: 48%; /* Two columns with gap */ float: left; margin-right: 4%; } .column:nth-child(even) { margin-right: 0; } @media (max-width: 768px) { .column { width: 100%; /* Stack on mobile */ margin-right: 0; } }
3. Hero Section with Viewport Units
/* Full-screen hero with responsive text */ .hero { width: 100vw; height: 100vh; display: flex; align-items: center; justify-content: center; } .hero h1 { font-size: 8vw; /* Scale with viewport */ max-width: 90vw; } .hero p { font-size: 3vw; line-height: 1.5; } @media (max-width: 768px) { .hero h1 { font-size: 6vw; } }
4. Component Scaling with em
/* Component that scales with em */ .button { font-size: 1rem; padding: 0.75em 1.5em; /* Scales with font-size */ border-radius: 0.25em; } .button.small { font-size: 0.875rem; /* Padding scales automatically */ } .button.large { font-size: 1.25rem; /* Padding scales automatically */ } /* All button sizes scale proportionally */
5. Spacing System with rem
/* Consistent spacing using rem */ html { --spacing-xs: 0.5rem; /* 8px */ --spacing-sm: 1rem; /* 16px */ --spacing-md: 1.5rem; /* 24px */ --spacing-lg: 2rem; /* 32px */ --spacing-xl: 3rem; /* 48px */ } .section { padding: var(--spacing-lg); } .card { margin-bottom: var(--spacing-md); padding: var(--spacing-md); } .button { padding: var(--spacing-sm) var(--spacing-md); }
6. Aspect Ratio with Percentage
/* Maintain aspect ratio with padding-bottom */ .container { position: relative; width: 100%; padding-bottom: 56.25%; /* 16:9 ratio */ } .content { position: absolute; top: 0; left: 0; width: 100%; height: 100%; } /* Create perfect squares */ .square { width: 200px; height: 200px; } /* Responsive square (always 1:1) */ .responsive-square { width: 30%; aspect-ratio: 1; /* Modern browsers */ }

✨ Best Practices & Guidelines

How to effectively use CSS units

1. Use rem for Global Sizing

Set base font-size on html element, then use rem for all spacing, font sizes, and layout dimensions.

2. Use em for Components

Build self-contained components with em so they scale proportionally when font-size changes.

3. Use % for Layouts

Use percentages for widths, columns, and flexible layouts that adapt to container size.

4. Minimize px Usage

Reserve pixels for small fixed sizes like borders, shadows, and outlines. Avoid for fonts and layouts.

5. Viewport Units for Heroes

Use vw/vh for full-screen sections and dramatic layouts. Avoid on mobile for vh.

6. Combine Units Strategically

Mix units for different purposes: rem for spacing, % for layout, em for components.

7. Test Responsive Scaling

Test your designs at different font sizes and viewport widths to ensure proper scaling.

8. Document Your Choices

Maintain a style guide documenting which units to use for different scenarios.

🎯 Modern Approach:
  • Use rem for font sizes and global spacing
  • Use % for layout widths and flex containers
  • Use em for component-level sizing
  • Use vw/vh for full-screen elements
  • Use px only for borders, shadows, and 1-2px elements
