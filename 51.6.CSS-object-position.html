CSS Object-Position Property

Complete Guide to Image and Video Positioning

What is Object-Position?

The object-position property specifies the alignment of replaced content (images, videos) within its container when using object-fit. It controls where the content is positioned when it doesn't fill the entire container or when cropping occurs.

Key Purpose: Object-position gives you precise control over how content is aligned and cropped within its container. It's essential for creating professional, intentional image layouts.

Object-position works hand-in-hand with object-fit. While object-fit controls how content scales, object-position controls where it's positioned when there's empty space or cropping involved.

Syntax & Property Values

Basic Syntax

object-position: [horizontal] [vertical]; object-position: left | center | right | top | bottom | percentage | pixels;

Value Types

Value Type Examples Description
Keywords top, bottom, left, right, center Named positions (can combine)
Percentages 0%, 50%, 100% Position from 0% (start) to 100% (end)
Pixels 10px, 20px, -5px Fixed pixel offsets (negative allowed)
Mixed right 10px bottom 20px Combine keywords with measurements

How Object-Position Works

With Object-Fit: Cover

When using object-fit: cover, the content is scaled to cover the container. Parts are cropped. Object-position determines which part is visible.

With Object-Fit: Contain

When using object-fit: contain, the content scales to fit. No cropping occurs. Object-position determines alignment within empty space.

Position Values Explained

1. Keyword Values

top, bottom, left, right, center - Predefined positions

  • top = Vertical position at 0%
  • center = Position at 50% (horizontal or vertical)
  • bottom = Vertical position at 100%
  • left = Horizontal position at 0%
  • right = Horizontal position at 100%

Examples:

img { object-position: center; /* Center both axes */ object-position: top center; /* Top, horizontally centered */ object-position: right bottom; /* Bottom-right corner */ }

2. Percentage Values

0%, 50%, 100% - Pixel-precise positioning

  • 0% 0% = Top-left corner (equivalent to left top)
  • 50% 50% = Exact center (equivalent to center)
  • 100% 100% = Bottom-right corner (equivalent to right bottom)
  • 75% 25% = Custom position (3/4 right, 1/4 down)

Examples:

img { object-position: 50% 50%; /* Center */ object-position: 100% 0%; /* Top-right */ object-position: 25% 75%; /* Custom offset */ }

3. Pixel Values

10px, 20px, -5px - Fixed pixel offsets

  • 0px 0px = Top-left corner
  • 10px 20px = 10px from left, 20px from top
  • -5px 10px = 5px left of edge, 10px from top
  • Negative values shift content toward top-left

Examples:

img { object-position: 0px 0px; /* Top-left */ object-position: 50px 30px; /* Offset positioning */ object-position: center 50px; /* Centered horizontally, 50px from top */ }

4. Mixed Values

Combine keywords and measurements

  • right 10px bottom 20px = 10px from right edge, 20px from bottom
  • center 30px = Centered horizontally, 30px from top
  • left top = Keywords only (equivalent to 0% 0%)

Examples:

img { object-position: right 10px bottom 20px; object-position: center 50px; object-position: left 5px top 10px; }

Real-World Use Cases

🎥 Hero Images with Face Focus

Use object-position: top center to keep faces in frame when cropping with object-fit: cover.

🌄 Landscape Photos

Use object-position: center bottom to focus on horizon when cropping above.

📸 Profile Pictures

Use object-position: center with object-fit: cover for consistent circular crops.

🖼️ Product Photos

Use object-position: center with object-fit: contain to show full product centered.

🎬 Video Thumbnails

Use object-position: center with object-fit: cover for consistent grid display.

🎨 Gallery Grids

Use object-position: various values to create intentional crop patterns.

Practical Code Examples

Example 1: Face-Focused Hero Image

img.hero { width: 100%; height: 400px; object-fit: cover; object-position: center top; /* Focuses on upper part of image (faces) */ }

Example 2: Landscape Horizon Focus

img.landscape { width: 100%; height: 300px; object-fit: cover; object-position: center bottom; /* Keeps horizon line in focus */ }

Example 3: Centered Profile Picture

img.profile { width: 150px; height: 150px; border-radius: 50%; object-fit: cover; object-position: center; /* Perfect circular crop, face centered */ }

Example 4: Product Image - Full View

img.product { width: 250px; height: 250px; object-fit: contain; object-position: center; padding: 10px; /* Show entire product, centered with padding */ }

Example 5: Custom Percentage Position

img.custom { width: 400px; height: 250px; object-fit: cover; object-position: 75% 25%; /* Focus on right-upper area (75% right, 25% down) */ }

Example 6: Pixel-Precise Positioning

img.precise { width: 100%; height: 500px; object-fit: cover; object-position: center 100px; /* Centered horizontally, 100px from top */ }

Object-Fit & Object-Position Combinations

Cover + Position Combinations

cover + center (Most Common)

Scales to cover, crops equally from all sides. Best for balanced cropping.

cover + top

Crops from bottom. Perfect for face-focused images where heads are at top.

cover + bottom

Crops from top. Great for landscape with horizon or foreground focus.

cover + left/right

Crops from opposite side. Use for off-center subject positioning.

Contain + Position Combinations

contain + center

Fits completely, centered in empty space. Standard product display.

contain + top left

Fits completely, aligned to top-left. Creates specific layout patterns.

contain + bottom right

Fits completely, aligned to bottom-right. Useful for watermarks or logos.

contain + percentage

Fits completely with precise positioning. Maximum layout control.

Best Practices & Tips

✓ Best Practices:
  • Always combine with object-fit for full control
  • Use center as default (most balanced)
  • Use top for face-focused images
  • Use bottom for landscape/horizon focus
  • Test different positions for different content types
  • Provide fallback values for unsupported browsers
  • Document your positioning choices
⚠ Common Mistakes:
  • Using object-position without object-fit
  • Forgetting object-fit-position is for replaced elements only
  • Not testing with various image aspect ratios
  • Inconsistent positioning across similar elements
  • Using fill with object-fit (causes distortion)
  • Not considering mobile viewport changes

Advanced Techniques

Responsive Position Adjustments

img.responsive { object-fit: cover; object-position: center; } @media (max-width: 600px) { img.responsive { object-position: center top; /* Focus on top for mobile */ } }

JavaScript Dynamic Positioning

// Adjust position based on image aspect ratio function setOptimalPosition(img) { const aspectRatio = img.naturalWidth / img.naturalHeight; if (aspectRatio > 1.5) { // Wide image - focus top img.style.objectPosition = 'center top'; } else if (aspectRatio < 0.7) { // Tall image - focus center img.style.objectPosition = 'center'; } }

Conclusion

Object-position is a powerful CSS property that gives you precise control over where content appears within its container. Combined with object-fit, it enables professional, responsive image layouts without JavaScript or complex workarounds.

Quick Decision Guide:

  • Default alignment: Use center
  • Face-focused images: Use top or center top
  • Landscape/horizon: Use bottom or center bottom
  • Precise control: Use percentage or pixel values
  • Off-center subjects: Use left or right
