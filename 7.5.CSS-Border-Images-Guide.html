CSS Border-Image Practical Examples

1. Gradient Border (Colorful)

Creates a smooth gradient transition across the border. Great for modern, vibrant designs.

Gradient Border Example
border: 15px solid;
border-image: linear-gradient(45deg, #ff6b6b, #4ecdc4, #45b7d1) 1;

2. SVG Pattern Border

Uses an SVG pattern for a repeating tile effect. Perfect for decorative borders.

SVG Pattern Border
border: 15px solid transparent;
border-image-source: url('data:image/svg+xml;...');
border-image-slice: 10;
border-image-repeat: repeat;

3. Multi-Color Smooth Gradient

A flowing gradient with multiple colors. Ideal for headers and featured content sections.

Multi-Color Gradient Border
border: 20px solid;
border-image: linear-gradient(90deg, #f093fb, #f5576c, #4facfe, #00f2fe) 1;

4. Dashed Pattern Border

Creates a dashed/striped effect using gradients. Useful for attention-grabbing elements.

Dashed Pattern Border
border: 12px solid;
border-image: repeating-linear-gradient(
  90deg,
  #ff6b6b 0px, #ff6b6b 10px,
  transparent 10px, transparent 20px
) 1;

5. Conic Gradient (Rainbow Effect)

Uses conic gradient for a rotating color effect. Creates a circular rainbow border.

Conic Gradient Border
border: 15px solid;
border-image: conic-gradient(from 0deg, #667eea, #764ba2, #667eea) 1;
border-radius: 15px;

6. Striped Color Blocks

Divides the border into distinct color bands. Good for status indicators or themed sections.

Striped Color Blocks
border: 15px solid;
border-image: linear-gradient(180deg,
  #ff6b6b 0%, #ff6b6b 25%,
  #ffa502 25%, #ffa502 50%,
  #4ecdc4 50%, #4ecdc4 75%,
  #667eea 75%, #667eea 100%
) 1;

7. 3D Shadow Effect

Creates an embossed or 3D appearance using gradients from light to dark.

3D Effect Border
border: 15px solid;
border-image: linear-gradient(135deg, #fff, #ddd, #666, #000) 1;

8. Angled Gradient Border

A diagonal gradient creating a sophisticated, directional effect.

Angled Gradient Border
border: 15px solid;
border-image: linear-gradient(45deg, #667eea 0%, #764ba2 50%, #f093fb 100%) 1;

Key Properties Explained

border-image-source

Defines the image or gradient to use: linear-gradient(), radial-gradient(), url(), conic-gradient()

border-image-slice

Divides the image into 9 regions. Value is in pixels or percentage. Example: 10 = 10px from edges

border-image-repeat

How to fill the border: stretch (default), repeat, or round

border-image-width

Width of the border image (defaults to border-width). Can be different values per side

⚡ Pro Tips

1. Performance: Gradients are lighter than image files. Use them when possible.

2. Compatibility: border-image doesn't work with border-radius on all browsers. Use caution.

3. Fallback: Consider providing a solid border as fallback for older browsers.

4. Animation: Border-images can't be animated directly, but you can animate the background or use multiple elements.

5. SVG: Use SVG with data URIs for crisp, scalable patterns without external file requests.
