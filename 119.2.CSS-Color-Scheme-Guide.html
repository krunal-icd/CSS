Example 1: Basic Theme Declaration with Variables

The foundation: declare color-scheme and define CSS variables for both themes. The browser automatically adapts form elements and native components.

/* HTML head */
<meta name="color-scheme"
      content="light dark">

/* CSS - Define variables */
:root {
  color-scheme: light dark;
  --color-bg-primary: white;
  --color-text-primary: black;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg-primary: #1a1a1a;
    --color-text-primary: white;
  }
}

Theme Adapts Automatically

Example 2: Form Elements with Browser Auto-Theming

Declare color-scheme and the browser automatically styles form inputs, buttons, and selects to match your theme. No extra CSS needed!

/* Just declare color-scheme */

}

/* Forms auto-style! */
input, button, select {
  /* Browser handles theming */
  /* in light/dark automatically */
}
