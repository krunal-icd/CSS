PRINT Print Media Basics

CSS print media allows you to create different styles for printed documents. Hide elements, adjust colors, and optimize layouts specifically for printing.

Syntax

@media print {
  /* Styles applied when printing */
  body {
    background: white;
    color: black;
  }
}

How It Works

  • Triggers on: Print dialog (Ctrl+P, Cmd+P) or Print to PDF
  • Screen media: Default styles (web display)
  • Print media: Overrides for printing
  • Both: Can target with both simultaneously
ℹ️ Tip: Print media activates in Firefox's Print Preview (Ctrl+Shift+P), Chrome's Print Dialog (Ctrl+P), or any "Print to PDF" function.

📊 Screen vs Print Styling

Different devices need different optimizations. Screen displays are bright and interactive. Print is static and requires readability on paper.

Key Differences

Aspect Screen (@media screen) Print (@media print)
Background Can be colorful Should be white to save ink
Colors RGB, vibrant Grayscale-friendly black
Navigation Visible, clickable Hidden (not printable)
Ads/Decorations Displayed Hidden
Page Breaks N/A Critical for layout
Font Size Relative units (px, rem) Physical units (pt, cm, in)

🚫 Hiding Elements for Print

Many page elements don't make sense in print. Navigation, ads, sidebars, and decorations should be hidden.

Common Elements to Hide

@media print {
  /* Hide navigation */
  nav, header {
    display: none;
  }
  
  /* Hide ads and sidebars */
  .advertisement, .sidebar {
    display: none;
  }
  
  /* Hide buttons and forms */
  button, form, .interactive {
    display: none;
  }
}

What to Hide

  • Navigation bars: Users can't click printed links
  • Advertisements: No value in print
  • Social media buttons: Not functional in print
  • Search forms: Can't be used on paper
  • Video players: Can't display videos
  • Sidebars: Often not needed in print
✨ Pro Tip: Add a "Print this page" button that shows only on screen using @media screen, then hide it in print.

🔗 Display URLs for Links

In print, users can't click links. Make URLs visible using the ::after pseudo-element.

Show URLs in Print

@media print {
  /* Display URLs after links */
  a::after {
    content: " (" attr(href) ")";
    font-size: 0.8em;
    color: #666;
  }
  
  /* Hide URLs for certain links */
  a.no-print-url::after {
    content: "";
  }
}

Example Output

Before Print: "Click here"

After Print: "Click here (https://example.com)"

⚠️ Note: Users see URLs for EVERY link. Be selective or it becomes clutter. Use .no-print-url class for exceptions.

🎨 Color Optimization for Print

Print uses CMYK color space. Optimize colors for ink efficiency and readability on paper.

Grayscale Conversion

@media print {
  body {
    background: white;
    color: black;
    filter: grayscale(1); /* Convert to B&W */
  }
}

Dark Text on White Background

@media print {
  body {
    background: white !important;
    color: black !important;
  }
  
  /* Override all colored text */
  * {
    background: white !important !important;
    color: black !important !important;
  }
}

Color Best Practices

  • Use black text: Maximum contrast and readability
  • White background: Saves ink and looks professional
  • Remove decorative colors: They add no value in print
  • Test on B&W printer: Ensure legibility
  • Use grayscale filter: Convert colored layouts to B&W
ℹ️ Ink Saving Tip: White backgrounds save ~50% ink compared to colored backgrounds. Users appreciate lower printing costs!

📄 Page Breaks

Control where content breaks across pages. Essential for multi-page documents.

Page Break Properties

@media print {
  /* Force page break before element */
  h2 {
    page-break-before: always;
  }
  
  /* Avoid breaking inside element */
  .card {
    page-break-inside: avoid;
  }
  
  /* Force page break after */
  section {
    page-break-after: always;
  }
}

Page Break Values

Property Values Use Case
page-break-before auto, always, avoid, left, right Break before element
page-break-after auto, always, avoid, left, right Break after element
page-break-inside auto, avoid Prevent breaking inside

Practical Page Break Example

@media print {
  /* New chapter on new page */
  h1 {
    page-break-before: always;
    page-break-after: avoid;
  }
  
  /* Keep paragraphs together */
  p {
    page-break-inside: avoid;
    orphans: 3;
    widows: 3;
  }
}

👥 Orphans & Widows

Control how text breaks across pages. Orphans are lines at bottom of page; widows at top.

Orphans & Widows Example

@media print {
  p {
    orphans: 2; /* Keep 2+ lines at bottom */
    widows: 2; /* Keep 2+ lines at top */
  }
}

Explanation

  • orphans: 2: Don't leave a single line at bottom of page
  • widows: 2: Don't leave a single line at top of page
  • Default: Usually 2 for both
  • Higher values: Stricter control but may increase pages
📋 Rule: Always set both orphans and widows to 2 or higher for professional-looking printed documents.

📝 Font Sizing for Print

Use physical units for print. Points (pt) and centimeters (cm) work better than pixels (px).

Units Comparison

Unit Screen Print Recommendation
px (pixels) ✅ Good ⚠️ Varies Use for screen
pt (points) ⚠️ Unusual ✅ Excellent Use for print
cm (centimeters) ❌ Rare ✅ Excellent Use for print
rem (relative) ✅ Good ⚠️ Unpredictable Use for screen

Print-Specific Font Sizing

@media print {
  body {
    font-size: 12pt;
    line-height: 1.5;
  }
  
  h1 { font-size: 28pt; }
  h2 { font-size: 20pt; }
  h3 { font-size: 16pt; }
  p { font-size: 12pt; }
}
ℹ️ Conversion: 1 point = 1/72 inch = 0.35mm. For web: 12px ≈ 9pt.

📐 Page Size & Margins

Use @page rule to set paper size, margins, and page orientation.

@page Rule

@page {
  size: A4;
  margin: 2cm;
}

@page {
  size: 8.5in 11in; /* Letter size */
  margin-top: 1in;
  margin-bottom: 1in;
  margin-left: 0.75in;
  margin-right: 0.75in;
}

Common Page Sizes

  • A4: 210mm × 297mm (most common)
  • Letter: 8.5in × 11in (North America)
  • Legal: 8.5in × 14in
  • Landscape: Rotate page with orientation
ℹ️ Tip: Set page margins to leave space for printer margins and binding. Most printers have 0.5in minimum margins.

Full Implementation

@page {

🏆 Best Practices & Tips

✅ Do:

  • Test the output: Use Print Preview (Ctrl+Shift+P) to verify
  • Use white backgrounds: Saves ink and looks professional
  • Hide all navigation: It's not functional in print
  • Show URLs for links: Users can't click on paper
  • Use physical units: Points (pt) and cm work best
  • Set page margins: Respect printer limitations
  • Control page breaks: Keep content logical across pages
  • Test on real printer: Screen preview may differ

❌ Don't:

  • Print backgrounds: Users disable them to save ink
  • Use bright colors: They don't print well on B&W
  • Keep ads visible: No value in print format
  • Hide important URLs: Users need to reference them
  • Use only pixels: Unreliable on print output
  • Ignore page breaks: Content becomes hard to read
  • Make text too small: Minimum 10pt for readability
  • Assume print = screen: Always test separately
⚠️ Critical: Always test your print styles in Firefox Print Preview (Ctrl+Shift+P) or Chrome Print Dialog (Ctrl+P). Different browsers render print media differently!

⚡ Common Pitfalls & Solutions

Pitfall 1: Colored Backgrounds Print

Problem: User's browser prints background colors, wasting ink.

Solution: Force white backgrounds in print media

@media print {
  * {
    background: white !important;
  }
}

Pitfall 2: Content Breaks Mid-Section

Problem: Page breaks in wrong places, separating heading from content.

Solution: Use page-break-inside: avoid

@media print {
  section, .card, table {
    page-break-inside: avoid;
  }
}

Pitfall 3: Missing Page Numbers

Problem: Multi-page documents have no page numbers.

Solution: Add page numbers using counter CSS

@page {
  @bottom-right {
    content: "Page " counter(page);
  }
}

Pitfall 4: Links Not Clickable (But No URL Shown)

Problem: Links are visible but users can't reference the URL.

Solution: Display URLs with ::after pseudo-element

@media print {
  a::after {
    content: " (" attr(href) ")";
    font-size: 0.9em;
  }
}
