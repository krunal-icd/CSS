CSS Grid: Items Positioning

Master grid-column, grid-row, and grid-area for precise item placement

Understanding Grid Item Positioning

Grid items can be positioned precisely within the grid using several CSS properties. Instead of relying on the default auto-placement algorithm, you can control exactly where each item appears.

Key Positioning Properties

  • grid-column - Position items horizontally (columns)
  • grid-row - Position items vertically (rows)
  • grid-area - Shorthand for column, row, and named areas
  • justify-self - Horizontal alignment within cell
  • align-self - Vertical alignment within cell
  • z-index - Stacking order of overlapping items

These properties work on individual grid items, giving you pixel-perfect control over layouts.

grid-column and grid-row Properties

Basic Positioning with Line Numbers

Grid lines are numbered starting from 1. Use these numbers to position items:

.item {
    grid-column: 2;      /* Place in column 2 */
    grid-row: 1;         /* Place in row 1 */
}

Span Syntax - Spanning Multiple Tracks

Use the span keyword to span multiple columns or rows:

.item {
    grid-column: 2 / 4;   /* From line 2 to line 4 (spans 2 columns) */
    grid-row: 1 / 3;      /* From line 1 to line 3 (spans 2 rows) */
}

/* Shorthand span syntax */
.item {
    grid-column: span 2;  /* Span 2 columns */
    grid-row: span 3;     /* Span 3 rows */
}

Understanding Line Numbers

Syntax Description Spans
grid-column: 1; Start at line 1, end at line 2 1 column
grid-column: 1 / 3; Start at line 1, end at line 3 2 columns
grid-column: 1 / -1; Start at line 1, end at last line All columns
grid-column: span 2; Span 2 tracks from current position 2 columns
Tip: Using grid-column: 1 / -1; automatically spans all available columns, perfect for full-width items.

grid-area Property

Assigning Items to Named Areas

Use grid-area with grid-template-areas for semantic, readable layouts:

.grid {
    display: grid;
    grid-template-columns: 1fr 2fr;
    grid-template-areas:
        "header header"
        "sidebar main"
        "footer footer";
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

Shorthand grid-area

You can also use grid-area as a shorthand for grid-row and grid-column:

.item {
    grid-area: 1 / 2 / 3 / 4;
    /* = grid-row-start / grid-column-start / grid-row-end / grid-column-end */
}

Spanning Items

Column and Row Spanning

Make items span multiple columns and/or rows:

.featured {
    grid-column: span 2;  /* Spans 2 columns */
    grid-row: span 2;     /* Spans 2 rows */
}

Auto-Placement Algorithm

Default Behavior

Without explicit positioning, grid items automatically fill available spaces:

.grid {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-flow: row;  /* Default: fill rows first */
}

.item-1 { grid-column: 1; grid-row: 1; }
.item-2 { grid-column: 3; grid-row: 1; }
/* item-3 auto-places in next available spot */

Item Alignment: justify-self & align-self

Aligning Items Within Cells

Control how items are positioned within their grid cells:

.item {
    justify-self: start;   /* Horizontal: left */
    align-self: start;     /* Vertical: top */
}

/* Values: start, end, center, stretch */

Stacking Order with z-index

Overlapping Grid Items

When items overlap, use z-index to control which appears on top:

.item-1 {
    grid-column: 1 / 3;
    grid-row: 1 / 3;
    z-index: 1;
}

.item-2 {
    grid-column: 2 / 4;
    grid-row: 2 / 4;
    z-index: 2;  /* Appears on top of item-1 */
}

Negative Grid Line Indexing

Counting from the End

Negative line numbers count backwards from the end of the grid:

.grid {
    grid-template-columns: repeat(4, 1fr);
}

.item {
    grid-column: -2 / -1;  /* Last column */
    grid-row: -3 / -2;     /* Third row from bottom */
}

Negative Line Benefits

  • Dynamic Positioning: Always positions from the end, regardless of grid size
  • Responsive: Works with auto-fit/auto-fill columns
  • Less Calculation: No need to count total columns

Named Grid Lines

Semantic Grid Line Names

Name grid lines for readable, maintainable positioning:

.grid {
    display: grid;
    grid-template-columns: 
        [start] 1fr 
        [sidebar-end main-start] 2fr 
        [main-end];
    grid-template-rows: 
        [header] 80px 
        [main] 1fr 
        [footer] 60px;
}

.header {
    grid-column: start / main-end;
    grid-row: header;
}

Best Practices for Item Positioning

Do's ✓

  • Use named areas for semantic, readable layouts
  • Use grid-column: 1 / -1; for full-width items
  • Use negative line numbers for dynamic positioning
  • Keep positioning rules organized and consistent
  • Combine grid positioning with flexbox on items
  • Test overlapping items with z-index carefully

Don'ts ✗

  • Don't over-position every item (let auto-placement work)
  • Don't use positioning to force content flow
  • Don't forget accessibility when overlapping items
  • Don't hardcode line numbers that might change
  • Don't mix positioning systems unnecessarily
  • Don't forget to test on different screen sizes

Positioning Methods Comparison

grid-column / grid-row

Best for: Line-based positioning

Explicit control over which grid lines to span. Most common and flexible approach.

grid-area

Best for: Semantic layouts

Named areas make layouts self-documenting and easier to understand at a glance.

justify-self / align-self

Best for: Item alignment

Position content within cells independently of grid structure.

Auto-placement

Best for: Simple layouts

Let items fill automatically for flexibility. Minimal CSS needed.
