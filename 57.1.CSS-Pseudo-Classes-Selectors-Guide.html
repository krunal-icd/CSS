CSS Pseudo-Classes

Complete Guide to State and Position Selectors

CSS Pseudo-Classes represent special states or positions of elements in the DOM. They allow you to select and style elements based on their state (interactive, checked, disabled), position in the document tree (:nth-child, :first-child), or relationship to other elements (:has). Pseudo-classes are powerful for creating interactive, responsive styles without JavaScript.

:hover

What It Does

Applies styles when the user hovers over an element with the mouse cursor.

Syntax

element:hover {
  property: value;
}

Example

/* Button hover effect */
button:hover {
  background: #764ba2;
  transform: scale(1.05);
  box-shadow: 0 5px 15px rgba(0,0,0,0.2);
}

/* Link hover effect */
a:hover {
  text-decoration: underline;
  color: #667eea;
}

Common Use Cases

  • Button hover effects and color changes
  • Link underlines and color transitions
  • Revealing hidden elements on hover
  • Scale and transform animations
  • Menu dropdown activation
:focus

What It Does

Applies styles when an element receives keyboard focus. Essential for accessibility and keyboard navigation.

Syntax

element:focus {
  outline: 2px solid #667eea;
}

Example

/* Form input focus */
input:focus {
  border: 2px solid #667eea;
  outline: none;
  box-shadow: 0 0 0 3px rgba(102,126,234,0.1);
}

/* Button focus */
button:focus {
  outline: 2px solid #667eea;
  outline-offset: 2px;
}

Common Use Cases

  • Form input focus styling (borders, shadows)
  • Button focus rings for accessibility
  • Keyboard navigation visibility
  • Screen reader compatibility
  • Tab order indication
:active

What It Does

Applies styles when an element is being activated (e.g., during a mouse click).

Syntax

element:active {
  property: value;
}

Common Use Cases

  • Button press visual feedback
  • Creating "pushed" button effect
  • Link click animation
  • Interactive form element feedback
:first-child, :last-child

What It Does

Selects elements that are the first or last child of their parent.

Example

/* First list item */
li:first-child {
  border-radius: 8px 8px 0 0;
  margin-top: 0;
}

/* Last list item */
li:last-child {
  border-radius: 0 0 8px 8px;
  border-bottom: none;
}

Common Use Cases

  • List styling (rounded corners on edges)
  • Removing borders/margins from first/last items
  • Special styling for boundary elements
  • Card collections and grids
:nth-child(n), :nth-of-type(n)

What It Does

:nth-child(n) selects the nth child regardless of type. :nth-of-type(n) selects the nth element of that specific type.

Syntax and Patterns

/* Specific number */
li:nth-child(3) { /* 3rd child */
}

/* Every nth (2n = even, 2n+1 = odd) */
li:nth-child(2n) { /* Even items */
}

li:nth-child(2n+1) { /* Odd items */
}

/* Group of n (every 3rd) */
li:nth-child(3n) { /* Every 3rd: 3, 6, 9, ... */
}

Common Use Cases

  • Zebra striping (alternating row colors)
  • Every nth element styling
  • Grid layout patterns
  • List animations with staggered delays
  • Dynamic column layouts
:not(selector)

What It Does

Selects elements that do NOT match the selector.

Example

/* All paragraphs except those with class "intro" */
p:not(.intro) {
  color: #666;
}

/* All buttons except disabled */
button:not([disabled]) {
  cursor: pointer;
}

Common Use Cases

  • Exclusion-based styling
  • Styling all but one element
  • Margin reset patterns
  • Conditional display logic
:is(), :where()

What It Does

:is() matches any selector in the list. :where() is identical but has 0 specificity.

Example

/* Instead of: h1, h2, h3, h4, h5, h6 { } */
:is(h1, h2, h3, h4, h5, h6) {
  margin: 20px 0;
}

/* Match any button or link inside nav */
nav :is(a, button) {
  color: white;
}

Common Use Cases

  • Grouping multiple selectors
  • Reducing selector redundancy
  • Complex selector simplification
  • :where() for low-specificity resets
:has(selector)

What It Does

Selects elements that contain the specified selector (parent selector). This is a powerful relational pseudo-class.

Example

/* Article that contains an img */
article:has(img) {
  background: #f9f9f9;
  padding: 20px;
}

/* Label containing checked input */
label:has(input:checked) {
  background: #e8f5e9;
}

Common Use Cases

  • Parent styling based on children
  • Conditional container styling
  • Card styling based on content
  • Complex layout patterns
  • State management without JavaScript
:checked, :disabled, :enabled

What It Does

Form-related pseudo-classes for styling form controls based on their state.

Example

/* Checked checkbox or radio */
input:checked {
  background: #4caf50;
}

/* Disabled form controls */
input:disabled, button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

/* Enabled form controls */
input:enabled {
  cursor: text;
}

Common Use Cases

  • Checkbox and radio button styling
  • Disabled state indication
  • Toggle switches
  • Custom form control styling

Best Practices

✓ Do's

  • Combine with element type - button:hover is better than :hover
  • Use :focus for accessibility - Never remove focus indicators without replacing them
  • Test keyboard navigation - Ensure :focus styles are always visible
  • Use :nth-child() for patterns - Avoid multiple margin-bottom rules
  • Use :has() for parent styling - Replaces JavaScript selector patterns
  • Chain pseudo-classes - a:link:hover for specific link states

✗ Don'ts

  • Don't remove :focus styling - It's essential for keyboard users
  • Don't over-chain pseudo-classes - Too many chains reduce readability
  • Don't rely on :hover for mobile - Hover doesn't work on touch devices
  • Don't use :visited for styling links - Browser security restricts it heavily
  • Don't use pseudo-classes as JavaScript replacements - Use both together
