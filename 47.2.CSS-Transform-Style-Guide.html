Real-world implementations of transform-style. Discover 10 practical patterns for creating 3D structures with preserve-3d.

Example 1: Rotating 3D Cube

Classic 3D cube with all 6 faces visible - demonstrates transform-style: preserve-3d in action.

.cube { position: relative; width: 150px; height: 150px; transform-style: preserve-3d; animation: rotateCube 8s infinite linear; } .cube-face { position: absolute; width: 150px; height: 150px; } .cube-f { transform: translateZ(75px); } .cube-b { transform: rotateY(180deg) translateZ(75px); } .cube-l { transform: rotateY(-90deg) translateZ(75px); } .cube-r { transform: rotateY(90deg) translateZ(75px); } .cube-t { transform: rotateX(90deg) translateZ(75px); } .cube-bo { transform: rotateX(-90deg) translateZ(75px); }
Key Technique: transform-style: preserve-3d on the cube allows each face's translateZ to position it correctly in 3D space, creating the 3D cube structure.

CSS Code

.flip-card-inner { position: relative; width: 100%; height: 100%; transition: transform 0.6s; transform-style: preserve-3d; } .flip-card:hover .flip-card-inner { transform: rotateY(180deg); } .flip-card-front, .flip-card-back { backface-visibility: hidden; } .flip-card-back { transform: rotateY(180deg); }

Example 4: Nested 3D Rotations

Outer and inner elements rotate in opposite directions for dynamic effect.

Nested 3D

CSS Code

.outer-box { transform-style: preserve-3d; animation: rotateOuter 6s infinite linear; } .middle-box { transform-style: preserve-3d; animation: rotateMiddle 4s infinite linear reverse; } /* Each level maintains its own 3D context */

Example 10: Nested Rotation Containers

Container rotates while inner element counter-rotates for complex effect.

Nested

CSS Code

Advanced Technique: Multiple levels of transform-style: preserve-3d create complex hierarchical 3D structures with independent rotations.

Key Takeaways

  • ✓ Use transform-style: preserve-3d on containers with 3D children
  • ✓ Combine with perspective on outermost element
  • ✓ Use translateZ to position elements in 3D depth
  • ✓ Combine rotations for dynamic animations
  • ✓ Use backface-visibility: hidden for flip cards
  • ✓ Nest multiple preserve-3d elements for complexity
  • ✓ Test performance on mobile and lower-end devices
