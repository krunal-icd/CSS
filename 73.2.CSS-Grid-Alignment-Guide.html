10. Sidebar Layout (Using place-self for Different Items)
Sidebar stretches full height. Main content at top. Side widget at bottom. Each element positioned with different alignment.

.sidebar { place-self: start stretch; /* Top, full height */ }
.main-content { place-self: start stretch; /* Top, full width */ }
.side-widget { place-self: end stretch; /* Bottom, full width */ }

Quick Reference & Best Practices

Common Alignment Combinations:

  • place-items: center — Center all items (most common)
  • place-items: stretch — Full-height equal items (default)
  • place-items: start — All items top-left
  • place-items: end — All items bottom-right
  • place-content: center — Center entire grid in container

When to Override with place-self:

  • Most items follow default, but one or two need different alignment
  • Sidebar spans full height while content aligns differently
  • Hero sections and banners that need special positioning
  • Footer items aligned to bottom while header at top

Performance Tips:

  • Use align-items: stretch for equal-height cards (simpler than explicit heights)
  • Combine place-items with gap for consistent spacing
  • Test alignment across different screen sizes
  • Use browser DevTools to verify grid alignment visually
