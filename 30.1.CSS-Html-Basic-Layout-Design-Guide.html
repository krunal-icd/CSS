Layout Fundamentals

Web layouts are built using HTML structure combined with CSS styling. Understanding semantic HTML and layout techniques is crucial for building professional websites.

Key Concept: A well-designed layout uses semantic HTML elements and flexible CSS to create responsive, accessible web pages.

Semantic HTML Elements

Element Purpose Typical Use
<header> Page or section header Logo, navigation, title
<nav> Navigation links Menu, breadcrumbs
<main> Main page content Primary content area
<article> Self-contained content Blog post, news item
<section> Thematic grouping Related content blocks
<aside> Sidebar/related content Sidebar, related articles
<footer> Page or section footer Copyright, links, info

Layout Methods

  • Flexbox: 1D layouts (rows/columns)
  • Grid: 2D layouts (rows and columns)
  • Floats: Legacy method (mostly replaced)
  • Positioning: Absolute positioning for overlays

Basic HTML Structure

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Page Title</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header></header>
    <nav></nav>
    <main></main>
    <footer></footer>
</body>
</html>

Common Layout Patterns

1. Simple Single Column

The simplest layout: full-width single column.

Header
Main Content - Full Width
Footer
<body>
    <header></header>
    <main></main>
    <footer></footer>
</body>

/* CSS */
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

main {
    flex: 1;
}

2. Header + Sidebar + Main + Footer

Classic layout with navigation sidebar.

Header
Sidebar
Main Content
Footer
<body>
    <header></header>
    <aside></aside>
    <main></main>
    <footer></footer>
</body>

/* CSS */
body {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: auto 1fr auto;
    min-height: 100vh;
}

header { grid-column: 1 / -1; }
aside { grid-row: 2; }
main { grid-row: 2; }
footer { grid-column: 1 / -1; }

3. Three Column Layout

Main content with left and right sidebars.

Header
Left Sidebar
Main Content
Right Sidebar
Footer
<body>
    <header></header>
    <aside class="left"></aside>
    <main></main>
    <aside class="right"></aside>
    <footer></footer>
</body>

/* CSS */
body {
    display: grid;
    grid-template-columns: 200px 1fr 200px;
    grid-template-rows: auto 1fr auto;
}

4. Responsive Card Grid

Cards that adapt to different screen sizes.

Header
Card 1
Card 2
Card 3
Footer
<main class="card-grid">
    <article class="card"></article>
    <article class="card"></article>
    <article class="card"></article>
</main>

/* CSS */
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

5. Sticky Header & Footer

Header stays at top, footer at bottom while scrolling.

header {
    position: sticky;
    top: 0;
    z-index: 100;
}

footer {
    position: sticky;
    bottom: 0;
    z-index: 100;
}

Real-World Examples

Example 1: Blog Layout

<body>
    <header>
        <h1>Blog Title</h1>
        <nav></nav>
    </header>
    
    <main>
        <article>
            <h2>Post Title</h2>
            <p>Post content...</p>
        </article>
    </main>
    
    <aside>
        <h3>Recent Posts</h3>
        <ul></ul>
    </aside>
    
    <footer></footer>
</body>

/* CSS */
body {
    display: grid;
    grid-template-columns: 1fr 250px;
    grid-template-rows: auto 1fr auto;
    gap: 20px;
}

header { grid-column: 1 / -1; }
aside { grid-row: 2; grid-column: 2; }
main { grid-row: 2; grid-column: 1; }
footer { grid-column: 1 / -1; }

<body>
    <header></header>

            <article class="product"></article>

        </section>

main {
    display: grid;

    gap: 20px;

Example 3: Dashboard Layout

<body>

Layout Quick Reference

Container Query Breakpoints

/* Mobile First Approach */
@media (max-width: 640px) {
    /* Phones */
}

@media (min-width: 641px) and (max-width: 1024px) {
    /* Tablets */
}

@media (min-width: 1025px) {
    /* Desktop */
}

Common Layout Properties

  • display: flex; - 1D flexible layout
  • display: grid; - 2D layout system
  • gap: - Space between items
  • grid-template-columns: - Define columns
  • grid-auto-fit: - Auto responsive columns
  • position: sticky; - Sticky positioning
  • min-height: 100vh; - Full viewport height

Responsive Patterns

.grid {
    display: grid;
    grid-template-columns: 1fr;
    gap: 15px;
}

@media (min-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

@media (min-width: 1024px) {
    .grid {
        grid-template-columns: repeat(3, 1fr);
    }
}
.container {
    max-width: 1200px;
    margin: 0 auto;
    padding: 0 20px;
}

main {
    display: flex;
    gap: 20px;
    flex-wrap: wrap;
}
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
    gap: 20px;
}

/* Automatically adjusts columns based on available space */
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

main {
    flex: 1;  /* Takes remaining space */
}
body {
    display: grid;
    grid-template-columns: 250px 1fr;
    grid-template-rows: auto 1fr auto;
    min-height: 100vh;
    gap: 20px;
}

header { grid-column: 1 / -1; }
footer { grid-column: 1 / -1; }
aside { grid-row: 2; grid-column: 1; }
main { grid-row: 2; grid-column: 2; }

Best Practices

  • ✅ Use semantic HTML elements
  • ✅ Mobile-first design approach
  • ✅ Flexible layouts (flex/grid)
  • ✅ Proper spacing and alignment
  • ✅ Accessible navigation
  • ✅ Responsive images
  • ✅ Readable typography
  • ❌ Don't use tables for layout
  • ❌ Don't forget viewport meta tag
