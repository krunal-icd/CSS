Example 3: Interactive Button States

Buttons with filter effects for hover, active, and disabled states without adding extra markup.

CSS Button States with Filters

.btn { padding: 1rem 2rem; border: none; border-radius: 8px; font-size: 1em; font-weight: 600; cursor: pointer; transition: filter 0.3s ease; background: linear-gradient(135deg, #667eea, #764ba2); color: white; } .btn:hover { filter: brightness(110%) contrast(120%); } .btn:active { filter: brightness(90%); } .btn:disabled { filter: grayscale(100%) brightness(80%) opacity(60%); cursor: not-allowed; }
Benefit: Using filters for button states keeps CSS cleaner than managing multiple background colors and hover states.

Example 5: Loading State Animations

Animated loading indicators using filter properties with keyframe animations.

CSS Animation with Filters

@keyframes pulse-brightness { 0%, 100% { filter: brightness(100%); } 50% { filter: brightness(150%); } } @keyframes color-shift { 0% { filter: hue-rotate(0deg) brightness(100%); } 50% { filter: hue-rotate(180deg) brightness(110%); } 100% { filter: hue-rotate(360deg) brightness(100%); } } .loading-pulse { width: 60px; height: 60px; border-radius: 50%; background: linear-gradient(135deg, #667eea, #764ba2); animation: pulse-brightness 1.5s ease-in-out infinite; } .loading-color-shift { width: 60px; height: 60px; border-radius: 50%; background: linear-gradient(135deg, #667eea, #764ba2); animation: color-shift 2s ease-in-out infinite; }
Advantage: Animation with filters is GPU-accelerated and performs better than animating background colors or transforms.

CSS & JavaScript

/* CSS */ .focus-item:not(.active) { filter: brightness(60%) blur(2px); } .focus-item.active { filter: brightness(100%) blur(0px); } /* JavaScript */ function setFocus(element) { document.querySelectorAll('.focus-item').forEach(item => { item.classList.remove('active'); }); element.classList.add('active'); }

Example 7: Dark Mode with Filters

Toggle between light and dark modes using filter inversion—works on entire sections or pages.

Welcome to our Application

This content switches between light and dark modes using CSS filters. Toggle the buttons above to see the effect.

This approach is quick but note that inverting all colors may not be suitable for images or complex layouts.

CSS & JavaScript

/* CSS */ .dark-mode-content { padding: 2rem; background: white; border-radius: 8px; transition: filter 0.3s ease; } .dark-mode-content.dark { filter: invert(1) hue-rotate(180deg); } /* JavaScript */ function toggleDarkMode(isDark) { const content = document.getElementById('darkModeContent'); const buttons = document.querySelectorAll('.mode-btn'); buttons.forEach(btn => btn.classList.remove('active')); event.target.classList.add('active'); if (isDark) { content.classList.add('dark'); } else { content.classList.remove('dark'); } }
Note: While filter-based dark mode is fast, dedicated dark mode CSS is usually better for production. This works well for quick implementations.

Example 8: Disabled UI States

Use filters to visually indicate disabled buttons and controls without custom styling.

CSS Disabled State

.icon-button { width: 60px; height: 60px; border-radius: 8px; background: linear-gradient(135deg, #667eea, #764ba2); border: none; color: white; font-size: 1.5em; cursor: pointer; transition: filter 0.3s ease; } .icon-button:hover { filter: brightness(120%); } .icon-button:disabled { filter: grayscale(100%) brightness(60%) opacity(50%); cursor: not-allowed; }
Tip: Combining grayscale, brightness, and opacity creates a clear visual indication of disabled state without complex styling.

Example 10: Interactive Filter Control Sliders

Real-time filter adjustment using range sliders—perfect for image editors or design tools.

🎨

HTML & JavaScript

<div class="filter-preview" id="filterPreview">🎨</div> <input type="range" id="brightnessSlider" min="0" max="200" value="100" oninput="updateFilter()"> <input type="range" id="contrastSlider" min="0" max="200" value="100" oninput="updateFilter()"> <!-- More sliders -->

JavaScript Filter Update

function updateFilter() { const brightness = document.getElementById('brightnessSlider').value; const contrast = document.getElementById('contrastSlider').value; const saturation = document.getElementById('saturationSlider').value; const blur = document.getElementById('blurSlider').value; const filterString = `brightness(${brightness}%) contrast(${contrast}%) saturate(${saturation}%) blur(${blur}px)`; document.getElementById('filterPreview').style.filter = filterString; document.getElementById('brightnessValue').textContent = brightness; document.getElementById('contrastValue').textContent = contrast; document.getElementById('saturationValue').textContent = saturation; document.getElementById('blurValue').textContent = blur; }
Use Case: Image editors, photo filters, real-time effect preview tools. Users can instantly see how filters affect their images.
