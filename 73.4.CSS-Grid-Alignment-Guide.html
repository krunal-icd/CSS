🎨 CSS Grid Alignment Properties

place-items (Shorthand)

place-items is shorthand for align-items and justify-items. It centers or aligns all items in their grid cells.

place-items: center; /* align-items: center + justify-items: center */

place-self (Individual Item)

place-self is shorthand for align-self and justify-self. It aligns individual items within their grid cells.

.item:nth-child(1) { place-self: start; }
.item:nth-child(2) { place-self: center; }
.item:nth-child(3) { place-self: end; }

center

place-content (Grid Alignment)

place-content is shorthand for align-content and justify-content. It aligns the entire grid content within the grid container.

place-content: center; /* align-content: center + justify-content: center */

align-self (Individual Vertical Alignment)

align-self aligns individual items vertically within their grid cells, overriding align-items.

.item:nth-child(1) { align-self: start; }
.item:nth-child(2) { align-self: center; }
.item:nth-child(3) { align-self: end; }

📊 Quick Reference Chart

Property Type Purpose Scope
place-items Shorthand Align items in cells (both axes) Container
place-self Shorthand Align item in cell (both axes) Item
place-content Shorthand Align grid in container (both axes) Container
align-items Full Vertical alignment of items in cells Container
align-self Full Vertical alignment of individual item Item
align-content Full Vertical alignment of grid in container Container
justify-items Full Horizontal alignment of items in cells Container
justify-self Full Horizontal alignment of individual item Item
justify-content Full Horizontal alignment of grid in container Container
