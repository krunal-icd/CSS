What is CSS Cursor?

Control the appearance of the mouse cursor with CSS

The CSS cursor property specifies which cursor to display when the mouse pointer is over an element. It's a powerful tool for improving user experience by providing visual feedback about element interactivity and available actions.

💡 Key Point: The cursor property enhances UX by communicating element behavior. Users expect specific cursors for different actions (pointer for clickable, text for input, not-allowed for disabled, etc.).

Basic Syntax

/* Single cursor value */ element { cursor: pointer; } /* Fallback cursor values */ element { cursor: url('custom-cursor.png'), auto; } /* Multiple fallbacks */ element { cursor: url('hand.png') 5 5, url('hand2.png'), pointer; }

Custom Cursors

Create your own cursor images with CSS

Custom URL-based Fallback

You can create custom cursors using image files. The cursor property accepts URL values with optional coordinates for the hotspot (click point).

/* Basic custom cursor */ .custom-cursor { cursor: url('hand.png'), pointer; } /* Custom cursor with hotspot coordinates */ /* url('image.png') x y, fallback */ .custom-with-hotspot { cursor: url('custom.png') 5 5, auto; } /* Multiple fallbacks */ .cursor-with-fallbacks { cursor: url('primary.png'), url('secondary.png'), pointer; } /* Supported formats */ cursor: url('cursor.png'), pointer; cursor: url('cursor.svg'), pointer; cursor: url('cursor.gif'), pointer; cursor: url('cursor.cur'), pointer;
💡 Custom Cursor Guidelines:
  • File formats: PNG, GIF, SVG, CUR, JPG
  • Recommended size: 32x32 pixels or smaller
  • Hotspot coordinates: (x y) where cursor clicks from
  • Always include fallback: Second cursor value for unsupported images
  • Performance: Large/animated cursors can impact performance
/* Examples with coordinates */ /* Pointer at position 5,5 (top-left offset) */ .draw-pen { cursor: url('pen.png') 5 5, auto; } /* Hotspot at center */ .crosshair-custom { cursor: url('crosshair.svg') 16 16, crosshair; } /* Data URI approach */ .data-uri-cursor { cursor: url('data:image/svg+xml;utf8,<svg xmlns="http://www.w3.org/2000/svg" width="32" height="32">...</svg>') 0 0, auto; }
💡 Best Practice: Always provide a fallback cursor. Many browsers won't load external cursor files, so always include a standard cursor value as a backup.

🎯 Practical Examples

Real-world use cases and implementations

1. Interactive Button States
/* Button states with cursor feedback */ button { cursor: pointer; transition: all 0.3s ease; } button:disabled { cursor: not-allowed; opacity: 0.5; } button:hover:not(:disabled) { background: #667eea; cursor: pointer; }
2. Draggable Element
/* Draggable elements with drag cursor */ .draggable { cursor: grab; transition: cursor 0.2s; } .draggable:active { cursor: grabbing; } .draggable.being-dragged { opacity: 0.7; }
3. Data Grid with Resizable Columns
/* Grid with resizable columns */ .column-header { cursor: default; } .column-divider { cursor: col-resize; border-right: 2px solid #ddd; transition: border-color 0.2s; } .column-divider:hover { border-right-color: #667eea; }
4. Form Input States
/* Form inputs with appropriate cursors */ input[type="text"], textarea { cursor: text; } input[type="checkbox"], input[type="radio"] { cursor: pointer; } input:disabled, textarea:disabled { cursor: not-allowed; background: #f0f0f0; } input[readonly] { cursor: default; }
5. Image Viewer with Zoom
/* Image viewer with zoom cursors */ .image-viewer { cursor: zoom-in; user-select: none; } .image-viewer.zoomed { cursor: zoom-out; } .image-viewer.panning { cursor: grabbing; }
6. Drawing Canvas
/* Canvas with drawing tool cursors */ .canvas { cursor: default; } .canvas.pen-tool { cursor: url('pen-cursor.png') 5 20, auto; } .canvas.eraser-tool { cursor: url('eraser-cursor.png') 5 20, auto; } .canvas.color-picker { cursor: url('pipette-cursor.png') 5 20, auto; }

✨ Best Practices

Guidelines for using cursor properties effectively

1. Use Standard Cursors

Stick to standard cursors like pointer, text, not-allowed for consistency and familiarity.

2. Pointer for Clickable

Always use cursor: pointer on clickable elements. Users expect this visual feedback.

3. Indicate Disabled State

Use cursor: not-allowed on disabled form elements to indicate unavailability.

4. Resize Cursor Alignment

Match resize cursor direction to actual resize capability (n-resize for top edge, se-resize for corner).

5. Custom Cursor Optimization

Keep custom cursors small (32x32px or less) and always provide a fallback standard cursor.

6. Context-Appropriate Cursors

Use cursors that match element functionality. Don't use pointer on non-clickable elements.

7. Loading Indication

Use cursor: wait or cursor: progress during async operations.

8. Test Accessibility

Some users may not see cursor changes. Always pair cursor changes with other visual feedback.

💡 Accessibility Note: Don't rely solely on cursor changes for critical information. Combine cursor properties with other visual indicators, labels, and hover states to ensure accessibility for all users.
