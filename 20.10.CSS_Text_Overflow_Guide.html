📝 CSS Text-Overflow - Practical Guide

🎯 What is Text-Overflow?

Text-Overflow controls how hidden text is displayed when it overflows its container. It works together with overflow and white-space properties to handle text that doesn't fit in the available space.

✓ Common Uses:
• Truncate long titles in cards
• Show ellipsis (...) for overflowing text
• Create responsive text effects
• Display partial text with custom markers
• Multi-line text truncation
💡 Required Properties: Text-overflow works best when combined with overflow: hidden and white-space: nowrap (for single line).

📋 Syntax & Value Types

Basic Syntax

/* Single-line text overflow */ text-overflow: clip; text-overflow: ellipsis; text-overflow: " [...]"; text-overflow: fade; text-overflow: fade(10px); text-overflow: fade(5%); /* Multi-line text overflow */ display: -webkit-box; -webkit-line-clamp: 3; -webkit-box-orient: vertical; overflow: hidden; text-overflow: ellipsis;
clip Text is cut off abruptly
No visual indicator
ellipsis (...) Shows three dots
Most common choice
custom string Custom character/text
e.g., " [...]" or " →"
fade Fades text gradually
Limited browser support
-webkit-line-clamp Multi-line truncation
2, 3, 4 lines, etc.
white-space: nowrap Prevents line breaking
Required for single-line
✓ Most Used: text-overflow: ellipsis is the standard and most widely supported approach.

1️⃣ Single-Line Text Overflow

For text that stays on one line and gets truncated:

overflow: visible
This is a very long text that will overflow the container
width: 300px; white-space: nowrap; overflow: visible; /* Text overflows outside */
overflow: hidden
This is a very long text that will overflow the container
width: 300px; white-space: nowrap; overflow: hidden; /* Text is cut off */
overflow: clip
This is a very long text that will overflow the container
width: 300px; white-space: nowrap; overflow: clip; /* Similar to hidden */
text-overflow: ellipsis ⭐
This is a very long text that will overflow the container
width: 300px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; /* Shows ... at end */
text-overflow: clip
This is a very long text that will overflow the container
width: 300px; white-space: nowrap; overflow: hidden; text-overflow: clip; /* No indicator */
Custom Overflow String
This is a very long text that will overflow the container
width: 300px; white-space: nowrap; overflow: hidden; text-overflow: " →"; /* Custom ending */
💡 Key Requirements: For single-line text-overflow to work, you need:
• A fixed or max-width
• white-space: nowrap
• overflow: hidden
• text-overflow: ellipsis (or other value)

📋 Complete Property Reference

Required Properties Combination

Property Value Purpose
white-space nowrap Prevents line breaking (single-line only)
overflow hidden Hides overflowing content
text-overflow ellipsis / clip / custom Shows how text is cut off

💡 Best Practices & Tips

1. Always Test on Mobile
Text truncation behavior may differ on small screens. Test thoroughly.
2. Combine with Tooltips
Show full text in title attributes or tooltips when truncating important content.
3. Use Consistent Line Clamping
Keep the same number of lines across similar components for consistency.
4. Consider Readability
Don't truncate critical information. Ensure users can still understand the content.
5. Avoid Excessive Truncation
If you need to truncate multiple times, reconsider the layout or content structure.
6. Provide Context
Make it clear to users that content is truncated (use ellipsis, "Read More", etc.).

⚡ Quick Copy-Paste Snippets

Single-Line Truncation (Most Common)

/* Standard ellipsis */ .truncate-single { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; max-width: 300px; } /* Usage in HTML */ <h3 class="truncate-single"> Long title that will be truncated with ellipsis </h3>

Multi-Line Truncation (2-3 Lines)

/* Truncate to 2 lines */ .truncate-lines-2 { display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical; overflow: hidden; text-overflow: ellipsis; } /* Truncate to 3 lines */ .truncate-lines-3 { display: -webkit-box; -webkit-line-clamp: 3; -webkit-box-orient: vertical; overflow: hidden; text-overflow: ellipsis; }

Responsive Truncation

.truncate { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; } /* Mobile: 2 lines */ @media (max-width: 768px) { .truncate { display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical; white-space: normal; } }

❌ Common Mistakes & Solutions

❌ Wrong

Missing white-space: nowrap
.truncate { overflow: hidden; text-overflow: ellipsis; } /* Won't work without nowrap */
No fixed width
.truncate { text-overflow: ellipsis; /* No width specified */ }
Using visibility: hidden
.truncate { visibility: hidden; text-overflow: ellipsis; } /* Use overflow: hidden instead */

✅ Correct

Include all required properties
.truncate { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
Set width on parent
.truncate { max-width: 300px; white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
Use overflow: hidden
.truncate { overflow: hidden; text-overflow: ellipsis; /* Correct approach */ }
