📐 CSS Flexbox Flex-Basis Tutorial

Master the base size of flex items before growth or shrinkage

What is Flex-Basis?

The flex-basis property defines the default size of a flex item before the remaining space is distributed according to flex-grow and flex-shrink. It sets the main size (width in row direction, height in column direction).

Default value is auto, which means the item's size is based on its content or width property. You can set it to any length value (px, em, %) or auto.

💡 Key Point: Flex-basis defines the starting size BEFORE flex-grow/flex-shrink calculations. It's the foundation for all flex sizing.
/* Basic Syntax - Applied to individual flex items */ .flex-item { flex-basis: 200px; /* Item starts at 200px */ } /* Default value */ .flex-item-default { flex-basis: auto; /* Size based on content/width */ } /* Shorthand */ .flex-item { flex: 1 1 200px; /* flex-grow flex-shrink flex-basis */ }

Flex-Basis Property Values

Value Description Example
auto Default - size based on content or width property flex-basis: auto
0 Item starts at zero, only flex-grow matters flex-basis: 0
Length (px) Fixed pixel size as starting point flex-basis: 200px
Percentage (%) Percentage of container width flex-basis: 25%
em/rem Relative to font size flex-basis: 15em

Understanding Flex-Basis Behavior

📌 flex-basis: auto

Default value. Item size is based on content or the width property.

.item { flex-basis: auto; /* OR just don't set it */ } /* Size = content width or width property */

📌 flex-basis: 0

Item starts at zero size. Useful with flex-grow to create equal-width layouts.

.item { flex: 1 1 0; /* flex-grow flex-shrink flex-basis */ } /* All items: 0 starting size, grow equally */

📌 flex-basis: 200px

Item starts at 200px, then grows or shrinks based on flex-grow/shrink.

.item { flex-basis: 200px; } /* Item will be at least 200px before growth */

📌 flex-basis: 25%

Item starts at 25% of container width, then grows/shrinks.

.item { flex-basis: 25%; } /* Item starts at 1/4 of container width */

Flex-Basis vs Width

Key Differences:

  • Width: Fixed, doesn't consider flex properties
  • Flex-Basis: Starting point, can grow/shrink
  • Direction: Width is always horizontal, flex-basis follows flex-direction
  • Priority: Flex-basis takes precedence over width in flex containers
/* In flex container */ .item-with-width { width: 200px; /* May be overridden */ } .item-with-basis { flex-basis: 200px; /* Takes precedence */ } .item-both { width: 200px; flex-basis: 300px; /* flex-basis wins */ }

Common Layout Patterns with Flex-Basis

🎨 Equal Width Items

.item { flex: 1 1 0; /* Start at 0, grow equally */ } /* Result: All items equal width */

🎨 Minimum Width Items

.item { flex: 1 1 200px; /* At least 200px, can grow */ } /* Result: Items never smaller than 200px */

🎨 Sidebar + Content

.sidebar { flex: 0 1 250px; /* Fixed 250px sidebar */ } .content { flex: 1 1 0; /* Fills remaining space */ }

🎨 Responsive Percentages

.item { flex: 1 1 calc(33.333% - 10px); /* 3 columns with gap */ }

Important Tips & Best Practices

✓ Flex-Basis vs Width: In flex containers, use flex-basis, not width. It works better with flex-grow/shrink.
✓ Use Shorthand: flex: 1 1 0 is cleaner than separate properties.
⚠ 0 vs auto: flex-basis: 0 ignores content size; auto respects it.
✓ With Flex-Grow: flex-basis: 0 + flex-grow: 1 = equal distribution.
✓ Percentage Basis: Use percentages for responsive grids. Combine with gap and calc().
⚠ Content Overflow: Small flex-basis values may cause content overflow. Test thoroughly.
✓ Min/Max Width: Combine with min-width/max-width for better control.

Real-World Use Cases

📊 3-Column Grid: flex-basis: calc(33.333% - 10px)
📱 Responsive Cards: flex-basis: 0 with flex-grow: 1
🎯 Sidebar Layout: flex-basis: 250px for fixed sidebar
📝 Form Inputs: flex-basis: auto to fit content
🎨 Gallery Layout: flex-basis: 200px with grow

Browser Support

The flex-basis property is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.item { flex-basis: 200px; /* No vendor prefixes needed for modern browsers */ }
