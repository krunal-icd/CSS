CSS Grid: Nested Grids & Subgrid

Master grids within grids and leverage parent grid tracks

Understanding Nested Grids
What is a Nested Grid?
Nested Grid: A grid item that is also a grid container. You can create grids inside grid items, allowing unlimited nesting depth.
Two Types of Nesting
Traditional Nesting: A grid item becomes a grid container with its own independent track definitions. Completely separate from parent grid.
Subgrid: A grid item inherits parent grid's track definitions. Child grid items can align with parent grid tracks. (Requires display: subgrid)

Traditional Nested Grids
How It Works
  • Grid item has display: grid applied
  • Creates completely independent grid structure
  • Parent grid tracks are invisible to nested grid
  • Nested grid has its own column/row definitions
  • Can nest infinitely deep
Syntax
/* Parent grid */ .parent-grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-template-rows: repeat(2, 200px); gap: 20px; } /* Child item that becomes a grid */ .parent-grid > .card { display: grid; /* Makes it a grid container */ grid-template-columns: repeat(2, 1fr); /* Independent columns */ grid-template-rows: repeat(2, 1fr); gap: 10px; }
Key Characteristics
  • Independence: Child grid doesn't know about parent grid
  • Size Constraints: Nested grid is limited to parent item's size
  • Complete Control: Define all child tracks explicitly
  • Flexibility: Each nested grid can have different structure
  • Complexity: More CSS needed to align across grids
When to Use Traditional Nesting
  • Child items have completely different layout than parent
  • You want full independence from parent grid
  • Nested items have unique track requirements
  • Supporting older browsers (subgrid is newer)
  • Building reusable components with their own grids
Subgrid: Inheriting Parent Tracks
What is Subgrid?
display: subgrid: A grid item inherits parent grid's track definitions. Children align with parent grid tracks automatically, enabling perfect alignment across multiple nested grids.
Syntax
/* Parent grid with named tracks */ .parent-grid { display: grid; grid-template-columns: 100px 1fr 200px; grid-template-rows: auto 1fr auto; } /* Child becomes subgrid - inherits parent columns/rows */ .child-subgrid { display: subgrid; grid-column: 1 / -1; /* Span all parent columns */ grid-row: 2; /* Position in parent rows */ } /* Grandchild items align with parent grid tracks */ .child-subgrid > .item { grid-column: 2; /* Aligns to parent column 2 */ }
Key Advantages
  • Perfect Alignment: Nested items align perfectly with parent grid
  • Inherits Tracks: Don't need to redefine columns/rows
  • Responsive Sync: When parent grid changes, subgrid adjusts automatically
  • Cleaner CSS: Less code needed for alignment
  • Flexible Nesting: Can nest subgrids within subgrids
Column and Row Subgrid
/* Inherit only columns, define own rows */ .column-subgrid { display: subgrid; grid-template-columns: subgrid; /* Inherit parent columns */ grid-template-rows: auto 1fr; /* Own row definition */ } /* Inherit only rows, define own columns */ .row-subgrid { display: subgrid; grid-template-columns: repeat(2, 1fr); /* Own column definition */ grid-template-rows: subgrid; /* Inherit parent rows */ } /* Both columns and rows from parent */ .full-subgrid { display: subgrid; grid-template-columns: subgrid; grid-template-rows: subgrid; }
Browser Support for Subgrid
✓ Supported in: Chrome 90+, Firefox 71+, Safari 16+, Edge 90+
⚠️ Note: Subgrid is newer than Grid. Check browser support before using. Consider traditional nesting for older browser support.

Real-World Use Cases
Scenario 1: Card Grids (Traditional Nesting)
Product cards in a parent grid. Each card contains its own layout (image, title, price, button). Cards don't need alignment with parent grid.
.product-grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; } .product-card { display: grid; /* Nested grid */ grid-template-rows: 150px auto auto 50px; }
Scenario 2: Data Tables (Subgrid)
Data table with multiple rows that should align vertically in columns. Subgrid ensures column alignment across all rows.
.table { display: grid; grid-template-columns: 100px 150px 200px 100px; } .table-row { display: subgrid; grid-column: 1 / -1; } /* All rows align with parent columns */
Scenario 3: Form Layouts (Subgrid)
Multi-column form where labels and inputs need perfect vertical alignment. Subgrid keeps everything aligned.
.form { display: grid; grid-template-columns: 150px 1fr 150px 1fr; gap: 20px; } .form-field { display: subgrid; grid-column: span 2; /* Spans 2 parent columns */ }
Scenario 4: Article with Sidebar (Subgrid)
Article content with sidebar. Subgrid ensures article sections and sidebar elements align with parent grid.
.article-layout { display: grid; grid-template-columns: 1fr 250px; gap: 40px; } .article-content { display: subgrid; grid-template-columns: subgrid; /* Inherit parent columns */ }
Best Practices & Tips
✓ Do's
  • Use traditional nesting for card-like components: When each nested grid is independent
  • Use subgrid for multi-row alignment: When you need vertical alignment across rows
  • Plan your grid structure upfront: Know what needs to align before writing CSS
  • Test across browsers: Subgrid support varies by browser version
  • Use semantic HTML: Grid structure should reflect content hierarchy
  • Document your nesting: Comments help future maintenance
✗ Don'ts
  • Don't nest unnecessarily: Sometimes simpler CSS is better than nested grids
  • Don't over-complicate with deep nesting: 2-3 levels is usually sufficient
  • Don't assume subgrid support: Check browser compatibility before using
  • Don't use subgrid when independence is needed: Traditional nesting is better sometimes
  • Don't forget about gap: Gap applies at each grid level independently
Pro Tips
💡 Tip 1: Combine traditional nesting and subgrid. Use subgrid at top levels for alignment, traditional nesting for component internals.
💡 Tip 2: Use named grid areas with subgrid for powerful layout control and readable CSS.
💡 Tip 3: Subgrid inherits gap values from parent. Plan your spacing accordingly.
💡 Tip 4: Debug nested grids with browser DevTools. Toggle grid overlay to see alignment.
💡 Tip 5: Consider using CSS custom properties for nested grid values to make them reusable.
Quick Reference

Traditional Nesting:

  • display: grid; on child items
  • Define own columns/rows
  • Complete independence from parent
  • Use for card components, independent layouts

Subgrid:

  • display: subgrid; on child items
  • Inherit parent columns/rows
  • Perfect vertical alignment across rows
  • Use for data tables, forms, multi-row layouts

When to Choose:

  • Need alignment with parent? → Subgrid
  • Need independence? → Traditional nesting
  • Older browser support? → Traditional nesting
  • Multi-row alignment? → Subgrid
