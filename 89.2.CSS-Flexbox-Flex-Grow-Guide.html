Fixed-width sidebar with flexible main content area.

CSS Code

🔟 Split Layout - 1:2 Ratio

Sidebar (1) and main content (2) with proportional flex-grow.

CSS Code
.split-left { flex: 1; } .split-right { flex: 2; } /* Result: Left gets 1/3, Right gets 2/3 */
Live Example (Resize to see change)

Sidebar (1/3)

Takes 33% of available space with flex: 1

Main Content (2/3)

Takes 67% of available space with flex: 2. This area is twice as wide as the sidebar, making it perfect for content-heavy layouts.

💡 Key Takeaways

Equal Width: Use flex: 1 on all items for equal width distribution
Sidebar + Content: Use flex: 0 0 250px for sidebar, flex: 1 for content
Proportional: Use different flex-grow values (1, 1, 2) for 1:1:2 ratio
Spacer Element: Use flex: 1 on empty div to push other items apart
Shorthand: flex: 1 = flex-grow: 1; flex-shrink: 1; flex-basis: 0
Min-Width: Always set min-width with flex: 1 for responsive safety
🎯 Pro Tip: Combine flex-grow with flex-wrap and gap for responsive, flexible layouts
✅ Remember: flex-grow only expands items, doesn't shrink them. Use flex-shrink for that!
