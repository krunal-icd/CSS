CSS Object-Fit Property

Complete Guide to Image and Video Scaling

What is Object-Fit?

The object-fit property specifies how content (images, videos) should be resized to fit its container. It determines whether the content should be stretched, cropped, or scaled to maintain aspect ratio while fitting within a defined width and height.

Key Purpose: Object-fit solves the problem of responsive images and videos. Instead of distorting or awkwardly fitting content, you control exactly how it behaves in its container.

Before object-fit, developers had to use background-images or complex JavaScript. Now, with a simple CSS property, you get precise control over how content fills its space.

Syntax & Property Values

Basic Syntax

object-fit: fill | contain | cover | scale-down | none;

All Object-Fit Values

Value Description Aspect Ratio Common Use
fill Stretches to fill container (may distort) ❌ Ignored Rarely used
contain Scales to fit completely inside (may have empty space) ✓ Preserved Most common
cover Scales to cover container (may crop) ✓ Preserved Hero images, thumbnails
scale-down Smaller of contain or original size ✓ Preserved Large images on mobile
none No scaling (original size, may overflow) ✓ Preserved Precise control

Understanding Each Value

1. object-fit: fill (Default)

What it does: Content is stretched to fill the container's width and height completely. Aspect ratio is ignored.

Result: Image may appear distorted if container aspect ratio differs from content.

When to use:

  • Rarely recommended (causes distortion)
  • When exact fill is more important than appearance
  • Specific design requirements

Example:

img { width: 300px; height: 200px; object-fit: fill; /* Stretches to fill */ }

2. object-fit: contain (Most Common)

What it does: Content is scaled to fit completely inside the container while maintaining aspect ratio. Empty space may appear.

Result: No distortion, no cropping, but possible letterboxing/pillarboxing.

When to use:

  • Product galleries (show entire product)
  • Profile pictures with letter-boxing acceptable
  • Charts, diagrams, UI mockups
  • When aspect ratio is critical

Example:

img { width: 300px; height: 300px; object-fit: contain; object-position: center; /* Image fits completely, centered */ }

3. object-fit: cover (Second Most Common)

What it does: Content is scaled to cover the container completely while maintaining aspect ratio. Content may be cropped.

Result: No empty space, no distortion, but parts may be hidden.

When to use:

  • Hero images and banners
  • Background images (img element)
  • Video thumbnails
  • Gallery grids with fixed sizes
  • When covering container is priority

Example:

img { width: 100%; height: 400px; object-fit: cover; object-position: center; /* Hero image - covers full width */ }

4. object-fit: scale-down

What it does: Uses the smaller of contain or the original size. Never enlarges.

Result: Small images stay original size, large images scale down.

When to use:

  • Icons and small graphics
  • User-generated content of variable sizes
  • When you don't want to enlarge small images
  • Responsive design with varied image sizes

Example:

img { width: 150px; height: 150px; object-fit: scale-down; /* Never enlarges small images */ }

5. object-fit: none

What it does: Content is not scaled. Original dimensions are maintained. May overflow container.

Result: Precise control with object-position, but possible overflow.

When to use:

  • Precise image positioning (with object-position)
  • Image cropping effects
  • When overflow is controlled with CSS
  • Specific design requirements

Example:

img { width: 200px; height: 200px; object-fit: none; object-position: 50% 0%; overflow: hidden; /* Shows top portion of image */ }

Object-Position Property

The object-position property works with object-fit to control where the content is positioned within the container.

object-position: left | center | right | top | bottom | percentage | pixels;

Common Combinations

object-fit: cover + object-position: center

Crops equally from all sides (most common for hero images)

object-fit: cover + object-position: top

Crops from bottom (keeps faces/important top content)

object-fit: contain + object-position: center

Centers image with empty space around

object-fit: none + object-position: 50% 25%

Precise positioning with cropping

Example:

img { width: 300px; height: 200px; object-fit: cover; object-position: center top; /* Focus on top */ }

Real-World Use Cases

🖼️ Product Gallery

Use object-fit: contain to show entire product with white space. Keep aspect ratio intact for consistency.

📸 Hero Banner

Use object-fit: cover with object-position: center. Covers full width while cropping excess.

👤 Profile Pictures

Use object-fit: cover in circular containers. Automatically crops to square with best focus.

🎥 Video Thumbnails

Use object-fit: cover to ensure thumbnails fill grid cells uniformly without distortion.

📱 Responsive Images

Use object-fit: scale-down to prevent enlarging small images on large screens.

📊 UI Elements

Use object-fit: contain for icons, logos, and UI graphics to prevent distortion.

Practical Code Examples

Example 1: Product Gallery Grid

html <div class="product-grid"> <img src="product.jpg" alt="Product"> </div> css .product-grid { display: grid; grid-template-columns: repeat(3, 1fr); gap: 20px; } .product-grid img { width: 100%; height: 200px; object-fit: contain; padding: 10px; background: white; }

Example 2: Hero Image

html <img src="hero.jpg" alt="Hero" class="hero-image"> css .hero-image { width: 100%; height: 400px; object-fit: cover; object-position: center; }

Example 3: Video Element

html <video controls> <source src="video.mp4"> </video> css video { width: 100%; max-width: 800px; height: auto; object-fit: cover; }

Example 4: Circular Profile Picture

html <img src="profile.jpg" class="profile-pic"> css .profile-pic { width: 100px; height: 100px; border-radius: 50%; object-fit: cover; object-position: center; }

Example 5: Image with Aspect Ratio Box

html <div class="image-container"> <img src="image.jpg"> </div> css .image-container { width: 100%; aspect-ratio: 16 / 9; } .image-container img { width: 100%; height: 100%; object-fit: cover; }

Best Practices & Tips

✓ Best Practices:
  • Always set explicit width and height on images
  • Use contain for products and preservation
  • Use cover for hero images and thumbnails
  • Combine with object-position for precise control
  • Test on different image aspect ratios
  • Provide alt text for accessibility
  • Use aspect-ratio for responsive layouts
⚠ Common Mistakes:
  • Forgetting to set dimensions (width/height)
  • Using wrong value (fill causes distortion)
  • Not testing with various image sizes
  • Ignoring IE support requirements
  • Not combining with object-position
  • Using with background-image instead of img

Object-Fit vs Alternatives

object-fit (Recommended)

  • ✓ Works with img elements
  • ✓ Works with video elements
  • ✓ Responsive and flexible
  • ✓ Simple CSS property
  • ✗ No IE support

background-image

  • ✓ background-size: cover works everywhere
  • ✓ Full IE support
  • ✗ Can't use with semantic img
  • ✗ Performance concerns
  • ✗ Less accessible

Conclusion

Object-fit is essential for modern responsive web design. It provides elegant solutions to image sizing problems without JavaScript or hacky workarounds.

Quick Decision Guide:

  • Show entire image: Use contain
  • Fill container: Use cover
  • Don't enlarge small images: Use scale-down
  • Precise positioning: Use none + object-position
  • Never use: fill (causes distortion)
