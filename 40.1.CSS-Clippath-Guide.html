✂️ CSS clip-path Property

Complete Guide to Creating Custom Shapes

What is CSS clip-path?

Create custom shapes by clipping elements

The CSS clip-path property creates a clipping region that defines which parts of an element are visible. It allows you to define custom shapes—circles, polygons, ellipses, and more—without needing images or SVG.

💡 Key Benefits:
  • Create custom shapes without SVG or images
  • Responsive - scales with element size
  • Animatable with CSS transitions and animations
  • Great for creative layouts and designs
  • Lightweight and performant
/* Basic clip-path syntax */ clip-path: circle(50%); clip-path: ellipse(50% 30%); clip-path: polygon(50% 0%, 100% 100%, 0% 100%); clip-path: inset(10px 20px 30px 40px); /* Animated clip-path */ clip-path: polygon(0% 0%, 100% 0%, 100% 100%, 0% 100%); transition: clip-path 0.3s ease; /* On hover */ element:hover { clip-path: polygon(0% 10%, 90% 0%, 100% 90%, 10% 100%); }
💡 Browser Support: Supported in all modern browsers. Some performance considerations on older devices with complex polygons.

Circle & Ellipse Functions

Creating circular and oval shapes

circle() ellipse() Responsive

circle() Syntax

/* circle(radius [at position]) */ /* Basic circle - 50% of element */ clip-path: circle(50%); /* Circle at center (default) */ clip-path: circle(50% at center); /* Circle at specific position */ clip-path: circle(50% at 30% 40%); /* Pixel-based circle */ clip-path: circle(100px); /* Positioned circle */ clip-path: circle(100px at 50px 50px);

ellipse() Syntax

/* ellipse(rx ry [at position]) */ /* Basic ellipse */ clip-path: ellipse(50% 30%); /* Ellipse at center (default) */ clip-path: ellipse(50% 30% at center); /* Ellipse at specific position */ clip-path: ellipse(60% 40% at 40% 60%); /* Pixel-based ellipse */ clip-path: ellipse(100px 60px); /* Positioned ellipse */ clip-path: ellipse(100px 60px at 50px 50px);
💡 Parameters:
  • circle(radius): Single value for radius (% of element or pixels)
  • ellipse(rx ry): Horizontal and vertical radii
  • at position: Optional center position (default: center)

polygon() Function

Create any multi-sided shape with points

polygon() Custom shapes Flexible

The polygon() function lets you define any shape by specifying coordinates of vertices. Each coordinate is a pair of X and Y values representing a point.

/* polygon(x1 y1, x2 y2, x3 y3, ...) */ /* Triangle */ clip-path: polygon(50% 0%, 100% 100%, 0% 100%); /* Diamond/Rhombus */ clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); /* Pentagon */ clip-path: polygon(50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38%); /* Hexagon */ clip-path: polygon( 50% 0%, 100% 25%, 100% 75%, 50% 100%, 0% 75%, 0% 25% ); /* Star (5 points) */ clip-path: polygon( 50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35% ); /* Arrow shape */ clip-path: polygon( 0% 20%, 100% 50%, 0% 80%, 30% 50% );
💡 Coordinate System:
  • 0% 0% = top-left corner
  • 100% 100% = bottom-right corner
  • 50% 50% = center
  • Use either percentages or pixels

inset() Function

Create rectangular shapes with optional border radius

inset() Rectangle Offsets
/* inset(top right bottom left [round radius]) */ /* Uniform inset from all sides */ clip-path: inset(20%); /* Inset with different values */ clip-path: inset(10% 20% 30% 40%); /* Inset with rounded corners */ clip-path: inset(20% round 10px); /* Inset with different corner radii */ clip-path: inset(15% round 10px 20px 15px 5px); /* Pixel-based inset */ clip-path: inset(10px 20px 10px 20px); /* Inset with percentage and pixels mixed */ clip-path: inset(10% 10px 10% 10px round 5px); /* Use 0 values for full visibility */ clip-path: inset(0% 0% 0% 0%);
💡 Syntax Order: Top, Right, Bottom, Left (like margin/padding). Single value applies to all sides.

clip-path Animations

Animate between different clip-path shapes

Animations Transitions Creative
/* Animate clip-path on hover */ .element { clip-path: circle(0%); transition: clip-path 0.5s ease; } .element:hover { clip-path: circle(50%); } /* Animation with keyframes */ @keyframes revealCircle { from { clip-path: circle(0%); } to { clip-path: circle(50%); } } .element { animation: revealCircle 1s ease forwards; } /* Animate polygon shape */ @keyframes shapeMorph { 0% { clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); } 50% { clip-path: polygon(50% 0%, 100% 100%, 0% 100%); } 100% { clip-path: polygon(50% 0%, 100% 50%, 50% 100%, 0% 50%); } } /* Performance note: Keep animations simple for better performance */
⚠️ Performance: Complex polygon animations can impact performance. Test on lower-end devices and optimize for smooth 60fps animations.

🎯 Practical Use Cases

Real-world applications of clip-path

1. Profile Image Circles

/* Profile image in circle */ .profile-image { clip-path: circle(50%); } /* Animated profile hover */ .profile-image { clip-path: circle(48%); transition: clip-path 0.3s ease; } .profile-image:hover { clip-path: circle(50%); }

2. Diagonal Sections

/* Diagonal background section */ .diagonal-section { clip-path: polygon(0 0, 100% 0, 100% 90%, 0 100%); } /* Angled design element */ .angled { clip-path: polygon(0 10%, 100% 0, 100% 100%, 0 90%); }

3. Image Reveals

/* Reveal animation on scroll */ .image-reveal { clip-path: inset(0% 100% 0% 0%); animation: slideReveal 1s ease forwards; } @keyframes slideReveal { from { clip-path: inset(0% 100% 0% 0%); } to { clip-path: inset(0% 0% 0% 0%); } }

4. Creative Buttons

/* Hexagonal button */ .hex-button { clip-path: polygon( 30% 0%, 70% 0%, 100% 50%, 70% 100%, 30% 100%, 0% 50% ); padding: 1rem 2rem; } /* Star-shaped button */ .star-button { clip-path: polygon( 50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%, 50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35% ); }

5. Video/Media Shapes

/* Circular video thumbnail */ .video-thumb { clip-path: circle(50%); } /* Oval image gallery */ .gallery-image { clip-path: ellipse(45% 35%); }

6. Shape Hover Effects

/* Shape transform on hover */ .shape-hover { clip-path: polygon(50% 0%, 100% 100%, 0% 100%); transition: clip-path 0.4s cubic-bezier(0.68, -0.55, 0.265, 1.55); } .shape-hover:hover { clip-path: polygon(50% 10%, 100% 90%, 0% 90%); }

✨ Best Practices & Tips

Guidelines for using clip-path effectively

1. Use for Creative Designs

clip-path is perfect for creative shapes. Keep functional elements rectangular for better usability.

2. Performance Considerations

Complex polygons can impact performance. Test on lower-end devices. Simple shapes like circle perform best.

3. Accessibility

Ensure clipped content is still accessible. Text should remain readable. Provide alternative layouts for screen readers.

4. Animate Smoothly

Use ease functions and reasonable durations. Test animations on various devices for smooth 60fps performance.

5. Provide Fallbacks

For IE11, use fallback styling or alternative approaches. Test that content is visible without clip-path.

6. Use with mask-image

Combine clip-path with mask-image for more complex effects. But be aware of performance implications.

7. Responsive Shapes

clip-path scales with element size. Use percentages for responsive designs that work across device sizes.

8. Test Thoroughly

Test clip-path on different browsers, devices, and screen sizes to ensure consistency and performance.

/* ===== BEST PRACTICES EXAMPLE ===== */ /* Fallback styling for IE11 */ .shape-element { border-radius: 50%; /* Fallback for circle */ clip-path: circle(50%); } /* Responsive clip-path */ .responsive-shape { clip-path: polygon(50% 0%, 100% 38%, 82% 100%, 18% 100%, 0% 38%); /* Scales with element size automatically */ } /* Performant animation */ .animated-shape { clip-path: circle(30%); transition: clip-path 0.3s ease; /* Smooth animation without performance impact */ } .animated-shape:hover { clip-path: circle(50%); } /* Accessible clipping */ .clipped-content { clip-path: polygon(0% 10%, 100% 0%, 100% 90%, 0% 100%); } .clipped-content p { /* Ensure text remains readable and accessible */ font-size: 1rem; line-height: 1.6; color: #333; }
