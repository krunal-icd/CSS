CSS overflow-wrap

Practical Real-World Examples

1. Chat Message with Long Words

User sends a message with long unbreakable words. Without overflow-wrap, text overflows the container. With overflow-wrap, it breaks at word boundaries.

Without overflow-wrap

Check this out: supercalifragilisticexpialidocioushahahaha!

With overflow-wrap: break-word

Check this out: supercalifragilisticexpialidocioushahahaha!
CSS
.chat-message { overflow-wrap: break-word; }

2. Long URLs in Fixed-Width Container

URLs are naturally long and unbreakable. Without overflow-wrap, they overflow. With it, they break cleanly at word boundaries.

Without overflow-wrap

Result:
https://www.example.com/very/long/path/to/page?query=parameter&another=value

With overflow-wrap: break-word

Result:
https://www.example.com/very/long/path/to/page?query=parameter&another=value
CSS
.url-container { overflow-wrap: break-word; word-break: break-all; /* Optional: break within words too */ }

9. overflow-wrap: anywhere vs break-word

Understand the difference between "break-word" and "anywhere" values. The main difference is in how they interact with word-spacing.

Value Behavior Best For
normal Only breaks at normal word boundaries. Text overflows if word is too long. Traditional layouts where overflow is acceptable
break-word Breaks long unbreakable words to prevent overflow. Respects word spacing. Most common use case (URLs, emails, long words)
anywhere Breaks at any point if needed. Can break very aggressively. When you must fit text at all costs (rare)
Comparison
/* break-word: More conservative, respects word spacing */ p { overflow-wrap: break-word; } /* anywhere: More aggressive, breaks anywhere needed */ p { overflow-wrap: anywhere; } /* Recommended: Use break-word for most cases */

10. Combining with word-break Property

overflow-wrap and word-break can work together for maximum control over text wrapping behavior.

CSS Behavior
overflow-wrap: break-word; Breaks long words only if they exceed container width
word-break: break-all; Breaks words at any character if needed (very aggressive)
word-break: break-word; Similar to overflow-wrap: break-word (deprecated, use overflow-wrap)
overflow-wrap + word-break Combined: overflow-wrap: break-word; word-break: break-all;
Common Pattern
/* Conservative: breaks only if necessary */ .text { overflow-wrap: break-word; } /* Aggressive: breaks at any point */ .text { overflow-wrap: break-word; word-break: break-all; } /* For CJK languages (Chinese, Japanese, Korean) */ .text { word-break: break-word; overflow-wrap: break-word; }

Result: Long breadcrumb wraps gracefully within its container without breaking layout

Key Takeaways

When to use overflow-wrap:
  • Long URLs that might overflow their container
  • Email addresses in narrow columns
  • User-generated content with potential long words
  • Code snippets or terminal output
  • Mobile-responsive design (recommended for all text)
  • Chat applications with messages
  • Data tables with variable content length
💡 Best Practice: Apply overflow-wrap: break-word to body or use it globally for consistent text wrapping behavior across your entire site. It's safe to use on all text elements.
Global CSS (Recommended)
/* Apply to all text content for consistent wrapping */ body, html { overflow-wrap: break-word; word-wrap: break-word; } /* Or more selectively */ p, div, span, td, li { overflow-wrap: break-word; }
