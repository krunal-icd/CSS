CSS :placeholder-shown

12 Practical Examples • Form Enhancement Patterns

1. Border State Change

Form UX

Change border color and background based on whether placeholder is shown (empty) or hidden (filled).

input:placeholder-shown { border-color: #17a2b8; background: #f0f8fa; } input:not(:placeholder-shown) { border-color: #28a745; background: #f1f9f6; } input:focus { border-color: #667eea; }

2. Floating Label Animation

UX Pattern

Animate label from inside the input to float above when user starts typing. Pure CSS floating label effect.

.label { position: absolute; top: 16px; transition: all 0.3s ease; } input:not(:placeholder-shown) ~ label { top: -8px; font-size: 0.75em; color: #667eea; }

3. Search Clear Button

Interactive

Show a clear button that only appears when user has typed in the search field.

.clear-btn { opacity: 0; pointer-events: none; transition: all 0.3s ease; } input:not(:placeholder-shown) ~ .clear-btn { opacity: 1; pointer-events: auto; }

4. Conditional Help Text

UX Pattern

Show help text only when the input is empty (placeholder visible). Hide when user starts typing.

💡 Example: user@example.com

.help-text { display: block; opacity: 1; transition: all 0.3s ease; } input:not(:placeholder-shown) ~ .help-text { display: none; opacity: 0; }

5. Icon State Indicators

Interactive

Display different icons based on input state - empty state icon vs. filled state icon.

📝 ✓
input:placeholder-shown ~ .empty { opacity: 1; color: #999; } input:not(:placeholder-shown) ~ .filled { opacity: 1; color: #28a745; }

6. Email Validation

Validation

Show green border for valid email and red for invalid, no styling when empty (placeholder shown).

input:placeholder-shown { border-color: #e0e0e0; } input:not(:placeholder-shown):valid { border-color: #28a745; background: #f1f9f6; } input:not(:placeholder-shown):invalid { border-color: #dc3545; background: #fef5f5; }

7. Smooth Background Transition

UX Pattern

Subtle background color transitions between empty, filled, and focused states.

input:placeholder-shown { background: #f8f9fa; } input:focus { background: #f0f4ff; } input:not(:placeholder-shown) { background: white; }

8. Textarea Enhancement

Form Field

Apply :placeholder-shown styling to textarea elements for multi-line input areas.

textarea:placeholder-shown { border-color: #e0e0e0; background: #f8f9fa; } textarea:not(:placeholder-shown) { border-color: #667eea; background: white; }

9. Label Color Coordination

UX Pattern

Change label color to match input state - gray when empty, blue when filled.

label { color: #999; transition: all 0.3s ease; } input:not(:placeholder-shown) ~ label { color: #667eea; font-weight: 600; }

10. Password Strength Indicator

Form Field

Show/hide a visual indicator for password field state with different colors.

.strength-indicator { opacity: 0; transition: all 0.3s ease; } input:not(:placeholder-shown) ~ .strength-indicator { opacity: 1; }

11. Dynamic Button Enable/Disable

Interactive

Enable submit button only when user has entered text (placeholder hidden).

.submit-btn { background: #ccc; cursor: not-allowed; } input:not(:placeholder-shown) ~ .submit-btn { background: #667eea; cursor: pointer; pointer-events: auto; }

12. Multi-Field Form

Form Pattern

Complete form with floating labels, validation, and state-based styling on all fields.

input:placeholder-shown ~ label { top: 12px; color: #999; } input:not(:placeholder-shown) ~ label { top: -8px; color: #667eea; font-size: 0.75em; } input:not(:placeholder-shown) ~ .submit-btn { background: #667eea; pointer-events: auto; }
