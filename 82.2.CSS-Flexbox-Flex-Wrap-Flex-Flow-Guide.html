🎯 Flexbox flex-wrap & flex-flow Practical Examples

1️⃣ Responsive Product Grid
Uses flex-flow: row wrap to create a responsive product grid that adapts from 4 columns on desktop to fewer on smaller screens.
CSS
.product-grid { display: flex; flex-flow: row wrap; gap: 20px; } .product-card { flex: 1 1 calc(25% - 15px); /* 4 columns */ min-width: 150px; } @media (max-width: 1024px) { .product-card { flex: 1 1 calc(33.333% - 13px); /* 3 columns */ } } @media (max-width: 768px) { .product-card { flex: 1 1 calc(50% - 10px); /* 2 columns */ } }

3️⃣ Responsive Form with flex-wrap
Uses flex-flow: row wrap for form fields. Two-column layout on desktop, single column on mobile.
CSS
.form-grid { display: flex; flex-flow: row wrap; gap: 20px; } .form-field { flex: 1 1 calc(50% - 10px); /* 2 columns */ min-width: 200px; } .form-field.full-width { flex: 1 1 100%; /* Full width */ } @media (max-width: 768px) { .form-field { flex: 1 1 100%; /* Single column */ } }
💡 Tip: Use flex: 1 1 100% for fields that should span the full width.
4️⃣ Responsive Image Gallery
Uses flex-flow: row wrap with equal-width items for a masonry-like gallery that wraps responsively.
CSS
.gallery { display: flex; flex-flow: row wrap; gap: 15px; } .gallery-item { flex: 1 1 calc(33.333% - 10px); /* 3 columns */ min-width: 150px; aspect-ratio: 1; /* Square items */ } @media (max-width: 1024px) { .gallery-item { flex: 1 1 calc(25% - 11px); /* 4 columns */ } }

✨ Key Takeaways
1. flex-flow: row wrap – The most common pattern for responsive layouts. Items flow horizontally and wrap to next line.

2. Use flex: 1 1 percentage – Creates flexible items that grow/shrink: flex: 1 1 calc(25% - 15px)

3. Always set min-width – Prevents items from becoming too small: min-width: 150px

4. Use flex: 0 0 auto for fixed sizes – Tags, badges, and items that shouldn't grow.

5. Media queries for column changes – Adjust flex-basis at breakpoints to change number of columns.

6. gap for consistent spacing – Works on wrapped lines too, no margin collapsing issues.

7. align-content for wrapped lines – Controls vertical distribution of multiple wrapped lines.
