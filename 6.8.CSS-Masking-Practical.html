CSS Masking - Advanced Examples

Display Images on Text & Specific Image Parts

Example 1: Display Image on Text

This example demonstrates how to display an image or gradient pattern within text. Using CSS masking and background-clip, we can create stunning text effects where the text acts as a window for the image to show through.
Method 1: Using background-clip (Simple & Smooth)
.text-with-image { background: url('data:image/svg+xml,...'); background-size: cover; background-position: center; -webkit-background-clip: text; background-clip: text; -webkit-text-fill-color: transparent; font-size: 4em; font-weight: 900; }
Creative Design
Method 2: Using mask-image (More Control)
.text-with-mask { background: url('data:image/svg+xml,...'); background-size: cover; background-position: center; -webkit-mask-image: linear-gradient(135deg, black 0%, black 100%); mask-image: linear-gradient(135deg, black 0%, black 100%); font-size: 3.5em; font-weight: 900; }
Awesome Effects

✓ Advantages of background-clip:

• Simpler and more concise code
• Better browser support
• Works with any background property
• Great for animated backgrounds

✓ Advantages of mask-image:

• More fine-grained control
• Works with semi-transparent gradients
• Can mask other properties too
• Better for complex effects

💡 Tips: You can animate the background-position for a moving effect, or combine multiple gradients for more complex text effects. Always include vendor prefixes (-webkit-) for better browser support.

Example 2: Display Specific Part of Image

Using CSS masking, you can reveal only specific portions of an image or gradient. This technique is useful for creating focus effects, framing important content, or building creative layouts.
Masking Techniques for Image Parts
/* Circle mask - Center focus */ .circle-part { background: linear-gradient(...); -webkit-mask-image: radial-gradient(circle at 50% 50%, black 0%, black 40%, transparent 70%); mask-image: radial-gradient(circle at 50% 50%, black 0%, black 40%, transparent 70%); } /* Linear gradient mask - Side reveal */ .left-side { background: linear-gradient(...); -webkit-mask-image: linear-gradient(90deg, black 0%, black 40%, transparent 100%); mask-image: linear-gradient(90deg, black 0%, black 40%, transparent 100%); } /* Polygon mask - Custom shape */ .top-corner-part { background: linear-gradient(...); -webkit-mask-image: polygon(0 0, 100% 0, 100% 50%, 50% 100%, 0 50%); mask-image: polygon(0 0, 100% 0, 100% 50%, 50% 100%, 0 50%); clip-path: polygon(0 0, 100% 0, 100% 50%, 50% 100%, 0 50%); } /* SVG mask - Star shape */ .star-shape { background: linear-gradient(...); -webkit-mask-image: url('data:image/svg+xml,...'); mask-image: url('data:image/svg+xml,...'); mask-size: contain; mask-position: center; }

✓ Common Masking Methods:

• Radial Gradient: Circle/ellipse focus
• Linear Gradient: Fade from sides
• Polygon: Custom geometric shapes
• SVG: Complex icons/symbols

✓ Use Cases:

• Image galleries with effects
• Focus highlighting on hero sections
• Creative portfolio displays
• Interactive image reveals
• Loading animations

💡 Performance Tips: Use simple masks (radial/linear gradients) for better performance. Complex SVG masks on large images can be resource-intensive. Always test on multiple devices and browsers for the best results.

Best Practices & Browser Support

✓ Do This:

• Always use vendor prefixes (-webkit-)
• Test on multiple browsers
• Provide fallbacks for older browsers
• Use efficient mask images/gradients
• Consider performance impact

✗ Avoid This:

• Complex masks on large elements
• Animating masks frequently
• Using masks on critical UI elements
• Forgetting vendor prefixes
• Masks on low-end devices
