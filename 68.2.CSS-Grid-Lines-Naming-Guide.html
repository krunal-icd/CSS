CSS Grid Lines Naming - Practical Examples

Real-world implementations using semantic named lines

1. Website Layout with Semantic Names

Full-width website using named lines for header, nav, sidebar, content, aside, and footer

.website-layout { grid-template-columns: [full-start nav-start] 200px [nav-end content-start] 1fr [content-end aside-start] 250px [aside-end full-end]; grid-template-rows: [header] 80px [nav] 50px [main] 1fr [footer] 60px; } .header { grid-column: full-start / full-end; grid-row: header; } .sidebar { grid-column: nav-start / nav-end; grid-row: main; } .main { grid-column: content-start / content-end; grid-row: main; }

2. Magazine Layout with Column Names

Three-column magazine using col-1, col-2, col-3 naming for articles

.magazine-layout { grid-template-columns: [full-start] 1fr [col-1-start] 1fr [col-1-end col-2-start] 1fr [col-2-end col-3-start] 1fr [col-3-end full-end]; grid-template-rows: [feature] auto [articles] auto [footer] auto; } .featured { grid-column: full-start / full-end; } .main-article { grid-column: col-1-start / col-2-end; } .side-article { grid-column: col-3-start / col-3-end; }

3. Dashboard with Positioned Sections

Dashboard using sidebar-start/end, main-start/mid/end named lines for layout control

4. Card Grid System with Named Boundaries

Responsive card layout using full-start, card-2-start, card-3-start, full-end names

.card-system-layout { grid-template-columns: [full-start] 1fr [card-2-start] 1fr [card-3-start] 1fr [full-end]; grid-template-rows: [header] auto [cards] auto [footer] auto; } .card-featured { grid-column: full-start / card-2-start; } .card-1 { grid-column: card-2-start / card-3-start; } .card-2 { grid-column: card-3-start / full-end; }

5. Asymmetric Blog Layout

Blog with hero, posts, and sidebar using full-start, sidebar-start/end naming

.blog-layout { grid-template-columns: [full-start] 1fr [sidebar-start] 250px [sidebar-end full-end]; grid-template-rows: [hero] 250px [posts] auto [footer] auto; } .hero { grid-column: full-start / full-end; } .posts { grid-column: full-start / sidebar-start; } .sidebar { grid-column: sidebar-start / sidebar-end; }

Shop layout with filters and products using filters-start/end, products-start/end
