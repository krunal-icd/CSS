📦 CSS Flexbox Align-Content Tutorial

Master alignment of multiple flex lines in wrapped flex containers

What is Align-Content?

align-content is a CSS property that aligns wrapped flex lines (rows or columns) as a whole within a flex container. It only applies when there are multiple lines created by flex-wrap: wrap.

While align-items aligns individual items within their line, align-content aligns the lines themselves as a group.

⚠ Important: Align-content only works with flex-wrap: wrap or flex-wrap: wrap-reverse. It has no effect with flex-wrap: nowrap (the default).
/* Basic Syntax - Must have flex-wrap: wrap */ .flex-container { display: flex; flex-wrap: wrap; height: 400px; /* Container must have height */ align-content: center; }

All Align-Content Values

Value Description
stretch Lines stretch to fill the container (default)
flex-start Lines pack to the start of the container
flex-end Lines pack to the end of the container
center Lines center within the container
space-between Equal space between lines; first and last touch edges
space-around Equal space around each line
space-evenly Equal space everywhere (between and around lines)

Detailed Explanations

📌 stretch

This is the default value. All flex lines stretch to fill the available space in the container.

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: stretch; }
Use case: Gallery layouts where all rows should fill the container height equally

📌 flex-start

All flex lines are packed toward the start of the container (top in row direction).

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: flex-start; }
Use case: Product grids where items should align to the top with empty space below

📌 flex-end

All flex lines are packed toward the end of the container (bottom in row direction).

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: flex-end; }
Use case: Less common, but useful for layouts where content should push to the bottom

📌 center

All flex lines are centered within the container, with equal space above and below.

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: center; }
Use case: Modal dialogs or centered content sections

📌 space-between

First line touches the start, last line touches the end, with equal space between all lines.

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: space-between; }
Use case: Perfectly distributed multi-row layouts

📌 space-around

Each line has equal space around it. Space before first and after last is half the space between lines.

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: space-around; }
Use case: Evenly distributed card grids with consistent padding

📌 space-evenly

Every line has equal space around it, including before the first and after the last line.

.container { display: flex; flex-wrap: wrap; height: 400px; align-content: space-evenly; }
Use case: Dashboard layouts with perfect uniform spacing

Align-Content vs Other Properties

Understand the difference between align-content, align-items, and justify-content:

Property What It Aligns Requires Common Values
justify-content Individual items along main axis display: flex flex-start, center, space-between, space-around
align-items Individual items along cross axis display: flex stretch, center, flex-start, flex-end, baseline
align-content Multiple lines as a group display: flex; flex-wrap: wrap stretch, center, space-between, space-around, space-evenly

Common Layout Patterns

🎨 Product Grid

.product-grid { display: flex; flex-wrap: wrap; height: 600px; align-content: flex-start; /* Items align to top */ justify-content: space-around; /* Items distributed horizontally */ gap: 20px; }

🎨 Centered Wrapped Content

.centered-content { display: flex; flex-wrap: wrap; height: 400px; align-content: center; /* Lines centered vertically */ justify-content: center; /* Items centered horizontally */ gap: 15px; }

🎨 Evenly Distributed Dashboard

.dashboard { display: flex; flex-wrap: wrap; height: 800px; align-content: space-evenly; /* Lines evenly spaced */ justify-content: space-around; /* Cards evenly spaced */ gap: 20px; padding: 20px; }

🎨 Full Height Gallery

.gallery { display: flex; flex-wrap: wrap; height: 100vh; align-content: stretch; /* Rows fill height */ justify-content: space-between; gap: 10px; }

Important Tips & Best Practices

🔴 No Effect Without Wrap: Align-content only works when flex items wrap to multiple lines. With flex-wrap: nowrap (default), this property has no effect.
✓ Container Must Have Size: The flex container must have a defined height (in row direction) or width (in column direction) for align-content to have a visible effect.
✓ Works with Both Directions: Align-content works with both flex-direction: row and flex-direction: column. In column direction, it affects horizontal distribution of columns.
⚠ Not the Same as Align-Items: Don't confuse align-content with align-items. Align-items aligns individual items within their line, while align-content aligns the lines themselves.
✓ Combine with Justify-Content: Use both properties together for complete control - justify-content distributes items horizontally, align-content distributes lines vertically.
✓ Gap Property: The gap property works well with align-content to provide consistent spacing between items and lines.

Browser Support

align-content is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.container { display: flex; flex-wrap: wrap; align-content: center; /* No vendor prefixes needed for modern browsers */ }
