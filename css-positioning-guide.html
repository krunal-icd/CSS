02

position: absolute

Badge document flow se poori tarah nikal kar apne sabse najdeeki position: relative parent (card) ke corner par chipak gaya hai.

NEW

Parent card par position: relative hai, isliye badge isi card ke corner ke against position hota hai.

.abs-card {
  position: relative;
}

.abs-badge {
  position: absolute;
  top: -12px;
  right: -12px;
}
03

position: fixed

Neeche daayin taraf ka gol button viewport ke against fixed hai — page ko scroll karte waqt woh apni jagah se hilta nahi, hamesha wahi rehta hai.

Poore page ko scroll karke neeche daayin taraf dekhein — woh teal button fixed rahega.

.fixed-fab {
  position: fixed;
  bottom: 28px;
  right: 28px;
}
04

CSS anchor positioning

Button par anchor-name diya gaya hai, aur tooltip us anchor ko position-anchor aur anchor() function se follow karta hai — koi JavaScript position-calculation ki zaroorat nahi.

Yeh tooltip button ke anchor-name ko follow karke apne aap upar position ho gaya hai.
.anchor-btn {
  anchor-name: --info-anchor;
}

.anchor-tooltip {
  position: fixed;
  position-anchor: --info-anchor;
  bottom: anchor(top);
  left: anchor(center);
  translate: -50% -10px;
}

Browser support: Chromium browsers (Chrome, Edge) mein achi tarah kaam karta hai. Firefox aur Safari mein support abhi bhi partial/naya hai (2026 tak), isliye production mein @supports ke saath fallback zaroor rakhein — is demo mein bhi ek fallback diya gaya hai.

05

CSS popover

Native popover attribute aur popovertarget se panel bina kisi JavaScript ke khulta-band hota hai, aur ::backdrop pseudo-element se background par dim overlay milta hai.

Native popover panel

Yeh poori tarah CSS aur HTML attributes se chal raha hai — koi JavaScript event listener nahi likha gaya.

<button popovertarget="demoPopover">
  Popover kholein
</button>

<div id="demoPopover" popover>
  ...
</div>

.popover-panel::backdrop {
  background-color: rgba(20, 23, 28, 0.72);
}
Har property yahan longhand form mein likhi gayi hai — koi bhi shorthand (margin, padding, border, background, font, gap, inset, border-radius, transition) istemal nahi kiya gaya.
