Understanding CSS Grid Layouts

CSS Grid is a powerful layout system that allows you to create two-dimensional layouts with rows and columns. It's perfect for complex, responsive designs.

The fit-content() function is especially useful for sidebars that should grow with their content but never exceed a maximum width.

Common Patterns & Quick Reference

Two Column (Sidebar + Content):

  • grid-template-columns: fit-content(300px) 1fr;
  • Perfect for: Navigation, filters, sidebars

Three Column (Left + Center + Right):

  • grid-template-columns: fit-content(200px) 1fr fit-content(250px);
  • Perfect for: Dashboards, complex layouts

Full Page (Header/Main/Footer):

  • grid-template-rows: fit-content(100px) 1fr fit-content(80px);
  • Perfect for: Website layouts, full-screen apps

Key Principle:

  • fit-content(max) = min(content-size, max)
  • Uses only what content needs, up to maximum
  • Pair with 1fr for flexible areas
  • No minimum size (unlike minmax)
