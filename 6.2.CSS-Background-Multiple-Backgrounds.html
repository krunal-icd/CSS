Key CSS Properties

Essential Syntax

/* Multiple backgrounds are comma-separated */ background: linear-gradient(135deg, red, blue), radial-gradient(circle, yellow, green), url('image.png'), #color; /* Control sizing independently */ background-size: cover, 50% 50%, 100px 100px, auto; /* Control positioning independently */ background-position: center, top left, 50% 50%, 0 0; /* First layer appears on top, last layer at bottom */
