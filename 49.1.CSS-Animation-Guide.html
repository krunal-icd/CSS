CSS Animation Property

A Complete Guide to Creating Smooth, Engaging Animations

What is CSS Animation?

The animation property in CSS allows you to create smooth, continuous transitions between different states of an element without requiring JavaScript. It's a powerful tool for creating engaging user interfaces and drawing attention to important elements.

Key Advantage: Animations run on the GPU, making them performance-efficient compared to JavaScript-based animations. They can run independently and don't require JavaScript interaction.

CSS animations consist of two main components:

  • @keyframes - Defines the animation frames and what changes
  • animation - Applies the animation to an element with timing and behavior

Animation Syntax & Properties

Basic Syntax

animation: name duration timing-function delay iteration-count direction fill-mode play-state;

Individual Animation Properties

Property Description Default Value
animation-name Name of the @keyframes animation to use none
animation-duration Time for one animation cycle (in seconds or milliseconds) 0s
animation-timing-function Speed curve of the animation ease
animation-delay Time before animation starts 0s
animation-iteration-count Number of times animation plays 1
animation-direction Direction of animation playback normal
animation-fill-mode Style of element before/after animation none
animation-play-state Pause or play animation running

@keyframes Declaration

The @keyframes rule defines what happens at each stage of the animation.

Syntax

@keyframes animationName { 0% { property: value; } 50% { property: value; } 100% { property: value; } }

Examples

Example 1: Color Transition

@keyframes colorChange { 0% { background-color: red; } 50% { background-color: yellow; } 100% { background-color: blue; } }

Example 2: Movement

@keyframes slide { from { transform: translateX(0); } to { transform: translateX(200px); } }

Example 3: Complex Animation

@keyframes complexMove { 0% { transform: translateX(0) scale(1); opacity: 1; } 50% { transform: translateX(100px) scale(1.2); opacity: 0.7; } 100% { transform: translateX(0) scale(1); opacity: 1; } }
Note: You can use percentages (0%, 50%, 100%) or keywords (from, to). "from" is equivalent to 0% and "to" is equivalent to 100%.

Animation Properties in Detail

1. animation-duration

Specifies how long one animation cycle takes to complete.

div { animation-duration: 3s; /* seconds */ /* or */ animation-duration: 3000ms; /* milliseconds */ }

2. animation-timing-function

Controls the speed curve of the animation:

Built-in Values:
  • ease - Slow start, fast middle, slow end (default)
  • linear - Constant speed throughout
  • ease-in - Slow start, accelerates
  • ease-out - Fast start, decelerates
  • ease-in-out - Slow start and end, fast middle
  • cubic-bezier(n,n,n,n) - Custom speed curve
  • steps(n, direction) - Jump animation (frame-by-frame)
div { animation-timing-function: linear; /* or */ animation-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1); /* or */ animation-timing-function: steps(5, end); }

3. animation-delay

Specifies a delay before the animation starts.

div { animation-delay: 2s; /* Animation waits 2 seconds before starting */ }

4. animation-iteration-count

How many times the animation repeats.

div { animation-iteration-count: 3; /* Play 3 times */ /* or */ animation-iteration-count: infinite; /* Loop forever */ }

5. animation-direction

Determines animation playback direction:

  • normal - Forward (default)
  • reverse - Backward
  • alternate - Forward then backward
  • alternate-reverse - Backward then forward
div { animation-direction: alternate; animation-iteration-count: infinite; }

6. animation-fill-mode

Specifies how the element looks before and after the animation:

  • none - Default state before/after (default)
  • forwards - Keeps final keyframe values after animation
  • backwards - Applies first keyframe values before animation starts
  • both - Combines forwards and backwards
div { animation-fill-mode: forwards; /* Element stays in final state after animation */ }

7. animation-play-state

Control whether animation is playing or paused.

div { animation-play-state: paused; /* or running */ } div:hover { animation-play-state: running; }

Complete Practical Examples

Example 1: Loading Spinner

/* HTML */ <div class="spinner"></div> /* CSS */ .spinner { width: 50px; height: 50px; border: 5px solid #f3f3f3; border-top: 5px solid #667eea; border-radius: 50%; animation: spin 1s linear infinite; } @keyframes spin { 0% { transform: rotate(0deg); } 100% { transform: rotate(360deg); } }

Example 2: Button Hover Animation

button { padding: 10px 20px; background: #667eea; color: white; border: none; border-radius: 5px; transition: transform 0.3s ease; } button:hover { animation: pulse 0.5s ease-out; } @keyframes pulse { 0% { transform: scale(1); } 50% { transform: scale(1.1); } 100% { transform: scale(1); } }

Example 3: Slide-in Animation on Page Load

.content { animation: slideIn 0.6s ease-out forwards; } @keyframes slideIn { 0% { opacity: 0; transform: translateY(20px); } 100% { opacity: 1; transform: translateY(0); } }

Example 4: Delayed Staggered Animation

.item { animation: fadeInUp 0.5s ease-out; } .item:nth-child(1) { animation-delay: 0.1s; } .item:nth-child(2) { animation-delay: 0.2s; } .item:nth-child(3) { animation-delay: 0.3s; } @keyframes fadeInUp { 0% { opacity: 0; transform: translateY(30px); } 100% { opacity: 1; transform: translateY(0); } }

Example 5: Keyframe Percentages

@keyframes complexAnimation { 0% { left: 0px; top: 0px; } 25% { left: 100px; top: 0px; } 50% { left: 100px; top: 100px; } 75% { left: 0px; top: 100px; } 100% { left: 0px; top: 0px; } }

Animation Timing Functions Explained

ease (Default)

Starts slow, speeds up in the middle, then slows down at the end. Good for natural-feeling animations.

Cubic-bezier: (0.25, 0.1, 0.25, 1)

linear

Constant speed throughout the entire animation. Best for continuous spinning or scrolling effects.

Cubic-bezier: (0, 0, 1, 1)

ease-in

Starts slow and accelerates. Good for objects leaving the viewport.

Cubic-bezier: (0.42, 0, 1, 1)

ease-out

Starts fast and decelerates. Perfect for objects entering the viewport.

Cubic-bezier: (0, 0, 0.58, 1)

ease-in-out

Starts slow, fast in middle, slow at end. Similar to ease but more pronounced.

Cubic-bezier: (0.42, 0, 0.58, 1)

steps()

Creates frame-by-frame animation jumps. Useful for sprite animations and typewriter effects.

Example: steps(5, end)

Best Practices & Performance Tips

✓ Do's

  • Use transform and opacity for best performance (GPU accelerated)
  • Keep animations under 3 seconds for better UX
  • Use animation-delay to stagger multiple animations
  • Test animations on mobile devices
  • Provide prefers-reduced-motion support for accessibility
  • Use meaningful animation durations (not too fast, not too slow)

✗ Don'ts

  • Avoid animating width, height, or position (causes reflows)
  • Don't overuse animations - they can distract users
  • Avoid long animation durations for simple effects
  • Don't animate too many elements simultaneously
  • Avoid complex animations with many keyframes
  • Don't ignore browser compatibility issues

Accessibility - Respecting Reduced Motion Preferences

/* Respect user's motion preferences */ @media (prefers-reduced-motion: reduce) { * { animation: none !important; transition: none !important; } }

Common Animation Patterns

Pattern 1: Infinite Loop

.element { animation: rotate 2s linear infinite; }

Pattern 2: Hover Trigger

.button { transition: transform 0.3s; } .button:hover { animation: bounce 0.6s ease-out; }

Pattern 3: Sequential Animation

.item { animation: fadeIn 0.5s ease-out; animation-fill-mode: both; } .item:nth-child(n) { animation-delay: calc(0.1s * n); }

Pattern 4: Animation on Scroll

.animated { opacity: 0; } .animated.in-view { animation: slideUp 0.6s ease-out forwards; } /* Use JavaScript to add 'in-view' class on scroll */

Troubleshooting & Common Issues

Issue 1: Animation Not Working

Problem: Animation isn't playing at all.

Solutions:
  • Check that @keyframes is defined with correct name
  • Verify animation-duration is not 0s
  • Ensure animation-iteration-count is set (default is 1)
  • Check browser console for CSS errors

Issue 2: Animation Stutters

Problem: Animation plays but feels choppy.

Solutions:
  • Use only transform and opacity
  • Avoid animating properties that trigger layout recalculation
  • Reduce the number of simultaneous animations
  • Check for heavy JavaScript running simultaneously

Issue 3: Animation Won't Stop

Problem: Animation loops infinitely when it shouldn't.

Solutions:
  • Remove or change animation-iteration-count: infinite
  • Set animation-iteration-count to specific number
  • Use JavaScript to control animation-play-state

Issue 4: Animation Jumps at Start

Problem: Animation looks jerky when it begins.

Solutions:
  • Use animation-fill-mode: backwards
  • Make sure first keyframe (0%) matches initial state
  • Add animation-delay if needed

Quick Reference Cheat Sheet

All Animation Properties Together

element { animation-name: slidein; animation-duration: 3s; animation-timing-function: ease-in; animation-delay: 1s; animation-iteration-count: 3; animation-direction: alternate; animation-fill-mode: forwards; animation-play-state: running; } /* Shorthand */ element { animation: slidein 3s ease-in 1s 3 alternate forwards running; }

Animation Execution Timeline

animation-delay (2s): Wait 2 seconds
Start (0%): Animation begins with first keyframe
Middle (25-75%): Animation progresses through keyframes
End (100%): Animation completes
animation-fill-mode: Determines state after animation

Conclusion

CSS Animations are a powerful and efficient way to add movement and interactivity to your web applications. By understanding the properties and best practices, you can create smooth, engaging animations that enhance user experience without impacting performance.

Key Takeaways:

  • Use @keyframes to define animation steps
  • Apply animations with the animation property
  • Optimize by animating only transform and opacity
  • Consider accessibility with prefers-reduced-motion
  • Test across browsers and devices
  • Use animation-delay for staggered effects
  • Respect performance and avoid overuse
