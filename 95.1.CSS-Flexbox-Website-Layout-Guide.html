Building Website Layouts with Flexbox

Website layouts are the foundation of web design. Before flexbox and CSS Grid, creating responsive layouts required floats, tables, or JavaScript. Flexbox changed this dramatically, making it simple to build sophisticated, responsive layouts with pure CSS.

Flexbox excels at website layouts because:

  • Perfect alignment of content vertically and horizontally
  • Responsive design without media queries (often)
  • Content reordering without changing HTML
  • Flexible, predictable spacing and sizing
  • Works seamlessly with nested containers
Key Insight: Most modern websites use flexbox for the primary layout structure, often combined with CSS Grid for more complex sections.

Common Website Layout Patterns

There are several foundational layout patterns that appear across most websites. Understanding these patterns gives you the building blocks for any layout.

Full-Height Layouts

Many websites need header + main content + footer to fill the entire viewport height. Flexbox makes this trivial with the flex: 1 property.

The Challenge

When content is short, the footer should stick to the bottom. When content is long, it should scroll naturally. Before flexbox, this required JavaScript or complex CSS calculations.

Full-Height Layout Pattern
html, body { height: 100%; } body { display: flex; flex-direction: column; } header { flex-shrink: 0; /* Header maintains size */ } main { flex: 1; /* Main grows to fill space */ min-height: 0; /* Allow main to shrink if needed */ overflow-y: auto; /* Enable scrolling for content */ } footer { flex-shrink: 0; /* Footer maintains size */ }

This pattern works perfectly:

  • Short page: footer sticks to bottom of viewport
  • Long page: footer stays below content naturally
  • No JavaScript needed
  • Works in all modern browsers

Sidebar + Main Content

One of the most common patterns: fixed or flexible sidebar with main content.

Sidebar Layout Pattern
/* Full page with header, sidebar, and footer */ body { display: flex; flex-direction: column; min-height: 100vh; } header { flex: 0 0 auto; } .page-body { display: flex; flex: 1; gap: 20px; } .sidebar { flex: 0 0 250px; /* Fixed width sidebar */ overflow-y: auto; } .main { flex: 1; /* Main content takes remaining space */ overflow-y: auto; } footer { flex: 0 0 auto; } /* Mobile: Stack sidebar and main */ @media (max-width: 768px) { .page-body { flex-direction: column; } .sidebar { flex: 0 0 auto; width: 100%; } }

Multi-Column Content Areas

Create flexible multi-column layouts that adapt to different screen sizes.

Two-Column Layout (Equal)
.content-area { display: flex; gap: 30px; } .column { flex: 1; } /* Mobile: Stack columns */ @media (max-width: 768px) { .content-area { flex-direction: column; } }
Three-Column Layout (2:1:1 ratio)
.content-area { display: flex; gap: 30px; } .main-column { flex: 2; /* Takes twice the space */ } .sidebar-column { flex: 1; /* Takes 1x space */ } .aside-column { flex: 1; /* Takes 1x space */ }

Card Grid Layouts

Card grids are everywhere: product listings, portfolios, team members. Flexbox makes responsive grids simple.

Responsive Card Grid
.card-grid { display: flex; flex-wrap: wrap; gap: 20px; } .card { flex: 1; flex-basis: 250px; /* Minimum card width */ min-width: 0; /* Allow shrinking */ } /* Ensures cards stack properly */ @media (max-width: 768px) { .card { flex-basis: 100%; } }

flex-basis vs width

Use flex-basis to set the initial size of flex items. It's more flexible than width because it respects flex-shrink and flex-grow, making it perfect for grids that need to adapt to container size.

Responsive Design with Flexbox

Flexbox reduces the number of media queries you need. When you do need them, change flex-direction or flex-basis to adapt layouts.

Complete Responsive Layout
/* Desktop: Header + Sidebar + Main + Footer */ body { display: flex; flex-direction: column; } .page-body { display: flex; } .sidebar { flex: 0 0 300px; } .main { flex: 1; } /* Tablet: Narrower sidebar */ @media (max-width: 1024px) { .sidebar { flex: 0 0 200px; } } /* Mobile: Sidebar hidden or stacked */ @media (max-width: 768px) { .page-body { flex-direction: column; } .sidebar { flex: 0 0 auto; width: 100%; order: -1; /* Show sidebar first */ } }

Hero Section Layouts

Hero sections (large banners with text and image) are flexbox staples.

Hero Section Pattern
.hero { display: flex; align-items: center; justify-content: space-between; gap: 40px; padding: 60px 20px; min-height: 400px; } .hero-content { flex: 1; } .hero-image { flex: 1; height: 300px; } /* Mobile: Stack vertically */ @media (max-width: 768px) { .hero { flex-direction: column; min-height: auto; } .hero-image { width: 100%; } }

Sticky Headers and Footers

Combining flexbox with position: sticky creates powerful layouts where headers/footers stay visible while content scrolls.

Sticky Header Pattern
header { flex: 0 0 auto; position: sticky; top: 0; z-index: 100; } main { flex: 1; overflow-y: auto; } footer { flex: 0 0 auto; position: sticky; bottom: 0; z-index: 100; }

Best Practices for Website Layouts

✓ Use min-height: 100vh on Body

For full-height layouts, use min-height: 100vh instead of height: 100% to allow content to extend if needed.

✓ Set flex: 0 0 auto on Fixed-Size Elements

Headers, footers, and fixed-width sidebars should have flex: 0 0 auto to prevent unexpected shrinking.

✓ Add min-height: 0 to Flexible Containers

When a flex item should scroll, add min-height: 0 to override flexbox's default auto sizing.

✓ Use flex-basis with Grids

For card grids, use flex-basis instead of width for better responsiveness without media queries.

✓ Combine with CSS Grid

Flexbox handles 1D layouts (header, sidebar, footer). For 2D grids, consider CSS Grid for the content area.

✗ Don't Rely on Flexbox for Complex Grids

Flexbox wrapping isn't perfect for complex multi-column grids. CSS Grid handles this better.

✗ Don't Forget Media Queries

While flexbox reduces media queries, you still need them for significant breakpoints (mobile, tablet, desktop).

Quick Reference: Layout Patterns

  • Full-height page: body { display: flex; flex-direction: column; } + main { flex: 1; }
  • Header + Sidebar + Main: Nested flex with header full-width, then page-body with sidebar/main
  • Sticky header: Combine flex with position: sticky; top: 0
  • Responsive sidebar: Use flex-direction: column on mobile media query
  • Card grid: flex-wrap: wrap with flex-basis for minimum card width
  • Hero section: flex with gap and space-between alignment
  • Multi-column content: Multiple flex: 1 items in flex-direction: row
  • Footer at bottom: main { flex: 1; } pushes footer to viewport bottom
  • Equal-width columns: All items with flex: 1
  • Proportional columns: Use different flex values (flex: 2, flex: 1, etc.)

Key Takeaways

  • Flexbox is perfect for 1D page layouts (vertical and horizontal stacking)
  • Use flex: 1 on main content to create full-height layouts
  • Combine with position: sticky for persistent headers/footers
  • Use flex-basis for responsive card grids without fixed widths
  • Media queries change flex-direction for responsive design
  • Nested flexbox containers enable sophisticated layouts
  • Always use flex: 0 0 auto on fixed-size elements
  • Add min-height: 0 when flex items need to scroll
  • Flexbox + CSS Grid combine for powerful layouts
  • Test on multiple devices to ensure responsive behavior
