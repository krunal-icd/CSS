CSS Grid Layout Introduction Guide

Master the fundamentals of CSS Grid for modern, responsive web design

What is CSS Grid?

CSS Grid is a powerful two-dimensional layout system that allows you to create complex, responsive designs with minimal code. Unlike Flexbox (which is one-dimensional), Grid works on both rows and columns simultaneously.

Key Benefits

  • Two-Dimensional Layout: Control both rows and columns
  • Responsive Design: Create layouts that adapt to different screen sizes
  • Alignment Control: Precise control over content alignment
  • Reduced Markup: Less HTML needed for complex layouts
  • Performance: Native browser implementation, no JavaScript required

Getting Started

The Basics

To create a grid, you need:

  • A grid container (parent element with display: grid)
  • One or more grid items (direct children)

Simple Example

.grid-container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 10px;
}

.grid-item {
    background-color: #667eea;
    padding: 20px;
    text-align: center;
}

Core Properties

Grid Container Properties

grid-template-columns

Defines the number and size of columns. Use 1fr for flexible units, 200px for fixed sizes, or repeat() function.

grid-template-columns: 1fr 2fr 1fr;
grid-template-columns: repeat(3, 1fr);
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
grid-template-rows

Defines the height and number of rows, similar to columns.

grid-template-rows: 100px auto 100px;
grid-template-rows: repeat(3, 1fr);
gap (or grid-gap)

Sets the space between grid items. Can use shorthand for row and column gaps.

gap: 20px;
gap: 20px 30px; /* row | column */
row-gap: 20px;
column-gap: 30px;
justify-items

Aligns items horizontally within their grid cells.

justify-items: start | center | end | stretch;
align-items

Aligns items vertically within their grid cells.

align-items: start | center | end | stretch;
justify-content

Aligns the entire grid horizontally within the container.

justify-content: start | center | end | space-between | space-around;

Grid Item Properties

grid-column

Specifies which columns an item spans.

grid-column: 1 / 3; /* start / end */
grid-column: span 2; /* span 2 columns */
grid-row

Specifies which rows an item spans.

grid-row: 1 / 4; /* start / end */
grid-row: span 3; /* span 3 rows */
justify-self

Aligns an individual item horizontally.

justify-self: start | center | end | stretch;
align-self

Aligns an individual item vertically.

align-self: start | center | end | stretch;

Units & Functions

Fraction Unit (fr)

The fr unit represents a fraction of the available space. 1fr takes up one fraction, 2fr takes two fractions, etc.

grid-template-columns: 1fr 2fr 1fr; /* 25% 50% 25% */

repeat() Function

Shorthand for repeating column or row definitions.

grid-template-columns: repeat(3, 1fr);
/* Same as: 1fr 1fr 1fr */

grid-template-columns: repeat(2, 200px 100px);
/* Same as: 200px 100px 200px 100px */

auto-fit vs auto-fill

Function Description Use Case
auto-fit Collapses empty tracks to zero width Better for flexible layouts with varied content
auto-fill Maintains empty tracks at full size Better for fixed-size items with consistent spacing 
grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));

minmax() Function

Sets minimum and maximum sizes for columns or rows.

grid-template-columns: minmax(200px, 1fr) 2fr minmax(100px, 200px);

Named Grid Areas

Create semantic, readable layouts using named grid areas.

.grid {
    display: grid;
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
    grid-template-columns: 1fr 2fr 2fr;
    grid-template-rows: auto 1fr auto;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

Media Query Approach

/* Desktop */
.grid {
    grid-template-columns: repeat(4, 1fr);
}

/* Tablet */
@media (max-width: 768px) {
    .grid {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Mobile */
@media (max-width: 480px) {
    .grid {
        grid-template-columns: 1fr;
    }
}

Grid vs Flexbox

CSS Grid

  • Two-dimensional layout
  • Works with rows AND columns
  • Better for page layouts
  • Precise positioning control
  • Great for complex designs

Flexbox

  • One-dimensional layout
  • Works with rows OR columns
  • Better for component layouts
  • Great for alignment
  • Perfect for navigation bars

Best Practice: Use Grid for overall page layout and Flexbox for component-level layouts. They complement each other!

Tips & Best Practices

Do's

  • Use grid-template-areas for semantic, readable code
  • Combine Grid and Flexbox for maximum layout power
  • Use repeat() and minmax() for responsive designs
  • Start with a mobile-first approach and enhance for larger screens
  • Use CSS variables for reusable grid values

Don'ts

  • Don't use Grid for simple one-dimensional layouts (use Flexbox instead)
  • Don't add unnecessary wrapper divs
  • Don't ignore browser DevTools for debugging
  • Don't forget to test on different screen sizes
  • Don't hardcode pixel values when flexible units work better
