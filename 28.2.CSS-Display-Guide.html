Practice Examples

Work through these interactive examples to understand each display value.

1️⃣ Display: Block

Block elements take full width and stack vertically. They respect all margins and padding.

Block 1 - Takes full width
Block 2 - Starts new line
Block 3 - Respects margins
.block {
    display: block;
    width: 100%;
    margin: 10px 0;
    padding: 15px;
}

Key Points:

  • Takes full available width
  • Starts on new line
  • Respects width, height, margin, padding
  • Default for <div>, <p>, <section>

2️⃣ Display: Inline

Inline elements flow with text, only take needed width. Width/height ignored.

Inline 1 Inline 2 Inline 3 Inline 4 
.inline {
    display: inline;
    background: color;
    padding: 5px;
    margin: 2px;
}

Key Points:

  • Flows inline with text
  • Only takes needed width
  • Width/height ignored
  • Vertical margin/padding not respected
  • Default for <span>, <a>, <em>

3️⃣ Display: Inline-Block

Hybrid of inline and block. Flows inline but respects sizing.

Box 1
Box 2
Box 3
.inline-block {
    display: inline-block;
    width: 150px;
    padding: 15px 20px;
    margin: 5px;
}

Key Points:

  • Flows inline with other elements
  • Respects width and height
  • Respects all margins and padding
  • Mostly replaced by flexbox today

4️⃣ Display: Flex

Enables flexible 1D layout. Items distribute space intelligently.

Flex 1
Flex 2
Flex 3
.flex-container {
    display: flex;
    gap: 10px;
}

.flex-item {
    flex: 1;  /* Equal width */
}

Key Points:

  • One-dimensional layout (row or column)
  • Items flex to fill space
  • Powerful alignment options
  • Most popular for modern layouts

5️⃣ Display: Grid

Enables 2D layout with rows and columns. Precise control.

Grid 1
Grid 2
Grid 3
Grid 4
Grid 5
Grid 6
.grid-container {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(150px, 1fr));
    gap: 15px;
}

Key Points:

  • Two-dimensional layout
  • Control rows and columns
  • Powerful alignment
  • Best for full layouts

6️⃣ Display: None

Hides element completely, removes from layout flow.

This is visible

This is hidden with display: none

Back to visible

.hidden {
    display: none;  /* Completely hidden, takes no space */
}

.visible {
    display: block;  /* Visible and in layout */
}

Key Points:

  • Element is completely hidden
  • Takes no space in layout
  • Common for responsive design
  • Different from visibility: hidden

Challenge Exercises

Test your knowledge by creating layouts with display values.

Challenge 1: Create Navigation Bar (Flex)

Create horizontal navigation using display: flex with space between items.

nav {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

nav a {
    padding: 10px 15px;
}

Challenge 2: Center Content Vertically

Use display: flex to center content both horizontally and vertically.

.center-container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 200px;
}

Challenge 3: Responsive Card Grid

Create responsive card grid using display: grid with auto-fit.

.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}

Challenge 4: Hide on Mobile

Hide sidebar on mobile using display: none in media query.

@media (max-width: 768px) {
    .sidebar {
        display: none;
    }
    
    main {
        grid-column: 1 / -1;
    }
}

Challenge 5: Flex Direction Column

Create vertical layout using flex-direction: column.

.form {
    display: flex;
    flex-direction: column;
    gap: 15px;
}

.form input {
    width: 100%;
}

Full page layout with header, sidebar, main, footer.

Quick Reference & Tips

Display Value Selection

  • Block: Main content, sections, containers
  • Inline: Text within text, em, strong, span
  • Inline-Block: Avoid - use flex/grid instead
  • Flex: Navigation, toolbars, 1D layouts
  • Grid: Page layouts, 2D structures
  • None: Hide elements, responsive design

Common Patterns

.flex-row {
    display: flex;
    gap: 10px;
}

.flex-row > * {
    flex: 1;
}
.flex-column {
    display: flex;
    flex-direction: column;
    gap: 15px;
}
.center {
    display: flex;
    justify-content: center;
    align-items: center;
}
.grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
    gap: 20px;
}
.space-between {
    display: flex;
    justify-content: space-between;
}

Best Practices

  • ✅ Use flex for 1D layouts
  • ✅ Use grid for 2D layouts
  • ✅ Use block for sections
  • ✅ Use none for responsive hiding
  • ❌ Don't use inline-block
  • ❌ Don't use floats for layout
  • ✅ Combine flex and grid
  • ✅ Test responsive at all breakpoints

Troubleshooting

  • Items not sizing: Check display value - inline ignores size
  • Layout broken: Verify grid/flex container on parent
  • Elements overlapping: Check z-index and positioning
  • Responsive issues: Add display: block for mobile
  • Margin collapse: Use flex/grid or padding instead
