CSS list-style-type

12 Practical Examples • Complete List Styling Guide

1. Decimal Numbers (1, 2, 3...)

Numeric

Standard numbered list using decimal (base 10) integers. Most common for ordered lists and step-by-step instructions.

  1. First step in the process
  2. Second step in the process
  3. Third step in the process
  4. Fourth step in the process
  5. Fifth step in the process
ol { list-style-type: decimal; } Result: 1, 2, 3, 4, 5...

2. Decimal Leading Zero (01, 02, 03...)

Numeric

Numbered list with leading zeros for single-digit numbers. Useful for formal documents, specifications, or when visual alignment matters.

  1. Introduction and overview
  2. Requirements and specifications
  3. Implementation details
  4. Testing procedures
  5. Deployment checklist
ol { list-style-type: decimal-leading-zero; } Result: 01, 02, 03, 04, 05...

3. Roman Numerals (I, II, III...)

Numeric

Uppercase Roman numerals for classical or formal documents, legal sections, or outline-style organization.

  1. Executive Summary
  2. Main Findings
  3. Recommendations
  4. Conclusion
  5. Appendix
ol { list-style-type: upper-roman; } Result: I, II, III, IV, V... Lowercase: lower-roman = i, ii, iii...

4. Uppercase Letters (A, B, C...)

Alphabetic

Uppercase alphabetic markers for labeled options, questions, or subsections. Common in educational materials and forms.

  1. Multiple choice option one
  2. Multiple choice option two
  3. Multiple choice option three
  4. Multiple choice option four
ol { list-style-type: upper-alpha; } Result: A, B, C, D, E... Lowercase: lower-alpha = a, b, c...

5. Lowercase Letters (a, b, c...)

Alphabetic

Lowercase alphabetic markers for detailed sub-points or nested organization. Less formal than uppercase.

  1. First detailed requirement
  2. Second detailed requirement
  3. Third detailed requirement
  4. Fourth detailed requirement
  5. Fifth detailed requirement
ol { list-style-type: lower-alpha; } Result: a, b, c, d, e...

6. Symbol Markers (•, ○, ■)

Symbols

Three basic symbol types for unordered lists. Disc (filled), Circle (outline), and Square provide visual variety for bullet points.

Disc (•)
  • Feature one
  • Feature two
  • Feature three
Circle (○)
  • Feature one
  • Feature two
  • Feature three
Square (■)
  • Feature one
  • Feature two
  • Feature three
ul { list-style-type: disc; /* • */ /* or */ list-style-type: circle; /* ○ */ /* or */ list-style-type: square; /* ■ */ }

7. No Markers (None)

Custom

Remove list markers entirely while maintaining semantic structure. Provide alternative visual indicators like borders or styling.

  • Clean list item one
  • Clean list item two
  • Clean list item three
  • Clean list item four
ul { list-style-type: none; } li { border-left: 3px solid #667eea; padding-left: 20px; }

8. Multi-Level Nested Lists

Structure

Use different marker types for each nesting level. Creates visual hierarchy: decimal → lower-alpha → lower-roman.

  1. Main section
    1. Subsection
      1. Detail point
      2. Detail point
    2. Subsection
  2. Main section
    1. Subsection
    2. Subsection
ol { list-style-type: decimal; } ol ol { list-style-type: lower-alpha; } ol ol ol { list-style-type: lower-roman; }

9. Greek Letters (α, β, γ...)

Language

Greek alphabetic markers for mathematical, scientific, or academic content. Also useful for international documentation.

  1. Alpha marker
  2. Beta marker
  3. Gamma marker
  4. Delta marker
  5. Epsilon marker
ol { list-style-type: lower-greek; } Result: α, β, γ, δ, ε... Note: Also available: hebrew, armenian, georgian

10. Code Structure Reference

Learning

Display HTML structure with numbered markers. Useful for documentation and code examples.

  1. <html>
  2. <head> ... </head>
  3. <body>
  4. <header> ... </header>
  5. <main> ... </main>
  6. <footer> ... </footer>
  7. </body>
ol { list-style-type: decimal; font-family: 'Courier New'; color: #333; }

11. Task List with Checkboxes

Interactive

Task list using list-style-type: none with custom checkbox indicators via ::before pseudo-element.

  • Setup development environment
  • Install dependencies
  • Read documentation
  • Create project structure
  • Implement main features
  • Write unit tests
  • Code review
ul { list-style-type: none; } li::before { content: "☐"; margin-right: 12px; } li.completed::before { content: "☑"; color: #28a745; }

12. Priority-Based List

Advanced

Color-coded priority list combining list-style-type: none with custom borders and pseudo-elements for visual priority indicators.

  • Critical bug in production database
  • Security vulnerability patch needed
  • Performance optimization required
  • Update documentation
  • Refactor legacy code
  • Add new feature request
ul { list-style-type: none; } li.high { border-left: 4px solid #dc3545; background: #ffe5e5; } li::before { content: attr(data-priority); margin-right: 10px; }
