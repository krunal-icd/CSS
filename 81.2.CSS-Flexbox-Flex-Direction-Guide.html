3️⃣ Vertical Form Layout
Uses flex-direction: column for vertical form stacking and flex-direction: row for buttons.
CSS
.form-container { display: flex; flex-direction: column; /* Stack form fields vertically */ gap: 20px; } .form-group { display: flex; flex-direction: column; /* Label above input */ gap: 8px; } .form-actions { display: flex; flex-direction: row; /* Buttons side-by-side */ gap: 10px; justify-content: flex-end; }
💡 Tip: This is the most common form pattern—vertical stacking on all screen sizes for readability.
4️⃣ Responsive Card Grid
Uses flex-direction: row with flex-wrap: wrap for a responsive grid. Each card uses flex-direction: column internally.
CSS
.cards-grid { display: flex; flex-direction: row; /* Horizontal layout */ flex-wrap: wrap; /* Wrap to next line */ gap: 20px; } .card { flex: 1 1 calc(33.333% - 14px); min-width: 250px; } .card-body { display: flex; flex-direction: column; /* Vertical card content */ gap: 15px; }

5️⃣ Chat Application with column-reverse
Uses flex-direction: column-reverse to display newest messages at the top, with each message using flex-direction: row.
CSS
.chat-box { display: flex; flex-direction: column-reverse; /* Newest at top */ gap: 15px; } .message { display: flex; flex-direction: row; /* Avatar and text side-by-side */ gap: 10px; align-items: flex-end; }

6️⃣ Responsive Hero Section
Uses flex-direction: row on desktop and switches to flex-direction: column on mobile via media queries.
CSS
/* Desktop */ .hero { display: flex; flex-direction: row; /* Image and text side-by-side */ gap: 40px; align-items: center; } /* Mobile */ @media (max-width: 1024px) { .hero { flex-direction: column; /* Stack vertically */ text-align: center; } }

8️⃣ Centered Profile Card
Uses flex-direction: column with centered alignment to create a vertical profile card. Action buttons use flex-direction: row.
CSS
.profile-card { display: flex; flex-direction: column; /* Vertical stacking */ align-items: center; /* Center horizontally */ gap: 20px; } .profile-actions { display: flex; flex-direction: row; /* Buttons side-by-side */ gap: 10px; justify-content: center; }

✨ Key Takeaways
1. flex-direction: row – Items flow left-to-right. Use for horizontal navigation, sidebars, product layouts.

2. flex-direction: column – Items flow top-to-bottom. Use for forms, vertical menus, centered profiles.

3. Responsive changes – Use media queries to change from row to column for mobile devices.

4. Nested directions – Combine row containers with column children for complex layouts.

5. column-reverse for chats – Display newest messages at top without changing DOM order.

6. Always test – Resize browsers and test on different devices to ensure layouts adapt correctly.
