CSS Counter Increment & Reset

Complete Guide to Automatic Numbering and Counting

CSS Counters allow you to automatically number elements without hardcoding numbers in HTML. Using counter-reset, counter-increment, and the counter() function, you can create dynamic, automatic numbering for lists, headings, chapters, and more. This is perfect for table of contents, outlines, and structured documents.

Core Concepts

CSS counters work through three main components:

Property Purpose Example
counter-reset Initialize a counter to a value (default 0) counter-reset: chapter 0;
counter-increment Increase counter by amount (default 1) counter-increment: chapter 1;
counter() function Display counter value in content content: counter(chapter);
counters() function Display nested counter values content: counters(section, ".");

counter-reset Property

counter-reset initializes one or more counters. It should be applied to a parent element.

Syntax

/* Reset single counter */
body {
  counter-reset: chapter;
}

/* Reset with initial value */
body {
  counter-reset: chapter 1;
}

/* Reset multiple counters */
body {
  counter-reset: chapter 1 section 0;
}

Important Notes

  • Place on parent element (body, div, section)
  • Default initial value is 0
  • Reset happens before children are processed
  • Can reset multiple counters in one declaration

counter-increment Property

counter-increment increases a counter value. Apply it to elements you want to count.

Syntax

/* Increment by 1 (default) */
h2 {
  counter-increment: chapter;
}

/* Increment by specific amount */
h2 {
  counter-increment: chapter 2;
}

/* Increment multiple counters */
li {
  counter-increment: list-item 1 total 1;
}

Important Notes

  • Default increment is 1
  • Increment happens before content is processed
  • Can increment multiple counters
  • Can use negative values for decrementing

counter() Function

The counter() function retrieves and displays the current counter value. Use with the content property.

Syntax

/* Basic counter display */
h2::before {
  content: counter(chapter);
}

/* With text */
h2::before {
  content: "Chapter " counter(chapter) ": ";
}

/* With style (decimal, roman, letter, etc.) */
li::before {
  content: counter(item, lower-roman);
}

Counter Styles

Style Output Example (1,2,3...)
decimal Numbers 1, 2, 3
decimal-leading-zero Numbers with leading zero 01, 02, 03
lower-roman Lowercase Roman numerals i, ii, iii
upper-roman Uppercase Roman numerals I, II, III
lower-alpha Lowercase letters a, b, c
upper-alpha Uppercase letters A, B, C

counters() Function (Nested Counters)

The counters() function displays hierarchical numbering like 1.1.1, 2.2.3, etc.

Syntax

/* Display nested counters with separator */
li::before {
  content: counters(item, ".");
}

/* With style */
li::before {
  content: counters(item, ".", decimal-leading-zero);
}

How Nested Counters Work

  • Each nesting level has its own counter
  • The separator joins all levels (e.g., "." creates 1.1.1)
  • Perfect for outlines, nested lists, and hierarchical numbering
  • Automatically handles nesting depth

Complete Workflow Example

Here's a practical example combining all components:

/* 1. Reset counter on parent */
body {
  counter-reset: chapter;
}

/* 2. Increment on each h2 */
h2 {
  counter-increment: chapter;
}

/* 3. Display counter in content */
h2::before {
  content: "Chapter " counter(chapter) ": ";
  margin-right: 10px;
}

Result: "Chapter 1: ", "Chapter 2: ", "Chapter 3: "...

Best Practices

✓ Do's

  • Reset on parent container - Place counter-reset on body or section
  • Increment on child elements - Apply counter-increment to items to count
  • Use meaningful names - "chapter", "section", "item" instead of "c", "s"
  • Use counters() for nested lists - Perfect for outlines and hierarchies
  • Combine with ::before/::after - This is where counter() displays
  • Test nesting carefully - Each level needs proper reset/increment

✗ Don'ts

  • Don't reset on every element - Reset once at parent level
  • Don't increment non-target elements - Only count what you need
  • Don't use undefined counters - Always reset before incrementing
  • Don't forget counter-reset in nested scenarios - Each level needs its own
  • Don't use for semantic content - Counters are for presentation only
