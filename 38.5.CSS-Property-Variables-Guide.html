CSS @property Variables

Complete Guide to CSS Custom Properties with Type Definition

1. What is @property?

The @property CSS at-rule allows you to register custom CSS properties with a type definition, initial value, and inheritance behavior. This enables type-safe CSS variables with transitions and animations.

Key Characteristics:

  • Register CSS custom properties with explicit types
  • Define initial values for fallback
  • Control inheritance behavior
  • Enable animations and transitions on properties
  • Type validation for custom properties
  • Modern, powerful CSS capability

Syntax:

@property --property-name {
    syntax: '';
    initial-value: #667eea;
    inherits: false;
}
Why @property? Regular CSS variables cannot be animated. @property enables smooth transitions on color, size, angle, and other values!

2. @property Syntax & Components

Three Required Components:

Component Description Example
syntax Type definition for the property syntax: '<color>';
initial-value Default value if not set initial-value: #667eea;
inherits Whether it inherits to children inherits: false;

5. Syntax Types Explained

Color Type:

@property --accent-color {
    syntax: '';
    initial-value: #667eea;
    inherits: false;
}

/* Usage */
.element {
    background: var(--accent-color);
    transition: --accent-color 0.3s;
}

Length Type:

@property --spacing-size {
    syntax: '';
    initial-value: 16px;
    inherits: false;
}

.element {
    margin: var(--spacing-size);
    padding: var(--spacing-size);
}

Angle Type:

@property --rotation-angle {
    syntax: '';
    initial-value: 0deg;
    inherits: false;
}

.element {
    transform: rotate(var(--rotation-angle));
    transition: --rotation-angle 1s;
}

Number Type:

@property --scale-factor {
    syntax: '';
    initial-value: 1;
    inherits: false;
}

.element {
    transform: scale(var(--scale-factor));
    opacity: var(--scale-factor);
}

Custom Ident (Keywords):

@property --size-level {
    syntax: 'small | medium | large';
    initial-value: medium;
    inherits: false;
}

.element {
    font-size: calc(var(--size-level) * 16px);
}

Multiple Types:

@property --flexible-size {
    syntax: ' | ';
    initial-value: 100px;
    inherits: false;
}

7. Advanced Techniques

Technique 1: Cascade of Properties

@property --primary-color { syntax: ''; initial-value: #667eea; inherits: false; }
@property --secondary-color { syntax: ''; initial-value: #764ba2; inherits: false; }
@property --accent-opacity { syntax: ''; initial-value: 1; inherits: false; }

:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --accent-opacity: 1;
}

.gradient {
    background: linear-gradient(
        to right,
        rgba(var(--primary-color), var(--accent-opacity)),
        rgba(var(--secondary-color), var(--accent-opacity))
    );
}

Technique 2: Complex Animations

@property --hue-rotate {
    syntax: '';
    initial-value: 0deg;
    inherits: false;
}

@keyframes hue-shift {
    0% { --hue-rotate: 0deg; }
    50% { --hue-rotate: 180deg; }
    100% { --hue-rotate: 360deg; }
}

.element {
    filter: hue-rotate(var(--hue-rotate));
    animation: hue-shift 3s infinite;
}

Technique 3: Responsive Properties

@property --responsive-size {
    syntax: '';
    initial-value: 16px;
    inherits: false;
}

:root {
    --responsive-size: 16px;
}

@media (min-width: 768px) {
    :root {
        --responsive-size: 20px;
    }
}

@media (min-width: 1024px) {
    :root {
        --responsive-size: 24px;
    }
}

Technique 4: JavaScript Integration

// Set custom property from JavaScript
document.documentElement.style.setProperty('--progress-width', '75%');

// Animate between values
let progress = 0;
const interval = setInterval(() => {
    progress += 5;
    document.documentElement.style.setProperty('--progress-width', progress + '%');
    if (progress >= 100) clearInterval(interval);
}, 50);

8. Best Practices & Tips

✓ Do's:

  • Use @property for animatable properties
  • Define clear initial values
  • Use appropriate syntax types
  • Leverage transitions and animations
  • Test with @supports
  • Provide fallback styles
  • Use descriptive property names

✗ Don'ts:

  • Don't use without feature detection
  • Don't forget fallback values
  • Don't use incorrect syntax types
  • Don't overcomplicate animations
  • Don't assume all browsers support it
  • Don't ignore performance impact

Performance Considerations:

Performance: @property animations are GPU-accelerated in modern browsers. Use them liberally, but test on lower-end devices. Complex cascading properties may impact performance.
