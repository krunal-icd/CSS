CSS if() Function - Practical Examples

Real-world patterns and implementation strategies for experimental conditional CSS

⚠️ Experimental Feature: CSS if() has <1% browser support. Examples show current approaches with future if() equivalents.

Example 1: Responsive Typography Without Media Queries

Currently we use media queries. With CSS if(), typography would respond smoothly to viewport changes with a single declaration.

/* Current Approach (Works Today) */
h1 {
  font-size: 1.5rem;
  line-height: 1.2;
}

@media (min-width: 768px) {
  h1 {
    font-size: 2.5rem;
    line-height: 1.3;
  }
}
/* Future with CSS if() */
h1 {
  font-size: if(
    viewport-width > 768px,
    2.5rem,
    1.5rem
  );
  line-height: if(
    viewport-width > 768px,
    1.3,
    1.2
  );
}

Comparison: With media queries, you need multiple rule blocks. With if(), each property is self-contained and immediately clear about its responsive behavior.

Example 2: Display Capability Detection

Different displays support different color spaces. CSS if() can deliver the perfect colors to each device without JavaScript detection.

/* Current: JavaScript Detection */
const supportsP3 =
  matchMedia(
    "(color-gamut: p3)"
  ).matches;

if (supportsP3) {
  element.style.color =
    "color(display-p3 1 0.5 0)";
} else {
  element.style.color =
    "rgb(255, 128, 0)";
}
/* Future: Pure CSS */
.accent {
  color: if(
    color-gamut: p3,
    color(display-p3 1 0.5 0),
    rgb(255, 128, 0)
  );
}

Example 3: Respecting User Motion Preferences

Users with motion sensitivity can prefer reduced motion. CSS if() makes it easy to disable animations while keeping visual polish for others.

/* Current Approach */
.card {
  transition: all 0.3s ease;
}

.card:hover {
  transform: translateY(-5px);
}

@media (prefers-reduced-motion: reduce) {
  .card {
    transition: none;
  }
  .card:hover {
    transform: none;
  }
}
/* Future with CSS if() */
.card {
  transition-duration: if(
    prefers-reduced-motion,
    0s,
    0.3s
  );
}

.card:hover {
  transform: if(
    prefers-reduced-motion,
    none,
    translateY(-5px)
  );
}

Accessibility Win: If() makes accessibility the default, not a special case. Each property clearly states its behavior for different preferences.

Example 4: High Contrast Mode Support

Some users need higher contrast for readability. CSS if() with prefers-contrast ensures accessible experiences automatically.

/* Current Approach */
.info-box {
  background: #f8f9fa;
  border: 1px solid #e5e7eb;
  color: #666;
}

@media (prefers-contrast: more) {
  .info-box {
    background: white;
    border: 2px solid black;
    color: black;
  }
}
/* Future with CSS if() */
.info-box {
  background: if(
    prefers-contrast: more,
    white,
    #f8f9fa
  );
  border: if(
    prefers-contrast: more,
    2px solid black,
    1px solid #e5e7eb
  );
}

Example 5: Adaptive Spacing Based on Screen Size

Spacing is crucial for responsive design. CSS if() makes it easy to scale padding and margins alongside viewport changes.

/* Current: Multiple Rules */
.section {
  padding: 1rem;
  gap: 1rem;
}

@media (min-width: 768px) {
  .section {
    padding: 2rem;
    gap: 2rem;
  }
}

@media (min-width: 1024px) {
  .section {
    padding: 3rem;
    gap: 3rem;
  }
}
/* Future with CSS if() */
.section {
  padding: if(
    viewport-width > 1024px,
    3rem,
    if(
      viewport-width > 768px,
      2rem,
      1rem
    )
  );
}

Example 6: Component Layout Switching

CSS if() works perfectly with container queries for truly responsive components that adapt to their container, not the viewport.

/* Component responds to its container */
.card {
  display: if(
    container-width > 500px,
    grid,
    flex
  );
  grid-template-columns: if(
    container-width > 500px,
    1fr 1fr,
    1fr
  );
}

Example 7: Automatic Dark Mode with Color Scheme Detection

Respect user's preferred color scheme and let if() handle theme switching automatically.

/* Automatic theme adaptation */
:root {
  --bg-primary: if(
    prefers-color-scheme: dark,
    #1f2937,
    #ffffff
  );
  --text-primary: if(
    prefers-color-scheme: dark,
    #f3f4f6,
    #333333
  );
}

body {
  background: var(--bg-primary);
  color: var(--text-primary);
}

Implementation Strategy for 2026

Since CSS if() is still experimental, use a progressive enhancement strategy that provides excellent experiences in all browsers.

❌ Don't: Rely Only on if()

/* Breaks in 99% of browsers */ .title { font-size: if(viewport-width > 768px, 2rem, 1rem); }

✅ Do: Progressive Enhancement

/* Works everywhere */ .title { font-size: 1rem; /* fallback */ } @media (min-width: 768px) { .title { font-size: 2rem; } } /* if() for enhanced experience */

Recommended Approach

Future Timeline: CSS if() browser support is expected to gradually increase through 2026-2027. Start experimenting now for future-ready code, but maintain media query fallbacks for production.

Key Takeaways

More Concise: Responsive logic fits inline with properties instead of separate media query blocks.

Self-Documenting: Each property clearly shows its responsive behavior without hunting through media queries.

No JavaScript Needed: Feature detection and conditional logic stay in CSS.

Future-Oriented: Using if() today prepares code for tomorrow's browser capabilities.

Progressive Enhancement: Works alongside media queries for universal compatibility.
