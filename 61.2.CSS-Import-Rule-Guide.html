CSS @import Rule Practical Examples

Real-World Applications and File Organization Patterns

1. Basic Multi-File Organization

Organize CSS into logical modules with @import at the entry point:

Main CSS File Structure

/* styles/main.css - Entry point */ /* Import in order of specificity/dependency */ @import url("./variables.css"); @import url("./reset.css"); @import url("./typography.css"); @import url("./layout.css"); @import url("./components.css"); @import url("./utilities.css"); /* Additional custom styles */ body { background-color: var(--bg-color); }

Project Structure

styles/ ├── main.css ..................... (entry point) ├── variables.css ................ (CSS custom properties) ├── reset.css .................... (CSS reset/normalize) ├── typography.css ............... (font & text styles) ├── layout.css ................... (grid & flexbox) ├── components.css ............... (UI components) └── utilities.css ................ (helper classes)

2. Component-Based Architecture

Import component-specific stylesheets for scalability:

Components Folder Organization

/* styles/main.css */ @import url("./base/reset.css"); @import url("./base/typography.css"); @import url("./components/buttons.css"); @import url("./components/forms.css"); @import url("./components/cards.css"); @import url("./components/navigation.css"); @import url("./components/modals.css"); @import url("./layouts/grid.css"); @import url("./layouts/flexbox.css");
styles/ ├── main.css ├── base/ │ ├── reset.css │ ├── typography.css │ └── variables.css ├── components/ │ ├── buttons.css │ ├── forms.css │ ├── cards.css │ ├── navigation.css │ └── modals.css └── layouts/ ├── grid.css └── flexbox.css

3. Media Query-Based Imports

Conditionally load stylesheets based on device or screen size:

Responsive Layout

@import url("desktop.css") (min-width: 1024px); @import url("tablet.css") (min-width: 768px) and (max-width: 1023px); @import url("mobile.css") (max-width: 767px);

Media Type Imports

@import url("screen.css") screen; @import url("print.css") print; @import url("handheld.css") handheld;

Feature Detection

@import url("dark.css") (prefers-color-scheme: dark); @import url("light.css") (prefers-color-scheme: light); @import url("high-contrast.css") (prefers-contrast: more);

4. Importing Fonts from CDN

Import Google Fonts or other font libraries directly within CSS:

Font Imports from Google Fonts

/* styles/main.css */ /* Import multiple fonts with different weights */ @import url('https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap'); @import url('https://fonts.googleapis.com/css2?family=Playfair+Display:wght@400;700;900&display=swap'); @import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&display=swap'); /* Use imported fonts */ body { font-family: 'Roboto', sans-serif; } h1, h2, h3 { font-family: 'Playfair Display', serif; } button { font-family: 'Inter', sans-serif; }

5. CSS Framework Integration

Import framework stylesheets as base layer before custom components:

Bootstrap Integration

/* main.css */ /* Bootstrap framework */ @import url('https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css'); /* Custom overrides */ @import url("./overrides.css"); @import url("./components.css");

Tailwind + Custom

/* main.css */ /* Tailwind base styles */ @import url('https://cdn.tailwindcss.com'); /* Custom components */ @import url("./custom-components.css"); /* Theme customization */ @import url("./theme.css");

Icon Libraries

/* main.css */ /* Font Awesome */ @import url('https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css'); /* Material Icons */ @import url('https://fonts.googleapis.com/icon?family=Material+Icons'); @import url("./local-styles.css");

6. Theme Management with Conditional Imports

Switch between themes using media queries and @import:

Light and Dark Theme Imports

/* styles/main.css */ /* Core styles always loaded */ @import url("./base.css"); @import url("./components.css"); /* Theme-specific imports */ @import url("./theme-light.css") (prefers-color-scheme: light); @import url("./theme-dark.css") (prefers-color-scheme: dark); /* Accessibility-focused imports */ @import url("./high-contrast.css") (prefers-contrast: more);
💡 Pro Tip: Modern approach uses CSS custom properties instead of separate imports. Keep base styles in one file and use variables for theming.

7. CSS Layers Organization

Use @import with @layer for explicit cascade control (modern browsers):

Layer-Based Architecture

/* main.css - Define layer order */ @layer reset, base, layout, components, utilities, overrides; /* Import into specific layers */ @import url("./normalize.css") layer(reset); @import url("./base.css") layer(base); @import url("./grid.css") layer(layout); @import url("./buttons.css") layer(components); @import url("./utilities.css") layer(utilities); /* High specificity overrides go last */ @layer overrides { button.primary { background: blue !important; } }

Note: CSS Layers allow explicit control over cascade priority, reducing need for specificity wars. Browser support: Chrome 99+, Firefox 97+, Safari 16+.

8. Print Stylesheet Organization

Keep print-specific styles separate and import conditionally:

Print Media Import

/* styles/main.css */ /* Screen styles */ @import url("./screen.css") screen; /* Print-specific styles */ @import url("./print.css") print; /* Alternative: Responsive media query */ @import url("./print-optimized.css") (prefers-color-scheme: light) print;

Sample Print Stylesheet

/* styles/print.css */ body { background: white; color: black; font-size: 12pt; } header, nav, footer { display: none; } a { color: black; text-decoration: underline; } a:after { content: " (" attr(href) ")"; }

9. Relative Path Examples

Different import scenarios with relative and absolute paths:

Same Directory Import

/* styles/main.css */ @import url("./reset.css"); @import url("./typography.css"); /* Alternative */ @import url("reset.css");

Subfolder Import

/* From styles/main.css to styles/base/reset.css */ @import url("./base/reset.css"); @import url("./components/buttons.css");

Parent Directory

/* From styles/components/buttons.css to styles/base/variables.css */ @import url("../base/variables.css"); /* To root-level stylesheet */ @import url("../../shared.css");

10. Performance Comparison

Understanding @import vs <link> and modern bundling:

Method Syntax Parallel Loading Best For
@import (CSS) @import "file.css"; ❌ Sequential Modular CSS organization
<link> tag <link rel="stylesheet" href="file.css"> ✅ Parallel Production sites (better performance)
Bundle/Minify webpack, vite, parcel ✅ Single file Large applications (best practice)
CSS Modules import styles from 'file.css' ✅ Scoped + bundled Component-based apps

Development vs Production

/* Development: Use @import for organization */ @import url("./base.css"); @import url("./components.css"); /* Production: Build tool concatenates into one file */ /* Result: styles.min.css (all CSS bundled) */

11. Avoiding Common Mistakes

Learn from common @import issues:

❌ @import After Rules

body { margin: 0; } /* This import is IGNORED! */ @import url("reset.css");

✅ @import at Top

/* ✓ Move @import to beginning */ @import url("reset.css"); body { margin: 0; }

❌ Wrong File Path

/* styles/main.css */ @import url("components/buttons.css"); /* File not found! Path is wrong */

✅ Correct Relative Path

/* styles/main.css */ @import url("./components/buttons.css"); /* or with ./ prefix for clarity */

❌ Circular Dependencies

/* main.css imports utils */ @import url("utilities.css"); /* utilities.css imports main (Circular!) */ @import url("main.css");

✅ Linear Dependencies

/* Plan hierarchy: no cycles */ /* main.css */ @import url("base.css"); /* base.css - standalone */ /* utilities.css - standalone */

12. Real-World Project Example

Complete project structure with organized imports:

Complete Project Setup

project/ ├── index.html ├── styles/ │ ├── main.css ..................... (entry point) │ ├── base/ │ │ ├── variables.css ............ (CSS custom properties) │ │ ├── reset.css ............... (CSS reset) │ │ ├── typography.css .......... (fonts & text) │ │ └── colors.css ............. (color palette) │ ├── layout/ │ │ ├── grid.css ............... (grid system) │ │ ├── flexbox.css ............ (flexbox utilities) │ │ └── responsive.css ......... (media queries) │ ├── components/ │ │ ├── buttons.css ............ (button styles) │ │ ├── forms.css ............. (form elements) │ │ ├── cards.css ............. (card component) │ │ ├── navigation.css ......... (navbar) │ │ └── modals.css ............ (modal dialogs) │ ├── utilities/ │ │ ├── spacing.css ........... (margin/padding) │ │ ├── visibility.css ........ (display utilities) │ │ └── effects.css .......... Main.css Implementation

/* styles/main.css - Master stylesheet */ /* ===== BASE LAYER ===== */ @import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;600;700&display=swap'); @import url("./base/variables.css"); @import url("./base/reset.css"); @import url("./base/typography.css"); @import url("./base/colors.css"); /* ===== LAYOUT LAYER ===== */ @import url("./layout/grid.css"); @import url("./layout/flexbox.css"); @import url("./layout/responsive.css"); /* ===== COMPONENTS LAYER ===== */ @import url("./components/buttons.css"); @import url("./components/forms.css"); @import url("./components/cards.css"); @import url("./components/navigation.css"); @import url("./components/modals.css"); /* ===== UTILITIES LAYER ===== */ @import url("./utilities/spacing.css"); @import url("./utilities/visibility.css"); @import url("./utilities/effects.css"); /* ===== THEME LAYER ===== */ @import url("./themes/light.css") (prefers-color-scheme: light); @import url("./themes/dark.css") (prefers-color-scheme: dark);

Key Takeaways

  • Use @import for organizing CSS into logical modules
  • Place all @import rules at the top of your stylesheet
  • Use relative paths for flexibility and portability
  • Organize files by functionality (base, components, utilities)
  • Conditional imports with media queries reduce unused CSS
  • Consider build tools for production optimization
  • Use <link> tags for better parallel loading performance
  • CSS Layers provide modern cascade control
  • Keep imports linear - avoid circular dependencies
  • Document your file structure for team collaboration
  • Test paths after file reorganization
  • Consider bundling for production deployment
