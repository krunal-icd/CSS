CSS Grid: Items Spanning

Master spanning techniques for multi-track grid items

Understanding Grid Item Spanning

Grid item spanning allows a single item to occupy multiple columns or rows. This is essential for creating complex, varied layouts where some items need more prominence or space.

Spanning Methods

  • span Keyword - Span N tracks from current position
  • Line Numbers - Explicit start and end lines
  • Negative Lines - Count from the end backwards
  • Auto-Spanning - Dynamic spanning with auto-fit/auto-fill
  • Full-Width Spanning - Span all available columns

Combining column and row spanning creates flexible layouts with items of different sizes.

The span Keyword

Basic Span Syntax

Use span to span a number of tracks from the item's starting position:

.item {
    grid-column: span 2;  /* Span 2 columns */
    grid-row: span 1;     /* Span 1 row (default) */
}

Explicit Line Number Spanning

Start / End Syntax

Specify exact grid lines where the item starts and ends:

.item {
    grid-column: 1 / 3;   /* From line 1 to line 3 (2 columns) */
    grid-row: 2 / 4;      /* From line 2 to line 4 (2 rows) */
}

Line Number Calculation

Syntax Lines Spanned Tracks Covered
grid-column: 1 / 2; 1 to 2 1 column
grid-column: 1 / 3; 1 to 3 2 columns
grid-column: 2 / 5; 2 to 5 3 columns
grid-column: 1 / -1; 1 to end All columns
Important: The end line is exclusive—it marks where the item ENDS, not the last track it occupies.

Negative Line Spanning

Counting From the End

Negative line numbers count backwards from the end of the grid:

.item {
    grid-column: -3 / -1;  /* Last 2 columns */
    grid-row: -2 / -1;     /* Last row */
}

Full-Width Spanning

Spanning All Columns

Make items span the entire grid width regardless of column count:

.full-width {
    grid-column: 1 / -1;  /* From start to end */

Spanning Beyond the Explicit Grid

Implicit Grid Creation

When items span beyond defined tracks, implicit tracks are automatically created:

.grid {
    grid-template-columns: repeat(3, 1fr);
    grid-template-rows: repeat(2, 80px);
    grid-auto-rows: 80px;  /* Size of implicit rows */
}

.item {
    grid-column: span 2;
    grid-row: span 3;  /* May exceed defined rows */
}

Spanning with Named Grid Areas

Semantic Area Spanning

Named areas automatically handle spanning without manual line numbers:

.grid {
    grid-template-areas:
        "header header header"
        "sidebar main main"
        "footer footer footer";
}

.header { grid-area: header; }  /* Auto-spans 3 cols */

Complex Multi-Item Spanning

Combining Multiple Spans

Create sophisticated layouts by combining column and row spanning:

.grid {
    grid-template-columns: repeat(4, 1fr);
    grid-template-rows: repeat(4, 80px);
}

.item-1 {
    grid-column: 1 / 3;   /* 2 columns */
    grid-row: 1 / 3;      /* 2 rows */
}

.item-2 {
    grid-column: 3 / 5;   /* 2 columns */
    grid-row: 1;          /* 1 row */
}

.item-3 {
    grid-column: 3;       /* 1 column */
    grid-row: 2 / 4;      /* 2 rows */
}

Spanning with Auto-Fit/Auto-Fill

Responsive Spanning

Spanning works with responsive auto-fit and auto-fill grids:

.grid {
    grid-template-columns: repeat(auto-fit, minmax(100px, 1fr));
    gap: 10px;
}

.item-featured {
    grid-column: span 2;  /* Spans 2 of the responsive columns */
}

Spanning in Masonry Layouts

Grid-Auto-Flow Dense with Spanning

Use spanning with grid-auto-flow: dense for masonry-like layouts:

.masonry {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    grid-auto-rows: 100px;
    grid-auto-flow: dense;  /* Fill all gaps */
}

.item.wide {
    grid-column: span 2;
}

.item.tall {
    grid-row: span 2;
}

Best Practices for Item Spanning

Do's ✓

  • Use span for relative sizing from current position
  • Use explicit line numbers for precise control
  • Use 1 / -1 for full-width responsive items
  • Use named areas for semantic spanning
  • Combine row and column spanning for 2D layouts
  • Test spanning at different breakpoints

Don'ts ✗

  • Don't over-span items unnecessarily
  • Don't hardcode line numbers that might change
  • Don't forget implicit grid creation when spanning beyond
  • Don't ignore content when determining span sizes
  • Don't use spanning for every item (simplicity matters)
  • Don't forget accessibility of overlapping spans

Spanning Methods Comparison

span Keyword

Use for: Relative spanning

Best when you want items to span from their current position. Simple and flexible.

Line Numbers (start/end)

Use for: Absolute positioning

Best for precise control. Specify exact lines where spanning starts and ends.

Negative Lines

Use for: Dynamic positioning

Best for responsive layouts. Position from the end automatically.

Named Areas

Use for: Semantic layouts

Best for readable code. Visual template shows spanning automatically.

Quick Reference Cheat Sheet

/* Span by keyword (relative) */
grid-column: span 2;       /* Span 2 columns */
grid-row: span 3;          /* Span 3 rows */

/* Explicit line numbers (absolute) */
grid-column: 1 / 3;        /* From line 1 to 3 (2 cols) */
grid-row: 2 / 5;           /* From line 2 to 5 (3 rows) */

/* Negative lines (from end) */
grid-column: -3 / -1;      /* Last 2 columns */
grid-row: -2 / -1;         /* Last row */

/* Full-width spanning */
grid-column: 1 / -1;       /* All columns */
grid-row: 1 / -1;          /* All rows */

/* 2D Spanning */
grid-column: span 2;
grid-row: span 2;

/* Named areas */
grid-area: header;         /* Named area in template */
