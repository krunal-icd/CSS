3. Magazine Layout with Column/Row Spanning

Featured article spans multiple columns and rows, with article cards filling the grid

.magazine-layout { display: grid; grid-template-columns: repeat(4, 1fr); gap: 20px; grid-auto-rows: minmax(150px, auto); } .featured-article { grid-column: 1 / 3; /* Spans 2 columns */ grid-row: 1 / 3; /* Spans 2 rows */ }

Hero section spans multiple rows while content areas sit beside it
