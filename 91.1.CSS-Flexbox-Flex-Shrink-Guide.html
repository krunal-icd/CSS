Master how flex items shrink when space is limited

What is Flex-Shrink?

The flex-shrink property determines how much a flex item will shrink relative to other flex items when there isn't enough space in the flex container. It's the opposite of flex-grow.

Default value is 1, meaning items shrink proportionally. A value of 0 prevents shrinking. Higher values cause faster shrinking.

💡 Key Point: Flex-shrink only shrinks items. It doesn't expand them. Use flex-grow for expansion.
/* Basic Syntax - Applied to individual flex items */ .flex-item { flex-shrink: 1; /* Item shrinks proportionally */ } /* No shrinking */ .flex-item-fixed { flex-shrink: 0; /* Item won't shrink */ } /* Shorthand */ .flex-item { flex: 1 1 200px; /* flex-grow flex-shrink flex-basis */ }

How Flex-Shrink Distribution Works

Shrinkage Formula: Overflow = Sum of Item Widths - Container Width Item Shrinkage = (Item Width × Item's flex-shrink / Total shrink weight) × Overflow Final Item Width = Base Width - Item Shrinkage

Example Calculation:

Container width: 300px Item widths: 200px + 200px + 200px = 600px Overflow: 600px - 300px = 300px Item 1: flex-shrink: 1 Item 2: flex-shrink: 1 Item 3: flex-shrink: 0 (won't shrink) Total shrink factor: 1 + 1 + 0 = 2 Item 1 shrinks: (200 × 1/2) × 300 = 100px → Final: 100px Item 2 shrinks: (200 × 1/2) × 300 = 100px → Final: 100px Item 3 shrinks: (200 × 0/2) × 300 = 0px → Final: 200px

Flex-Shrink Property Values

Value Description Example
0 Item doesn't shrink (maintains size) flex-shrink: 0
1 Default - item shrinks equally with others flex-shrink: 1
2, 3, 4... Item shrinks faster (2x faster than flex-shrink: 1) flex-shrink: 2

Common Layout Patterns with Flex-Shrink

🎨 Fixed Sidebar (No Shrink)

.sidebar { flex: 0 0 250px; /* Won't shrink */ } .content { flex: 1 1 0; /* Shrinks to accommodate */ }

🎨 Protected Important Item

.priority-item { flex-shrink: 0; /* Won't shrink */ } .normal-item { flex-shrink: 1; /* Shrinks as needed */ }

🎨 Proportional Shrinking

.item-1 { flex-shrink: 1; } /* Shrinks normally */ .item-2 { flex-shrink: 1; } /* Shrinks normally */ .item-3 { flex-shrink: 2; } /* Shrinks twice as fast */

🎨 No Shrinking at All

.item { flex-shrink: 0; /* Item maintains size, may overflow */ }

Important Tips & Best Practices

✓ Default is 1: By default, flex items shrink. Set to 0 to prevent shrinking.
✓ Works with Flex-Basis: Flex-shrink calculates based on item's flex-basis or width.
⚠ Flex-Shrink Only Shrinks: It cannot expand items. Use flex-grow for that.
✓ Combine with Min-Width: Use min-width to prevent items shrinking below a certain size.
⚠ Content Overflow: With flex-shrink: 0, content may overflow container. Plan accordingly.
✓ Proportional Shrinking: Higher values shrink faster. 2 shrinks twice as fast as 1.
✓ Use Shorthand: flex: 1 0 250px is cleaner than separate properties.

Real-World Use Cases

📱 Navigation Bar: Logo/buttons don't shrink, menu shrinks
🎯 Dashboard: Important widgets shrink less than secondary ones
📊 Table Layout: Fixed-width columns don't shrink
📝 Form: Labels maintain size, inputs shrink
🎨 Card Layout: Header doesn't shrink, body shrinks as needed

Flex-Shrink vs Flex-Grow Comparison

Key Differences:

  • Flex-Grow: Expands items when container is larger than content
  • Flex-Shrink: Shrinks items when container is smaller than content
  • Default: Grow = 0 (no growth), Shrink = 1 (will shrink)
  • Use Together: Combine for responsive layouts
/* Responsive item that grows and shrinks */ .flex-item { flex: 1 1 0; /* grow: 1, shrink: 1, basis: 0 */ } /* Item that grows but doesn't shrink */ .item-no-shrink { flex: 1 0 0; /* grow: 1, shrink: 0, basis: 0 */ } /* Item that doesn't grow but shrinks */ .item-no-grow { flex: 0 1 250px; /* grow: 0, shrink: 1, basis: 250px */ }

Browser Support

The flex-shrink property is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.item { flex-shrink: 1; /* No vendor prefixes needed for modern browsers */ }
