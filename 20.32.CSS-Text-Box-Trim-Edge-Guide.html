1. Typography System

Consistent spacing throughout a website with tight typography control.

Without text-box-trim (extra whitespace)

Main Heading

This paragraph follows the heading. Notice the large gap above and below.

Subheading

Typography without trim includes ascender and descender space.

With text-box-trim (compact spacing)

Main Heading

This paragraph follows the heading. The spacing is now tighter.

Subheading

With trim, we remove extra whitespace for precise spacing.

CSS Implementation:
/* Recommended for typography systems */
h1, h2, h3 {
    text-box-trim: trim-both;
    text-box-edge: cap alphabetic;
    /* Now margins are predictable and tight */
}

p {
    text-box-trim: trim-both;
    text-box-edge: text;
    margin: 1rem 0;
}
Benefit: Achieve consistent baseline-to-baseline spacing throughout your design.

Best Practices for Implementation

Progressive Enhancement:

/* Fallback for browsers without support */
h1 {
    margin-top: -0.1em;
    margin-bottom: 1rem;
}

/* Enhanced with text-box-trim */
@supports (text-box-trim: trim-both) {
    h1 {
        text-box-trim: trim-both;
        text-box-edge: cap alphabetic;
        margin-top: 0;
        margin-bottom: 1rem;
    }
}

Comprehensive Typography System:

/* Complete system with fallbacks */
:root {
    --text-box-trim: trim-both;
    --text-box-edge: cap alphabetic;
}

h1, h2, h3, h4, h5, h6 {
    @supports (text-box-trim: trim-both) {
        text-box-trim: var(--text-box-trim);
        text-box-edge: var(--text-box-edge);
    }
}

p, span, li {
    @supports (text-box-trim: trim-both) {
        text-box-trim: trim-both;
        text-box-edge: text;
    }
}
⚠️ Important: Always provide fallback margins for browsers that don't support text-box-trim yet.
