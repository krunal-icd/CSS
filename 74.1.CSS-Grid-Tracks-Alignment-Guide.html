CSS Grid: Tracks Alignment Properties

Master justify-content, align-content, and track distribution

Understanding Tracks Alignment
Core Concept: Tracks vs Items
Tracks: The rows and columns that make up your grid. They are the structure itself.
Track Alignment: How the grid tracks themselves are positioned within the grid container when they don't fill all available space.
Grid Container vs Tracks: Container: 600px wide ┌──────────────────────────────────────────────┐ │ Track 1 Track 2 Track 3 │ │ (100px) (100px) (100px) Extra Space │ │ ┌────┐ ┌────┐ ┌────┐ │ │ │ │ │ │ │ │ │ │ └────┘ └────┘ └────┘ │ │ │ │ Tracks are 300px total, container is 600px │ │ justify-content determines placement │ └──────────────────────────────────────────────┘
When Does Track Alignment Matter?
  • Grid tracks don't fill the entire container width (justify-content)
  • Grid tracks don't fill the entire container height (align-content)
  • Using fixed-size columns like repeat(3, 100px) instead of 1fr
  • Using auto-fit/auto-fill with explicit gap values
  • Creating centered grids in larger containers

justify-content (Horizontal Track Alignment)
Definition
justify-content: Aligns the entire grid HORIZONTALLY within its container. Only works when the grid is narrower than the container.
Available Values
start

Grid aligned to container start (left)

end

Grid aligned to container end (right)

center

Grid centered horizontally

stretch

Grid columns stretch to fill width

space-between

Space distributed between columns

space-around

Space around each column equally

space-evenly

Equal space between all columns

Syntax & Example
.grid-container { display: grid; grid-template-columns: repeat(3, 100px); /* 300px total */ width: 600px; /* Container is 600px wide */ justify-content: center; /* Grid centered in 600px */ }
Real-World Scenarios
/* Centered dashboard on large screens */ .dashboard { grid-template-columns: repeat(4, 200px); /* Fixed size */ justify-content: center; } /* Distribute columns across container */ .toolbar { grid-template-columns: repeat(5, auto); justify-content: space-around; /* Space buttons evenly */ } /* Grid right-aligned */ .sidebar-grid { grid-template-columns: repeat(2, 100px); justify-content: end; }
align-content (Vertical Track Alignment)
Definition
align-content: Aligns the entire grid VERTICALLY within its container. Only works when the grid is shorter than the container.
Available Values
start

Grid aligned to container top

end

Grid aligned to container bottom

center

Grid centered vertically

stretch

Grid rows stretch to fill height

space-between

Space distributed between rows

space-around

Space around each row equally

space-evenly

Equal space between all rows

Syntax & Example
.grid-container { display: grid; grid-template-rows: repeat(2, 100px); /* 200px total */ height: 400px; /* Container is 400px tall */ align-content: center; /* Grid centered vertically */ }
Real-World Scenarios
/* Vertically centered grid on full-screen page */ .page { display: grid; min-height: 100vh; align-content: center; } /* Rows distributed with space between */ .form-grid { grid-template-rows: repeat(4, auto); height: 500px; align-content: space-between; } /* Rows stretched to fill height */ .full-height-grid { grid-template-rows: auto auto auto; height: 100vh; align-content: stretch; /* Equal row heights */ }
place-content (Shorthand)
Definition
place-content: Shorthand for align-content and justify-content. Format: place-content: align-content justify-content.
Syntax
/* Single value: applies to both axes */ .grid { place-content: center; /* Centers grid both horizontally and vertically */ } /* Equivalent to: */ .grid { align-content: center; justify-content: center; } /* Different values for each axis */ .grid { place-content: start end; /* Align: top, Justify: right */ } /* Equivalent to: */ .grid { align-content: start; justify-content: end; }

Real-World Scenarios
Scenario 1: Centered Dashboard
Dashboard with fixed-size cards (200px each) centered on large screens.
.dashboard { display: grid; grid-template-columns: repeat(4, 200px); /* Fixed size */ width: 100%; justify-content: center; /* Center on large screens */ gap: 20px; }
Scenario 2: Full-Page Centered Grid
Grid centered both horizontally and vertically on a full-page layout.
.page { display: grid; grid-template-columns: repeat(3, 150px); grid-template-rows: repeat(2, 150px); width: 100vw; height: 100vh; place-content: center; /* Center both axes */ }
Scenario 3: Distributed Navigation
Navigation menu with items distributed across container width.
.navbar { display: grid; grid-template-columns: repeat(5, auto); width: 100%; justify-content: space-around; /* Distribute items */ height: 60px; align-content: center; }
Scenario 4: Equal-Height Full-Screen Layout
Rows automatically fill available height equally.
.layout { display: grid; grid-template-rows: auto auto auto; min-height: 100vh; align-content: stretch; /* Rows fill height */ }
Best Practices & Tips
✓ Do's
  • Use justify-content when grid width < container width: For centered or distributed horizontal layouts
  • Use align-content when grid height < container height: For centered or distributed vertical layouts
  • Use place-content for shorthand: Cleaner than writing both properties separately
  • Use space-evenly for truly even spacing: Most visually balanced distribution
  • Combine with fixed grid sizes: Works best with repeat(n, fixed-size) columns/rows
  • Test at different viewport sizes: Track alignment behavior changes responsively
✗ Don'ts
  • Don't use when grid fills container: If using 1fr, justify-content won't have effect (grid already fills)
  • Don't confuse with gap property: gap is spacing between tracks; justify/align-content positions entire grid
  • Don't combine stretch with fixed sizes: stretch only works when tracks don't have explicit sizes
  • Don't forget container must have excess space: These properties need room to work (container larger than grid)
Pro Tips
💡 Tip 1: Track alignment + items alignment can be combined for precise control. Use both to achieve complex layouts.
💡 Tip 2: space-evenly provides the most "modern" distribution. Use it for perfectly balanced spacing.
💡 Tip 3: For responsive track alignment, combine with media queries at different breakpoints.
💡 Tip 4: Debug with browser DevTools: Inspect grid container and enable grid overlay to see track boundaries.
💡 Tip 5: Use align-content: stretch to create equal-height rows without specifying explicit row heights.
Quick Reference

Three Track Alignment Properties:

  • justify-content: Horizontal track alignment (left/right/center/distribute)
  • align-content: Vertical track alignment (top/bottom/center/distribute)
  • place-content: Shorthand for both (place-content: align justify)

When to Use Track Alignment:

  • Grid is smaller than container (fixed-size columns/rows with 1fr flexible areas)
  • Centering grids on large screens
  • Distributing grid space across container
  • Equal-height/equal-width track distribution

Common Values & Their Meanings:

  • start/end: Align to container edge
  • center: Center grid in container
  • stretch: Tracks expand to fill container
  • space-between: Space between tracks only
  • space-around: Even space around tracks (half at edges)
  • space-evenly: Equal space everywhere (including edges)
