CSS Pseudo-Classes

Practical Examples & Real-World Use Cases

Button Hover Effects

:hover

Interactive button with hover and active states.

button {
  transition: all 0.3s ease;
}

button:hover {
  background: #764ba2;
  transform: translateY(-2px);
  box-shadow: 0 5px 15px rgba(...);
}

button:active {
  transform: translateY(0);
}
Use Case: Interactive feedback for clickable buttons and controls.

Form Input Focus

:focus

Keyboard accessible form inputs with focus styling.

input:focus {
  outline: none;
  border-color: #667eea;
  box-shadow: 0 0 0 3px rgba(102,126,234,0.1);
  background: #f9f9f9;
}
Use Case: Keyboard navigation indication and accessibility.

Disabled Button States

:disabled

Visual distinction between enabled and disabled buttons.

button:not([disabled]) {
  background: #667eea;
  color: white;
  cursor: pointer;
}

button[disabled] {
  background: #ccc;
  cursor: not-allowed;
  opacity: 0.6;
}
Use Case: Form state management without JavaScript.

Is Selector Grouping

:is()

Apply same styles to multiple selectors at once.

Link 1 Link 2
/* Instead of button:hover, a:hover {} */
button:is(:hover, :focus),
a:is(:hover, :focus) {
  background: #764ba2;
  transform: scale(1.05);
}
Use Case: Reducing selector redundancy and improving readability.

Staggered Animation

:nth-child()

Animated list items with staggered delays.

  • Item 1 - Animates First
  • Item 2 - Animates Second
  • Item 3 - Animates Third
  • Item 4 - Animates Last
li {
  animation: slideIn 0.5s ease forwards;
}

li:nth-child(1) { animation-delay: 0s; }
li:nth-child(2) { animation-delay: 0.1s; }
li:nth-child(3) { animation-delay: 0.2s; }
li:nth-child(4) { animation-delay: 0.3s; }
Use Case: Visually pleasing sequential animations.

Pseudo-Classes Reference

Pseudo-Class Example What It Does
:hover button:hover User hovers over element
:focus input:focus Element receives keyboard focus
:active button:active Element is being clicked/activated
:checked input:checked Checkbox or radio is checked
:disabled button:disabled Form control is disabled
:first-child li:first-child First child element
:last-child li:last-child Last child element
:nth-child(n) li:nth-child(2n) Every nth child (even, odd, pattern)
:not(selector) p:not(.intro) All except matching selector
:is(selectors) :is(h1, h2, h3) Match any selector in list
:has(selector) div:has(img) Parent containing selector
:empty div:empty Element with no children

Key Takeaways

  • :hover, :focus, :active: Essential for user interaction and accessibility.
  • :first-child, :last-child: Perfect for edge element styling in lists and cards.
  • :nth-child(n): Powerful for patterns - use 2n for even, 2n+1 for odd, 3n for every 3rd.
  • :checked, :disabled: Form state styling without JavaScript.
  • :not(selector): Exclusion-based styling for cleaner CSS.
  • :is(), :where(): Simplify multiple selectors - :is() has specificity, :where() doesn't.
  • :has(selector): Modern parent selector - now supported in Chrome, Safari, Firefox.
  • :empty: Identify and style containers with no content.
  • Always include focus states: Essential for keyboard accessibility and WCAG compliance.
  • Combine with CSS animations: Use :nth-child() for staggered delays in list animations.
