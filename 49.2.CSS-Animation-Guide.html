CSS Animation Property

18 Practical Interactive Examples

1. Loading Spinner

Classic rotating loader

Uses: animation, @keyframes
Perfect for loading states and progress indicators. Uses simple rotation with linear timing.
@keyframes spin { 0% { transform: rotate(0deg); } 100% { transform: rotate(360deg); } } .spinner { animation: spin 1s linear infinite; }

2. Pulsing Button

Call-to-action animation

Uses: transform, box-shadow
Draws attention to interactive elements with scale and shadow effects. Great for CTAs.
@keyframes buttonPulse { 0%, 100% { box-shadow: 0 4px 15px rgba(..., 0.4); transform: scale(1); } 50% { box-shadow: 0 4px 25px rgba(..., 0.8); transform: scale(1.05); } }

3. Bouncing Ball

Physics-like bouncing motion

Uses: translateY easing
Simulates a ball bouncing with ease-in-out timing. Use for playful UI feedback.
@keyframes bounce { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(-100px); } } .bouncing-ball { animation: bounce 1.5s ease-in-out infinite; }

4. Sliding Text

Back and forth text movement

Uses: translateX
Text slides left and right smoothly. Perfect for headlines or status messages.
Slide Me!
@keyframes slideLeft { 0% { transform: translateX(0); } 50% { transform: translateX(100px); } 100% { transform: translateX(0); } } animation: slideLeft 4s ease-in-out infinite;

5. Fading In & Out

Opacity-based fade animation

Uses: opacity
Text fades in and out continuously. Great for emphasis or blinking effects.
Fade Me!
@keyframes fadeInOut { 0%, 100% { opacity: 0.3; } 50% { opacity: 1; } } animation: fadeInOut 2s ease-in-out infinite;

6. Rotating Icon

360-degree rotation

Uses: rotate
Perfect for spinning icons, loading states, or refresh buttons.
⚙️
@keyframes rotateIcon { 0% { transform: rotate(0deg); } 100% { transform: rotate(360deg); } } animation: rotateIcon 2s linear infinite;

7. Scaling Up & Down

Growing and shrinking effect

Uses: scale
Box grows and shrinks smoothly. Great for hover effects or attention grabbing.
@keyframes scaleUpDown { 0%, 100% { transform: scale(1); } 50% { transform: scale(1.3); } } animation: scaleUpDown 2s ease-in-out infinite;

8. Rainbow Colors

Color cycling animation

Uses: background-color
Box cycles through vibrant colors. Creates a playful, eye-catching effect.
@keyframes rainbowColors { 0% { background: #FF6B6B; } 20% { background: #FFA07A; } 40% { background: #FFD93D; } 60% { background: #6BCB77; } 80% { background: #4D96FF; } 100% { background: #9D84B7; } }

9. Floating Card

Smooth up and down motion

Uses: translateY
Card gently floats up and down. Perfect for hero sections and featured content.
🎈
Floating
@keyframes floating { 0%, 100% { transform: translateY(0px); } 50% { transform: translateY(-30px); } } animation: floating 3s ease-in-out infinite;

10. Shake Effect

Side-to-side vibration

Uses: translateX
Box shakes vigorously. Great for error alerts or emphasis.
@keyframes shake { 0%, 100% { transform: translateX(0); } 25% { transform: translateX(-10px); } 75% { transform: translateX(10px); } } animation: shake 0.5s ease-in-out infinite;

11. Typing Effect

Typewriter-like text reveal

Uses: steps(), width
Text appears one character at a time with blinking cursor. Great for intros.
Hello World!
@keyframes typing { 0% { width: 0; } 100% { width: 250px; } } animation: typing 4s steps(20, end) infinite, blink 0.75s step-end infinite;

12. Wave Bars

Music-like wave effect

Uses: animation-delay staggering
Bars move up and down in sequence. Perfect for audio players and loaders.
.wave-bar:nth-child(1) { animation-delay: 0s; } .wave-bar:nth-child(2) { animation-delay: 0.1s; } /* ... and so on */ @keyframes wave { 0%, 100% { height: 20px; } 50% { height: 80px; } }

13. Strobe Flash

On-off blinking effect

Uses: opacity steps
Box flashes on and off. Use sparingly for alerts or notifications.
@keyframes strobe { 0%, 49%, 100% { opacity: 1; } 50%, 99% { opacity: 0.2; } } animation: strobe 1s ease-in-out infinite;

14. 3D Card Flip

Rotating card transformation

Uses: rotateY, perspective
Card flips in 3D space. Combines animation with 3D transforms.
Front
Back
@keyframes flip { 0%, 100% { transform: rotateY(0deg); } 50% { transform: rotateY(180deg); } } animation: flip 2s ease-in-out infinite;

15. Zigzag Motion

Complex path animation

Uses: translate multiple keyframes
Box moves in a zigzag pattern. Shows multi-directional movement.
@keyframes zigzag { 0% { transform: translate(0, 0); } 25% { transform: translate(80px, 0); } 50% { transform: translate(80px, 80px); } 75% { transform: translate(0, 80px); } 100% { transform: translate(0, 0); } }

16. Cascading Items

Staggered animation sequence

Uses: animation-delay nth-child
Multiple items bounce with delays. Great for list animations and entrances.
.cascade-item:nth-child(1) { animation-delay: 0s; } .cascade-item:nth-child(2) { animation-delay: 0.15s; } /* ... staggered delays */ @keyframes cascadeDown { 0%, 100% { transform: translateY(0); } 50% { transform: translateY(60px); } }

17. Glow Effect

Animated box shadow

Uses: box-shadow animation
Box emits pulsing glow. Creates atmospheric and glowing effects.
@keyframes glow { 0%, 100% { box-shadow: 0 0 5px #667eea; } 50% { box-shadow: 0 0 30px #667eea, 0 0 50px #764ba2; } } animation: glow 2s ease-in-out infinite;

18. Expanding Ring

Ripple effect animation

Uses: scale + opacity
Rings expand outward with fading. Perfect for ripple or pulse effects.
@keyframes expandRing { 0% { transform: scale(0.3); opacity: 1; } 100% { transform: scale(1); opacity: 0; } } .ring:nth-child(n) { animation-delay: n*0.3s; }

Key Takeaways

✓ Use transform and opacity for best performance
✓ animation-delay creates staggered effects
✓ @keyframes defines animation steps
✓ animation-timing-function controls speed curves
✓ Combine multiple effects for complex animations
