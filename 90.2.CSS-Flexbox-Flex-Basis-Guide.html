Three columns with equal width, starting from zero base size.

CSS Code

Fixed sidebar with flexible main content area.

CSS Code

2-column grid that wraps responsively using calc() with flex-basis.

CSS Code

1️⃣2️⃣ Split Layout - 60/40 Ratio

60% main content, 40% sidebar using flex-basis percentages.

CSS Code
.split-left { flex: 1 1 calc(60% - 10px); } .split-right { flex: 1 1 calc(40% - 10px); }
Live Example

💡 Key Takeaways

Equal Width: Use flex: 1 1 0 for equal distribution from zero base
Minimum Width: Use flex: 1 1 200px to set minimum item size
Fixed + Flexible: Mix flex-basis values for different item behaviors
Responsive Grids: Use calc() with flex-basis: calc(25% - 15px)
Percentage Layouts: Use percentages for proportional sizing
Auto Sizing: Use flex: 1 1 auto for content-driven sizing
🎯 Pro Tip: Combine flex-basis with gap and min-width for robust responsive layouts
✅ Remember: flex-basis is the starting point; flex-grow/shrink modifies from there!
