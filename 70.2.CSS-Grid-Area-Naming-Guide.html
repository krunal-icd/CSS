1. Blog Layout with Grid Areas

Two-column blog with header, posts, sidebar, and footer using grid-template-areas

.blog-layout { grid-template-columns: 1fr 250px; grid-template-rows: 80px 1fr 60px; grid-template-areas: "blog-header blog-header" "blog-posts blog-sidebar" "blog-footer blog-footer"; } .blog-header { grid-area: blog-header; } .blog-posts { grid-area: blog-posts; } .blog-sidebar { grid-area: blog-sidebar; } .blog-footer { grid-area: blog-footer; }
