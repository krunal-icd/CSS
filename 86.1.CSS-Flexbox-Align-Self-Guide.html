🎯 CSS Flexbox Align-Self Tutorial

Override align-items for individual flex items with precision control

What is Align-Self?

align-self is a CSS property that allows individual flex items to override the container's align-items setting. It lets you align a specific item differently from its siblings along the cross axis.

While align-items applies the same alignment to all items in a flex container, align-self provides item-level control.

💡 Key Point: Align-self works on individual flex items, not the container. Apply it directly to the item you want to position differently.
/* Applied to individual items */ .flex-container { display: flex; align-items: center; /* Default for all items */ } .item-3 { align-self: flex-end; /* This item only */ }

All Align-Self Values

Value Description
auto Use the container's align-items value (default)
stretch Item stretches to fill the cross axis
flex-start Item aligns to the start of the cross axis
flex-end Item aligns to the end of the cross axis
center Item centers on the cross axis
baseline Item aligns to text baseline

Detailed Explanations

📌 auto

This is the default value. The item uses whatever alignment is set on the container's align-items property.

.item { align-self: auto; /* Inherits from align-items */ }
Use case: Explicitly resetting an item back to container's default alignment

📌 stretch

The item stretches to fill the available space on the cross axis. Great for dynamic sizing.

.item { align-self: stretch; /* Item grows to fill container height */ }
Use case: Making one item full height while others remain normal size

📌 flex-start

The item aligns to the start of the cross axis (top in row direction).

.item { align-self: flex-start; /* Aligns to top */ }
Use case: Positioning specific items at the top of a centered row

📌 flex-end

The item aligns to the end of the cross axis (bottom in row direction).

.item { align-self: flex-end; /* Aligns to bottom */ }
Use case: Right-aligning icons or elements to bottom of container

📌 center

The item centers itself on the cross axis. Perfect for precise centering.

.item { align-self: center; /* Centers vertically */ }
Use case: Centering a single item that needs different alignment than siblings

📌 baseline

The item aligns based on its text baseline. Useful for text alignment.

.item { align-self: baseline; /* Text baselines align */ }
Use case: Aligning text items of different sizes along their baseline

Align-Self vs Align-Items

Understand how align-self overrides align-items:

Property Applied To Scope Specificity
align-items Container All children (unless overridden) Lower (can be overridden)
align-self Individual item Only that item Higher (overrides align-items)

Example:

.container { display: flex; align-items: center; /* All items center */ } .item-2 { align-self: flex-end; /* Only item 2 goes to bottom */ } /* Result: Item 1 and 3 are centered, Item 2 is at bottom */

Common Layout Patterns

🎨 Header with Aligned Items

.header { display: flex; align-items: center; height: 60px; } .header-logo { align-self: flex-start; /* Logo at top */ } .header-nav { align-self: center; /* Nav centered */ } .header-button { align-self: flex-end; /* Button at bottom */ }

🎨 Sidebar with Mixed Alignment

.sidebar { display: flex; flex-direction: column; align-items: stretch; } .sidebar-header { align-self: flex-start; } .sidebar-content { align-self: stretch; } .sidebar-footer { align-self: flex-end; }

🎨 Card Container with Varied Heights

.card-row { display: flex; align-items: flex-start; gap: 20px; } .featured-card { align-self: stretch; /* Takes full height */ } .regular-card { align-self: flex-start; /* Normal height */ }

🎨 Form with Varied Input Heights

.form-row { display: flex; align-items: center; } .form-input { align-self: center; /* Normal inputs centered */ } .form-textarea { align-self: flex-start; /* Textarea aligned top */ }

Important Tips & Best Practices

✓ Only Works on Flex Items: Align-self only applies to direct children of a flex container. Ensure the parent has display: flex.
✓ Overrides Container Setting: Any align-self value (except auto) overrides the container's align-items setting for that specific item.
⚠ Not for Main Axis: Align-self only controls cross-axis alignment. For main-axis control per item, use justify-self (limited support) or margin manipulation.
✓ Works with Both Directions: Align-self works with both flex-direction: row and flex-direction: column.
✓ Combine with Margins: Use margin: auto with align-self for advanced positioning control.
⚠ Auto Property: The default value is auto, which means "use the container's align-items value." Use it to reset items explicitly.

Real-World Use Cases

💼 Navigation Bar: Logo at top, nav centered, auth button at bottom
📱 Card Row: Featured card stretches while others remain normal height
📝 Form Layout: Short inputs centered, textarea aligned to top
🎯 UI Components: Button groups with varied heights per item

Browser Support

align-self is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.item { display: flex; align-self: center; /* No vendor prefixes needed for modern browsers */ }
