CSS :is() Pseudo-Class

12 Practical Examples • Selector Simplification

1. Multiple Heading Levels

Headings

Apply same styles to multiple heading levels using :is() instead of repetitive selectors.

Heading 1

Heading 2

Heading 3

/* Without :is() - repetitive */ h1, h2, h3 { color: #667eea; } /* With :is() - cleaner */ :is(h1, h2, h3) { color: #667eea; }

2. Form Input Elements

Form

Style all form inputs consistently with :is(). Try focusing on inputs to see the effect.

/* All form elements at once */ :is(input, textarea, select) { padding: 10px; border: 2px solid #e0e0e0; border-radius: 6px; } :is(input, textarea, select):focus { border-color: #667eea; }

3. Button & Link Styling

Interactive

Unify button and link styling with :is(). Hover over them to see the effect.

Link Button
/* Style both buttons and links together */ :is(button, a.btn) { padding: 12px 24px; background: #667eea; color: white; } :is(button, a.btn):hover { background: #764ba2; }

4. Combined Pseudo-Classes

Pseudo-classes

Apply hover, focus, and active effects to multiple elements. Interact to see changes.

Hover me!
I'm a card
Interact with me
/* Multiple pseudo-classes with :is() */ :is(.item, .card, .panel):is(:hover, :focus) { box-shadow: 0 8px 24px rgba(102, 126, 234, 0.2); transform: translateY(-3px); }

5. List Styling

Lists

Apply consistent styling to both ordered and unordered lists with :is().

  • First item
  • Second item
  • Third item
  1. First step
  2. Second step
  3. Third step
/* Style both ul and ol */ :is(ul, ol) { list-style: none; } :is(ul, ol) li { padding-left: 25px; position: relative; }

6. Text Content Styling

Text

Consistent styling for different text elements with :is().

Regular paragraph with bold text and emphasis

Span text with highlighted content
/* Group text elements */ :is(p, span, div) { line-height: 1.6; color: #333; } :is(strong, em, .highlight) { color: #667eea; }

7. Nested Context Styling

Nesting

Simplify context-specific styling. Elements in header, nav, footer all styled together.

Header Link
Nav Link
Footer Link
/* Without :is() - very repetitive */ header a, header button, nav a, nav button, footer a, footer button { color: white; } /* With :is() - one line! */ :is(header, nav, footer) :is(a, button) { color: white; }

8. Multiple Input Types

Form Inputs

Target specific input types with :is() for cleaner selectors.

/* Group input types */ :is([type="text"], [type="email"], [type="tel"]) { width: 100%; padding: 10px; border: 2px solid #e0e0e0; } :is([type="text"], [type="email"], [type="tel"]):focus { border-color: #667eea; }

9. Pseudo-Class Combinations

Interactive

Combine multiple pseudo-classes elegantly. Interact with items to see changes.

Link 1 Span Item
/* Combine multiple pseudo-classes */ :is(a, button, .link):is(:hover, :focus, :active) { color: #764ba2; text-decoration: underline; transform: scale(1.05); }

10. Featured Content Highlighting

Conditions

Target featured or highlighted content within specific sections using :is().

This is featured content
This is highlighted content
/* Highlight featured or highlighted items */ :is(article, section) :is(.featured, .highlighted) { background: #fff3cd; border-left: 4px solid #ffc107; padding: 15px; }

11. Attribute-Based Priority

Attributes

Style elements based on data attributes using :is() for multiple attribute values.

Critical Priority
High Priority
Medium Priority
Low Priority
/* Group attribute selectors */ :is([data-priority="high"], [data-priority="critical"]) { border: 2px solid #dc3545; background: #ffebee; } :is([data-priority="medium"]) { border: 2px solid #fd7e14; }

12. Complex Nested Selectors

Complex

Deeply nested selectors become much simpler with multiple :is() combinations.

Article Title

Article content goes here with consistent styling.

Section Title

Section content styled the same way.
/* Without :is() - very verbose */ main article header h2, main article .intro h3, main section header h2, main section .intro h3 { color: #667eea; } /* With :is() - clean and readable */ main :is(article, section) :is(header, .intro) :is(h2, h3) { color: #667eea; }
