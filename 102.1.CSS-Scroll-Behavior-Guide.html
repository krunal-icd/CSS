What is scroll-behavior?

The scroll-behavior CSS property specifies how the browser should behave when navigating to a target element via anchor links or the scrollIntoView() JavaScript method. It controls whether scrolling happens instantly or animates smoothly over a duration.

Core Concept:

  • Controls scrolling animation when jumping to anchors (#id)
  • Works with both HTML anchor navigation and JavaScript scrollIntoView()
  • Applies to the root element (html) for document-level scrolling
  • Can be set on individual scrollable containers (overflow elements)
  • Creates smooth user experience without JavaScript libraries
  • Respects user's motion preferences (prefers-reduced-motion)
Browser Support: Modern browsers (Chrome 61+, Firefox 36+, Safari 15.4+, Edge 79+). Requires fallback for older browsers.

Property Values

auto (Default)

Instant scrolling without animation. Navigation jumps directly to target.

html { scroll-behavior: auto; /* Jump instantly to target */ } /* Result: Immediate navigation to anchor, no animation */

smooth

Animated scrolling. Navigation smoothly animates to target over browser-determined duration.

html { scroll-behavior: smooth; /* Smooth animated scrolling */ } /* Result: Animated navigation with easing */

Using scroll-behavior in CSS

/* Apply to entire document */ html { scroll-behavior: smooth; } /* Apply to specific scrollable container */ .scrollable-container { scroll-behavior: smooth; height: 500px; overflow-y: auto; } /* Disable animation for users with motion sensitivity */ @media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto; } }

Combining with JavaScript

/* CSS enables smooth scrolling */ html { scroll-behavior: smooth; } /* JavaScript scrollIntoView() respects the CSS property */ const element = document.getElementById('target'); element.scrollIntoView(); /* Uses smooth behavior from CSS */ /* JavaScript can override with options */ element.scrollIntoView({ behavior: 'smooth', /* or 'auto' */ block: 'start' /* or 'center', 'end', 'nearest' */ });

Common Use Cases

Table of Contents Navigation

Smooth scrolling from table of contents links to document sections.

html { scroll-behavior: smooth; } /* TOC links scroll smoothly to sections */ <a href="#section-1">Section 1</a> <a href="#section-2">Section 2</a> <section id="section-1">...</section> <section id="section-2">...</section>
Navigation

"Back to Top" Button

Smooth scrolling animation when returning to page top.

html { scroll-behavior: smooth; } /* Button scrolls smoothly to top */ <a href="#top" class="back-to-top">↑ Back to Top</a> <html id="top">
UX Enhancement

Single Page Application Navigation

Smooth scrolling between different page sections in SPAs.

html { scroll-behavior: smooth; } /* Anchor navigation in single page app */ router.navigate('/page#section-1'); /* Smooth scroll applied automatically */

Smooth scrolling within overflow containers.

Best Practices

✓ DO:

  • Enable smooth scrolling globally: Apply to html for site-wide effect
  • Respect motion preferences: Use @media (prefers-reduced-motion: reduce)
  • Combine with scroll-snap: Create snapping and smooth behavior together
  • Provide visual feedback: Highlight active navigation sections
  • Use meaningful anchors: IDs should clearly describe targets
  • Test on multiple browsers: Verify support and behavior consistency
  • Consider performance: Usually minimal impact, but test heavy pages

✗ DON'T:

  • Ignore accessibility: Respect prefers-reduced-motion media query
  • Override user preferences: Don't force smooth on users who want auto
  • Combine with auto-scroll scripts: May conflict with user expectations
  • Use on pages with extensive content jumping: Can cause disorientation
  • Forget fallback for older browsers: Provide meaningful experience in IE 11
  • Mix smooth and auto inconsistently: Use unified approach across site

JavaScript Integration

scrollIntoView() Method

Programmatically scroll elements into view with smooth animation:

/* Basic scrollIntoView - uses CSS scroll-behavior */ const element = document.getElementById('target'); element.scrollIntoView(); /* With behavior options */ element.scrollIntoView({ behavior: 'smooth', /* or 'auto' */ block: 'start', /* or 'center', 'end', 'nearest' */ inline: 'nearest' /* or 'start', 'center', 'end' */ }); /* Example: Scroll item to center */ document.getElementById('item-5').scrollIntoView({ behavior: 'smooth', block: 'center' });

scroll() Method with options

/* Smooth scroll to position */ window.scroll({ top: 1000, behavior: 'smooth' }); /* Scroll container smoothly */ const container = document.querySelector('.scrollable'); container.scroll({ left: 500, top: 0, behavior: 'smooth' });

Intersection Observer for Animation Triggers

Combine scroll-behavior with Intersection Observer for enhanced effects:

const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { entry.target.classList.add('in-view'); } }); }); document.querySelectorAll('.animate-on-scroll').forEach(element => { observer.observe(element); });

Accessibility & Motion Preferences

Respecting prefers-reduced-motion

Important for users with vestibular disorders or motion sensitivity:

/* Default: smooth scrolling enabled */ html { scroll-behavior: smooth; } /* Respect user's motion sensitivity preference */ @media (prefers-reduced-motion: reduce) { html { scroll-behavior: auto; } } /* Also apply to other animations */ @media (prefers-reduced-motion: reduce) { * { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; } }

Testing Motion Preferences

Detect user preferences in JavaScript:

const prefersReducedMotion = window.matchMedia( '(prefers-reduced-motion: reduce)' ).matches; if (prefersReducedMotion) { // Use auto scrolling behavior document.documentElement.style.scrollBehavior = 'auto'; } else { // Use smooth scrolling document.documentElement.style.scrollBehavior = 'smooth'; }

Key Takeaways

  • Two Values: auto (default) for instant scrolling, smooth for animated scrolling
  • Global Scope: Apply to html element for document-level smooth scrolling
  • Container Scope: Apply to individual overflow elements for local smooth scrolling
  • Anchor Navigation: Works automatically with href="#id" links
  • JavaScript Integration: scrollIntoView() and scroll() methods respect CSS property
  • Accessibility Critical: Always respect prefers-reduced-motion for user health
  • Modern Browser Support: Available in all modern browsers, graceful fallback in older ones
  • Performance Impact: Minimal - just animation easing on navigation
