CSS Animation-Fill-Mode

12 Practical Interactive Examples

1. Button Click Effect

forwards fill-mode

fill-mode: forwards
Button scales and stays enlarged briefly, then resets. Stays in final animated state until page reloads.
animation: buttonBounce 0.6s ease-out 1 forwards; @keyframes buttonBounce { 0% { transform: scale(1); } 50% { transform: scale(1.08); } 100% { transform: scale(1.05); } }
Click the button multiple times to see the effect. Animation maintains final state.

2. Slide-In Menu

forwards fill-mode

fill-mode: forwards
Menu slides in from left and stays in final position. Perfect for navigation reveals.
Menu
animation: slideInLeft 0.6s ease-out 1 forwards; @keyframes slideInLeft { 0% { transform: translateX(-200px); opacity: 0; } 100% { transform: translateX(0); opacity: 1; } }
Menu slides in and stays visible permanently.

3. Fade with Delay

backwards fill-mode

fill-mode: backwards
Content starts invisible (0% opacity), fades in after 2s delay. Visible during delay thanks to backwards.
Content
animation: fadeInBackwards 1s ease-in 2s 1 backwards; @keyframes fadeInBackwards { 0% { opacity: 0; } 100% { opacity: 1; } }
Watch the delay: backwards keeps opacity at 0% during the 2s wait.

4. Modal Popup

both fill-mode

fill-mode: both
Modal starts small, scales up after 1s delay, and stays enlarged. Uses both for full control.
Modal
animation: modalScaleIn 0.5s ease-out 1s 1 both; @keyframes modalScaleIn { 0% { transform: scale(0.7); opacity: 0; } 100% { transform: scale(1); opacity: 1; } }
Modal stays small during 1s delay, then scales up and stays enlarged.

5. Loading Spinner

none fill-mode (infinite)

fill-mode: none
Spinner rotates infinitely. None fill-mode allows continuous looping without state persistence.
animation: spin 1s linear infinite none; @keyframes spin { 0% { transform: rotate(0deg); } 100% { transform: rotate(360deg); } }
Runs infinitely. None is perfect for continuous animations.

6. Text Reveal

forwards fill-mode

fill-mode: forwards
Text fades in and slides up, then stays visible permanently. Great for page load effects.
Hello!
animation: textReveal 1s ease-in-out 0.5s 1 forwards; @keyframes textReveal { 0% { opacity: 0; transform: translateY(20px); } 100% { opacity: 1; transform: translateY(0); } }
Text reveals with delay and remains visible.

7. Sequential List Items

both fill-mode (staggered)

fill-mode: both + animation-delay
List items appear one by one with staggered delays. Both ensures each item stays visible.
Item 1
Item 2
Item 3
animation: listItemFade 0.5s ease-out both; .list-item:nth-child(1).animate { animation-delay: 0s; } .list-item:nth-child(2).animate { animation-delay: 0.15s; } .list-item:nth-child(3).animate { animation-delay: 0.3s; }
Each item fades in with delay and stays visible.

8. Growing Box

forwards fill-mode

fill-mode: forwards
Box grows larger smoothly and remains at final size. Great for progressive reveals.
animation: grow 1.5s ease-out 0.5s 1 forwards; @keyframes grow { 0% { width: 80px; height: 80px; } 100% { width: 140px; height: 140px; } }
Box grows and stays enlarged.

9. Hidden Until Animation

backwards fill-mode

fill-mode: backwards
Element stays hidden during 2s delay, then appears. Backwards prevents early visibility.
animation: appear 0.8s ease-out 2s 1 backwards; @keyframes appear { 0% { opacity: 0; transform: scale(0.5); } 100% { opacity: 1; transform: scale(1); } }
Element stays hidden for 2s delay, then appears.

10. Infinite Pulse

none fill-mode (infinite)

fill-mode: none
Box pulses continuously. None fill-mode perfect for infinite repeating animations.
animation: pulse 1.5s ease-in-out infinite none; @keyframes pulse { 0%, 100% { transform: scale(1); opacity: 1; } 50% { transform: scale(1.15); opacity: 0.7; } }
Continuous pulse animation. None allows infinite looping.

11. Bar Chart Animation

both fill-mode (staggered)

fill-mode: both + nth-child delays
Bars grow sequentially with staggered delays. Both ensures they stay at final height.
animation: barGrow 0.6s ease-out both; .bar:nth-child(n).animate { animation-delay: n*0.15s; } @keyframes barGrow { 0% { height: 20px; } 100% { height: 100px; } }
Each bar grows with delay and stays at final height.

12. Color Transition

forwards fill-mode

fill-mode: forwards
Box transitions through colors and stops at final color. Great for status indicators.
animation: colorShift 2s ease-in-out 1s 1 forwards; @keyframes colorShift { 0% { background: #667eea; } 50% { background: #764ba2; } 100% { background: #f5576c; } }
Box changes color and stays at final color (pink).

Quick Reference Guide

fill-mode: none → No persistence (use for infinite)
fill-mode: forwards → Stays in final state (most common)
fill-mode: backwards → Applies first frame before animation
fill-mode: both → Full control before and after

✓ Use forwards for one-time animations
✓ Use none for infinite/looping
✓ Use both with animation-delay for precision
✓ Use backwards with delays to prevent initial jumps
