📏 CSS Flexbox Align-Items Tutorial

Master alignment along the cross axis of flex containers

What is Align-Items?

align-items is a CSS property that aligns flex items along the cross axis of a flex container. It controls vertical alignment (by default) or horizontal alignment when the flex direction is column.

While justify-content aligns items along the main axis, align-items handles alignment perpendicular to the main axis.

Default Flex Direction (row):
↔ Main Axis (justify-content)
↕ Cross Axis (align-items)
Column Direction:
↕ Main Axis (justify-content)
↔ Cross Axis (align-items)
/* Basic Syntax */ .flex-container { display: flex; align-items: center; }

All Align-Items Values

Value Description
stretch Items stretch to fill the container (default)
flex-start Items align to the start of the cross axis
flex-end Items align to the end of the cross axis
center Items center along the cross axis
baseline Items align to their text baseline

Detailed Explanations

📌 stretch

This is the default value. All flex items stretch to fill the height of the flex container (in row direction).

.container { display: flex; align-items: stretch; height: 200px; }
Use case: Navigation menus where all items should be the same height

📌 flex-start

All flex items are aligned to the start of the cross axis (top when in row direction).

.container { display: flex; align-items: flex-start; }
Use case: Image galleries where items should align to the top

📌 flex-end

All flex items are aligned to the end of the cross axis (bottom when in row direction).

.container { display: flex; align-items: flex-end; }
Use case: Footer items that should align to the bottom

📌 center

All flex items are centered along the cross axis. Perfect for perfect vertical centering!

.container { display: flex; align-items: center; height: 300px; }
Use case: Centering icons and text together, hero sections, card layouts

📌 baseline

All flex items are aligned such that their baselines align. Useful for typography.

.container { display: flex; align-items: baseline; } /* Different font sizes will align at baseline */
Use case: Text with different font sizes, icon + text combinations

Justify-Content vs Align-Items

These two properties work together but control different directions:

Property Axis Default Direction Common Values
justify-content Main Axis Horizontal (→) flex-start, flex-end, center, space-between, space-around, space-evenly
align-items Cross Axis Vertical (↓) stretch, flex-start, flex-end, center, baseline
✓ Perfect Centering: Combine both properties: justify-content: center; and align-items: center;

Common Layout Patterns

🎨 Perfect Vertical & Horizontal Centering

.container { display: flex; justify-content: center; /* horizontal */ align-items: center; /* vertical */ height: 400px; }

🎨 Card with Icon and Text

.card { display: flex; align-items: center; gap: 15px; } .card-icon { font-size: 2em; }

🎨 Navigation Bar with Vertical Center

.navbar { display: flex; justify-content: space-between; align-items: center; height: 60px; }

🎨 Equal Height Cards in Grid

.card-container { display: flex; align-items: stretch; /* makes all cards same height */ } .card { flex: 1; }

🎨 Form with Input and Button

.form-row { display: flex; align-items: center; gap: 10px; } input, button { padding: 10px; }

Important Tips & Best Practices

✓ Cross Axis Only: Align-items only affects the cross axis. Its behavior depends on the flex direction.
🔄 Direction Matters: In flex-direction: row, align-items controls vertical alignment. In flex-direction: column, it controls horizontal alignment.
✓ Default is Stretch: Unlike justify-content (default flex-start), align-items defaults to stretch, making items fill the cross axis.
✓ Container Must Have Size: For align-items to work, the flex container must have a defined size on the cross axis (e.g., height for row direction).
⚠ Baseline is Text-Based: The baseline value aligns items based on their text baseline, not their edge. Items with different font sizes will appear at different vertical positions.
✓ Individual Control: Use align-self on individual flex items to override the container's align-items setting.

Real-World Use Cases

💼 Example 1: Search Bar
.search-bar { display: flex; align-items: center; gap: 10px; background: #f0f0f0; padding: 10px; } /* All items (icon, input, button) are vertically centered */
💼 Example 2: Team Member Cards
.team-card { display: flex; align-items: center; gap: 20px; } .avatar { width: 60px; height: 60px; } /* Avatar and name/bio are vertically centered */
💼 Example 3: Alert Message
.alert { display: flex; align-items: center; gap: 15px; padding: 15px; background: #e3f2fd; } /* Icon is vertically centered with text */
💼 Example 4: Price Tag
.price-tag { display: flex; align-items: baseline; gap: 5px; } .currency { font-size: 0.8em; } .amount { font-size: 2em; } /* Currency and amount align at text baseline */

Bonus: Align-Self Property

Override the container's align-items setting for individual items using align-self:

.container { display: flex; align-items: center; height: 200px; } .item-3 { align-self: flex-end; /* This item aligns to bottom */ }
Use case: When most items should be centered, but one or two need different alignment

Browser Support

align-items is supported in all modern browsers including Chrome, Firefox, Safari, Edge, and Internet Explorer 11+. It's a core flexbox feature with excellent cross-browser compatibility.

.container { display: flex; align-items: center; /* Usually no vendor prefixes needed */ }
