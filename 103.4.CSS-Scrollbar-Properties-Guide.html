CSS Scrollbar Properties

Master scrollbar-color, scrollbar-width, and scrollbar-gutter

scrollbar-color

Controls the colors of the scrollbar thumb and track. Only works with the scrollbar-width property.

Syntax

scrollbar-color: track-color | thumb-color;

Values

  • track-color: Background color of the scrollbar track
  • thumb-color: Color of the scrollable thumb
  • auto: Default browser colors (default)

scrollbar-width

Sets the thickness of the scrollbar. Works with standard scrollbars only, not webkit pseudo-elements.

Syntax

scrollbar-width: auto | thin | none;

Values

  • auto: Default scrollbar width (usually 15-17px) (default)
  • thin: Thin scrollbar (usually 8-12px)
  • none: Scrollbar is hidden but content is still scrollable

Example: Thin Scrollbar

scrollbar-width: thin;

This scrollbar is set to 'thin'. Notice how it takes up less space compared to the default width.

⚠️ Warning: Using scrollbar-width: none removes the scrollbar but keeps the element scrollable. This can make navigation less obvious to users. Consider usability!

scrollbar-gutter

Reserves space for the scrollbar, preventing content shift when scrollbars appear/disappear.

Syntax

scrollbar-gutter: auto | stable;

Values

  • auto: Scrollbar space taken from content when needed (default)
  • stable: Always reserves space for scrollbar, prevents layout shift
  • stable both-edges: Reserves space on both sides (not widely supported)

Example: auto (Content Shifts)

scrollbar-gutter: auto; (Default Behavior)

Notice: When you scroll, the content may shift horizontally as the scrollbar appears.

This happens because the scrollbar takes up space from the content width when it appears.

Example: stable (No Content Shift)

The scrollbar-gutter property ensures a fixed layout, improving user experience.

Practical Implementation Guide

Example 1: Complete Custom Scrollbar

div {
  scrollbar-width: thin;
  scrollbar-color: #667eea #f0f0f0;
  overflow-y: scroll;
}

Example 2: Prevent Layout Shift

body {
  scrollbar-gutter: stable;
}

Example 3: Dark Mode Scrollbar

html {
  scrollbar-color: #888 #222;
  scrollbar-width: thin;
}

/* Fallback for webkit browsers */
::-webkit-scrollbar {
  width: 10px;
}
::-webkit-scrollbar-track {
  background: #222;
}
::-webkit-scrollbar-thumb {
  background: #888;
}
ℹ️ Tip: Combine scrollbar-color/scrollbar-width with webkit pseudo-elements for broader browser compatibility across all scrollbar customization needs.

Best Practices & Tips

✅ Do:

  • Use scrollbar-gutter: stable on main container to prevent layout shift
  • Ensure good contrast between thumb and track colors for accessibility
  • Test across different browsers for consistency
  • Combine CSS scrollbar properties with webkit fallbacks
  • Use thin scrollbars for modern, minimal designs

❌ Don't:

  • Use scrollbar-width: none without providing an alternative for scrolling indication
  • Create low-contrast scrollbars that are hard to see
  • Assume webkit properties work everywhere (always use standard CSS fallback)
  • Hide scrollbars on touch devices without alternative scroll indicators
  • Make scrollbars too thin for comfortable interaction
♿ Accessibility Note: Always ensure scrollbars are visible and easily recognizable. People with motor impairments may need larger, more visible scrollbars. Consider user preferences!
