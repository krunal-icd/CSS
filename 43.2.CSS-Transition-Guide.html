CSS Transition Properties: Practical Examples

Real-world implementations of CSS transitions. Discover 10 practical patterns for creating smooth, professional animations with hover effects and state changes.

Example 1: Button Hover Effects

Professional button animations with smooth elevation and color transitions on hover.

HTML & CSS

<button class="btn">Hover Me</button>
.btn { padding: 1rem 2rem; border: none; border-radius: 8px; font-size: 1em; font-weight: 600; cursor: pointer; transition: all 0.3s ease; background: linear-gradient(135deg, #667eea, #764ba2); color: white; } .btn:hover { transform: translateY(-2px); box-shadow: 0 8px 16px rgba(0, 0, 0, 0.2); background: linear-gradient(135deg, #764ba2, #f093fb); } .btn:active { transform: translateY(0); }
Key Technique: Combine transform: translateY() for elevation with box-shadow for depth. Use all 0.3s ease for smooth multi-property animation.

Smooth color and underline transitions for links with two different effects.

CSS Link Transitions

/* Simple color transition */ .link { color: #667eea; text-decoration: none; border-bottom: 2px solid transparent; transition: all 0.3s ease; display: inline-block; } .link:hover { color: #764ba2; border-bottom-color: #764ba2; } /* Animated underline effect */ .link-underline::after { content: ''; position: absolute; width: 100%; height: 2px; background: #764ba2; bottom: 0; left: -100%; transition: left 0.3s ease; } .link-underline:hover::after { left: 0; }

CSS Staggered Transition

.stagger-item { transition: all 0.3s ease; } .stagger-item:nth-child(1) { transition-delay: 0s; } .stagger-item:nth-child(2) { transition-delay: 0.1s; } .stagger-item:nth-child(3) { transition-delay: 0.2s; } .stagger-item:nth-child(4) { transition-delay: 0.3s; } .stagger-demo:hover .stagger-item { transform: translateY(-10px); }
Technique: Use transition-delay with nth-child() selectors to create wave-like staggered effects without JavaScript.

CSS Size Transition

.size-box { width: 100px; height: 100px; background: linear-gradient(135deg, #667eea, #764ba2); border-radius: 8px; transition: all 0.3s ease; cursor: pointer; } .size-box:hover { width: 120px; height: 120px; }
Performance Note: Size transitions trigger layout recalculation. For better performance on many elements, consider using transform: scale() instead.

CSS Multi-Property Transition

.complex-card { transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1); cursor: pointer; } .complex-header { height: 100px; background: linear-gradient(135deg, #667eea, #764ba2); transition: all 0.4s ease; } .complex-body { opacity: 1; transition: opacity 0.3s ease 0.1s; } .complex-card:hover { transform: translateY(-8px); box-shadow: 0 12px 24px rgba(0, 0, 0, 0.15); } .complex-card:hover .complex-header { background: linear-gradient(135deg, #764ba2, #f093fb); height: 120px; }
Advanced Technique: Stagger delays between properties (opacity: 0.3s ease 0.1s) to create complex choreographed animations while keeping the code maintainable.

Best Practices Summary

Scenario Recommended Transition Duration
Button hover all 0.3s ease 0.3s
Card lift all 0.3s cubic-bezier(0.4, 0, 0.2, 1) 0.3s
Link underline all 0.3s ease 0.3s
Menu expand max-height 0.3s ease 0.3s
Fade in/out opacity 0.3s ease 0.3s
Staggered items all 0.3s ease + delay 0.3s + 0.1s increments

Key Takeaways

  • ✓ Fast is Better: Use 0.2s-0.4s for most interactions to feel responsive
  • ✓ Choose Transform Over Position: Animate transform instead of left/top for better performance
  • ✓ Use ease-in-out Default: Works well for most animations
  • ✓ Combine Properties: Multiple properties transitioning together create polished effects
  • ✓ Respect User Preferences: Always use @media (prefers-reduced-motion: reduce)
  • ✓ Delay for Effect: Small delays (0.1s increments) create professional staggered animations
  • ✓ Test on Real Devices: Smoothness depends on device capabilities

Accessibility: Respecting User Motion Preferences

Always respect the prefers-reduced-motion media query for users with vestibular disorders or motion sensitivity:

/* Default transitions enabled */ button { transition: all 0.3s ease; } /* Respect user's motion preference */ @media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation-duration: 0.01ms !important; animation-iteration-count: 1 !important; transition-duration: 0.01ms !important; } }
Note: The code above is already included in this page. Users with motion preferences will see minimal transitions.
