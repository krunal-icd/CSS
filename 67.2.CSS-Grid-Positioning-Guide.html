2. Hero Section with Full-Width Item

Hero spans all columns using grid-column: 1 / -1 for responsive full-width coverage

.hero { grid-column: 1 / -1; /* Spans all columns */ grid-row: 1; } .hero-content { grid-row: 2; }

5. Item Alignment with justify-self & align-self

Demonstrating how justify-self and align-self position items within their cells

.align-start { justify-self: start; /* Left */ align-self: start; /* Top */ } .align-center { justify-self: center; /* Center horizontally */ align-self: center; /* Center vertically */ } .align-end { justify-self: end; /* Right */ align-self: end; /* Bottom */ } .align-stretch { justify-self: stretch; /* Fill width */ align-self: stretch; /* Fill height */ }

6. Named Grid Areas Layout

Semantic layout using grid-area with grid-template-areas for readable positioning

.named-grid { grid-template-areas: "header header header" "sidebar main rightbar" "footer footer footer"; } .named-header { grid-area: header; } .named-sidebar { grid-area: sidebar; } .named-main { grid-area: main; } .named-rightbar { grid-area: rightbar; } .named-footer { grid-area: footer; }

7. Overlapping Items with z-index

Items overlap using positioning, stacking order controlled with z-index

.overlap-1 { grid-column: 1 / 3; grid-row: 1 / 3; z-index: 1; } .overlap-2 { grid-column: 2 / 4; grid-row: 2 / 4; z-index: 2; /* Appears on top */ }

8. Masonry-like Layout with grid-auto-flow: dense

Items with different sizes fill spaces efficiently using dense auto-flow

.masonry-grid { grid-auto-flow: dense; } .masonry-item.wide { grid-column: span 2; } .masonry-item.tall { grid-row: span 2; } .masonry-item.big { grid-column: span 2; grid-row: span 2; }

9. Responsive Grid Repositioning

Items change positioning at breakpoints using media queries

.responsive-pos-grid { display: grid; grid-template-columns: 1fr 1fr; gap: 20px; } .item-full { grid-column: 1 / -1; /* Full width on all sizes */ } @media (max-width: 768px) { .responsive-pos-grid { grid-template-columns: 1fr; } }

Parent grid positions major sections, child grids position their own content
