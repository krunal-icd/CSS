CSS Grid: Auto-Fill & Auto-Fit

Master responsive grid layouts without media queries

Understanding Auto-Fill vs Auto-Fit
The Quick Explanation
auto-fill: Creates as many columns/rows as will fit in the container, even if they're empty (creates implicit tracks).

auto-fit: Creates as many columns/rows as needed for your items, then collapses empty tracks to zero width/height.
When They Look Different
With 4 items and space for 5 columns: auto-fill: Creates 5 columns (4 filled + 1 empty) ┌────┬────┬────┬────┬────┐ │ A │ B │ C │ D │ │ ← Empty column still exists └────┴────┴────┴────┴────┘ auto-fit: Creates 4 columns (collapses the empty one) ┌────┬────┬────┬────┐ │ A │ B │ C │ D │ └────┴────┴────┴────┘ (Items stretch to fill space)
When They Look The Same
With 6 items and space for 6 columns: auto-fill: Creates 6 columns (all filled) ┌────┬────┬────┬────┬────┬────┐ │ A │ B │ C │ D │ E │ F │ └────┴────┴────┴────┴────┴────┘ auto-fit: Creates 6 columns (all filled) ┌────┬────┬────┬────┬────┬────┐ │ A │ B │ C │ D │ E │ F │ └────┴────┴────┴────┴────┴────┘ (Identical! Both fill completely)
auto-fill: Creates Empty Tracks
Definition
auto-fill: Fills the grid with as many columns/rows as will fit, even if some remain empty. Empty tracks still take up space but have no content.
How It Works
  1. Browser calculates how many columns of minmax(200px, 1fr) fit in the container
  2. Creates that many columns, even if items don't fill them all
  3. Empty columns are visible and take up space
  4. Items DON'T stretch beyond their max value (1fr means they can grow but stop at 1fr each)
Syntax
.grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)); } /* Creates as many 200px-1fr columns as fit Empty columns still appear in the grid */
When to Use auto-fill
  • You want consistent, predictable column widths
  • Items should maintain their max size (1fr)
  • You're okay with empty space in the last row
  • Creating galleries or product grids where items don't stretch to fill
  • Using gap that you want to maintain (gap doesn't apply to empty tracks in auto-fit)
Visual Example: auto-fill with 4 Items
Container: 700px wide Using: repeat(auto-fill, minmax(150px, 1fr)) ┌────────────────────────────────────────────────┐ │ 150px 150px 150px 150px (150px empty)│ │ ┌─────────────────────────────────────────────┤ │ │ Item 1 │ Item 2 │ Item 3 │ Item 4 │ │ │ └─────────────────────────────────────────────┤ │ (5 columns created, last one empty) │ └────────────────────────────────────────────────┘ Result: Items DON'T stretch to fill the gap Empty column 5 still exists
auto-fit: Collapses Empty Tracks
Definition
auto-fit: Creates as many columns/rows as will fit, but collapses empty ones to zero width/height. Remaining items stretch to fill available space.
How It Works
  1. Browser calculates how many columns fit (same as auto-fill)
  2. Creates that many columns initially
  3. Empty columns collapse to 0 width (they disappear)
  4. Remaining items grow to fill the space (1fr stretches)
Syntax
.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); } /* Creates as many 200px-1fr columns as fit Empty columns collapse to 0 width Remaining items stretch to fill space */
When to Use auto-fit
  • You want items to stretch and fill available space
  • Empty space in last row should be filled by items growing
  • Creating responsive grids that adapt to content amount
  • You want the most responsive, flexible behavior
  • Making product grids or card layouts that scale
Visual Example: auto-fit with 4 Items
Container: 700px wide Using: repeat(auto-fit, minmax(150px, 1fr)) ┌────────────────────────────────────────────────┐ │ ~175px ~175px ~175px ~175px │ │ ┌─────────────────────────────────────────────┤ │ │ Item 1 │ Item 2 │ Item 3 │ Item 4 │ │ │ └─────────────────────────────────────────────┤ │ (5 columns created, empty one collapses) │ │ (4 items stretch to fill width equally) │ └────────────────────────────────────────────────┘ Result: Items STRETCH to fill the gap No empty column visible Each item grows from 150px to ~175px
How gap Behaves Differently
The Gap Principle
auto-fill: Gap is applied between all columns, including empty ones. This affects total space calculation.
auto-fit: Gap is only applied between non-empty columns. Collapsed columns don't get gap, so items grow more.
Visual Comparison with gap: 15px
With 4 items and gap: 15px auto-fill (gap applied to empty column too): Item1(150) + gap(15) + Item2(150) + gap(15) + Item3(150) + gap(15) + Item4(150) + gap(15) + Empty(150) = 840px needed (May not fit 5 in 700px container!) auto-fit (gap NOT applied to collapsed empty): Item1(~165) + gap(15) + Item2(~165) + gap(15) + Item3(~165) + gap(15) + Item4(~165) = 700px (Fits perfectly, items grew beyond 150px)
auto-fill vs auto-fit Comparison
Aspect auto-fill auto-fit
Empty Tracks Creates them (visible, take space) Collapses them (0 width/height)
Item Stretching Items stay within max value Items grow to fill collapsed space
Gap on Empty Gap applied to empty columns Gap NOT applied to empty columns
Last Row Appearance May look sparse with gaps Items expand to fill evenly
Consistent Column Width Yes, stays at max value No, grows beyond max value
Responsive Feel Less stretchy, more structured More fluid, adaptive layout
Best For Product grids, galleries, consistent sizing Responsive grids, adaptive layouts
Real-World Scenarios & Decision Tree
Scenario 1: E-Commerce Product Grid
Use auto-fill: Each product card should be a consistent 250px. If there are 4 items in the last row, let them stay 250px with space on the right.
.product-grid { grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); gap: 20px; }
Scenario 2: Blog Post Cards
Use auto-fit: If there are only 2-3 blog posts, they should stretch to fill the width instead of staying narrow on the left.
.blog-grid { grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 30px; }
Scenario 3: Gallery with Fixed Size
Use auto-fill: Photos should be consistent square sizes. Gaps between photos matter.
.gallery { grid-template-columns: repeat(auto-fill, minmax(200px, 200px)); /* Fixed size, not 1fr */ gap: 10px; }
Scenario 4: Responsive Dashboard
Use auto-fit: Dashboard cards should be responsive and expand when fewer fit in a row.
.dashboard { grid-template-columns: repeat(auto-fit, minmax(300px, 1fr)); gap: 20px; }
Decision Guide: auto-fill or auto-fit?
Ask Yourself These Questions
  1. Should items maintain a consistent size?
    • YES → Use auto-fill with fixed minmax (e.g., minmax(250px, 250px))
    • NO → Use auto-fit with flexible max (e.g., minmax(250px, 1fr))
  2. Is the number of items dynamic/variable?
    • YES (2-20 items) → Use auto-fit for adaptive stretching
    • NO (always lots) → Use auto-fill for predictable sizing
  3. Should the last row fill completely?
    • YES → Use auto-fit to stretch remaining items
    • NO → Use auto-fill to keep consistent sizing
  4. Are gaps/spacing important to maintain?
    • YES → Use auto-fill (gap is consistent everywhere)
    • NO → Use auto-fit (gap only between items)
Best Practices & Tips
✓ Do's
  • Use 1fr for flexible maximum: minmax(200px, 1fr) allows growth
  • Choose based on behavior you want: Empty space → auto-fill; Fill space → auto-fit
  • Test with 1-2 items: See how auto-fit/auto-fill behaves at edge cases
  • Combine with gap: Both work great with gap for spacing
  • Use meaningful minmax values: Minimum should be your minimum readable size
  • Consider gap when deciding: Gap affects how many fit in a row
✗ Don'ts
  • Don't use both at once: Choose one or the other, not repeat(auto-fill) AND repeat(auto-fit)
  • Don't set fixed max with auto-fit: minmax(250px, 250px) with auto-fit defeats the purpose
  • Don't forget gap in calculations: Gap takes up space and affects column count
  • Don't use with explicit column count: If you know the exact columns, use repeat(3, 1fr) instead
  • Don't assume they're interchangeable: They behave very differently with empty tracks
Pro Tips
💡 Tip 1: Most modern responsive grids use auto-fit with minmax(). It's the most flexible for varying item counts.
💡 Tip 2: Combine with justify-items and align-items for precise control over item positioning within cells.
💡 Tip 3: Use browser DevTools to inspect: DevTools → Inspect Grid → See columns (auto-fill creates extras, auto-fit collapses them).
💡 Tip 4: For maximum flexibility, use: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))
💡 Tip 5: auto-fit + gap creates most responsive behavior. Empty columns don't waste space.
Quick Reference

auto-fill: Keep items consistent size, accept empty space

  • Empty columns created and displayed
  • Items don't stretch beyond max value
  • Gap applied to all columns (including empty)
  • Best for: Product grids, galleries with fixed sizing

auto-fit: Make items stretch to fill space

  • Empty columns collapse to 0 width
  • Items stretch/grow to fill space
  • Gap not applied to collapsed columns
  • Best for: Responsive grids, adaptive layouts

When They're the Same:

  • When all columns are filled (no empty columns)
  • When using fixed maximum width (not 1fr)
  • When you only have exactly the right number of items
