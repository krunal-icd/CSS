🔗 CSS Break Properties

Master break-before, break-after, break-inside

Control content breaks in columns, pages, and regions

📋 What Are Break Properties?

CSS break properties control where content breaks across multiple containers: columns, pages (print), regions, and pagination. They ensure optimal layout without awkward breaks.

Three Properties

  • break-before: Force break before element
  • break-after: Force break after element
  • break-inside: Prevent breaks inside element

Common Use Cases

  • Multi-column layouts (magazine style)
  • Print documents (page breaks)
  • Preventing heading separation from content
  • Keeping cards/boxes whole
  • Pagination control
ℹ️ Overview: Break properties work with columns (column-count), pages (print), and regions. They're similar to page-break properties but more modern.

BEFORE break-before

Forces a break before an element. Starts the element on a new page, column, or region.

Syntax

h2 {
  break-before: always;
}

Common Values

  • auto: Default, natural breaks (default)
  • always: Force break before element
  • avoid: Avoid break if possible
  • left: Break to odd page (print)
  • right: Break to even page (print)
  • page: Break between pages
  • column: Break between columns

Practical Example

/* New page for each chapter */
h1 {
  break-before: always;
}

/* Avoid break before paragraphs */
p {
  break-before: avoid;
}
✨ Use When: You want to force a new page or column before an element, like starting a new chapter or section.

AFTER break-after

Forces a break after an element. Creates space after the element, starting new content on a new page or column.

Syntax

section {
  break-after: always;
}

Common Values

  • auto: Natural breaks (default)
  • always: Force break after element
  • avoid: Avoid breaking after
  • left: Break to odd page
  • right: Break to even page
  • page: Break between pages
  • column: Break between columns

Practical Example

/* Full page for introductions */
.introduction {
  break-after: always;
}

/* New column after image galleries */
.gallery {
  break-after: column;
}
✨ Use When: You want content after this element to start fresh on a new page or column, like after a title block or section ending.

INSIDE break-inside

Prevents breaks inside an element. Keeps the element whole, not split across pages or columns.

Syntax

.card {
  break-inside: avoid;
}

Common Values

  • auto: Allow natural breaks inside (default)
  • avoid: Prevent breaks inside element
  • avoid-page: Prevent page breaks only
  • avoid-column: Prevent column breaks only

Practical Example

/* Keep cards whole */
.card {
  break-inside: avoid;
}

/* Keep tables on same page */
table {
  break-inside: avoid;
}

/* Allow breaks inside quotes */
blockquote {
  break-inside: auto;
}
✨ Use When: You want to keep elements together, like keeping a card from being split across columns or a heading from being separated from its content.

🔍 Quick Comparison

break-before
  • Forces break BEFORE
  • Starts element fresh
  • New page/column
  • Used for: Headings, sections
break-after
  • Forces break AFTER
  • Ends element section
  • Next content fresh
  • Used for: Blocks, sections
break-inside
  • PREVENTS breaks
  • Keeps element whole
  • No splitting
  • Used for: Cards, tables

📰 Multi-Column Layout Example

Break properties work great with CSS multi-column layouts. Keep cards whole across columns.

CSS Implementation

/* Magazine-style layout */
.magazine {
  column-count: 3;
  column-gap: 20px;
  column-rule: 1px solid #ddd;
}

/* Keep article headers at top of column */
h2 {
  break-after: avoid;
}

/* Keep article boxes whole */
.article {
  break-inside: avoid;
  background: white;
  padding: 15px;
  margin: 10px 0;
  border: 1px solid #e0e0e0;
}

🖨️ Print Document Example

Break properties are essential for print-friendly documents. Control where pages break.

Print CSS Implementation

@media print {
  /* Chapter on new page */
  h1 {
    break-before: always;
    break-after: avoid;
  }
  
  /* Section on new page */
  h2 {
    break-before: avoid;
    break-after: avoid;
  }
  
  /* Keep tables whole */
  table {
    break-inside: avoid;
  }
  
  /* Keep card content together */
  .info-box {
    break-inside: avoid;
  }
  
  /* Paragraph orphans/widows */
  p {
    break-inside: avoid;
    orphans: 2;
    widows: 2;
  }
}
ℹ️ Tip: Combine break properties with orphans/widows for professional multi-page documents. Always test in print preview!

🏆 Best Practices & Tips

✅ Do:

  • Use break-inside: avoid for cards: Keep design elements whole
  • Use break-after: avoid for headers: Keep heading with content
  • Test with column-count: Preview multi-column layouts
  • Combine with print media: Optimize document breaks
  • Test in print preview: Verify page breaks look good
  • Use avoid sparingly: Too many can force awkward gaps
  • Consider readability: Breaks should improve layout flow

❌ Don't:

  • Force breaks everywhere: Can create excessive gaps
  • Ignore column layout: Test both print and columns
  • Use always on everything: Causes poor pagination
  • Forget fallbacks: Not all browsers support all values
  • Assume it works: Test on real printers/displays
  • Combine conflicting breaks: Contradictory rules are ignored
  • Overlook performance: Many breaks can affect rendering
⚠️ Important: Always test break properties in both screen and print contexts. Different browsers handle breaks differently, especially with complex layouts.

⚡ Advanced Patterns

Pattern 1: Prevent Orphaned Headings

/* Keep heading with at least some content */
h2, h3 {
  break-after: avoid; /* Don't separate from content */
  page-break-after: avoid; /* Legacy support */
}

Pattern 2: Magazine Grid Layout

.article-grid {
  column-count: 3;
  column-gap: 20px;
}

.article-grid article {
  break-inside: avoid;
  margin-bottom: 20px;
}

Pattern 3: Multi-Page Document

@media print {
  h1 {
    break-before: always; /* Chapter on new page */
    break-after: avoid; /* Stay with content */
  }
  
  table, figure {
    break-inside: avoid; /* Keep intact */
  }
}

Pattern 4: Responsive Breaks

/* Column breaks on large screens */
@media (min-width: 1200px) {
  .card-grid {
    column-count: 3;
  }
  .card {
    break-inside: avoid;
  }
}

⚠️ Common Pitfalls & Solutions

Pitfall 1: Excessive Gaps from Too Many Breaks

Problem: Using break-before/after: always on many elements creates too much empty space.

Solution: Use avoid and let natural breaks happen

/* ❌ Creates excessive gaps */
p { break-before: always; }

/* ✅ Better: natural breaks */
p { break-inside: avoid; }

Pitfall 2: Not Testing Column Layout

Problem: Breaks work differently in columns vs pages.

Solution: Test with column-count and column-gap properties

Pitfall 3: Browser Inconsistency

Problem: Different browsers handle breaks differently, especially with complex layouts.

Solution: Include legacy page-break properties for compatibility

.element {
  break-inside: avoid;
  page-break-inside: avoid; /* Legacy fallback */
}

Pitfall 4: Conflicting Break Rules

Problem: Setting break-before: always and break-inside: avoid on same element.

Solution: Apply breaks to different elements

/* ❌ Conflicting */
section {
  break-before: always;
  break-inside: avoid;
}

/* ✅ Better: clear roles */
h2 { break-before: always; }
.card { break-inside: avoid; }
