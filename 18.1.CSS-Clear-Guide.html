CSS Clear Property

Master the art of controlling floated elements

1. Introduction to the Clear Property

The clear property specifies on which sides of an element floating elements are not allowed to float. It's used to prevent content from wrapping around floated elements.

Syntax

clear: left | right | both | none | inherit;

Values

  • left - No floating elements allowed on the left side
  • right - No floating elements allowed on the right side
  • both - No floating elements allowed on either side
  • none - Default; floating elements allowed on both sides
  • inherit - Inherits the clear value from its parent

2. Practical Examples

Example 1: No Clear (Problem)

Without using clear, text wraps around floated elements, which might not be desired.
<div style="float: left; width: 200px; height: 150px; background: #667eea;"> Floated Box </div> <p>This text wraps around the floated element...</p>
Floated Box

This text wraps around the floated element. Without the clear property, content continues to flow alongside the float. This can create interesting layouts, but sometimes you want to force content below the float instead of beside it.

Example 2: Using clear: left

The clear: left moves content below any left-floated elements.
<div style="float: left; width: 200px; height: 150px; background: #667eea;"> Left Float </div> <p style="clear: left;">This paragraph is cleared...</p>
Left Float

This paragraph uses clear: left so it starts below the floated element on the left.

Example 3: Using clear: right

The clear: right moves content below any right-floated elements.
<div style="float: right; width: 200px; height: 120px; background: #f5576c;"> Right Float </div> <p style="clear: right;">This paragraph is cleared...</p>
Right Float

This paragraph uses clear: right so it starts below the floated element on the right.

Example 4: Using clear: both

The clear: both is the most common usage - it clears both left and right floats.
<div style="float: left; width: 150px;">Left</div> <div style="float: right; width: 150px;">Right</div> <p style="clear: both;">This paragraph is below both floats...</p>
Left Float
Right Float

This paragraph uses clear: both and sits below both floated elements.

3. Common Use Cases

Use Case 1: Two-Column Layout with Footer

<div style="float: left; width: 60%;"> Main Content </div> <div style="float: right; width: 40%;"> Sidebar </div> <footer style="clear: both;"> Footer always below both columns </footer>

Use Case 2: Image with Text Separation

<img src="image.jpg" style="float: left;" /> <p>Text wraps around image...</p> <h2 style="clear: left;">Next Section</h2> <p>This section starts cleanly below the image</p>

Use Case 3: Gallery Layout

<div style="float: left; width: 33.33%;">Image 1</div> <div style="float: left; width: 33.33%;">Image 2</div> <div style="float: left; width: 33.33%;">Image 3</div> <div style="clear: both;"></div> <!-- Clear for next row -->

4. The Clearfix Technique

A parent container with only floated children can collapse. The clearfix technique solves this using a pseudo-element.

HTML

<div class="clearfix"> <div style="float: left;">Box 1</div> <div style="float: left;">Box 2</div> </div>

CSS (Clearfix Method)

.clearfix::after { content: ""; display: table; clear: both; }
Why this works: The ::after pseudo-element creates an invisible element at the end of the container with clear: both, which forces the parent to expand to contain all floated children.

5. Clear Property Values Comparison

Value Description Use Case
none Default. Element can float to the left and right of floated elements. Allowing text wrapping around floats
left Element must be placed below any floated element on the left. Clearing only left-floated elements
right Element must be placed below any floated element on the right. Clearing only right-floated elements
both Element must be placed below all floated elements on both sides. Most common - layout control
inherit Inherits the clear value from its parent element. Maintaining consistent clearing behavior

6. Modern Alternatives

Note: While the clear property still works, modern CSS layouts prefer Flexbox and CSS Grid for most layout tasks.

Flexbox Alternative

.container { display: flex; flex-wrap: wrap; } .sidebar { flex: 0 0 30%; } .main { flex: 0 0 70%; }

CSS Grid Alternative

.container { display: grid; grid-template-columns: 1fr 3fr; gap: 20px; } .sidebar { grid-column: 1; } .main { grid-column: 2; }
Best Practice: Use Flexbox or Grid for new projects. Use clear only for maintaining legacy code or simple text-wrapping scenarios.

7. Browser Support & Tips

  • ✅ Supported in all modern browsers (Chrome, Firefox, Safari, Edge)
  • ✅ IE 6+
  • ✅ Mobile browsers

Best Practices

  • Always use clear: both unless you have a specific reason to use left or right
  • Consider using Flexbox or Grid for new layouts instead of floats
  • Use the clearfix technique to prevent container collapse
  • Test your layout across different browsers and screen sizes
  • Use clear selectively; excessive clearing can lead to unwanted spacing

8. Complete Example: Multi-Column Layout

<!-- HTML --> <div class="layout"> <aside style="float: left; width: 25%;"> <h3>Sidebar</h3> <p>Left column content...</p> </aside> <main style="float: right; width: 75%;"> <h3>Main Content</h3> <p>Main column content...</p> </main> <footer style="clear: both;"> <p>Footer appears below all floats</p> </footer> </div>
/* CSS */ .layout { width: 100%; } .layout aside { background: #667eea; color: white; padding: 20px; margin-right: 20px; } .layout main { background: #f5f5f5; padding: 20px; } .layout footer { background: #333; color: white; padding: 20px; text-align: center; }
