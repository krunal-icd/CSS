Simple List Numbering

counter-reset

Basic numbered list without default browser numbering.

  • First item in the list
  • Second item here
  • Third item example
  • Fourth item shown
.demo-area {
  counter-reset: item;
}

li {
  counter-increment: item;
}

li::before {
  content: counter(item) ". ";
}
Use Case: Custom list numbering without HTML list-style.

Key Takeaways

  • counter-reset: Initialize counters on parent elements (body, section, div).
  • counter-increment: Apply to elements you want to count (li, h2, .item).
  • counter(): Display single counter value with optional style.
  • counters(): Display nested counter hierarchy with separator (1.1.1).
  • Styles available: decimal, roman (upper/lower), alpha (upper/lower), leading-zero.
  • Reset for nesting: Each level needs its own counter-reset for proper hierarchy.
  • No JavaScript needed: Pure CSS auto-numbering without any dependencies.
  • Perfect for: Outlines, table of contents, equations, steps, and hierarchical documents.
  • Browser support: Excellent support from IE 8+ to all modern browsers.
  • Combine with ::before/::after: Use pseudo-elements to display counter values.
