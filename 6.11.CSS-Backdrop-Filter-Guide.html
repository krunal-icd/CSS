Combined Filters

Multiple filters applied together for a custom effect

Hover Effect

Hover over the image to see animated filter transition

Code Examples

Single Filter:

.blur-image { filter: blur(5px); }

Multiple Filters:

.combined-filter { filter: brightness(1.1) contrast(1.2) saturate(1.5) sepia(20%); }

Hover Animation:

.image { transition: filter 0.4s ease; } .image:hover { filter: blur(3px) brightness(0.8); }

Background Image with Filter:

.hero { background-image: url('image.jpg'); filter: grayscale(50%) brightness(0.9); }
